# S2522–S2534：保留原生推理的射门学习入口

2026-09-16，SIM_ONLY。未完成高角精准射门、干净纯足部射门或连续比赛宣传片。

## 改变学习位置，而不是继续微调接球

S2514 说明很小的接球策略变化也可能破坏后续射门。历史 S2148–S2166 虽已将完整可训练踢球网络用于八人世界，但该网络使用不同于原 ONNX 的累加精度，初始模型不等于当前原生基线。

本轮保留实际 ONNX 推理，在其**同一球员、同一时刻的原始动作输出**上增加初始为零的神经网络反馈。接球专家组合、其他球员、行走底座、原生动作映射及物理保护冻结。没有扩大碰撞体、改变球或根部状态，也没有用后处理动画制造连续性。

新增数值模块 `training/native_anchored_kick_learning.py`：

- 观察布局为原踢球 547 维、目标 3 维、根速度 3 维、当前原生动作 29 维、训练活动位 1 维，共 583 维。
- 此布局不是历史 autoregressive583：最后 29 个动作特征来自当前原生推理，不是上一帧动作。使用独立 schema，不能只凭维数互换。
- actor 为 `582 → 128 → 29`，输出均值为 `native + 0.1*tanh(feedback)`；critic 为 `582 → 128 → 1`。
- 0.1 是原始策略动作空间中的**均值残差上限**，不是弧度或力矩上限，也不限制 Gaussian 探索样本。原生动作裁剪及世界关节/力矩保护仍执行。
- 模块不加载原生 ONNX、不步进物理、不拥有控制权，不创建运行时、租约或硬件执行。调用者必须证明本人的同帧原生输出来源。
- 学习位不改变均值或 critic，是训练元数据，不是运动许可。模型没有隐藏时序状态。

因此这是可学习射门反馈模块，不是重新训练整个行走/射门底座，也不是直接输出关节力矩的端到端小脑。

## 初始物理等价性

S2522 使用零反馈运行完整 25 s 已知进球课程，各执行两次。所有球、机器人、关节、力矩及控制轨迹数组与 S2520 完全一致；105 个射门推理帧的输出与原 ONNX 精确一致。不是仅比较网络权重或离线单点输出。

该课程只有一个已知初始情境，仍有小腿触球和约 1.063 m 高角误差；零层保留它不代表基线达到目标。

## S2524：真正进入原生射门的探索

固定零反馈均值，logstd = −6，四个动作随机种子，各执行完整 25 s 并独立重放，共 8 次物理执行。每条均有 105 帧实际原生学习样本，共 **420 个训练样本**；重复物理不算新样本。

四条轨迹全部保持进球及全队安全，进入原生射门前的轨迹与基线精确一致。中心平面到目标点误差分别约为 **1.109、1.046、1.029、1.160 m**。四条仍有自身小腿接触，没有纯足部高角成功。四个随机动作种子不是四个独立初始球位。

## S2526 拒绝与 S2527 实际 PPO

S2526 的 logstd 仍可训练却没有归属优化器，公共更新器在任何更新前拒绝。原始 batch、初始 optimizer/RNG 和拒绝说明保留，没有伪造候选。S2527 用独立目录和脚本显式冻结 logstd 后重新开始。

S2527 使用同一四条 on-policy 轨迹，训练 actor 学习率 1e−6、critic 1e−4，4 epochs / minibatch 128，实际 **16 次优化器更新**。采用回合均衡和组相对 outcome 信用，目标 KL 0.005，更新后同方差 Gaussian 平均解析 KL 为 **0.00108668**。

终局信用区分全队安全、是否实际脚触球、自身非脚接触、进球和目标误差。未观测交点的代价不冒充实测误差；接触法向力之和只是控制帧统计，不是接触冲量。折扣、GAE、组内归一化不构成约束 RL，独立物理门仍然必要。

实际改变 78,359 个 actor 参数及 critic 参数；原生网络、接球器和 logstd 不变。核心可塑性证明绑定当前适配器及声明的冻结资产，不能据此声称全队所有角色都在学习。

S2530 独立重新执行 420 次原 ONNX 推理，逐帧重构随机动作、log probability 和 value；再恢复初始 optimizer/RNG 重做 PPO。权重、优化器状态、RNG 和统计均精确一致，8 个原始物理文件逐一校验。审计不新增物理样本。

## S2528：关闭探索后并未实现精度突破

两次完整 25 s 考试保持接球、进球和全队安全，仍有两帧自身非脚接触。中心平面误差为 **1.063894 m**，原基线约 **1.063390 m**：精度略差，不是提升。自身非脚接触力统计变化很小，不足以宣称身体动作更自然。

本轮获得的是“更新射门反馈后仍保持这条完整成功链路”的工程证据，不是学会高角射门、扩大初态覆盖或晋升比赛策略。候选没有替换默认模型。
