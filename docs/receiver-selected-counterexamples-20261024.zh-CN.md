# 两条接球上游截获反例的因果复跑

接球平面的确定性12场对照中，两个模型的名义案例功能接球从否变是，
但到点误差和速度未改变；另两个初态没有联合成功。因此不宣布路线成立。

进一步只检验已完整采样并独立复跑过的state26 TRAIN第6、24条：原来球速度
2.364、2.425m/s，误差0.565、0.515m；两条均有干净足部触球、健康身体、
100步恢复和B功能接球，但B在目标上游接触导致球路窗口结束。横向和高度
合成误差较小只是选择反例的依据，不是原考试通过，也不证明反事实必成功。

复用原始两条事实轨迹及其独立native/RNG证明，不再执行事实组。新实验仅
两条种子×两次重复=4个新世界，另4个独立手动时钟复跑。A保持同一个实际
generation2权重与原私有随机种子，在自己的实时观测上重新推理和采样；
不播放事实组动作或隐藏状态。B只改为anchor-plane-v2，其余NN、PD、球体、
碰撞、300步期限、100步恢复、0.1m/3m/s和真实功能接球门槛均不变。

该组合使用独立诊断类型 `receiver-role-stochastic-diagnostic-native-v3`。
它不是原pure-v2学习数据，PPO损失合同明确拒绝；不能把B几何teacher的改变
说成A或B通过强化学习成长。收集器/复跑器要求显式诊断开关及完整随机恢复，
不能静默与其它teacher叠加。

成功最多证明这两条消耗过的同一初态反例可以被角色协作改变；失败则保留
原始数据并限制该假设。无论结果如何都不自动晋升、不作Fresh或球队宣传成绩。
如机制成立，应再声明新课程、训练角色策略、检查保持与隔离Fresh，而不是
扩大选例宣传。原全恢复PPO续训链独立进行，不为这个实验改权重或目标。
