# S127：实测来球驱动的运行时射门路由

## 结论

S127 将 S126 的赛前静态分类器改造成了真正读取仿真中本体与足球状态的运行时路由，
并打通“历史轨迹转换 → 成功/失败联合训练 → 运行时授权 → 漏球恢复 → 新鲜封存考试”。
安全与可复现性取得了实质进展，但新鲜 v3 仍为 `0/6` 完整链，因此候选被严格拒绝，
不得制作晋升宣传视频。

相对 S126 新鲜 v2 的候选安全 `4/6`，S127 v3 达到 `6/6` 安全；冻结父策略在同一 v3
只有 `3/6` 安全。未知域不再空挥至倒地，而是在稳定来球观测后立即撤销射门并平滑
交回站立恢复。与此同时，二选一的 `advance=0/12` 没能在连续变化的触球几何上泛化，
证明下一阶段必须学习三维接触口袋和任务空间肌肉反馈，而不能只增加相位扫描次数。

## 架构变化

### 1. 两个因果时钟

射门准备桥仍在前序传球动作达到固定提交点时启动，以保留冻结全身动作的支撑转换和
策略历史；但任何相位加速和 S96 接触力矩都不再提前决定。路由必须等到连续 5 个控制帧
检测到真实来球，才读取：

- 球在射手本体坐标系中的 `x/y`；
- 球的实测 `vx/vy`；
- 到接触口袋的 ETA；
- 骨盆横向位置；
- 29 关节速度 RMS。

这 7 维观测在运行时和训练轨迹中使用同一个构造函数，避免离线/在线特征漂移。

### 2. 权限随路由结果流动

`G1RuntimeCausalStrikeRouter` 只返回经过物理验证的离散接触模式。接受时，控制器只获得
有界的到达相位修正、脚踝 yaw/pitch 和 S96 肌肉记忆窗口；拒绝时：

- 到达相位修正归零；
- S96 力矩窗口不激活；
- 射门状态立刻转为 `ABORTED`；
- 通过 12 帧平滑切换到站立/恢复策略。

此外，即使已接受来球，如果运动相位到 275 仍没有实测脚球接触，也会触发第二个漏球
deadline，避免继续空挥。

### 3. Stability–Plasticity

新 actor 仍使用失败感知最近验证模式，而不是对稀疏碰撞数据做危险连续插值：

- stability：超出支持域或离同动作失败记忆更近就拒绝；
- plasticity：完整保留每条成功和失败的 MuJoCo 轨迹；
- actor 为 JSON/NumPy，内容哈希绑定，不允许热更新；
- 永久 `SIM_ONLY`，不具备 ROS、DDS、硬件或自我批准权限。

## 为什么仍然失败

S127 已经在正确时刻看到了来球，但动作空间只有“最多提前 0 或 12 帧”。v3 轨迹显示：

- 成功历史通常在球的射手局部 x 约 `1.02–1.21 m` 时接触；
- v3.00 和 v3.05 在约 `0.75–0.78 m` 才接触，已经太晚；
- v3.01 的 x 约 `1.13 m`，但横向接触位置约 `0.33 m`，形成明显擦边；
- 多个实际接触发生在运动相位 247，而 S96 力矩峰固定在 256，晚约 0.18 秒。

所以决定“提前多少”还不够。系统还必须共同控制身体预站位、脚的三维接触点和肌肉
脉冲时刻，并且要让前序传球质量进入联合训练。

## 封存后的开发诊断

这些实验只用于生成 S128 假设，不属于 S127 晋升证据：

- 将 S96 峰值从 256 移到 248，可把一个早接触场景从约 4.92 提升到 5.71 m/s；
- 只增大关节残差会改变碰撞拓扑，速度反而降至约 2.75 m/s；
- 有界脚部拦截反射可达到 6.3–7.0 m/s，但仍从错误横向一侧偏出；
- 把射手接触口袋沿 x 前置 0.12 m 后出现真实门将扑救，但速度仅 5.01 m/s；
- 在该正确口袋上叠加受限前向脚速教师后，达到 7.262 m/s、真实扑救、全链安全通过，
  射手最低骨盆约 0.658 m。

最后一项证明“预站位 + 三轴脚速反馈 + 原肌肉记忆”方向可行，但教师是数据生成器，
不能直接晋升为产品 actor。

## S128 固定方向

1. 将赛前已知传球计划用于低权限接球预站位 actor，而非直接改写运行中 qpos；
2. 扩展接触动作到 `stance/contact pocket + torque timing + 3D foot velocity`；
3. 用前向/横向/垂直任务空间教师采集成功与失败探针，并蒸馏成三轴 Jacobian 解码 actor；
4. 运行时继续由 S127 的实测来球路由负责授权，未知域保持提前撤销；
5. 新 actor 必须在完全新鲜留出达到至少 `4/6` 完整链、`6/6` 安全、`6/6` 精确重放，
   且同时包含真实进球与门将扑救，才可录制阶段视频。
