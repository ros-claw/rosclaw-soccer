# 神经参考结束后的身体反馈断档：诊断与局部物理结果

这是 SIM_ONLY 的控制生命周期诊断，不是完整球队验收，也不是新增了一个
端到端神经小脑或完成在线强化学习。

## 发现了什么

R6 连续考试曾出现“第二脚分数增加，第三脚身体更差”。逐段复查发现，第二
脚神经参考结束时，16 个条件的身体水平/垂直合速度仅约 0.004–0.024 m/s，
直立量约 0.999–1.000。可是原研究采集器随后还执行 60 个控制周期（1.2 秒）
的固定目标保持。此时关节 PD 仍在闭环，但身体层不再更新关节目标。

例如条件 0 的身体速度从约 0.005 m/s 增至 0.375 m/s，局部俯仰角速度升至
约 0.644 rad/s，随后发生身体失败。条件 15 也有相似退化。

所以不能把这些后续失败全部归咎于踢球神经网络，更不能默认“继续加大 RL
训练量就会修好”。这里存在一个需要单独解决的技能结束/待机/下一技能衔接
问题。此前原始考试、失败收据、分数和固定尾段仍保留，不回写成成功。

## 排除了哪些方案

1. 新版触球网络在后半段平滑切到旧版网络：三个预声明时机全部没有改善。
2. 执行完固定尾段、身体已经明显失稳后才增加主动反馈：三个 CEM 搜索种子都没有
   找到能持续 2 秒的恢复。不能将这一局部搜索失败称为物理上绝对不可达。

## 新实验做了什么

只在条件 0、15 的诊断试验中，第一脚完整复现旧轨迹；第二脚全部神经控制
和原生物理前缀逐数组匹配旧证据。在参考结束的实际身体状态上，进入一个
独立声明的主动恢复阶段，不执行原来的固定目标尾段。

新阶段用当前姿态、角速度、局部线速度和高度偏差作为反馈，以 CEM 优化
9×4 个有界增益。输出作用于具名的双腿、腰部和肩部关节目标，偏移限幅
0.2 rad，单周期变化限幅 0.02 rad。PD、力矩上限、重力和物理身体不变。
不改根姿态/速度，不施加额外身体力，不填充运动参考。

这还是一个物理优化得到的反馈教师，不是 Adam 训练出的单网络。后续可用
实际状态/动作数据训练恢复模型，但需要重新做单模型闭环考试，不能只看
拟合误差。

零增益的新阶段逐数组复现原来的 60 周期尾段，随后在第 72、76 周期身体
失败；这提供了同状态、同模型、同物理的零干预对照。

## 已验证的结果及边界

三个预声明 CEM 搜索种子均找到了同一组增益同时支持两个条件的方案：

- 两个条件均持续执行 100 个恢复周期（2 秒），通过终态速度/角速度/直立
  检查。
- 实际返回球、重力落地并保持完整身体状态后，均继续完成第三脚，身体未
  失败。每个选中方案都从世界起点独立执行两次并匹配完整轨迹。
- 三组均通过独立原语审计、CEM 提案/选择重算及第三脚网络推理复算。
- 每组审计覆盖 198 个恢复段；复用已审计的父代前缀，不重复宣称新的独立
  场景；另执行并计数 930 次第三脚网络推理。

这只有两个不同的诊断条件，不是六个独立条件，也不是完整 16 条件的通过。
恢复后有一次第三脚成功，不等于长期稳态或连续比赛能力。

## 下一步为什么值得投入，什么结果会推翻它

先冻结这组反馈，扩展到完整 TRAIN/DEV 条件并做连续技能回归，不能按球位
选择最优增益或丢掉失败。再将可用的实际反馈数据形成数据驱动的恢复模型，
单独核验模型误差有没有改变物理结果。

如果扩展后出现大量身体退化、衔接失败或神经模型拟合后失稳，就不能把这组
增益直接接入球队。需要补足身体状态覆盖和恢复动作权限，而不是无限追加
同类种子。

真正的运行时方向是：技能结束后保持身体层闭环，转入已验证的恢复/站立或
移动技能，而不是长期保持最后一个关节目标。这不意味着真实机器人可以
自动启用未经验证的平衡策略；真实执行权限和安全边界完全不变。

## 2026-10-22 完整条件集给出的反例

冻结第 0 个搜索种子的一组参数，在完整 TRAIN16 和 DEV16 上比较零增益与
反馈增益，两边均使用同样的 R2/R6 踢球网络，每个条件完整重复两次。两组
考试及独立原语/新第三脚网络审计均完成。

| 新协议的指标 | TRAIN 零增益 → 反馈 | DEV 零增益 → 反馈 |
| --- | --- | --- |
| 恢复阶段身体未失败 | 4/16 → 6/16 | 7/16 → 2/16 |
| 恢复终态稳定检查 | 2/16 → 3/16 | 2/16 → 0/16 |
| 完成第三脚且身体未失败 | 2/16 → 4/16 | 4/16 → 0/16 |
| 第三脚球路质量 | 1/16 → 3/16 | 2/16 → 0/16 |

这否定了将双场景参数直接当作通用平衡控制器的方案。不能因为原来的两个
案例成功，就把整套球队切换到它。表中是新的 100 周期恢复协议，不是原先
固定尾段考试的直接改分。

DEV 还保留了两个发生于接管前的失败：条件 7 在第二脚早期身体失败，条件
10 在第一脚后的落球等待阶段身体失败；没有丢弃它们，也没有补齐未发生的
轨迹。它们提示身体层闭环应覆盖整个技能生命周期，而不是只在第二脚之后
启用一次恢复。

下一步优先检验已有运动神经网络的独立“闭环站立”技能。该网络本来就读取
关节姿态、速度、重力方向和上一动作，能够补足 8 维根部反馈缺少的身体
构型信息。新的站立技能必须有独立任务、控制边界和收据，不得通过填充原
运动参考或延长旧考试来制造成功。若复用模型也不成立，再以实际失败状态
建立完整本体观测和姿态条件化的恢复学习课程。
