## 不靠再次提醒接续

已经声明三组“原生执行 → 独立手动时钟重放”阶段，随后接整批只读比较。
比较器要求三组全部关闭，不允许只选择表现最好的种子。
父子代必须相同初态字节、课程、私有 A 电机噪声、固定 A θ12 和
冻结的 B 下层零修正模型。每个控制周期真实执行五次网络调用，
包含完整 100 控制周期神经恢复，不用动作播放代替推理。

整批比较输出每个指标逐例的新增成功和丢失成功：
功能接球、健康且合法的受控接球、原 0.1m/3m/s 精准接球、身体健康、
A 足触合法、完整恢复及 B 非法接触。精度改善不能掩盖旧接球或安全损失。
`strict_clean_foot_capture_regraded=false` 是不重评标志，不是原精准任务结果；
比较器从实际误差、速度和受控接球重构原组合结果。

每种子 6 个课程索引各重复两次，属于三个物理初态，不能写成
12 个独立环境。三种子也不是新场景泛化。即使全部局部改善，
下一步仍须扩展独立课程及任务方向，不能直接晋升球队策略。

## Agent loop 的边界

宿主的 active Goal 负责 Agent 接续；systemd 依赖链负责已冻结阶段的
执行接续；每分钟只读观察器检查真实进程、提交和队列。
连续五分钟无已声明活动会标记科研后继逾期，不能靠观察器自身更新时间
假装持续训练。观察器不唤醒 Agent、不自行生成新假设、不盲目重跑失败实验。

恢复指针记录确切源码、报告哈希、当前阶段和下一步；重启后先对账，
不能把丢失的 transient unit 当作成功，也不能重复收费实验掩盖失败。
此机制降低静默停滞风险，不保证平台永不中断，更不保证科研必然成功。
Goal 只在真正达到用户要求的球队效果时完成。
