# S406–S414：目标速度向量学习与迁移复查

这轮得到了可在 CPU 复现的定向低速出球，但尚未打通合法 4v4 传接球比赛。S413 对固定低速组全部通过，高速组全部未通过；换到相邻身体相位和新扰动后仅 1/16 成功。因此没有新的合格宣传视频，也没有策略晋升。

## 改变了什么

S405 主要奖励接触后的前向速度接近目标，对侧向偏移的塑形不足。S406 使用 `training.directed_velocity_reward.contact_velocity_progress`，奖励实际脚接触期间二维球速与目标速度向量之间的距离减小。反向、明显侧偏及超过目标后继续加速都会受罚。输入必须是对齐、有限、无梯度的二维速度张量和布尔接触掩码；外层仍屏蔽身体失败、非脚接触和出界回合。

这个奖励不是成功判定，也不是接触因果归因。合格标准未放宽：实际脚接触，前向速度在目标的 80%–120% 内，横向速度不超过 0.2 m/s，后续脚接触前向峰值不超过目标的 125%，全回合身体安全、无非脚接触、球在场内。没有用动画或直接修改球速代替脚触球。

S406 v1 在第一次开发 rollout 中因目标速度 float64 与物理速度 float32 不对齐而被校验器拒绝，尚未优化。v2 在调用处显式对齐 dtype，未削弱校验器；保留 v1 日志和初始模型。

## 实际结果

S406 v2 新建 139/32 actor-critic 和 Adam，共 32 轮、4096 个训练回合、1024000 个 50 Hz 控制步、6272 步优化。S413 完整恢复其第 32 轮的 actor、critic、Adam 和 Torch/CUDA/NumPy RNG，再做 16 轮、2048 回合、512000 控制步、3744 步优化。冻结 LSTM 基础、85% 力矩上限和原有关节保护均保留。

| 检查 | S406 第 32 轮 | S413 再训 16 轮 |
|---|---:|---:|
| GPU 固定开发计算的合格出球 | 28/128 | 64/128 |
| 其中目标 0.8 m/s 组 | 28/64 | 64/64 |
| 其中目标 1.2 m/s 组 | 0/64 | 0/64 |
| GPU 身体安全、无非脚接触、球在场内 | 各 128/128 | 各 128/128 |
| CPU 相同的 32 种不同起点 | 7/32 | 16/32 |
| CPU 相邻身体相位与新扰动 | 0/16 | 1/16 |
| 相邻相位 CPU 出现非脚接触 | 0/16 | 3/16 |

必须解释分母：GPU 固定开发的每个目标/速度条件只有 4 种球 y 偏移，每种重复计算 4 次，共 32 种不同起点，不是 128 个独立案例。S414 在 CPU 对这 32 种起点各跑一次，复现了 7/32 与 16/32 的比例，属于已见基准的后端迁移。

S407 的 16 例使用同一源轨迹中相邻的第 218/222 帧，并加入新的球 xy 与速度扰动；这一基准已经用于多代开发检查，不能再叫最终未见测试。S413 多成功一例但也增加了非脚接触，因此不是无条件优于 S406。

两轮训练均完成全部检查点/rollout 哈希与 Core 学习租约审计，第一轮 PPO 精确重放，全部参数误差为零；默认 133/29 PPO 的旧回合重放也仍为零误差。训练算法可复现与运动能力泛化是不同问题。

## 路线示范搜索没有解决泛化

S408 用 128 组有界导航修正与持续时间做物理可行性筛选，不训练网络、不修改球状态，只有 1 组达到出球标准。S409 局部细化后仍只有 1/128；128 个身体全部安全、球均在场内且无非脚接触，但大多数球速或方向不合格。

S410 在 CPU 检查两条候选路线，每条 16 例，结果为 0/16 和 1/16。唯一成功是无球扰动的精确源身体状态，其他身体时刻/扰动没有成功。所以没有把这条脆弱路线直接认定为优秀示范，也没有将评估轨迹拿回训练。S409 保存的 250 对专家训练标签是脚本路线动作，不是 PPO 的在策略样本。

## 时间连贯探索的正反结果

为探索持续绕行，S411 每 0.2 秒选择一次动作提案，关节残差滤波和冻结 LSTM 仍每 0.02 秒更新，物理接触每 0.002 秒检查。PPO 只保留 25 个真实决策样本/回合；区间内按原 gamma=0.995 折扣累积奖励，决策层 gamma=0.995^10，没有把保持的同一个动作当作十次独立采样。

但同时保持完整关节扰动明显损害训练中的平衡：前 6 轮身体安全数依次为 66、73、75、75、69、79/128。主动终止第 7 轮 rollout，进程退出码 130，保留 6 个完整更新、768 个完整训练回合和 88 步优化。未执行训练后的确定性开发检查，不能据此断言训练后均值策略的结果。

S412 从头改为导航优先课程，关节残差幅度/单步变化均收紧为原来的 10%，即 0.025 rad / 0.0025 rad，其他速度/力矩保护不变。16 轮共 2048 回合、376 步优化；最终固定开发 128 个身体全安全、球全在场内、无非脚接触，但合格出球仍为 0/128，最大脚接触前向球速约 0.528 m/s。它改善了探索稳定性，却没有完成传球，未采用。

S411、S412 的真实决策级第一轮均精确重放；后续宏时间段不允许在已观测到非脚接触之后重新获得正奖励或复活学习资格。

## 接下来必须验证的链路

新候选首先要保持旧低速出球能力，再扩大身体相位、球扰动和目标球速。共享世界必须使用同一帧的角色资格、真实邻居避让、场地约束和唯一一次 LSTM 推理；接球与持球权必须来自真实接触及原有资格检查，不能由出球网络自行授予。

S415 已开始八人实战接口检查，但初版适配器错误地要求接近自由球时已经确认持球，候选未运行。S406 实战对照的全部轨迹数组与 S403 基线完全一致，说明这不是模型退化，而是未入场。正在按现有“指定追球者/持球者”语义修正，不以取消资格检查来解决。S416 已另起四身体相位训练；这些正在实施的内容不计入本报告的成功数。
