# 稳定基础上的受限参考模仿：实验前声明

上一轮一百次 PPO iteration 没有改善开发集姿态跟踪，不晋升。独立
原生检查确认参考输入正确、参考速度和位移一致、参考脚轨迹能碰到
既定球。此次不修改数据坐标、身体动力学、球摆放或物理考核门。

先收集数据：以已验证的两轮稳定 actor 为固定策略，在八个 TRAIN
动作上各运行一个完整 episode，seed1601，最多 300 控制 ×8 世界
×10 子步，即 24,000 世界子步/2,400 个神经控制样本。保留完整
168D 输入、实际状态、动作和目标、参考/实测关节姿态、源 ID/相位、
首轮有效掩码、终止及实际执行器力。只用首个 episode 训练，不把
重置后轨迹冒充新独立数据。不使用 007/010 开发集或私有 Holdout。

监督目标是一种**未物理证明的伪标签**：以实际稳定神经策略目标为
基底，增加 `0.25 × clip(q_reference - q_measured, -0.6, 0.6)`
弧度的关节修正，即每关节最多 ±0.15 rad。按原动作 scale 反解
成 29D 动作标签。这不是修改参考姿态或状态，也不是部署时直接
插入关节补丁；候选仍需学习 168D →29D 神经网络。小幅修正假设
尚待真实物理验证，不能叫作已经安全或成功的教师。此前直接参考
PD 失败的证据保留，不直接拟合全幅参考目标。

首次监督实验固定 50 次梯度更新、每次 256 行 TRAIN 样本及 256 行
原生旧技能回放，学习率 1e-4，seed2401。由两轮 actor 初始化，
critic 保留用于后续在线 RL，不假装此监督阶段更新了 critic。
原 98D 归一化固定。回放后缀置零，训练后缀使用实际参考 70D。
拟合前后保存权重和优化器及全部输入哈希；不能用监督误差下降
宣称球技成功。

之后固定配对开发集、原生基础运动保留与真实触球检查。若运动
保留或足球效果退化，拒绝候选；不增大修正、不扩大训练量来掩盖。
只有实际效果证明受益，才考虑下一档模仿和在线 RL 闭环课程。

实际采集完成八个首轮动作：23,120 世界子步、2,312 行神经控制，
其中首轮有效 1,905 帧。50 次 actor 更新使用 12,800 行 TRAIN 与
12,800 行旧技能回放；critic 未更新，不携带失效的旧 PPO Adam
状态冒充连续恢复。拟合目标误差从 0.003553 降到 0.001275 rad²，
但回放误差由 3.27e-5 升至 2.72e-4。安全回读使用重新实例化的
网络并独立核对输出。拟合回执 SHA256：
`d805bb423c4f7e70ecbf0b5c5e2971344aed8e4cd171f6cd22c73c77fab5ecca`。

物理开发集前后各 64/64 达到参考时长，关节误差 007 从 0.17869
降至 0.16591 rad、010 从 0.18337 降至 0.17032 rad，约降 7%。
但 XY 误差分别从 0.44270/0.41122 升至 0.45389/0.43703 m，
球位移案例由 9/64 降为 7/64。这是局部模仿改善，不是足球改善。
原生旧运动保留仍 4/4，通过 24,000 步及完整独立重跑。
开发集/保留回执 SHA256 分别为
`4bb0b50de9317cdcd9d09bc4b6451b61530c394a7f32c005b9b94a2fe79ff3fb`、
`e416550f4285eb1052123c61d5b81e856e4bf03adafafc7b12a36dae73141089`。

下一接触 pilot 固定 DEV007/010 的 world0，不按结果挑选球位。
初始/模仿后两个模型各完整独立重跑两次；最多 24,000 原生步、
2,400 神经调用。使用同一编译身体和初始 q/v，原生默认 mocap/
warmstart，明确不施加 GPU 课程后续推动，因此是新的 nominal
实验，不能冒充 CPU/GPU 长程一致性。仅读取已声明的绝对参考计划，
每帧根据当前原生身体重新计算全部相对 70D 特征；不读取未来 GPU
状态或重放 GPU 动作。逐子步核验实际 PD 力、接触力和状态连续性。
脚—球力 >1 N 且接触后球速 ≥0.5 m/s 只是接触研究门；本实验没有
球门精度或团队协作考试，不作进球与宣传成功结论。

实际原生接触 pilot 完成 18,360 物理步、1,836 次推理，完整独立
重跑一致。007 在初始模型中没有触球；模仿后出现 18.22 N 的右脚
接触，球速 0.323 m/s、位移 0.115 m，尚未通过 0.5 m/s 门，而且
该源的意图是左脚踢球，不能叫作正确学会参考踢球。010 前后均未
触球。四条轨迹均满足站稳研究门。回执 SHA256：
`2fc3fe68e5f8cbdfd9f0f1b431f6e5e79e44f713e891f315df647178104b3c26`。

针对 XY 跟踪误差大的下一项是**固定权重的控制结构对照**，不是新
训练成绩：在参考世界线速度上加 `1 s^-1 × (参考 anchor - 当前
anchor)`，再转换到当前身体坐标并限制在原速度命令域。不改 70D
参考、不改模型权重、不修改最终关节目标或添加外部身体力；由
相同神经小脑继续产生所有关节目标。旧位置反馈增益 0 的完整结果
保留。新增益固定为 1，只试同一两个 world0、同一两模型及完整
独立重跑；最多仍为 24,000 原生步/2,400 次推理。另记录意图脚
接触，避免把支撑脚碰球当成目标技能。结果决定是否需要先补足
目标—速度闭环，再继续学习更大幅度的踢球动作。

位置反馈对照也已完成 18,360 原生步、1,836 次推理，全部完整
独立重跑一致。两球位、两模型均保持最低 upright >0.989、骨盆
高度 >0.763 m，并产生了 >0.5 m/s 的真实脚—球接触后运动。
007 原模型/模仿模型球速分别为 2.26/1.84 m/s，010 为 1.24/1.25
m/s；但 007 都是右脚触球，仍不符合左脚参考意图。模仿后也未
因此获得更大球速，不能把结构改进写成模型学习提升。
位置反馈后 mean anchor XY 误差约 0.16–0.22 m。新结果回执 SHA256：
`0ca9d78dcb05b5f3a492cf44881f30a5e69b477b04bb922c1fcba699f92d4bb3`。

接下来保持该目标—速度闭环，重新采集 TRAIN 实际经历，做新一代
受限模仿的数据聚合。标签幅度仍不增大，旧技能回放保留，指定脚
接触和发力作为独立指标。不能用走路时碰到球代替学会参考踢球，
也不将这两个 nominal 球位结果外推为进球精度或连续球队比赛。
