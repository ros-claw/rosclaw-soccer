# 仿真接触前几何与相对运动观测

`rosclaw_soccer.sim.precontact_kinematics` 从传入的 MuJoCo 模型和实际状态复制出独立的 scratch 数据，计算指定物体碰撞几何与目标几何中最近的一对分离表面点、距离、Jacobian 速度及径向分离速率；负值表示两点在该瞬间接近。函数不修改调用者的状态，不发布机器人命令。

返回状态区分 `SEPARATED`、`CONTACT_OR_OVERLAP` 和 `DISTANCE_CENSORED`；后两者没有可用的径向速度。`cushion_shaping` 仅将分离状态下的距离及接近速度映射为有界辅助信号，其他状态返回 `None`，不将未知当作零或成功。该潜势可能因远离、规避触球等方式被利用，必须与预先固定的真实触球、受控结果、双方身体状况和独立验证联合评估；不能拿它替换原任务门槛。

这是几何最近点在当前时刻的运动，不保证这些点后来发生接触，也不是碰撞力、净冲量、碰撞归因或实体机器人安全证明。其值依赖所选模型、几何及仿真状态，当前没有在视觉观测或实体硬件上验证。单纯观测或辅助分数不意味着训练过模型、策略已改善或可晋升。

`compare_separated_witnesses` 可比较两个指定部位的距离差和径向速度差；任一侧已经接触、重叠或距离被截断时，比较结果保持未知。其可选的匀速到达时差只是一阶算术外推，**不是碰撞预测**。在一批仅覆盖四个重复初始条件的 32 条双 G1 轨迹中，将它与后续不同阈值的脚／非脚接触先后比较，仅 15/29 个可比较符号一致；这不是统计泛化评测，却足以说明不能把该外推当作有效预测或安全门。不要据此自动决定动作或奖励；需要使用真实物理接触、全身体状态与独立情形验证。
