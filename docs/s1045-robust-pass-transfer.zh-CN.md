## 一、同一个动作必须接受多个来球扰动

S1045：32 个已保存的相关入场状态，每个 4 个动作候选，每个候选
4 个相同分布的来球扰动，4 轮共 2048 次仿真。不同候选使用相同
的四组扰动，以免把比较变成不同试题。球 XY 扰动 ±0.015 m，
速度 XY 扰动 ±0.03 m/s。原生传球精度阈值保持 0.1 m。

动作是在冻结神经策略上叠加一个整段固定偏置。只有四组均满足
身体、场内、无非足部与无迟触约束的候选才参与分布更新；排序
使用一半最差分数加一半平均分。它是离线教师搜索，不是线上
按训练场景编号选策略，也没有更新 actor/critic。

各轮精确传球 16、12、9、19 / 512。按“至少 3/4 精确，且全部
约束通过”的候选组数为 1、0、0、0。最后一轮不通过筛选。
S1046 重建全部参数采样、提案、共同初始输入及分布更新通过。
S1047 是预先编写的通过组 CPU 重放入口；因没有通过组而未执行。

S1048 专门重放最后一轮两个安全但只有 2/4 精确的失败组，
保留全部 8 次，包括失败；CPU 仍为 4/8 精确。这不是降低筛选
标准，也不是把 4 次成功拿出来宣称 100%。

S1049 换成实时 CPU 神经反馈加同一个固定偏置，仍为 4/8 精确。
与动作序列重放的任务标签完全一致，最大目标平面误差差异仅
0.000004773 m。S1050 审计通过。这个子集的主要问题不在于
“视频重放看似成功、实际网络根本没执行”。不主张全轨迹位级一致。

## 二、用干预区分球位和球速

S1054 在两种固定动作偏置下，分别对球 X、Y、VX、VY 做完整的
16 组合试验，共 32 次 CPU 仿真。两档数值来自已知的一组成功/
失败来球；身体、循环网络状态和其他初始状态保持不变。

单独把 VX 从约 0.02068 改为 0.05382 m/s 时，两种动作的目标
误差分别从 0.07036→0.54419 m、0.00402→0.52818 m。
这是该局部状态的干预结果，不能外推为所有角色的唯一瓶颈。
Y 与其他变量也有交互；不能从混合扰动直接归因于一个变量。

通俗说：当前动作会踢球，但对触球前球继续移动了多少不够稳健。
几厘米的时空偏差，就可能让脚碰到球的部位不同，导致出球差很多。
因此只增加同一个固定动作的成功录像，不足以解决问题。

## 三、来球自适应候选仍未通过新考试

S1051 的实验适配器因函数签名断言不匹配，在物理运行前失败，
保留原脚本；S1052 使用新脚本修正适配并完成 2048 次仿真。
每个候选为 7 个固定偏置系数及 28 个来球观测增益，依据实际
入场球相对 XY 与速度 XY 调整偏置，特征与潜变量均有显式限幅。
底层神经反馈、关节和导航约束、接触闭合规则均保留。

各轮精确传球为 13、13、9、11 / 512。最后一轮有一个 3/4 精确
且全部约束通过的组。S1053 精确重建观测、增益、参数更新通过；
S1055 CPU 重放全部四次，也为 3/4 精确，失败一次误差约 0.37 m。

S1056 用新种子 105601，在一个入场状态周围做 32 次新扰动：
固定截距对照与增加来球增益候选的精确传球为 14→11 / 32，
受控传球 30→23，场内 32→25；均身体通过且无非足部或迟触。
预先声明的局部目标是至少 26/32 精确；候选拒绝晋升。
S1057 独立目标平面与接触计分审计通过，并不改变失败结论。

这不是新训练的端到端小脑，也不是整场比赛的自主路由策略。
实验开始时身体场景是训练选择的；新扰动不等于新角色或新比赛。

S1058 对两个固定动作、四种球 Y/VX 条件，试验追球速度前馈
增益 0、0.25、0.5、1，共 32 次 CPU 仿真。每个增益共 8 次，
精确传球数分别为 2、1、0、0，身体均通过且无非足部接触。
没有选出可晋升的前馈参数。下一步需要更直接地学习触球前脚—球
相对位姿与相对速度，而不是扩大固定动作或导航补偿的训练量。

## 四、正式工程与验证

新增 `training/pass_replica_screen.py`，专门防止足球教师筛选时：

- 遗漏失败扰动，缩小分母；
- 混用不同动作参数或入场上下文；
- 重复副本、缺失副本或将非有限误差当作成功；
- 用平均精度掩盖某次身体、非足部或迟触失败。

候选和上下文要求显式 SHA256 绑定，副本须完整且唯一。
筛选器不认证调用方的物理证据、不授予执行权限、不提升策略。
足球计分留在下游仓库；通用 Growth、许可和安全边界没有移入
足球项目。S1050 用全部 512 个历史候选组实际调用正式模块，
逐组结果与原生标签一致，不只是新增单元测试。S1059 再次验证
大整数输入防溢出加固后的相同逻辑；误差仅接受 [0,1000] m，

报 403 个错误、涉及 64 个文件，不能宣称全仓类型检查通过。

复查再增加 2 个超大数值拒绝测试，新模块共 23 项测试通过；
最终全仓 2584 passed、29 skipped、11 failed，失败身份再次与
