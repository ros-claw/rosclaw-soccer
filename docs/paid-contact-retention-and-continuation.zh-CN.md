# 接触策略：保留旧能力不等于已经学会连续比赛

本阶段是 SIM_ONLY 的局部运动学习研究，不是球队宣传验收。

## 已完成的局部实验

冻结 R2 运动网络及归一化参数，训练有限幅度的关节目标残差网络和干预门。
运行时输入仍然是原有 160 维观测及其因果 LSTM 特征，没有球位编号、教师
动作查询或未来信息。残差最大 0.2 rad，通过原有 PD 控制器执行；不是直接
力矩策略，也不是在线强化学习。

此前单种子保护性学习得到第二脚 12/16。本轮回放这些真实物理成功的经验，
并约束所有已知不应干预的状态，而不只优化平均误差。三个独立种子完成各
1,024 次 Adam 更新，CPU 物理考试分别得到第二脚 13/16、12/16、13/16。
均保住上一代的全部 12 个成功条件、第一脚 16/16、单次 DEV 14/16 和两脚
世界身体稳定 16/16。物理原语审计和全部动作的独立神经网络复算均通过。

这证明局部能力增长可以不以遗忘旧能力为代价。但这 16 个起点是反复使用的
开发条件，不能称为新的盲测泛化或完整 Physical RSI 晋级。

## 一个重要的消融结论

加入的门参数投影检查了每次更新，但所有更新本身都满足约束，没有触发
回退。无投影消融与对应主实验的权重逐张量完全相同。因此不能把性能改善
归功于“投影修正了坏更新”。真正改变训练的是最坏状态损失、成功经验回放
及残差头初始化；需要后续对照才能进一步区分各自贡献。

## 为什么必须测连续状态

第一脚完成时不摔倒，不代表身体状态足够好去完成第三脚。两脚考试终点后
继续保持、再次接触球，都可能暴露原来没有看到的速度、姿态或接触问题。
本轮三个种子均安排三连踢考试，并自动接续原生物理与因果网络审计。

连续考试必须满足：

- 一个世界只初始化一次身体；不重置根位置、速度、仿真时间或积分状态。
- 只允许明确记录的训练夹具将球返回；这不是队友传球。
- 保留上一实际动作；各技能的参考时钟及私有循环记忆重置需显式声明。
- 每个条件分别执行完整世界的两次独立重复，不能把时间帧当独立样本。
- 首两脚必须逐数组复现已审计的 TRAIN 父代，才能执行新第三脚。
- 普通身体失败或夹具失败必须记录，不删球位、不无限重试、不变成成功。

## 补齐 DEV 连续考试

此前的 DEV 14/16 是单脚结果，且入口网络冻结。这个数字不能证明残差网络
能处理 DEV 落地后的第二、第三次动作。新增 `--course-bank dev` 明确：

- 使用父代声明的完整 DEV 16 条件，原样保留，不重新抽样。
- 第一脚必须逐数组匹配父代已审计的单脚 DEV 原始轨迹。
- 第二、第三脚从实际落地状态执行，没有现成的父代双脚证明可套用。
- 固定比较原 R2 与新网络，不按球位选择赢家。
- DEV 已经是开发集合，不改名为 Fresh，不自动晋级，也不将此次测试标签
  偷渡进本轮冻结模型的训练。

`paid_chain_courses.chain_parent_profile` 统一读取课程及合格前缀，生产器和独立
审计器都要求完整来源绑定；审计器另外核对完整课程与父代声明一致。

## 自动接续的范围

`scripts.rsi_continue_paid_contact` 核验父代考试、物理审计、网络审计的哈希依赖
后，依次执行三脚物理考试和独立审计。只有前一阶段退出成功且完成收据符合
合同才进入后一阶段。失败保留 journal，无自动物理重试，不重写旧输出。

这只是自动执行预先声明的实验，不是自动科研决策器。流水线结束后，Agent
仍必须分析救回/退化的具体条件、失败发生阶段，再实施下一轮学习。
局部审计完成不会设置 `goal_complete=true`。

下一轮是否值得投入，取决于新连续状态是否维持增长；若旧技能保持而更晚
状态退化，应调整 SuccessorState 训练目标、观测或恢复控制，而不是继续
只提高第二脚分数。真正的连续比赛、角色自主协作、历史对抗、Fresh 考核和
宣传视频验收仍未完成。
