# S455–S457：首次传球学会了什么，以及为什么还不是完整足球

本阶段的可确认进展是：把“追上球再次踢出的高速度”排除后，PPO 仍然能够提升**第一次真实触球的出球质量**，并迁移到八机同场。尚未获得连续、稳定的团队传接射门，不能以此发布合格的 4v4 宣传成果。

## 学习和复核

S455-v2 从 S442 generation 32 完整恢复 actor、critic、Adam 和随机数状态，执行 32 次更新、7,960 个优化器步骤、4,096 条训练 rollout、1,024,000 个 50 Hz 控制步。每条 rollout 只含一台机器人，不是多智能体自博弈；128 个并行环境来自同一真实开发回合的三个身体相位。

首次物理足部触球的前向球速达到 0.4 m/s 后进入出球恢复；仅首段连续接触、最长 0.12 秒获得首次出球信用。后续追球重踢会使首次传球失败。保留身体、关节、非足部接触、球出界等约束。

固定开发集的高速条件从 **0/96 提升到 66/96**。但低速保留集从 **31/32 降至 18/32**，所以不能整体替换旧模型。原低速传球和接球专家保持独立保存。

审计验证全部 checkpoint、rollout 和塑性审计哈希；非足部违规后的正奖励与学习存活样本均为零。11,840,000 个“2 ms 样本 × 环境”信用状态逐项重放一致。首个新优化器更新的 248 步、旧 133/29 模型回归的 352 步均逐参数完全一致。

S455-v1 曾因采集器变量遮蔽，将 critic value 存成布尔值，在第一次优化器更新前失败。没有将它当作成功训练。修复采集器后另建 v2，并将 PPO 张量类型前置检查加入公共训练模块及测试。

## 八机同场：必须分开看“出球”“碰球”“控球”

S457 使用与训练一致的首次出球信用和恢复语义。低速基线回归的 185 个运动数组完全一致，未改变原来的合法接球和残差释放。

| 传球检查点 / 接球专家 | 首次前向峰值 | 接球足部样本 | 身体安全 / 机器人碰撞样本 | 实际结论 |
| --- | ---: | ---: | --- | --- |
| g24 / S364 | 0.97490 m/s | 0 | 全部安全 / 0 | 漏接 |
| g24 / S430 | 0.97490 m/s | 0 | 全部安全 / 0 | 漏接 |
| g32 / S364 | 0.97824 m/s | 6 | 全部安全 / 0 | 碰到后将球弹向边线，未控住 |
| g32 / S430 | 0.97824 m/s | 0 | 并非全部安全 / 9 | 漏接且整场安全失败 |

这里的目标速度是 1.2 m/s，但旧容差门槛为 80%–120%，因此约 0.978 m/s 是**通过容差，不是实际踢到 1.2 m/s**。g32/S364 的真实首次接球时刻为 7.650 秒，接触前球速约 0.6011 m/s；接触后球速上升并带上抛分量，不能称为接稳。

g24 的首次接触结束横向速度为 0.12678 m/s，虽满足旧 0.2 m/s 约束，实际滚过固定目标纵向平面时却偏了 **0.57172 m**。g32/S430 未碰球时的对应误差为 **0.42395 m**。g32/S364 提前截到了球，后续轨迹被接球队员改变，因此不计算它的“无人干预源传球到点误差”。

这暴露出下一项任务：瞬时速度合格不能代替到点精度；碰到球不能代替吸收冲量和稳定控球。历史 `result.passed` 只覆盖较粗的世界指标，绝不是完整足球验收。

## 后续实验边界
