# S210：失败驱动的情境射门专家记忆闭环

## 结论先行

本阶段把 S209 的单一、固定情境射门协调 actor，扩展成了一个可审计的“情境观测 → 局部专家选择 → 物理执行 → 成败入库 → 独立重放 → 晋升门”闭环。它已经能从失败中补充局部动作记忆，并在不破坏三个既有成功目标的前提下，把 0.65 m 和 0.70 m 两个失败目标修复为成功。

结果必须分成两层理解：

- **局部成长证据通过**：旧基线在 5 个目标上为 3/5；加入失败修正后的 9 个训练锚点为 9/9，全部安全，18/18 个主证据与独立重放完全一致；0.90 m 未解决区域触发负面记忆并安全弃权。
- **连续泛化晋升被拒绝**：8 个从未参与训练的目标中点只有 3/8 成功，成功率 37.5%，没有达到预先冻结的 80% 门槛。因此不能声称它已学会任意目标射门，也不能把 9/9 训练点包装成泛化能力。

封存考试状态为：

```text
PASS_DAGGER_MEMORY_REJECT_HELDOUT_GENERALIZATION
evidence_passed = true
promotion_eligible = false
```

这是一次真实但有限的进步：ROSClaw 已经具备“失败不丢失、修正不遗忘、未知不冒进”的成长骨架；射门运动学仍然是离散局部专家，尚未成为能连续插值、稳定泛化的小脑模型。

## 1. 为什么要做这一轮

S209 的数据驱动 actor 在固定目标 `y=0.80 m` 上取得了更快的接球后射门，但把同一个 actor 移到相邻目标后出现明显的非平滑行为：

- 0.60、0.75、0.80 m 满足本轮统一候选成功合同；
- 0.65 m 虽有门框内弹道意图，但世界安全门失败；
- 0.70 m 同时出现世界不安全与偏出门框；
- 0.90 m 失败。

这说明“一个全局参数 actor”不足以描述目标位置、球位置和防守几何共同造成的接触敏感性。本轮没有继续盲调一个全局补丁，而是把成功与失败变成有边界的情境记忆，并验证这种记忆能否形成最小 DAgger 闭环。

## 2. 新增架构

### 2.1 情境观测

`StrikeTaskContext` 只从 MuJoCo 权威世界状态读取五个量：

| 特征 | 含义 |
|---|---|
| `goal_target_y_m` | 本次期望目标的横向坐标 |
| `ball_lateral_y_m` | 触发射门定向阶段时的球横向位置 |
| `nearest_opponent_distance_m` | 最近对手到球的距离 |
| `shot_line_clearance_m` | 对手到球—目标射线的最小横向净空 |
| `shot_line_progress` | 最近射线对手位于球到目标路径的相对进度 |

所有输入必须有限且处于显式边界内；归一化尺度进入训练产物和哈希，防止运行时悄悄改变距离语义。

### 2.2 局部专家记忆

每个 `ContextualStrikeExpert` 由一条已验证成功的 S209 参数教师构成，并绑定：

- 情境中心；
- actor 内容哈希；
- 来源报告哈希；
- 来源轨迹摘要；
- `SIM_ONLY` 权限上限。

路由器只在接受半径内选择最近的已验证专家。若最近的是未解决失败边界，或请求落在全部支持范围以外，则返回“弃权”，继续由冻结父路径掌控。它不能生成新动作，不能改变射门相位，不能直接输出关节位置、速度或力矩。

### 2.3 相位内锁存

专家仅在 `ORIENT` 相位入口咨询一次，并锁存到本次射门相位结束。这样避免了相邻专家在每个物理帧之间跳变而产生抖动。轨迹新增了六组可审计字段：

```text
strike_context_memory_consulted
strike_context_observation
strike_context_expert_index
strike_context_normalized_distance
strike_context_selection_code
strike_context_abstained
```

验证器会从原始轨迹重新计算每一次选择和每一帧锁存动作；只修改 JSON 中的“成功”字段无法通过校验。

### 2.4 失败驱动 DAgger

训练器同时接收成功和失败探针：

1. 已验证成功探针成为局部专家；
2. 失败情境若已有同目标、同球位的成功教师，则绑定为 DAgger 修正；
3. 未找到修正的失败成为负面边界；
4. 所有源 JSON、轨迹、实现文件和数据快照均被内容寻址；
5. 候选必须重新跑 CPU MuJoCo，并再跑一份独立重放。

这不是在线强化学习。它是保守的、离线教师搜索加失败聚合闭环，为后续连续 actor 或 actor-critic 提供不会遗忘安全边界的训练数据基础。

## 3. 实验设计

### 3.1 统一成功合同

旧基线和新候选按同一个可比较合同计分：

- CPU MuJoCo 世界安全；
- 射门相位完整经历 `[1,2,3,4,5,6]`；
- 队友物理传球确实被接到；
- 脚在射门相位发生物理触球；
- 恢复相位完成；
- 物理触球后弹道投影的完整足球位于标准球门内；
- 新候选还必须确实激活一个受支持专家。

“球门内弹道意图”不等于实际进球。防守球员仍可能在球到达球门前发生真实接触，本轮不声称 GOAL 或 GOALKEEPER_SAVE。

### 3.2 数据分组

- 旧基线：0.60、0.65、0.70、0.75、0.80 m，共 5 个目标；
- 训练锚点：0.60 到 0.80 m，每 0.025 m 一个，共 9 个目标；
- 严格留出中点：0.6125 到 0.7875 m，每个点位于两个训练锚点之间，共 8 个目标；
- 拒绝样本：0.90 m；
- 重放：上述 18 个新候选案例全部从相同封存记忆重新执行一次。

MotionDecode 本轮没有被冒充为射门目标教师。它能提供动作自然度先验，但当前局部问题是目标/碰撞几何引起的物理接触敏感性；MotionDecode 不带本实验所需的球—脚—目标因果标签，直接混入会污染成功定义。

### 4.4 未解决区域弃权

0.90 m 案例：

- 世界安全：是；
- 专家激活帧：0；
- 弃权帧：121；
- 选择码：`2`（negative-memory）；
- 射门相位停留于 `[1,2,3]`，没有伪造射门成功。

这验证了负面经验不是日志装饰，而是能实际阻止已知失败区域获得候选权限。

## 5. Stability–Plasticity 处理

本轮用四个工程约束处理稳定性—可塑性冲突：

1. **父路径冻结**：记忆只拥有两个高层融合量，原来的相位、PD、小脑和安全检查不被替换；
2. **保留集硬门**：新修正必须同时保留 0.60、0.75、0.80 m 的旧成功；
3. **负面记忆**：未解决失败不被删除，也不允许最近专家跨边界外推；
4. **留出晋升门**：即使训练点 9/9，只要未见中点低于 80%，就不能晋升为连续目标能力。

还尝试过把更强的关节安全保护直接加入现有控制链。该修改破坏了相位完成或降低了保留能力，因此已完全回退，没有进入候选。这个失败说明稳定性约束必须进入训练目标和接触时序，而不能在动作尾端粗暴截断。

## 6. ROSClaw 层面的价值

G1 足球只是压力测试，真正可复用的是以下模式：

```text
具身任务上下文
  → 内容寻址的成功专家与失败边界
  → 有权限上限的运行时路由
  → 相位/技能周期内锁存
  → 原始物理轨迹回算
  → 保留集 + 未见集 + 拒绝集
  → 独立重放
  → 证据通过与能力晋升分离
```

该结构可迁移到抓取、导航、恢复、门将和其他具身技能：每个专家必须绑定它在哪些上下文被证明过；未知上下文可以弃权；成长门同时检查新能力、旧能力、安全和可复现性。

## 7. 当前局限

- 这是局部专家选择，不是端到端神经小脑、在线 RL 或持续更新 actor-critic；
- 只在一个固定球初始横向位置和同一防守布置上验证，尚未覆盖球位、来球速度、左右脚和对手策略的组合分布；
- 留出泛化只有 37.5%，因此 `promotion_eligible=false`；
- 虽然多条弹道位于门框内，但距目标点的误差仍约 1.30–2.51 m，离 0.10 m 死角精度要求很远；
- 本轮验证的是射门意图和稳定恢复，不是实际进球率或扑救率；
- 所有证据均为 CPU MuJoCo `SIM_ONLY`，没有真实机器人迁移结论；
- MotionDecode/SONIC 自然度先验尚未与这一目标条件记忆做接触一致的联合训练。

## 8. 下一阶段建议

下一阶段不应继续无限加密离散专家，而应把本轮数据转成连续、可校准的动力学学习问题：

1. 学习 `目标 + 球位 + 来球速度 + 防守几何 + 本体状态 → 接触参数` 的连续条件 actor；
2. 以局部专家和失败边界为离线数据，训练带不确定度的 mixture-of-experts 或 latent dynamics 模型；
3. 用短时域 MPC/actor-critic 在仿真中优化脚面姿态、触球时刻和摆腿速度，而不是只调两个融合量；
4. 把世界安全、足底接触、COM/ZMP、踢后后退、动作平滑和 MotionDecode 风格作为联合约束；
5. 冻结训练/保留/未见/拒绝四套集合，要求未见成功率至少 80%、目标误差显著收敛后才允许扩大权限；
6. 保留本轮的负面记忆和失败关闭语义，连续模型超出校准支持域时仍回退父路径。
