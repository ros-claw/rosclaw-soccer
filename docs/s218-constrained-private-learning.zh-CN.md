## Core 模块实际复用

每次私有 actor 更新前，创建 Core `PlasticityLease`：只允许当前一人改变，
绑定八名球员起始权重、真实轨迹数据、父策略和更新步数。更新后执行 Core
`audit_plasticity_lease`，任何冻结球员变化或超步数均拒绝；Soccer 额外核验
起始权重与租约绑定完全一致。这是训练约束，不是机器人动作 Lease 或 Permit。

使用 S217 第一代真实数据重新训练，加入 Core 约束后重现了完全相同的 checkpoint。
证明新约束实际经过优化器路径，而不只是创建一个没有使用的对象。

## 全角色速度建议约束

此前预测性分离主要作用于支持/掩护角色。新增显式 opt-in 的全角色 2D 速度
投影，限制朝附近身体继续逼近的分量，保留切向跑动；同时满足速度上限。
实现枚举二维半平面与速度圆的可行边界，避免逐个排斥导致的邻居顺序依赖。
不可行会记录 `clearance_feasible=false`，不能称为安全证明。

该层仅调整步行速度请求，不传送身体、改球速、禁用碰撞或修改回放。
仍须 MuJoCo 证明实际步态、接触和稳定性。默认关闭。
