# S400–S403：把技能仿真与合法比赛分开

整体画面复查暴露了一个必须明确的问题：S380–S399 的旧连续开发场景关闭了出界终止。S391 的 24 秒轨迹在 11.28 秒已发生整球越过 y=3 m 边线，后续仍继续模拟。因此其中出界后的成功停球只能证明运动技能，不能算合法比赛传接球。相关早期报告已补充这一边界，没有删除或修改原轨迹。

## 已实施

- S400 强制启用已有 `ball_exit_reason` 和共享世界的 `stop_on_ball_exit`，首个整球出界事件后结束仿真。没有暗中移球或重开比赛。
- 对称地将两队中场初始位置和战术本位放到 y=±2 m，作为显式新场景，其他角色数、模型和保护不变。
- 增加可复用的 `world.pitch_velocity.PitchRootBounds`，生成场地内机器人根部的速度半平面约束。
- 扩展原 `propose_clearance_velocity`：可同时求解场地约束和真实邻居避让。没有在避障完成后简单裁剪速度，也没有增加墙碰撞体。
- 默认不传额外约束时保持旧行为，1024 个确定性投影对照结果完全一致。新约束是解析导航保护，不是学习策略，也不保证步态跟踪或足球不出界。

## 结果

S400 原布局在 11.28 秒出界；新场内布局在 8.86 秒出界。仅挪动站位没有改善传接球，不能算成功。

S403 在同一新布局比较不加约束与加场地约束。无约束基线逐数组完全复现 S400：

| 实际轨迹指标 | 基线 | 加场地约束 |
|---|---:|---:|
| 蓝队前锋最大绝对根部 y | 2.899 m | 2.396 m |
| 蓝队中场最大绝对根部 y | 2.565 m | 2.369 m |
| 八人身体安全 | 是 | 是 |
| 机器人间碰撞 / 电机故障 | 0 / 0 | 0 / 0 |
| 末帧整球出界时刻 | 8.86 s | 8.86 s |

3544 次根部导航投影中，356 次受约束，0 次无解。两次仿真的足球轨迹完全一致：这次改变改善了球员向场外漂移，但没有改善传球方向，也没有提高合法比赛成功率。

诊断原始轨迹：出球时球速约 vx=0.53、vy=0.48 m/s，方向约 42°；而队友目标方向约 14°。接球者还需要横向追赶，最终来不及接稳。源身体当时仍朝约 51°，尚未转向队友方向就先触球。这提示需要联合学习接近路径、转身和触球，而不只是微调最后一脚的关节。
