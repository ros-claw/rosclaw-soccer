# S235–S236：球状态条件化的全身学习与接近动作

日期：2026-09-09。这些都是单 G1、SIM_ONLY 的技能实验，尚未使共享 4v4 球队通过验收；没有制作新的整体突破宣传视频。

## 确实训练了什么

冻结 SONIC 全身教师，增加可训练的 **133 → 128 → 128 → 29** actor 和独立 critic；输入包含本体状态、球的相对位置及速度、动作阶段、上次残差和教师目标。PPO 在实际 MuJoCo Warp 回合后更新网络，保留每代数值权重和优化器恢复文件。

输出是 29 个关节的**目标位置残差**，最大 0.25 rad、每次控制更新最大变化 0.025 rad，并低通平滑。物理层每 2 ms 重算教师 PD 和关节保护。这不是直接力矩端到端策略，也不是已经训练好的全角色通用球员。参考姿态只进入策略输入，不在回合中改写机器人或足球的位置。

可复用实现：`training/ball_residual.py`。Torch 是延迟加载的可选学习后端；零均值初始化保留教师动作，非法状态不静默放行。

## 两次失败带来的具体修正

1. **踢远球反被扣分。** 第一版持续用“脚与球更近”作为奖励，触球后球飞远仍被惩罚。修正为首次真实触球后停止接近项，由物理出球和身体状态评价后续动作。代码中用 `precontact_approach_reward` 明确表达并测试这一边界。
2. **控制频率不等于接触采样频率。** 50 Hz 采样会漏掉几毫秒的触球。同一冻结策略的批量测试，50 Hz 只记录 8 个世界触球，500 Hz 记录全部 32 个静止球世界；独立 CPU 每 2 ms 检查也确认 8 个不同静止球位均有真实足部正接触力。因此不把两种采样率的计数直接当作学习效果比较。

可复用实现：`providers/g1/vector_contact.py`。调用者指定脚、手掌等碰撞组；采样要求每个物理步恰好一次，跳步、重复或未声明重置都会使本回合接触证据失效，不能事后重新对齐时间继续冒充完整记录。该组件不放大碰撞体、不推球、不决定晋升。

## 独立 CPU 验收

证据根目录：本机 `/code/rosclaw/phase8_evidence/`。

固定测试是 8 个横向偏移（±0.06 m），分别测试静止球及原轨迹中的滚远速度，共 **16 个不同情境**。GPU 的重复初态副本不是独立样本。验收用 MuJoCo 3.12.0、原始 ONNX，每 2 ms 检查身体和接触。局部通过要求身体门通过、真实脚触球、首触后 0.2 s 内有效方向速度 >1 m/s；其他非地面/非脚碰撞会截断速度归因窗口。

| 候选 | 训练 | CPU 身体门 | 静止球通过 | 滚远球通过 | 静止球有效出球均速 |
|---|---|---|---|---|---|
| 冻结父策略 | 无新增学习 | 16/16 | 8/8 | 0/8 | 1.703 m/s |
| S235 v2，第 64 代 | 4096 个训练回合，仍按 50 Hz 接触采样 | 16/16 | 5/8 | 0/8 | 1.165 m/s |
| S235 v3，第 32 代 | 2048 个训练回合，500 Hz 完整接触 | 16/16 | 8/8 | 0/8 | 2.108 m/s |

v2 拒绝采用。v3 保留为**局部研究候选**：静止球均速约增加 23.8%，但个别球位速度下降，精度、高球、完整射门与团队配合均未由此证明。

## 滚远球：不能只训练原地摆腿

S236 将预训练 SONIC 的跑动参考与物理踢球参考进行连续输入衔接，筛选 8 个接近长度 × 4 个参考起点 × 静止/滚远两类球，共 64 个实际物理案例。没有在物理中瞬移，也没有为此重新训练 SONIC 权重；这是**动作组合可行性筛选，不是新增 RL 成果**。

GPU 64/64 身体门通过，26 个局部候选。随后独立 CPU 验证“20 帧接近 + 踢球参考偏移 60”组合：身体 16/16，滚远球 **8/8**，静止球仅 **5/8**。滚远球首触约 0.58–0.59 s，有效方向速度约 2.06–2.58 m/s。它解决了一类接近问题，却不能全局替换原静止球策略。

证据：`s236-approach-reference-screen-v1/`、`s236-cpu-composition-exam-v1/generation-000/`。首次筛选脚本因重复 ONNX session 参数在回合开始前失败，保留 `run.log`；修正后的完整证据在 `retry.log` 与 `result.json`。

接着启动 `s236-mixed-reference-ppo-v1/`：从 v3 候选继续，用一半旧参考、一半接近参考训练同一个 actor–critic，分别保留四组固定检查，不允许总体分数掩盖某一组退步。优化器在新任务开始时重建，父权重哈希和参考哈希均记录。这一训练尚不能等同于球队部署。

## 测量与工程限制

- 当前方向奖励使用虚拟平面点 (7.5, 0.8)，局部物理夹具仍为默认 x=5 的球门；因此本文没有声称球门死角精度或进球率。这项差异必须在下一步真正射门任务中统一。
- 当前演员使用固定场地坐标系，未证明朝向、左右脚、不同身体或起始姿态的泛化。
- S235/S236 实验的网络更新尚不是完整 Core Growth 晋升闭环：有物理证据和权重保存，但不能回填声称当时已有 Core 学习租约。后续应前置绑定数据、冻结教师、优化器步数与晋升门。
- 全仓 ruff 通过；mypy 422 文件通过；新增模块定向测试合计 48 passed。启用 G1 资产的全量测试 **1295 passed、13 skipped、11 个既有历史证据绑定失败**，日志 `s235-full-pytest-v1.log`。没有隐藏这些失败。
