# S13：G1 机动门将与父代保护闭环报告

日期：2026-08-13
范围：`SIM_ONLY`；4×NVIDIA RTX A6000；无真实机器人命令。

## 结论

本轮把门将从“站着伸手”推进到“横移截球—卸力回中—连续二扑”的数据驱动策略。新策略通过 256 场 GPU 留出集与 96 场独立 CPU MuJoCo 考试，成为新的**合格 SIM_ONLY 策略分支**：CPU 首扑率由冻结小脑基线的 29.17% 提高到 38.54%，恢复率由 29.17% 提高到 37.50%，二扑率由 3.13% 提高到 8.33%，横移峰速均值提高近 9 倍，同时零摔倒、零关节越界、零力矩越界。

但本轮没有偷换“通过基线考试”和“替换总冠军”两个概念。与上一代 S12 Champion 在相同 96 个种子下配对后，新策略首扑、恢复、回报和横移略强，二扑由 9.38% 降为 8.33%，因此新加的父代 Pareto 门保留 S12 为全局 Champion，把 S13 归档为机动性专长分支。它可以用于展示和后续蒸馏，但不会覆盖父代。

## 为什么上一轮会甩臂和扭身

四卡短消融给出了直接证据：

| 控制方式 | 首扑 | 根部角速度峰值 |
|---|---:|---:|
| 冻结小脑、无残差 | 28.13% | 0.832 rad/s |
| 仅横移 | 31.25% | 1.710 rad/s |
| 横移 + 双臂、无腰 | 43.75% | 4.471 rad/s |
| 完整确定性教师 | 40.63% | 3.500 rad/s |

所以高角速度并非主要来自腿脚横移，而是高方差探索下的单臂大幅伸展。盲目削弱所有动作会同时杀死机动性；本轮改为只治理腰臂动量。

## 实现

### 后端中立的敏捷控制契约

新增 `goalkeeper_agility.py`，CPU NumPy 与 GPU Torch 共享同一配置和数学逻辑：

- 对 actor 的横移意图做有界非线性增益，不超过冻结行走小脑的 0.40 m/s 命令上限；
- 扑救结束后用当前位置与横向速度预测短期偏移，主动回中，而不是残差全部清零后原地等待；
- 根部角速度接近自然度上限时只衰减腰臂，不削弱横移腿部小脑；
- 腰部加入小幅反向旋转，手臂统一权限缩放；
- 所有参数内容寻址、`SIM_ONLY`、无硬件权限。

PPO 初始探索标准差从 `exp(-1.5)` 降为 `exp(-2.0)`。这不是取消探索，而是避免用随机猛甩单臂制造偶然碰撞。短压力测试中，同一类随机探索的峰值角速度从 4.264 降到 2.711 rad/s，二扑不退化。

### 自进化父代保护

新增通用 `paired_champion_gate.py`：

- 候选必须显式绑定被比较父代的内容哈希；
- 父子必须使用同一密封场景哈希和相同 episode 数；
- 每个指标声明最大化/最小化、允许退化预算和硬上下限；
- 安全考试通过但不能 Pareto 支配父代时，状态为 `RETAIN_PARENT_ARCHIVE_CANDIDATE`；
- 只有支配父代才返回 `REPLACE_CHAMPION`。

这是 task-neutral growth 能力，可用于抓取、导航、操作等任何有父代/候选配对证据的技能，不依赖足球语义。

## 局限与下一轮

1. 当前横移由冻结 locomotion prior 实现，仍不是专用门将交叉步、侧滑步和受控鱼跃；下一轮要训练多个安全 leg option，由高层 actor 选项化调度。
2. 新策略更机动，但动作 P95 角速度比 S12 父代高，说明敏捷与自然度仍有明确 Pareto 张力；需要 CVaR/tail-risk loss，而非只看平均惩罚。
3. 二扑仍低于 10%，第二来球的分布与恢复奖励要改为难度课程，同时用父代 replay 防止遗忘。
4. 视频选段虽然全部真实通过考试，但视觉只用于理解，不代表总体成功率；总体结论必须以 96/256 场报告为准。
