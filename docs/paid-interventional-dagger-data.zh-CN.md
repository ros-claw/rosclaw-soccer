# 有物理见证的学生状态数据聚合

本阶段是 SIM_ONLY 的干预式模仿学习数据准备，不是在线 PPO，也不意味着学生已获得
教师的成功率。正式考试、旧能力保护和宣传标准均不改变。

## 纳入什么

先保持原 94 条 TRAIN 轨迹、21922 行特征与标签逐字节不变。在已经完成全量自身网络、
自身 R2 规划头、IK、原生物理与恢复审计的接管实验里，仅纳入：

- 比原动作开始时间更晚接管的分支，排除立即接管与原教师参考对照；
- 整条轨迹实际触球合格且恢复健康、观测完整；
- 标准重复 0，重复执行不增加独立样本数；
- 接管之后教师实际执行的行，不使用尚未执行的建议。

首批符合条件的是案例 4、第 80 周期接管的成功分支；案例 5 与更晚接管的失败分支
保留完整结果和原始轨迹，但不作为正示范。原独立来源仍只有两个初态，不宣称广泛
泛化。预计新增至多 209 行，实际数量由重复检查决定。

## 自身记忆与标签

重算整条混合轨迹的自身 R2 递归，从第 0 周期开始验证观测、h/c 前后状态、上一次
实际动作，以及教师规划使用的当前 R2 名义动作。不能在第 80 周期把记忆清零，也
不能借用原教师的记忆。只在此后选取已执行教师动作，转换为相对同一冻结父模型的
关节修正。最终相对 R2 的每关节 0.2 rad 权限不变。

特别不能把接管前学生的动作追加为教师标签：例如第 63 周期，两种策略可以处在
完全相同的状态却选择不同动作，之后通过不同路径完成任务。混成一个确定性标签
会制造冲突。新数据若与已有相同特征给出不同动作，整次整理拒绝，不做平均；兼容
重复行透明跳过，不改写旧数据。

## 可复核性

新建 `paid.interventional_dagger.TRAIN_features.v1`，不放宽原 94 轨迹的验证器。
加载新数据时，重新校验原数据与父模型，读取绑定的全量物理审计收据，重新计算新增
学生状态特征和已执行标签，并与保存的数组逐项比较。所有成功、失败和未选分支的
结果另存为持久记录。没有 DEV/Fresh 拟合，没有新增物理执行或优化器更新。

下一阶段用这批新状态继续训练实际神经动作头，分别统计继承与新增更新数，再进行
无教师接管的完整闭环考试。缓存拟合通过不能替代学生实际踢球成功。
