# S1655–S1673：触球事件附近的控制参考再学习

## 结论

仍没有达到新的宣传资格。全程参考投影下再学习六关节力矩，48 个候选
均未满足射门要求。新的**实时接近事件触发**对照保住了多组原有高球射门，
但高精度与小腿几何分离仍未同时达成。此时继续扩大宣传叙事不合适。

## 新的因果控制对照

全程调整 PD 参考会改变站立、支撑及接近阶段，微小参数变化也可能导致
后续接触大幅改变。我们改为逐原生 2 ms 子步测量球心与脚部打击参考点的
距离；第一次小于阈值后锁存触发。此前保持原始参考，不使用事后触球时间，
不编辑球的位置、速度或力。

控制参考从原目标向限位内目标插值，比例 0 与 1 分别代表不改变参考和
完整投影。**参考不是实际关节状态**；无论采用哪个比例，实际关节限位、
双方触球前保护、力矩/电机约束、1 N 非脚触球判定、小腿几何要求以及
0.10 m 射门精度要求都保持不变，没有改变验收门。

S1660 使用距离 0.15/0.25/0.40 m 与比例 0/0.1/0.5/1。完整投影在 0.40 m
触发时，小腿最小间隙从约 -2.363 mm 改善到 -1.221 mm，但球高从约
1.752 m 降到 1.573 m。S1662 在 0.50 m 触发得到 +0.183 mm，但球高仅
1.467 m，仍不合格；这个微小间隙也不能当成稳健性。

S1672 进一步将支撑腿和摆动腿的参考调整分开。只调整支撑腿时，门线点
约为 (-3.357, 1.750) m，间隙仍约 -2.327 mm。调整右髋三个关节时，
间隙约 +0.370 mm，而门线点约为 (-3.242, 1.457) m。这是有控制变量的
性能权衡证据，尚不是完整机理证明。
