# S80：G1 门将从低平球到真实高死角的闭环成长报告

日期：2026-08-24
边界：`SIM_ONLY`；没有启动 ROS/DDS、串口、CAN 或厂商硬件接口，没有向真实机器人发送命令。
物理裁判：CPU MuJoCo 数值轨迹；视频只重放已评分轨迹，像素不参与评分或晋级。

## 1. 本轮结论

本轮打通了同一门将候选在以下能力之间的稳定性—可塑性闭环：

```text
8 个冻结低平球旧技能
  → 中高左右球
  → 中路真实高球
  → 左右边角球
  → 1.4 秒快速左右边角球
  → 真实触球高度 ≥ 1.30 m 的左右高死角球
  → 每题发现运行 + 严格重放
  → 安全门 + 失败记忆 + 内容哈希
```

最终 38 次正式考试得到：

- 冻结低平球：`8/8`，通过率 `100%`；
- 必修空中球：`9/9`，通过率 `100%`；
- 1.4 秒快速边角前沿：`2/2`，通过率 `100%`；
- 真实高死角左侧：扑救成功，触球高度 `1.3268 m`；
- 真实高死角右侧：扑救成功，触球高度 `1.3921 m`；
- 两题最低骨盆高度分别约 `0.7001 m`、`0.7023 m`；
- 全课程安全率 `100%`，严格重放 `true`，失败记忆为空；
- 无门将关节越界、全局关节越界、力矩越界或执行器饱和；
- 结论为 `DEVELOPMENT_CURRICULUM_PASSED_NOT_PROMOTED`。

这里的“真实高”不是读取发射器的名义目标值，而是从 MuJoCo 接触帧的球心高度直接计算，并以 `contact_height_m >= 1.30` 作为硬门。

## 2. 为什么前一版看起来是高球，却还不能算高死角

早期课程把发射器的名义 `target_z=1.50 m` 当成高球标签。真实足球带有 `0.41 kg` 质量和自由关节线性阻尼，球在到达门将前还会继续下坠；因此左右角球的实际触球高度只有约 `0.97–1.15 m`。中路 GMT 专家确实在 `1.51 m` 触球，但不能据此声称左右高死角也已解决。

本轮因此做了两项修正：

1. 课程样本增加 `launch_vertical_bias_mps`，把更高的侧边球真正送到门将可观测、可接触的空间；
2. 每个高死角样本增加 `minimum_contact_height_m`，考试直接检查接触帧，不再相信名义配置。

这是一次重要的 ROSClaw Growth 纠偏：系统不仅要学会动作，也要发现“指标名字与真实物理量不一致”的自我欺骗风险。

## 3. 本轮小脑架构

门将不是一段按时间播放的补丁脚本，而是三类专家在一个因果路由器下协同：

| 威胁 | 专家 | 可见信息 | 写权限 |
|---|---|---|---|
| 冻结低平球 | S79 低球 Champion | 射门物理状态/旧时序契约 | 合格横移小脑 + 低位封堵 |
| 左右空中球 | 4×A6000 PPO Actor + 任务空间投影 | 最近 8 帧球、本体状态、历史残差 | 横移命令 + 有界 29 维残差 + 单臂 DLS 伸手 |
| 中路高球 | MOSAIC GMT 专家 | 因果拦截高度与到达时间 | 中路高球全身动作；与侧边 Actor 互斥 |

路由器只在以下条件满足时把控制权交给空中 Actor：

- 新来球经过因果分段，不能混入上一次传球或静止球历史；
- 当前球高至少 `0.30 m`；
- 估计来球速度至少 `2.50 m/s`；
- 预测拦截高度至少 `0.80 m`；
- 观测置信度至少 `0.25`，威胁热身至少 `0.04 s`。

低球不满足空中路由条件，因此学习 Actor 在 8 个低球回放中的任务空间伸手峰值严格为零；这正是没有遗忘旧技能的结构原因。

## 4. 从失败中长出的双侧迎球校准

最初 1.4 秒边角球的失败不是判断方向错误：

- 左侧可以触球，但偏转不足；
- 右侧来不及形成有效接触；
- 单纯提高伸手增益或缩短斜坡，只会扩大左右不对称。

三维轨迹复盘发现，G1 左右臂、当前步态相位和碰撞包络并不具有理想镜像。使用同一个手掌前后目标时，一侧会迎球，另一侧会追着球向门线擦碰。失败驱动搜索得到的安全校准是：

```text
左臂目标局部 x = -0.10 m
右臂目标局部 x = +0.10 m
```

工程上没有写成“遇到左球就播放动作 A”的案例补丁，而是增加通用参数：

- `actor_operational_space_reach_local_x_m`
- `actor_operational_space_reach_side_offset_m`

任务空间控制器根据因果预测选择解剖侧，并在 `[-0.35, 0.35] m` 总包络内投影。左右偏移、总和边界和非有限值均 fail-closed。这个能力可复用于任意需要双侧不对称接触的具身任务，而不是只服务足球。

## 5. 数据驱动成分与“训练”的准确含义

当前候选 Actor 来自 4×A6000 的在线 PPO/非对称 Actor-Critic 训练：

- 训练样本：`983,040`；
- 平均代理奖励：约 `0.3709 → 0.5544`；
- 最终 save proxy：约 `0.5087`；
- 最终 recovery proxy：约 `0.8540`；
- 四卡最大参数差：`0.0`；
- Actor policy：`sha256:208f57baf883e9a1ee837944d94b9727dc32174d38cfa8ce93513536618d32ac`。

MotionDecode 生成的 13 类门将动作库只用于训练先验/代理，不被冒充为真实门将标注。MOSAIC GMT 只负责其已经证明有效的中路高球区间。

本轮新增的左右迎球深度不是重新训练神经权重，而是“失败回放 → 安全权限候选 → CPU MuJoCo 物理选择”的 Growth 参数学习。换言之：神经 Actor 决定何时、向哪侧以及多大程度行动；通用运动学层把意图投影为当前 G1 可执行的肌肉记忆；物理考试决定新权限能否保留。

因此目前可以声称“数据驱动 Actor + 失败驱动持续成长闭环”，还不能声称已经完成高保真 MuJoCo 端到端力矩 Actor-Critic 在线训练。

## 6. 正式课程与硬门

正式课程包含：

- `LOW`：8 个 S79 三 G1 传球—射门—扑救旧技能；
- `MID`：左右 `y=±0.70 m`；
- `HIGH_CENTER`：中路高球；
- `HIGH_INNER`：左右内侧高球；
- `HIGH_CORNER`：左右普通边角球；
- `TRUE_HIGH_CORNER`：左右真实接触高度至少 `1.30 m`；
- `FAST_CORNER`：左右 1.4 秒困难前沿。

每题运行两次，只有结果字典和整条轨迹摘要完全一致才满足 `strict_replay=true`。安全硬门要求：

- 数值状态有限；
- 无全局或门将关节越界；
- 无力矩越界和执行器饱和；
- 门将最低骨盆高度不低于 `0.65 m`；
- 必须真实接触、阻止进球；
- 两个真实高死角还必须满足接触高度硬门。

这是开发考试，不是密封留出集，所以即使全通过也只允许 `DEVELOPMENT_CURRICULUM_PASSED_NOT_PROMOTED`。

## 8. 当前仍不能夸大的地方

1. 高死角硬门目前是球心接触高度 `≥1.30 m`，还不是接近 2 m 横梁的世界级飞身极限；
2. 视频与轨迹质检显示，两次真实高球更接近头部/上躯干封堵：接触帧目标侧手掌距球心仍约 `0.61 m / 0.68 m`。本轮证明的是高位阻止进球和稳定横移，不应宣传成双手飞扑；
3. 空中课程由确定性发射器产生，还不是另一名学习前锋在完整传球—射门链上踢出的分布；
4. 当前没有球速、质量、摩擦、PD、感知延迟的密封随机化留出集；
5. 门将没有在本轮展示摔倒后的自主站起与连续第二扑；
6. Actor 仍输出速度和关节位置残差，不直接输出真实机器人关节力矩；
7. 所有结果仅限仿真，不能推导真实 G1 安全性。

## 9. 下一步

1. 把目标侧手掌—球心距离加入硬门，先把当前头部封堵升级为真正的高举双手或飞扑触球；
2. 把真实高死角和 1.4 秒快速角球写入 nightmare replay，进入下一轮物理 Actor-Critic 训练；
3. 在 MJX/MuJoCo 多步动力学中联合学习横移、起跳、双臂接触、落地和二次扑救，而不是继续扩大位置残差；
4. 把学习前锋纳入同一联赛，逐步替换发射器，并保持发射器作为可重复单元测试；
5. 增加左右脚射手、旋转球、遮挡和感知延迟随机化；
6. 建立独立 sealed holdout；开发集通过后只能打开一次；
7. 将双侧任务空间校准抽象为通用 ROSClaw embodiment calibration，供抓取、推挡和双臂接触任务复用。
