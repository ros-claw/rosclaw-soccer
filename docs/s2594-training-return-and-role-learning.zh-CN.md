# S2594–S2604：场外回球与球员继续学习

2026-09-16，SIM_ONLY。落实用户提出的“出界后从场外将球丢回场内”。
这是显式训练辅助，不是球员掷界外球、正式比赛重启或自主比赛验收。

## 工程改动

新增独立 `world/training_ball_return.py`：依据已测量的全球出界、单调时钟
和球员位置提出有限次数的回球。默认等待 1 秒，从边线外 0.8 米高度以
向内 2 m/s、向上 1.8 m/s 释放，最多三次。释放点与各球员骨盆水平位置
保持至少 0.75 米；这不是全身碰撞几何认证。入场必须再次实际观测确认。
没有可用释放位置则等待，不消耗预算、不向球员体内生成球。

共享世界仅在显式启用该配置时改写球的释放位姿、速度，并清理过期的
球权、接球和射门租约以及球网内部状态。机器人位姿、关节状态、策略历史、
运动故障和全局时钟不重置。前后球状态和事件码逐帧记录。
辅助关闭时保留原配置摘要和行为；45–60 秒课程仅对显式回球模式开放。

回球由模拟器侧训练助手执行，不经过球员动作网络，不计为球员传球、射门或
学习奖励；不能用这一机制证明球队已经能够自主重新组织进攻。
足球规则与场景代码留在 Soccer 下游，没有把足球特例塞入 ROSClaw Core。

## S2600：真实 PPO 更新，而非只改脚本参数

两条不同动作采样种子的 45 秒物理课程，各独立重放一次，均完成且通过
原安全检查。仅在场外回球实际重新进入场内后开放六名非门将球员的
近球 12 维腿部残差探索；门将、原射门模型和接球专家冻结。
原有 0.10 rad 残差、0.02 rad 单步变化约束不扩大。

按“已观测入场→下一次全球出界”切成六段，合计 2460 控制帧。
场外释放、死球阶段不参与球员奖励，优势计算不跨越球位重置。
使用既有 `contact_safety_v1` 奖励与 `update_private_actors`，每角色四轮更新，
由 ROSClaw Core 的 PlasticityLease 约束本次可变角色和其他冻结组件。

| 角色 | 有效学习样本 | 本次是否更新 |
| --- | ---: | --- |
| 蓝中场 | 813 | 是 |
| 红后卫 | 308 | 是 |
| 红中场 | 543 | 是 |
| 蓝后卫、蓝前锋、红前锋 | 各 0 | 否 |
| 两名门将 | 冻结 | 否 |

不得说“八名球员都训练好了”。其他球员没有足够实际激活样本，是下一步
角色课程覆盖要解决的问题，不应强行用无效数据更新。

两条课程物理执行已结束后，汇总器因嵌套目录引用错误退出。修复外部实验
脚本中的参考路径，再从原始轨迹恢复缺失的课程元数据；没有重写物理轨迹。
恢复时逐帧重新生成 NumPy 随机数、动作、log probability 和 value，均完全一致。
原版运行器单独保留。S2602 再独立检查全部 4500 帧动作和 PPO 更新，复现
候选参数与 Core 租约审计。旧字段 `optimizer_replay_exact` 仅代表最终参数
精确复现，未导出或检查优化器内部状态；审计明确记录了这一限制。

候选仅为 SIM_ONLY 实验权重，不写入冠军、不自动晋升。训练回报变化不能
证明实战更强，需以原物理环境的确定性复测判断。

## S2604：候选实战复测不通过，保留原模型

更新后的候选在回球实际入场后接管近球残差，之前仍使用父模型。
45 秒课程独立执行两次，八人安全门通过，原始数组逐项精确重放。
首次回球前的原传接射门和扑救轨迹仍保持一致。

| 回球后活球阶段 | 父模型 | PPO 候选 |
| --- | ---: | ---: |
| 足部接触控制帧总数 | 4 | 0 |
| 球权控制帧总数 | 28 | 0 |
| 新增完整踢球选项激活 | 0 | 0 |

候选仍有蓝中场 1 帧、红中场 2 帧非足部接触，但这不能代替控球。
因此明确拒绝晋升，保留失败权重、训练数据及复测轨迹。不能把稳定站立或
PPO 参数确实变化包装成球技提升。全轮累计 10 次物理执行：S2594 四次、
训练四次、候选实战两次；独立审计和视频重放不额外计入物理实验数。

本次结果说明当前采样覆盖和奖励不足以证明有效再接球；还不能仅凭该对照
确定是奖励、样本量、局部最优还是上层站位导致失败。下一轮先记录球员
到球距离、相对速度、任务意图、足部接近和控球丢失时刻，按角色构建接球
失败课程。用左右方向、速度变化的配对验证考察“触球→留球→传/射”链路，
再考虑扩大训练规模。保留本轮已验证的场外回球基础设施，但不合入候选策略。

## 验证边界

新增回球单元测试 22 项通过，最终相关组合测试 37 项通过、3 项跳过；改动文件 lint、格式、
定向类型检查和 compileall 通过。全量测试 4272 passed、18 skipped、11 failed：
11 项为既有 S78/S79/S80/S94/S104/S105/S107/S108/S113/S114 历史证据问题，
没有放宽验证器或修改历史凭据来制造全绿。旧配置摘要测试手工构造字典时
同步排除新增的默认 None 字段，默认配置摘要本身保持不变。

当前仍为 CPU MuJoCo 训练课程，不是四卡大规模训练，也未在本轮新增
MotionDecode 模仿训练。保留原 3×2 米训练球门、半径 0.115 米/质量 0.41 kg
足球，不能宣传为成年正式比赛规格。扑倒后起身、多轮射门技能重新启用、
每个角色持续有效接应及新的完整进攻回合仍需要后续工作。
