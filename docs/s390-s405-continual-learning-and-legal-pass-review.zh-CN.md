# S390–S405：持续学习、遗忘复查与合法传球训练

结论：没有达到合格 4v4 比赛，也没有新的合格宣传视频。接球开发集分数增加，没有可靠转化为原连续仿真的成功；锚点巩固也未解决这一问题。已经实际调用 ROSClaw Core 的稳定性—可塑性门控，拒绝退化候选。随后把训练重点移到合法场内状态的跑位与触球联合学习，首轮仍未过关。

## 首先修正证据范围

S380–S399 的旧连续场景用于动作开发，关闭了出界终止。复查 S391 发现整球在 11.28 秒已经越过边线。因此 S388 在 17.658 秒真实接到队友踢来的球，确实是物理接球进展，但不是合法比赛中的接球成功。原始轨迹未改，早期报告已补充说明。此前 S369 在 8.942 秒的中场接球发生于首次出界前。

下表中的“连续场景”均指旧动作实验场景，不能读成合法比赛。CPU 16 例也是反复使用的开发基准，不是未见过的最终测试集。

## 接球继续训练与遗忘

| 阶段 | 实施 | 固定训练环境开发检查 | CPU 16 例 | 原连续场景接球 |
|---|---|---|---|---|
| S388 / S389 | 继续 PPO | 184/480 | 旧终段标准 5/16 | 实际脚接触且接稳；出界后 |
| S390 / S393 | 再做 32 轮 PPO | 288/480 | 旧终段标准 8/16 | 无脚接触，有非脚接触，失败 |
| S392 / S396 | 32 轮 PPO，加入接触相对时间窗和入球速度要求 | 361/480 | 加严标准 11/16 | 无脚接触，有非脚接触，失败 |
| S399 / S404 | 32 轮 PPO，每轮另做 32 步专家动作巩固 | 378/480 | 加严标准 10/16 | 无脚接触，7 个非脚接触采样，失败 |

新旧计分口径不能直接混算：原标准检查回合末尾 0.2 秒是否低速、近脚；加严标准还检查首次脚接触后 0.3–0.5 秒的稳定窗口，以及接触前球速至少 0.4 m/s。全程身体安全、无非脚接触仍为必要条件。480 个世界来自同一轨迹的 60 个身体相位及扰动，并不等于 480 场独立比赛。

S390 的 CPU 总数增加，却丢掉 S388 在身体帧 816 附近的成功案例。这是需要保留旧能力的直接证据，不能用平均分掩盖。

S397 从 S388 冻结教师重新生成训练数据，480 个回合中 142 个符合加严接球标准，保存 14200 对观测和专家均值动作。没有把 CPU 或连续场景评估轨迹拿来回放。S399 的巩固是独立的离策略动作模仿步骤，不冒充 PPO：11328 步 PPO 加 1024 步巩固，共 12352 步优化。第一轮 PPO 加巩固精确重放，全部参数误差为零，巩固期间 critic 与 logstd 保持不变。但实际接球能力未保住，因此没有采用候选。

## ROSClaw Core 确实拒绝了退化候选

S395 用未修改的 `ContinualCandidateEvidence` 与 `StabilityPlasticityGate` 比较 S388 和 S390。声明的关键接球任务从成功变失败，即使 CPU 平均分上升仍被拒绝。历史保持、回放覆盖等条件不满足，可塑性/自我一致性证明也不完整。

这是对声明的开发任务运行的一次真实 Core 门控，不是整场比赛验收，也不是“自我意识”的证明。结果为 REJECT，未调用激活、解冻或硬件路径。报告绑定当时源树和证据哈希，不能拿后续修改的文件替换原证据后宣称同一次验收。

## 出球学习中的失败也保留

S394 v2 从旧场景停球后的身体状态训练 136 维目标条件策略，16 轮中有 28 个训练回合满足定向出球要求，但固定开发检查最终为 0/128。源状态在出界后，因此只是动作训练。

S398 原计划再做 32 轮，只完成 17 轮，随后因观测校验失败退出。固定第 16 轮检查出现 8/128 合格出球，但这不足以部署。S401 从最后完整检查点恢复做了一轮，没有重现异常；这只能说明单次恢复成功，不能宣称根因已修复。失败日志和检查点保留，没有将 17 轮写成 32 轮。

## 合法场内与联合动作学习

S400/S403 恢复真实整球出界判定，并同步限制球员根部的场内导航。场内布局仍在 8.86 秒出界。约束减少了球员漂移，却没有改变球的错误出球方向。详见 [S400–S403 报告](s400-s403-pitch-rule-and-navigation-audit.zh-CN.md)。

S405 因此引入实验性 139 维观测、32 维动作 actor-critic：29 个关节目标残差与 3 个导航残差共同学习。使用前一帧步态基础目标，让网络先决定导航，再运行一次冻结 LSTM 步态基础，避免同一帧推进两次隐藏状态。新的网络与 Adam 从头初始化，不把旧 133/136 维权重硬塞进来。

- 数据来自 S403 合法场内第 220 帧、首次触球之前的真实身体状态；8 个目标/速度条件，每个 16 个世界。训练中随机扰动球的位置和速度；固定开发检查实际只有每条件 4 种 y 偏移、每种重复 4 次，因此是 32 种不同起点的 128 次计算，不是 128 个独立案例，且只有一个源身体相位。
- 关节残差仍限制为 0.25 rad、单步 0.025 rad；组合导航平移速度上限 0.7 m/s、转向 0.8 rad/s。它仍是残差策略，不是直接输出电机力矩的端到端小脑。
- 全程使用原 85% 力矩保护。非脚触球、身体失败或出界结束该回合的学习资格，物理仍继续，不暗中重置。
- 合格要求实际脚接触、出球前向速度为目标的 80%–120%、横向速度不超过 0.2 m/s，后续脚接触速度峰值不超过目标 125%，并且全程身体安全、无非脚接触、不出界。这还不是队友接球或完整比赛成功。

16 轮共 2048 个训练回合、512000 个控制步、2848 步优化。训练中出现 33 个合格回合，但固定确定性开发检查第 0/8/16 轮全部为 0/128；留在场内数量为 80/64/44，身体安全均为 128/128。没有改善，更不能用于宣传。

全部 16 轮检查点和 rollout 哈希、Core 学习租约审计通过；非脚接触后正奖励及继续学习计数均为零。139/32 第一轮优化精确重放；使用默认 133/29 配置重放旧 S392 第一轮也完全一致。这证明优化实现和兼容性，不证明足球能力。

## 下一步由失败指导，而非单纯延长训练

S405 的接触塑形主要减少前向速度误差，横向偏差主要依赖稀疏成功条件惩罚。下一轮显式使用二维目标速度向量误差，同时约束侧向偏移和过快出球。奖励只是学习提示，不改变成功阈值，也不替代实际脚接触、队友接球和合法整场验收。

当前还没有 139/32 多人运行适配器；新网络不能加载进原接球适配器。应先通过确定性和独立 CPU 检查，再实现与真实避让投影及单次步态推理一致的适配，最后回到未中断 4v4 仿真。不得用孤立训练成功替代这一链路。
