# 从局部避碰转向接触条件化动作生成

当前完整目标仍是自主连续球队比赛。此文件只限定下一项个体技能实验，不代表目标缩小或已完成。

## 已推翻的局部假设

本次实际验证了反应式、实测速度提前式小腿排斥；编码、原 NN547、实际目标和私有预测链路均
有物理与独立读回证据。但固定六场难例/保护集仍是 2/6 → 2/6、零 rescue。
这不是总体成功率估计，而是预注册的困难子集结果。停止该教师族的网格扩展。

排斥梯度只要求“小腿远离球”，并不同时要求“足部在正确方向首先击球、支撑不变、触后可继续行动”。
提前式已先于触球工作，仍使某例碰撞变差，因此不能再把全部原因归结为控制激活太晚。
也不能把静态几何间隙的线性可达性等同于受 NN、PD 和接触动力学影响的任务可达性。

## 下一项有界研究对象

优先检验“接触条件化的参考轨迹生成”，不是继续给实际 NN 输出叠固定偏移：

1. 使用当前真实身体、球和目标，以及当前原 NN 生成的私有未来，确定足部首先触球所需的空间/相位条件。
   不能输入未来记录、已知考试结果或源球位编号来决定当前动作。
2. 同时约束足部接触点/朝向、小腿球间距、支撑足及姿态。复用已有
   `ball_surface_tasks`、`bounded_joint_tasks` 和本地 Mink 参考实现，先检验 IK 可行性。
   不应把此前仅做单周期 held-target 预测的 `TaskSpaceKickPlayer` 直接当成新教师。
3. 将可行解形成连续、显式速度一致的关节参考，保留当前入口，处理准备—触球—恢复。
   参考属于任务命令，不是直接改实际根状态、球位置或执行目标播放。
4. 原始 NN 每 20 ms 读取自己的当前身体，再通过原生 PD 执行。新参考必须先在原生
   物理预测和完整实际回合中有一致性证据，才能比较救回失败和保持旧成功。
5. 只有多状态及扰动 teacher 有效，才进行学生模仿/DAgger 和有限三种子 RL。
   训练量不能代替有效任务权限，模仿损失不能代替实际考试。

若参考 IK 在原始关节范围内不可行，或完整 NN 不能跟踪这一接触流，则保留失败并评估
已有的接触条件化跟踪器，而不是无限增大偏移。
新的动作权限必须明确声明；不得偷偷改变关节/力矩限制、球体尺寸、物理参数或正式考试。

## 可复用资产，不需要重新下载大项目

本地已有 OmniContact 作者实现及 `policy.onnx`、`kick_50k.onnx`。静态检查显示其输入
是 `obs[1,1244]` 与 `time_step[1,1]`，输出含 `actions[1,29]` 及参考身体/物体/接触信息。
这只是模型结构检查，不是本项目的执行通过。

其输入由 5 帧 141 维历史与 11 帧 49 维任务参考组成，与 RoboNaldo 的 547 维协议不同，
不能只替换权重文件。接入前要检查关节顺序、归一化、身体/球尺寸、时钟、目标编解码、
异步规划线程与可复现性，以及无 ROS/SDK 的纯 SIM 依赖边界。

仓库已有 2v1 战术 Actor、训练、完整身体桥接。后续保持与个体技能实验独立：
