# S1450：不拖慢参考挥腿的历史策略候选

S1437 原生复核显示，直接对完整动作均值做历史平滑并未提高成功率。
rho=0.5 的固定考试只有9/12完整回合，3条出现非脚部碰球。
因此不能把“动作更连续”的数学形式直接当成自然、安全的动作。

新候选 `training/reference_relative_kick_learning.py` 使用显式状态：
当前554维特征，加上29维“上一次采样动作减上一次冻结参考均值”。
条件均值为当前网络均值加 rho 倍这段偏差；不做采样后动作过滤。
原身体历史仍必须来自实际应用的目标，不得混用原始采样动作。

冻结参考必须独立于学习器，参考模型、输入及历史要能审计。
不能换成不断更新的当前学习器均值，否则状态转移的定义也会改变。
首次进入学习窗口，以及未取得踢球控制权时，历史显式清零。

初始化时，确定性学习器与冻结参考相同，历史偏差精确为零，所以
不同 rho 都不会拖慢原本快速变化的参考动作。训练之后均值变化
也会进入该偏差，仍可能累积、失稳，必须重新验证；这里不承诺
训练后轨迹保持不变。logstd 是条件创新噪声，不宣称不同 rho 的
平稳边缘噪声相同。critic 仍只使用原身体/目标基线。

14项测试覆盖输入、历史重置、四个rho的确定性均值与批处理一致性、
真实条件高斯 PPO 更新、冻结模型不变。该候选使用独立schema，
不能仅凭同为583维就与旧绝对动作历史模型互换。

目前仅数值候选，不是训练成果、物理稳定性证明或宣传片资格。
S1442精度学习对照继续运行，不改变其已开始的配置或证据。
