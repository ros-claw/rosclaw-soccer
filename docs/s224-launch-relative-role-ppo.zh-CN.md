# S224：把有效触球接力合约用于八角色在线采样与 PPO 续训

## 固定实验协议

- 父 checkpoint：S221 第 48 代；4 次完整的八角色更新，目标第 52 代。
- 每代双方各四角色开球，共 8 个采样回合，12 秒，重复 CPU MuJoCo 仿真。
- 保留冻结步行底座、12 维腿部残差、逐角色 Core PlasticityLease 和速度约束。
- 每段数据必须声明并实际使用 launch_relative_foot_only_v1 合约。
  审计同时核验采样、奖励和验收的任务接力配置；不同合约不能混算。
- 训练球位沿既定课程；验收采用双方四角色 ±0.10 m，每代父子各 16 场，
  均关闭探索噪声。该组球位不参与本轮更新，不能用验收反馈回头选本轮参数。

新增单元测试构造了准备 2 秒、踢出 2.5 秒后接球的轨迹：新计时合约只给
传球者和接球者各 +1，其他六人不获得完成奖励；中间非脚碰球则没有奖励。
浮点数组伪装成布尔合约标记也被拒绝。

视频区分 WORLD SAFE 与 FOOT CONTROL 状态，避免身体没有倒下却小腿碰球
的回合被一个笼统的 SAFE 标注误导。视频不用于验收，也不触发策略晋升。
