# S786–S804：实际入场学习与接球路径闭环

## 边界

本阶段仍未达到完整 4v4 宣传片标准。没有发布新宣传视频，没有晋升候选，也没有放宽 3 m/s、0.1 m、身体安全及非脚接触验收。以下“精度”仍指既有虚拟 XY 目标平面，并非高球死角或实际进球。

## 实际入场的 PPO 学习，及原生物理复核

S786 使用 S763 实际走到的身体/球状态，中心 -0.36 rad、偏移 ±0.1 rad 的明确参考配置，128 世界、32 次 actor-critic PPO 更新。动力学仍是已声明不满足严格 CPU 等价性的近似 GPU 训练域。

| 验证 | 速度合格 | 精度合格 | 平均虚拟平面误差 |
| --- | --- | --- | --- |
| S786 训练域初始评估 | 93/128 | 0/128 | 0.71405 m |
| S786 最终评估 | 128/128 | 0/128 | 0.64634 m |
| S793，原生 CPU 对照父模型 | 19/32 | 0/32 | 0.70947 m |
| S797，原生 CPU 新模型 | 32/32 | 0/32 | 0.64438 m |

S793/S797 使用完全相同的初始状态：1 个实际入场状态及 31 个新扰动。两个模型的身体安全均为 32/32、非脚接触均为 0。S798 独立核对显示，19 个原有速度合格样本全部保留，新增 13 个，31 个样本误差下降、1 个上升。

这是实际入场域的一项有限改进，**不是精度成功，也不是完整比赛成功**。

S786 的 32 次优化器精确重放、65 条微步物理重建、65 条延迟奖励检查通过；最大奖励回报重建差约 9.16e-7。另用独立 NumPy 公式核对全部 32 条训练回合、各 200 帧的动作滤波、参考朝向、观测历史与记录，最大差 2.98e-8。运行接口及测试见 [冻结小脑参考契约](s773-frozen-goal-motor-runtime.zh-CN.md)。

此前 S782 增大探索的 32 次更新最终仍是速度/精度均 0/128，平均误差 0.59102 m；优化器、微步与奖励审计均通过。它没有被挑选为成功策略。

## 回到共享世界：避免小腿挡球，而非移动仿真身体

S791 保留 S763 的等待位置与向前追球，来球越过身体的场地 X 平面后，才逐渐加入从合格课程统计出的横向走位修正。仍通过原步行策略、原 0.3 m/s 横向上限、避碰和原力矩约束执行；没有修改身体/球状态。

S802 复核：

- 全部 6 个场上球员及球的预控制 q/qvel，在第 0–436 帧与 S763 逐值一致，第 437 帧才开始变化。
- 本次每控制帧接触账本没有前锋的非脚碰球记录；此前 S770/S778 的右小腿碰球没有在该账本重现。这不是独立的碰撞几何重算证书。
- 8 台身体安全，无电机故障，但仍没有启动已准入的射门。
- 第 446–452 帧，其它射门几何条件、SHOOT 意图和争球者提名均满足，前进速度却约为 0.059–0.086 m/s，处于原“站稳 ≤0.05”与“跑动 >0.1”两个已定义域之间。

没有因此直接扩大准入域。先用这些真实状态继续做独立物理试验，避免把更宽的 if 条件当作技能成长。

### 教师推理差异必须区分层次

S807 将 S805 的 CPU 教师换为 CUDA 教师、保留原生 CPU 物理，严格闭环等价检查**失败**：接触前缀最大速度差 0.17108，超出原 0.01 阈值。标签一致、平面误差差值较小，不能抵消该失败。

S809 固定回放相同身体状态，但两套教师各用自身预测动作维护历史，最大关节目标差 0.08151 rad，也未通过。相同物理输入不等于相同完整神经网络输入。

随后只做诊断，不修改教师代码或阈值：

- S811：把完整 CPU 编码器/解码器输入交给 GPU，包括 CPU 的历史动作和 token。编码 token 逐值一致，解码动作最大差 2.80e-6，通过 1e-5 的组件检查。
- S812：检查原有批量编码特征构造。速度/姿态特征存在约 1e-6/1e-7 的差，但全部编码 token 一致，没有证据支持用修改特征精度来解决当前问题。

因此保留 S807/S809 的失败状态，不把组件检查包装成闭环资格。差异可能沿动作历史和接触反馈放大，尚未定位为某个已证明的软件缺陷。

S810 正在进行单独声明的**近似教师 + 近似 GPU 物理**训练：256 世界、计划 16 次 PPO 更新，S791 第 451 帧、参考中心 -0.1 rad、原偏移/关节/力矩限制。它不是失败等价检查的重试通过，也不改变默认运行后端。所有导出候选仍须原生 CPU/CPU ONNX 新扰动考试、恢复复核及共享世界验证。当前不得据此宣称达到宣传标准。
