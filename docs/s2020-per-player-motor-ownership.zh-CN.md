# S2020：每个球员独立的神经运动执行槽

## 原因与边界

旧 rolling option 桥接在任何一个球员动作未结束时，拒绝所有其他球员的
PASS/SHOOT 动作。每个球员虽然各有策略状态，执行仲裁仍是全场单槽。
这不符合传球、接球和对抗可能重叠的比赛要求，但不能据此认定它就是当前
传接球失败的主因。

新增默认关闭的 `per_player_options_enabled`，必须配合不可变任务目标绑定。
开启后，动作目标、策略帧、关节输出、足部接触归属都按球员隔离。
球权、站姿、朝向、接收承诺与再次入场门控仍然有效。没有移动球或机器人根节点，
没有给球附加演出轨迹。旧配置哈希保持不变。

并行动作不再挤进一个标量赢家：原标量在多动作同时存在时为零，新增逐球员
活动掩码和目标列。PPO 接触奖励与失败诊断读取各自的目标，缺失或无效列拒绝。
这是 SIM_ONLY 工程能力，不是候选晋升，也不是新的学习成绩。

## 真实对照

证据目录：`/home/dell/rosclaw_soccer_evidence/`。
冻结 S1954 g004 参数，真实八台 G1、25 秒 MuJoCo，并分别精确重放：

| 对照 | 公共列 | 改变列 | 多人动作重叠帧 |
|---|---:|---:|---:|
| S2016 中央 → S2020 legacy | 180 | 0 | 不适用 |
| S2020 中央 legacy → parallel | 180 | 0 | 0 |
| S2016 蓝门将后场 → S2020 parallel | 184 | 0 | 0 |

对应 `s2020-centre-legacy-v1`、`s2020-centre-parallel-v1`、
`s2020-blue-keeper-parallel-v1`。配置开启本身未增加实战动作，说明这些
场景还没有第二名球员满足运动入场条件。不能把测试中的并行入场成功等同于
比赛里已经出现连续配合。中央案例仍然是单次射门，没有通过完整比赛门。

定向测试覆盖：别人的恢复不阻塞新持球者、默认旧行为保留、逐角色目标隔离、
坏证据拒绝、两个同时动作都进入失败诊断，以及反方向接触奖励的正确归属。
下一步必须在训练/考试协议中显式绑定执行模式，观察有效接收后的动作入场，
而不是继续只增加中央单次射门的训练次数。
