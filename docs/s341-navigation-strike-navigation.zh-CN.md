# S341：跑动—射门—继续跑动的神经历史闭环

本阶段完成同一球员的 SONIC 导航、射门、重新导航之间的历史交接，
不是完成了合格的 4v4 比赛。未替换全局冠军，未提高速度或安全限值。

## 实施

新增导航 `start_from_history`：只能初始化全新实例，使用已有全局时钟，
边界帧既不重置导入的十帧本体历史，也不重复添加观测。
射门之前使用 `handoff_to` 退役旧导航。交接异常锁存故障，不允许重试
污染历史。蓝队的推理坐标旋转必须显式开启；世界线速度旋转，自由关节
局部角速度不旋转。两侧物理状态均不改写。

## 八体实验

红、蓝各比较启用/不启用射门后历史导航，四个条件各实际重复一次，
共八次 20 秒 MuJoCo CPU 八体实验。继续使用旧慢速域 S286 actor-024
和 reference 29，不把单体快速射门模型直接晋升到共享世界。

- 四组轨迹逐值精确复现；八次身体安全，零机器人间接触，无运动接口故障。
- 候选在全局帧 308 恢复导航，后续执行 692 帧，即 13.84 秒。
- 首次射门球速约 3.931 m/s；本次只执行一次神经射门，不宣称重复技能已完成。
- 红队踢后路程 5.716→6.134 m，蓝队 4.908→5.104 m。
  基线也会通过已有后备控制走动，因此不是从“静止”变成“会动”。
- 所有条件均无真实接球，完整比赛门控全部失败。球最终出界。
  更多跑动不代表更好的足球。

## 失败定位及下一步

射门入口时，对方后卫距球到目标球门的线段仅 0.140 m，位于线段约
42.8% 处；随后 3.26 秒时首个非脚触球体确实为对方后卫。两边镜像一致。
下一步检验受阻射门时的可用传球选择，不通过移除后卫或修改碰撞体制造成功。
这属于基于失败证据的决策改进，不应称为新增强化学习训练。
