# S2430–S2458：成功经验巩固、适用范围与技能交接

日期：2026-09-16。全部为 SIM_ONLY；没有硬件执行，没有替换比赛冠军策略。

## 结论先行

这轮确实把两条在线探索中的成功经验，分别训练成了关闭探索噪声后仍能通过物理考试的神经网络动作。组合后的接球专家在五个公开开发位置中通过 **3/5**，五个位置均保持全队安全。此前这组位置只有标称位置通过。

但这不是稳定自主比赛的突破，也不是未见场景的泛化成绩：新增通过的两处位置都用于训练，距离变化只有 5 mm，其他位置仍失败。一个通过样本的末段脚球距离为 0.3438 m，距 0.35 m 门槛仅约 6 mm，余量仍很小。

延长仿真后，学会接球的队伍仍未形成合格射门，19.62 秒时球出边线。没有合格的连续比赛宣传片；不把短课程、训练样本复现或拼接录像当作连续比赛。

## 1. 学了什么，没学什么

沿用冻结的 RoboNaldo G1 行走底座和原接球动作锚点；不是重新训练全部关节力矩策略。

- 当前状态包含原接球特征、接球事件、实测脚球相对位置及速度、独立的可学习区域标记，共 150 维。
- 新神经网络为 149 → 128 → 29 的 Tanh 反馈头；仅反馈头参与本轮离线模仿，父动作网络不变。
- 网络输出仍经过已有的关节残差幅度、逐步变化、平滑和实际电机保护；没有直接改机器人根位置、足球状态或碰撞体。
- 在线 PPO 更新的是反馈 actor 和 critic；成功经验随后进入离线 actor-only 模仿。不能把后者称为在线 PPO。
- 原成功轨迹附近禁止反馈学习和探索执行，以保留标称成功动作。这个保护只覆盖已记录的支持区域，不是对所有已有技能的普遍保证。

## 2. 在线 PPO 的真实结果

S2430 完成 3 代，每代 16 个训练课程、5 个无噪声考试课程。

| 项目 | 实测结果 |
| --- | --- |
| 探索训练 | 48 个课程、8400 个学习控制帧 |
| 无噪声考试 | 15 个课程 |
| 实际 CPU MuJoCo 执行 | 126 次：每个课程主执行与重复执行各一次 |
| PPO 更新 | 每代 28 步，共 84 步；每次更新另有确定性重算 |
| 探索中的接稳样本 | 各代分别 1、1、0；总计 2/48 |
| 各代无噪声考试 | 均为 `[通过, 失败, 失败, 失败, 失败]` |
| 原标称成功动作 | 每代物理轨迹均与保护参考完全一致 |

因此 **PPO 本身没有获得新的确定性通过位置，不晋升**。2/48 是这组重复开发条件中的探索结果，不是泛化成功率。

独立审计重新校验 126 个物理记录文件，重算接球结果、身体/碰撞安全、训练批次及学习掩码；安全加载优化器状态并重放更新，权重、优化器、随机状态均精确一致。冻结底座及其他策略的哈希保持不变。

审计脚本的初版有两个自身错误，失败记录保留：误要求未被激活的对手接球器也必须有起始帧；在加载对照模型消耗随机数后才比较优化器后的 RNG。修正为明确检查 `NO_ADMISSION`，并在更新完成时立即保存 RNG 后，v3 审计通过。没有改训练数据或放宽物理判据。

## 3. 成功经验如何成为神经网络动作

两个实际成功样本来自同一连续共享世界，传球不是手工设置的球速：

- `train-001-05`：前锋初始 X 位移 −0.005 m。
- `train-002-03`：前锋初始 Y 位移 −0.005 m。

它们均经过两次真实物理执行，记录完全一致。模仿只使用真正执行了探索动作的状态—动作对；忽略了的随机样本不充当训练目标。

第一条经验的有限拟合对照：

| 拟合步数 | 训练 MSE | 无噪声物理考试 |
| --- | --- | --- |
| 128 | 0.0053245 | 失败：末段脚球距离过大 |
| 512 | 0.0034079 | 失败 |
| 2048 | 0.0008655 | 通过；脚球距离最大 0.3438 m |
| 8192 | 0.0000445 | 失败；脚球距离最大 0.3571 m |

前两组有 0.1 锚点正则，后两组没有；不是仅比较训练步数的单因素试验。2048 和 8192 两组的目标及其余设置相同，结果说明更小的训练误差并不保证更好的物理闭环。

第二条经验也在 2048 步时通过，8192 步未通过。所有拟合均独立重复，参数和损失精确一致。选中的两个反馈头均为训练后固定参数、无随机探索运行。

## 4. 为什么不能直接全局替换

第一个 2048 步网络在其他三个位置的考试全部失败，其中两个出现全队安全失败。接球器自身局部得分不是唯一安全标准，其他球员也计入。

因此增加的是**适用范围与组合实验**，不是把这个候选直接设为默认：

1. 在第一次进入允许反馈的实时状态时，用 149 维观测与已验证的入场状态比较。
2. 仅在预先声明的特征空间 L2 半径 0.01 内选择对应专家；0.01 不是米。
3. 本次技能内锁定选择；区域外使用原冻结动作，不盲目外推。
4. 每个机器人实例拥有自己的选择状态，没有共享运动控制状态。

这仍是非常窄的适用范围。专家组合只在五个已公开开发条件中验证，未作为产品默认能力发布。

S2454 的组合结果：

| 初始位置变化 | 实时选择 | 接球 | 全队安全 |
| --- | --- | --- | --- |
| 标称 | 原动作 | 通过 | 通过 |
| X +5 mm | 原动作回退 | 失败 | 通过 |
| X −5 mm | 第一个神经网络专家 | 通过 | 通过 |
| Y +5 mm | 原动作回退 | 失败 | 通过 |
| Y −5 mm | 第二个神经网络专家 | 通过 | 通过 |

三个成功条件的整段物理轨迹与各自先前合格记录完全一致；不是只有最终分数相同。

另外做了状态检索记忆对照：按实时状态寻找成功动作、继续走原电机控制，而不是按时间回放姿态。它精确复现两条原成功物理轨迹并保留标称成功，结果同为 3/5。这个对照是非参数模仿，不是新训练的神经网络；用途是区分样本不可复现与神经网络拟合问题。

## 5. 为什么还不能宣传连续比赛

S2444 将标称条件与新 X−5 mm 条件分别运行到最多 25 秒，不插入中途重置。两者都保持全队安全，接球都通过，但提前因足球出界结束：

| 条件 | 实际持续时间 | 结束原因 |
| --- | --- | --- |
| 标称 | 15.70 s | GOAL_LINE_OUT |
| 新学会的 X−5 mm | 19.62 s | TOUCHLINE_OUT |

新条件在约 13.18 秒有前锋再次触球，随后又发生接触与反弹，未形成合格射门。接球后的较长间隔和二次接触也是下一段需要解决的问题。

原共享世界报告中的 `passed`、战术 `shot_intent_count` 和 `all_roles_autonomous` 都不等于成功射门或合格连续比赛。本报告不把意图计数当作实际足球动作成果。

## 6. 本次提交的通用接口改进

`NavigationObservation.motor_option_retired` 是本地运动选项的只读生命周期状态：

- 默认 `False`，严格要求 bool，随同其他观测重新校验；被篡改时提供者调用前即拒绝。
- 数据来自该角色已经被运行时验证的选项退出记录，不来自学习器自称完成。
- 导航在本控制帧的电机处理之前读取，因此看到的是截至前一控制帧的退出状态；物理验证对此做精确比较。
- 退出不代表成功、不授予运动权限、不自动触发下一技能；仍须结合实际任务证据。
- 坐标半转保持生命周期状态不变；不交换左右肢体名称。

S2458 对新 X−5 mm 长课程做两次真实执行：981 帧生命周期观测一致，216 项既有轨迹数组与修改前完全一致。仅新增只读信息，没有改变动作。

该接口供技能交接使用，不写死足球、球星、某只脚或固定第几秒开始行动。当前学习器与专家组合仍是证据目录中的实验原型，没有把这些窄条件模型全局激活。
