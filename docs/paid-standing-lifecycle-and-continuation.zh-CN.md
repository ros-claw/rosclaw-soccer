# 持续身体反馈与可恢复实验接续（2026-10-22）

这是足球运动能力的局部物理研究，不是连续比赛验收。所有内容仅限 SIM_ONLY。

## 发现、排除与当前方案

先前的神经踢球控制在参考结束后，转为保持最后关节目标。关节 PD 仍然运行，
但身体层不再重新感知、推理和修正目标。逐段证据发现，一些身体在网络结束时
非常稳定，却在这个保持阶段失稳。两状态成功的根部反馈增益也未能泛化到完整
DEV 条件，因此没有继续堆同类增益搜索。

新方案复用已经数据训练过的 R2 全身循环运动网络：读取关节位置/速度、身体
重力方向/角速度、上一实际动作及球/目标的本体坐标，在每个控制周期输出
29 个关节目标，经原有 PD 和力矩上限推进物理。每个机器人应有自己的记忆；
本次先在单机器人连续技能链验证这个基础。

每次踢球的参考结束后，进入单独命名的站立任务。站立目标为此前实际采用的
最后关节参考，期望关节速度和角速度为零；并不是延长或重复原来的运动数组。
循环记忆从同一身体、同一网络的实际踢球过程继承，落球等待期间也继续推理。
下一次踢球明确重置自己的技能循环记忆，同时保留实际身体与上一动作。

本轮没有新的 Adam/PPO 参数更新。改进若成立，属于已学模型复用和控制
生命周期修正，不能计作新一代强化学习增益。

## 完整 TRAIN16 结果

每个条件从世界起点完整执行两遍；这是 16 个条件的重复验证，不是 32 个
独立训练样本。三组使用相同物理身体和冻结权重，预先声明控制组合：

| 方案 | 完成三脚且全程身体未失败 | 三次站立终态稳定检查 | 第一/第二/第三脚粗球路质量 |
| --- | --- | --- | --- |
| 固定末目标，三脚 R2 | 0/16 | 2、0、0 | 16、2、0 |
| 持续神经站立，三脚 R2 | 16/16 | 16、16、16 | 16、14、6 |
| 持续神经站立，首脚 R2、后续 R6 | 16/16 | 16、16、16 | 16、13、7 |

没有把身体稳定等同于球踢得好。第三脚质量仍明显不足，R6 也没有统一胜过 R2。
粗球路要求包含正确脚先触球、完整 1.2 秒观察、前进至少 1 米、侧偏至多
0.75 米、身体后退至多 0.05 米、没有另一脚干扰或非法接触。它不是用户要求的
0.1 米高死角射门，更不是守门、传球或 4v4 能力。

三组独立读取审计均通过，分别覆盖：

- 原生物理子步：126000、332920、332920。
- 实际网络推理及审计方逐步重算：8950、33292、33292 次。
- 每组 32 个完整世界执行、全部原始数组与独立重复一致性。
- 160 维观测由独立 MuJoCo 几何读取器重构；无重新积分物理。
- 每个控制周期的私有记忆、输出，以及每 2ms 的原 PD 力矩关系。

因此这里的审计不是另跑一次独立求解器积分；物理重复由实验方的完整世界
重复提供。审计方没有声称执行新的原生物理步。

原始实验根目录为 `rsi-paid-neural-standing-train-v{0,1,2}-20261022`，
通过的审计根目录为 `rsi-paid-neural-standing-train-audit2-v{0,1,2}-20261022`。
它们在外部 evidence 根目录，不进入 Git。

初版审计将旧踢球原始数据的七项入口状态误当作十项完整快照，导致失败。
失败报告保留在不带 `audit2` 的审计目录；修正后审计同一份物理数据，未重跑、
未改动或补造原始轨迹。完整十项手交接快照单独检查，旧踢球入口严格检查
实际存在的七项字段，并核对外部力、目标和激活终态。

## Agent loop 的实际保证与边界

`rsi_continue_paid_standing.py` 是有限、预声明的实验接续器，不是另一个能够
自主改代码的智能体。它只执行固定的 SIM 实验与审计模块，没有任意 shell
命令配置、自动晋级或硬件动作权限。

接续链是：三个 TRAIN 审计通过 → 两个神经站立方案均达到 TRAIN16 稳定 →
逐一执行三个完整 DEV16 方案 → 每个方案独立网络/原语审计 → 留下待分析结果。
DEV 得分差是正常研究结果，不因此删除失败或反复重抽条件。

保证机制包括：

- 冻结源码并记录提交；开始和结束检查源码/输入证据没有改变。
- 对照完整报告内容、输入报告哈希和实际网络/物理计数，不凭进程存活或退出码。
- 文件锁避免同一个队列并发重复启动；阶段开始记录和日志先于执行落盘。
- 已闭合阶段只复核，不重复分配物理；不完整阶段保留并交由 Agent 诊断。
- 失败不自动重试同一个实验，不自动改变考核，完整失败经验不会丢失。
- 后续版本为单阶段设置两小时上限，保存超时/子进程失败记录；这是保险上限，
  不是用时指标。最早已启动的冻结队列不热修改源码，仍以它自己的声明为准。
- 全局研究目标保持未完成，有限队列结束后仍需 Agent 分析并选择下一轮机制。

定时存活观察器不能替代研究决策；后台队列也不能保证任何学习算法必然突破。
需要同时有实际实验接续、持久化恢复记录，以及产品层的 Agent 目标继续机制。

## 下一步与推翻条件

先看冻结 DEV16 的全部结果，而不是依据 TRAIN16 宣布泛化成立。若 DEV 身体
仍显著失败，要定位发生于踢球、站立还是落球等待，以及观测/构型适用域，
不能直接把本轮控制器接入整队或真实机器人。

如果身体稳定在 DEV 也成立，下一步使用新的稳定后继状态研究第二、第三脚的
接触精度与接近动作，收集成功/失败数据、训练适用的策略，并保持旧成功与
隔离 Fresh 考核。不得将两秒诊断站立等待带入宣传片后伪称一气呵成。

长期仍需把持续身体反馈接入每个角色的技能生命周期，把已验证的能力和
不确定性供团队策略使用。足球专用动作留在 Soccer；通用生命周期、恢复、
证据与研究决策协议才适合在干净 Core 工作区反哺 ROSClaw。

PAiD 派生资产的非商业研究许可仍然有效，本轮没有商业宣传授权。

## DEV 完成及下一项接触诊断

冻结参数后的 DEV16 已由有限队列自动执行完三组实验和三组独立审计。
两组神经持续反馈方案均完成 16/16 三脚且身体未失败，三次站立的终态检查
也均为 16/16；固定末目标对照组全链稳定仍为 0/16。

| DEV 方案 | 第一/第二/第三脚粗球路质量 |
| --- | --- |
| 固定末目标，三脚 R2 | 14、3、0 |
| 持续神经站立，三脚 R2 | 14、12、7 |

这支持“保持身体反馈”在这两组已消费的条件银行内有效；不支持 R6 总体优于
R2，更不支持 Fresh、动态比赛或高死角精确射门已经解决。

新的严格原生重放从完整十项状态开始，分别重放全部 TRAIN 后首脚阶段：
站立、落球等待、第二/第三脚及其站立。每组 224 个阶段、256720 个实际
原生物理子步，全体 q/v、接触力和完整终态逐数组一致。首脚没有在这项重放
中重复执行；各阶段是独立入口恢复，不冒充额外独立的完整比赛。

重放找到第三脚的重要失败机制：球已经由正确脚踢出，随后又接触同侧
`left_knee_link` / `right_knee_link`，被正式评分拒绝。这是脚触球后很短时段
内的真实膝部/小腿接触，不是身体摔倒，也不是地面碰撞；原来的三通道力
记录不足以直接指出具体部位，现在由逐步复现的原生碰撞对确认。

两个预声明困难来源（TRAIN 条件 2、3 与 10、11）的局部研究使用每对条件
共享的有界脚部笛卡尔位置/姿态意图。三组 CEM 随机种子均完成：每组 104 个
分支执行、4 次分布更新，候选和失败全部保存。选中教师在四个诊断状态均
达到粗质量合格、无非足接触且后续神经站立稳定；原始基线是 0/4。

这是特权复合教师搜索，没有新的神经权重更新。三个种子不是三个新神经
小脑，也不是 12 个独立初态。每次分支明确从已经审计的第三脚入口恢复，
未把状态恢复伪装成连续比赛。完整候选的独立网络、IK、原语和 2ms 物理
重放审计已在三个种子上全部通过，覆盖全部 104 个分支，不仅是选中动作。
审计方分别实际积分 306640、312060、328300 个物理子步，执行 30664、31206、
32830 次自己的网络推理；均与实验方实际工作计数一致。CEM 提案、精英选择
和分布更新也重新计算一致。

已预先固定第 0 个种子进入完整 TRAIN16、DEV16 扩展验证，而不是在 DEV 上
选最优种子。两个受训来源采用各自跨两条件共享的固定意图，其余来源保留
原策略；每个实际第三脚入口完整重复两次。这个按已知运动来源应用的教师
仍然不是通用神经策略，只有在扩展结果和独立审计通过后，才适合继续构造
接触条件化学习数据。不能重蹈双状态增益成功就宣称泛化的错误。
