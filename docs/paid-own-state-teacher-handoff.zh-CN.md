# 从学生实际状态接管的教师验证：DAgger 前置实验

本实验仅限 SIM_ONLY。所有动作、模型和数据仍为研究用途，不能授权真实机器人或自动
晋升；教师接管后的成功不是学生策略自身的成功，也不能用于宣传学生已经学会。

## 已有证据与转向理由

纯离线全轨迹拟合曾降低缓存误差，但学生闭环在触球时已经离开有效区域。完整自身
网络重算确认了这一点。缩小为活跃状态支撑、精确保留零修正前段后，新 TRAIN20 仍为
`[12,18,16]`，重点首脚案例 4/5 仍失败，低于既有编排 `[12,19,16]`。停止支撑变体，
不再通过调半径、换门或降低门槛继续同族试验。

接下来的问题不是“教师旧轨迹上该输出什么”，而是“学生实际偏离到这里，教师还能
不能把球踢好”。不先验证这个问题，就不能把教师同时间索引动作当作正确的新标签。

## 控制接口

`PaidResearchBench` 增加可选的 `causal_transform`，默认旧路径不变。宿主在每次同一
球员神经前向后提供 `CausalMotorContext`：当前周期、自身观测、自身 h/c 前后状态。
数组采用不可写字节存储，与网络状态不共享可变内存；跨球员、跨周期使用拒绝。

学生网络一直运行自己的递归并提出动作。教师读取该状态，通过同一冻结 R2 的动作头
恢复当前 R2 名义动作，再用原 `FootTaskSpaceIntent` 在当前身体姿态上求 IK。教师从
预声明的宿主周期开始替换实际执行动作。没有重置身体、传送球、借用旧教师 h/c，
没有在学生网络中隐藏接管计数器。研究用教师可使用当前仿真状态；这些特权不能成为
学生模型的推理输入。

每个周期都保存学生原提案、R2 名义动作、教师建议、是否实际接管、周期与 IK 细节。
未执行的教师建议只能称为反事实标签。宿主拒绝改写实际仿真状态、非有限动作、
错误 dtype/维度和复用状态。最终相对 R2 的每关节 0.2 rad 权限不变。

## 固定物理对照

沿用已完整独立审计的 seed0 CEM 教师，以及未通过晋级的 seed0 学生。两组原始 TRAIN
来球（案例 4、5），每个分支两次完整重复；不使用 DEV 或已消费的 Fresh。

原教师相位中心为 104、原动作参考长为 289。固定五个分支：

| 分支 | 接管周期 | 作用 |
| --- | ---: | --- |
| teacher | 0 | 已知物理成功的正对照 |
| phase_start | 62 | 原教师动作开始前接管 |
| middle | 80 | 学生执行了一段接触动作后接管 |
| late | 96 | 更晚接管，检查恢复范围 |
| student | 289 | 参考段内不接管，原学生负对照 |

边界由原教师相位的 `center-42/-24/-8` 固定推导，不根据新试验结果挑选。共 20 次
执行，至多 77800 个原生 2 ms 步；每次执行第一脚后继续用自身 R2 h/c 站立观察
100 个周期。合法身体失败保留，不能以异常掩盖。两次重复不增加独立场景数。

零接管分支必须逐字节复现原学生轨迹；立即接管分支必须复现原教师的实际动作、
物理轨迹和自身记忆。后者的“学生原提案”与原教师的提案不同，这是明确保留的字段，
不能删除或谎称相同。

## 独立验收

独立进程在同一原始入场状态重新构造观测，重算学生自身网络及 h/c、R2 动作头、
当前状态 IK、接管调度、实际关节目标与每 2 ms 力矩；独立积分全部原生轨迹并检查
球、非脚部碰撞、终态和站立恢复。对所有分支、所有重复执行，不只审计成功片段。

学生网络前向次数、教师额外 R2 动作头查询和 IK 查询分别计数；本试验不训练网络，
优化器更新为 0，不提供虚构策略似然。输出接管成功范围与失败反例，不自动晋级。

若中/晚接管可以恢复，下一步用这些有物理支持的自身状态构建新的数据聚合版本，
保留原成功教师、旧能力保护状态和学生失败状态。随后才做三种子有限学习、原 BANK
保留和新 Fresh。若教师也无法恢复，回到当前状态的教师能力与控制研究，不能把
没有物理能力的教师标签强行交给学生。

本实验仍是原生参考动作前缀研究，不等于正式 52 场考试、奔跑接球或连续 4v4。
