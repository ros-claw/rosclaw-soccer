## 不把后台存活误认为持续进化

持续目标由产品的 active goal 保持。研究进程、目标续轮和观察器是三件事：

- 原生实验由独立 systemd 服务执行，SQLite 日志先记意图、再扣预算、再记结果。
- 原生进程正常终止且全 6 个结果存在，才允许原始冻结源码的独立审计。
- 新后处理源码必须单独冻结。仅在原生与审计两个真实服务均正常终止后，
  才执行本阶段预声明的 6 条录制力矩重放、接触指标与运动差分诊断。
- 服务外层 once marker 在预检前写入；失败不会自动无限重试、重复消耗物理预算。
  工程失败保留现场，由 agent 诊断并声明单独修复实例。
- 观察器只检查进程与日志，不是学习器、不是 agent 唤醒器，也不签发成功证明。
  后处理完成仍需 agent 根据证据决定下一项科学假设，而不是把整个目标标为完成。
- 机器断电或 agent 产品停止调度时，不能承诺继续思考。保存源码、阶段声明和
  结果位置，恢复后先核对实际 PID/服务/日志，不因观察中断就重跑实验。

## 如何决定下一轮

- 若输入/资格/源码检查失败：修基础设施，不训练、不提升策略。
- 若命令变化但运动参考/身体几乎不变：研究规划和 Foundation 的实际控制权限。
- 若身体变化却未触球：重点研究接近时距、横向对齐与接触脚选择。
- 若能触球而球路失败：研究接触速度、法向冲量和后续再接触，不再归因“没有动作”。
- 若出现局部救回，同时破坏旧成功或增加非足部接触：保留全部反例，不晋级。
- 只有机制能跨训练来源复现，再计划更大开发域、独立学习种子、历史保持和 Fresh。

三个训练球位的脉冲即使全部通过，也不能声称接球、精准射门、门将或 4v4 突破。
所有输出继续保持 `SIM_ONLY`、禁止自动教师入库和策略激活。

## 分阶段能力诊断：避免条件比例的幸存者偏差

新增 `first_touch_stage_diagnostics.py` 和整批来源认证读回工具
`rsi_read_pulse_stage_pairs.py`，分别记录真实足部接触、球路观测覆盖、安全条件与
冻结 M0 成功，并输出配对接触救回/退化。既不替换旧总分，也不改变奖励。

第 239 帧接触仍有完整 60 帧球路；第 240、260、299 帧接触应记作“获得接触，
球路右删失”。没有接触与删失均保留 `None` 测量，不能填 0。无有效分母的条件
比例也保留未知，不假装是 0% 或 100% 能力。

负向研究的关键例子：M0 1/3→1/3，但接触率 2/3→1/3；已观测、安全触球中的
M0 成功比例却从 1/2→1/1。如果只看最后一个条件比例，会将丢失失败接触误读成
质量提高。因此三种分母和接触退化必须一起保留；这些只是经验比例，尚不是可
供球队直接信任的校准成功概率，更没有测得 successor readiness。

读回工具必须消费完整六体原生/审计及密集接触重放，重新认证所有源文件、收据、

### 后续 B+C 接口原型（未接入物理执行）

为“接近规划 + 原有有界脚部 IK”的独立对照准备了 values-only
`OriginalIkPlannerPulse` 合同。它复用相同导航投影数学，但明确要求原始父代与

算子的源码，不冒用此前“零关节参考”证据。

当前原生零参考入口仍明确拒绝这个类型（包括传入 None 和零模型两种情况）；
它只是后续教师研究接口，不是已经可运行的策略、肌肉记忆或物理改善。必须先
实现独立请求/标量复核/CPU 与 Foundation 资格、原始 IK 对照逐位复现及整批
读回，才可按单独预算试验。相关 66 项 values-only/原脉冲回归通过（5.19s），
新 typed 合同 mypy（follow-imports=silent）通过。

另有显式的 original-IK values-only 请求校验器，只允许 None 参考模型、精确类型、
原 B2 全部默认参数及真实布尔 planner capture 标志；拒绝零/已学习参考混用、
其他控制档和绕过冻结字段的布尔注入。原生零参考入口仍拒绝它，尚未接入新
物理执行。扩充后的相关回归 74 passed（5.30s），typed 合同 mypy 通过。
