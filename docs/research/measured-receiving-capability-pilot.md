# 从实测接球到战术能力模型：首轮未通过

2026-09-21，SIM_ONLY。没有更新运动策略，没有手填接球成功率。

冻结 R0，以独立训练种子生成 256 个连续采样课程，覆盖八角色，各 32 场，
来球初速 0.5–1.3 m/s、横向偏移 ±0.12 m。另有预先指定的 16 次重放，
总计 272 次物理执行。训练课程安全接球 13/256。该组不是 DEV 或 sealed。

每场只使用 0.60 s 的因果身体坐标上下文：球相对位置、高度、球速、相对
速度及球员速度；不把未来结果输入预测器。标签仍来自完整轨迹的固定接球
判决。这个前缀检查不等于完整 500 Hz 接触历史认证。

预先固定的模型使用同角色、同策略与物理哈希、同采样时刻的 16 个近邻，
超出覆盖范围返回 UNKNOWN，而非零成功率。未搜索超参数。独立 DEV256
上只有 116 场满足覆盖条件；这些相同课程上的 Brier 分数为 0.0444504，
训练集常数频率基线为 0.0413045（越低越好）。因此本轮没有预测收益，
不将该模型视为已校准的战术转移模型，也不据此启动大规模 MAPPO。

技能时长与后继 readiness 尚无合格标签，明确保持未知；近邻频率不被包装成
部署成功概率。后续需要物理技能及事件标签本身的提升，不能只增加虚拟比赛。

实现位于 `training/receiving_context.py` 和 `training/receiving_skill_model.py`。
