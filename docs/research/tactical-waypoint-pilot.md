# Human waypoint prior：一次固定预算的可复现训练

2026-09-20；仍是战术支线准备，不是足球身体策略、2v1 或团队 Champion。

SkillCorner 官方仓库固定于 `4340d274572876239c154c90bc507a9b3250a656`，
MIT，保留 [SkillCorner Open Data](https://github.com/SkillCorner/opendata) 署名。
三场 tracking 均按官方 Git LFS 指针核对文件哈希。

训练场次：2017461、1996435，共 183,406 条检测有效样本。
开发场次：2006229，共 109,170 条。按整场隔离；这是开发集，不是封存考试。
各时刻与球必须实际 detected，窗口帧连续、同一半场，缺失实体不补零。
根据官方 home_team_side 和 team_id 统一进攻方向，同时旋转 x/y。

输入为 20 维：归一化自身位置与过去半秒位移、相对球位置及球位移、最近
队友/对手、角色、球权。目标是未来半秒的归一化 waypoint 位移。
没有使用未来输入，也没有捏造 SUPPORT/PRESS 等意图标签。

模型为两层 64 宽 tanh MLP，预测匀速 baseline 上的米制修正。
固定种子 9202026、12 epochs、batch 1024，最终 epoch 保存，不按开发成绩选模。
CPU 训练，原始轨迹与权重外置。保存的权重独立 reload 后逐元素重现开发预测。

| 开发整场指标 | 匀速预测 | 学习修正 |
| --- | ---: | ---: |
| 平均半秒终点误差 | 0.31464 m | 0.27821 m |
| P90 终点误差 | 0.65000 m | 0.55651 m |

守门、后卫、中场、攻击手分组的平均误差都下降。
以 30 秒相关块做描述性复查，178 块中约 89.3% 平均误差下降；仍有退步块，
最差块退步约 0.0778 m。仅一场独立开发比赛，不能据此宣称跨比赛统计稳定。

这证明已跑通“真实 tracking → 训练 → 独立比赛开发比较 → 权重重载”的小闭环。
它尚未证明意图理解、足球决策、G1 可执行性或闭环团队收益。
下一步必须显式学习意图或加入事件语义，并由 Physical World 能力模型约束
2v1 行动；不能把这套人类位移模型直接当作机器人控制器。

外置证据目录：`receiving-mechanism-reboot/tactical-context-v1`、
`tactical-prior-v1`。前者含数据 provenance manifest，后者含模型、预测、训练记录、
独立 reload 验证。三个准备/训练/验证脚本随证据保存，未封存或晋升任何候选。
