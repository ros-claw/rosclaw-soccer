## 实际打通 Core Practice 的范围

将同一公开失败课程的原始与表面提案轨迹导入独立 Practice 目录，每条取
300 个真实控制时刻的目标、实际关节、误差、命令力矩和完成步支撑力，加一条
失败事件。导入前重新核验原始 NPZ 哈希并重算接球判决。

使用隔离 Core 分支的正式 CLI，两个 session 分别完成 `record`、`verify
--strict`、`distill`。输出各一条失败知识，候选、晋升、sim2real 记录均为零。
没有伪造改进措施或成功闭环；Practice 校验通过只表示数据链路完整。
数据的墙钟明确为**导入时间**，模拟时间单独保存，未虚构原仿真墙钟。
力矩字段是命令力矩，不冒充硬件传感器实测。

外置目录：`receiving-mechanism-reboot/practice-integration-v1/`，包含输入 JSON、
每条 CLI 的 stdout/stderr、目录数据库、知识文件和 `complete.json`。
没有调用机器人 Runtime、训练权重、访问设备或修改用户默认 ROSCLAW_HOME。

进一步实测：尚未索引时 `query failures` 返回空列表，不能据此说失败记忆已可
检索。随后通过 `ingest-seekdb` 显式写入本次独立 SQLite 兼容数据库，查询得到
两条带原始轨迹 SHA-256 的不同失败；重复索引仍为两条，不膨胀样本计数。
这验证的是本地结构化存储兼容路径，不是远端原生 SeekDB/OceanBase 服务。
最初检查脚本误用顶层 `failure_id`，实际查询主键是 `id`、原字段在 metadata；
修正检查后重跑通过，原日志保留。

还在本次私有导入副本上追加一个空行，严格校验确实拒绝；随后原字节完整恢复，
严格校验重新通过。原始物理 NPZ 从未修改。新增凭据为
`retrieval-and-tamper.json` 和 `indexed-retrieval.json`；前者记录索引前空查询，
后者才是索引后成功检索，不混淆二者。

## 接球输入数据质量补充（2026-09-21）

对上述 256 课逐课重新认证结果和 primary 文件哈希，课程组合键全部唯一。
按每课一个样本统计，不把重放、0.6 秒快照或 50 Hz 相邻帧加到独立样本数。

244 课出现记录到的球–机器人接触；12 课没有该记录。下表仅使用首次记录
接触之前的最后一个 50 Hz 状态，尚未把接触后的速度当作来球特征：

| 名义发球速度 m/s | 有接触课程数 | 接触前实际速度中位数 m/s | 球底水平滑移中位数 m/s |
| --- | --- | --- | --- |
| 0.75 | 58 | 0.5087 | 0.00169 |
| 0.85 | 58 | 0.5797 | 0.00193 |
| 1.00 | 64 | 0.6867 | 0.00230 |
| 1.25 | 64 | 0.8704 | 0.01486 |

球的自由关节角速度先从局部系旋转到世界系，再计算名义球底速度；不能把
原始 local angular qvel 直接与世界系平移速度相减。低速三档在此时滑移很小，
不支持“接球失败是因为球完全不滚”的推断。这不是现实足球的材料校准。

“最后接触前一帧”是回顾性选取，不能作为部署时提前知道接触时刻的触发器。
为避免这个时间泄漏，另保存固定 0.60 s 的因果快照，256 课均满足此前没有
记录到身体接触。骨盆速度只用当前与前一帧差分，不读取未来位置。
50 Hz 摘要不是完整微步接触历史，未记录不等于证明不存在任意瞬时接触。

影响：已有 capability 表的 `speed_mps` 是课程发球条件，不能不加转换就作为
TacticalWorld 的实测来球速度。两种数据保留各自语义，未知技能完成时长和
successor readiness 仍为空，没有凭此构造已校准的技能成功概率。
外部可重跑代码：`audit_incoming_contexts.py`；结果：
`r0-development-256-v1/incoming-context-audit-v1.json`。

可复用的 `training.receiving_context` 现从固定观察帧提取骨盆朝向坐标系的
球位置、球–身体相对速度、实际水平球速和身体速度。只读取当前及更早帧；
未来数据替换为 NaN 后输出不变的测试通过。已发生记录接触、时钟断裂、
非有限输入和未归一化姿态均拒绝。该接口不根据未来接触时刻选择输入。

真实 256 课均完成固定 0.60 s 提取，每课一个样本，10 个安全成功标签保持
不变。输出 `fixed-time-contexts-v1.json` 绑定课程身份、策略和原始文件哈希。
这不是新 rollout，不增加独立课程数，也不是已校准的概率或完整技能转移模型。
尚未测得的技能耗时和后继准备状态不以课程长度、接球成功代替。
