# 全身接球反馈接口：为可达性比较建立同等执行条件

总纲要求比较 A0 腿部 residual 与 A1 全身 residual。此前静态 oracle 已支持
29 关节，但在线状态反馈入口只接受 12 维。不能用反馈式 A0 对比静态 A1
就宣称两者控制能力已经公平比较，更不能用随机搜索失败宣布动作空间不可达。

## 这次工程变更

- A0 默认不变，包括原观察哈希、幅度 ±0.1 rad、滤波 0.25、单步 ±0.02 rad。
- A1 提案者必须显式声明 `action_substrate="A1_body29"`，并绑定对应完整
  schedule hash；29 维输出不得隐式填充、截断、裁剪或混入相位覆盖。
- A1 观察包含完整上一拍 29 维滤波输出，腿部前十二维必须与原观察一致。
  入场前上肢为零，入场后以执行 cursor 的真实内部状态为准，不以零替代。
- 每拍核对动作空间、提案者身份、时钟和输入不变性；错误锁存并终止实验。
- A3 SONIC 反馈仍拒绝；本变更没有证明 SONIC 上下文可复用此入口。

这是下游足球实验接口，不是硬件权限，也不是教师或策略的晋升。
冻结实验不受主仓变更影响。未调整模型、身体、物理、接球考试或安全阈值。

## 验证层次

单元测试验证显式权限、完整状态、错误长度/非有限值拒绝、跨拍和提案期间
绑定变更拒绝；在同一旧滤波初态下，A0 与零扩展 A1 连续三十拍逐值相同，
非零上肢输出和不再准入时的衰减遵循相同限幅滤波。

全仓复测为 **5207 passed、39 skipped、11 failed**；与前版 XML 比较，
仍为同一批历史外置证据失败。第一遍另发现一个观察哈希测试使用新字段
构造旧格式预期，已显式排除默认扩展字段，原运行 XML 保留。
全仓 lint、修改文件格式及两模块定向类型检查通过；包含导入依赖的类型
检查仍报三项既有问题，不能宣称全仓类型检查通过。
