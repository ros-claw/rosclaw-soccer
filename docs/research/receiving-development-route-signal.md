# 公开接球路线门，不是学生或比赛晋升

`training.receiving_route_signal.receiving_development_route_signal` 固化总纲
的历史路线标准：完整旧 128 门，原 17 门成功全保留，候选至少 25 门安全
成功，并且没有任何候选不安全课程。接口要求八个角色实例各十六门，
每门只占一行，独立重放不能作为另一门课凑数。

输入绑定完整执行方案的哈希，而不是只绑定未变化的神经权重。逐门明确
`intervention_applied`，将保持原策略的角色与新教师覆盖区分开；未施加
干预的课程不能声称结果改变。拒绝混合方案、缺课、重复课、非布尔标签、
角色不均衡、错误的 R0 成功数量或未通过重放的记录。

复用既有 `receiving_research_branch` 的成对安全/保留检查；调用方仍负责
认证原轨迹、复算原考试、核对独立重放及冻结银行。函数不认证输入布尔值，
也不会仅凭一个 JSON 哈希就宣称验证了物理。既有函数的“可保留研究候选”
允许持平，而新的路线门不把持平或 17→18 描述成路线突破。

返回 `ROUTE_VALIDATED` 也只限已见开发集；教师资格、训练授权、晋升授权
全部保持 false，未评估 blind，不选择 checkpoint 或自动打开 sealed。
E1/E2、学生、独立训练种子、fresh paired blind 和后继动作仍各有独立门控。

相关 42 项测试通过；全仓复测 5223 passed、39 skipped、11 failed，
仍为同一组历史外置证据失败。全仓 lint 与新增模块定向类型检查通过。
当前实际 128 门评测还在运行；本文件记录实现，不提前填写通过成绩。
