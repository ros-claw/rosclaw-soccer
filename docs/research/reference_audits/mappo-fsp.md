# MAPPO + FSP：技能组合与停球代价

2026-09-21，阅读[官方论文](https://proceedings.mlr.press/v305/su25a.html)
第 3.2–3.4 节及附录 A、D。外部保存 PDF，不复制论文资产进仓库。
PDF SHA256：`f4f1b2bf81d172c27e4392152b2686dc922408d52b433864122ff9d3398deba4`。

论文将低层运动技能与 5 Hz 高层 GRU 决策分开；动作包含技能和方向。
MAPPO 训练一方时冻结对手池，各环境均匀抽取历史对手；达到评估条件后加入
快照、换另一方训练。起始对手包括随机与追球策略。低层技能激活有接近球、
动作完成和避碰条件，不是每个高层动作都保证即时成功。

附录 A 的关键负结果：独立 Receive 技能在训练后被弃用。先面向队友停球再
转身进攻会损失时间，相比之下直接顺势带球或踢球更有效。这是四足实验的结果，
不能推断 G1 必须同样弃用接球。

本项目据此保留总纲的 M0/M1 诊断门，同时禁止把“停球通过率”当作最终
足球能力。M2 必须实测 Receive→Pass/Dribble/Shoot 的时长与 successor readiness。
缺失时保持 UNKNOWN，不能用六秒课程时长或人为成功率填 TacticalWorld。

工程上仍采用本项目的独立球员身份、单 Plastic 球员、冻结对手哈希及晋升门；
不照搬论文的全队共享更新方式，也不拿抽象世界胜率代替 G1 物理结果。
当前没有宣称已运行这篇论文的完整系统或完成新的 MAPPO + FSP 训练。
