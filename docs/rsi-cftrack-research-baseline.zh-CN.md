# 任务空间学习型跟踪器：新研究分支

有界接触参考已表达正确 IK 端点，但原 547 网络的实际关节跟踪仍有显著偏差。
读回后的 FK 组合诊断：父代根部 + IK 关节误差 2.835 mm，实际根部 + IK 关节 13.511 mm，
父代根部 + 实际关节 155.642 mm，实际根部 + 实际关节 166.550 mm。
这些数不能相加为因果百分比，也不是反事实动态执行证明，但支持先攻关低层关节跟踪。
右膝比 IK 端点少屈约 0.328 rad，右髋偏航偏约 0.195 rad；随后实际右胫与球发生不安全接触。

新增独立 `SharedOmniContactPlayer`，研究外部已有 CFtrack 训练权重是否能提供更好的任务空间跟踪。
它不是将 1244 维策略假装成原 547 维策略：输入包括 11 帧任务空间未来和私有 5 帧 141 维历史。
外部源由调用方在隔离进程中锁定并初始化，适配器不运行原 deployment runner，不接触任何硬件。

- 每个球员独占策略、状态、输出和历史；所有球员的动作仍由一个世界同步推进。
- 正确检查 ONNX 输入、CPU 执行、HG/Lab 双向排列及显式 PD 参数。
- 每次观察自己的当前实际本体和实际球，不用未来球轨迹冒充测量。
- 每个共享边界只允许一次策略提议；实际世界执行了相同目标才可提交历史。
- 仅资格检查单技能 kickball，不放行外部异步阶段线程或技能链。

新的有限基线在同一标准球/身体及 0.85 力矩帽下，从明确初始站姿运行最多 600 个控制周期。
**控制器、初始条件和软件冷启动历史均是新协议**：使用外部训练时的 PD，绝非承袭 RoboNaldo 的
原 H300 证书或已验证平滑接续。原外部 0.10 m 球及摩擦/球门场景不用于本实验；
标准原生世界仍使用 0.11 m、0.43 kg 球，不修改任何运行中物理状态。
保存实际 q/v、力矩、接触、NN 输入/输出及脚踝跟踪误差，失败也保留，不挑种子或剪裁成成功。

这只是外部已训练模型的 SIM 基线验证，不代表本项目已做了新权重训练，也不能取代球队完整闭环。
外部 README 标注 CC BY-NC-SA 4.0，商业宣传使用权尚未核实；因此此分支仅作研究，不授权将其
素材/权重纳入商业宣传，也不自动提升产品支持等级。通过基本动态验证后仍需要独立输入重建及任务考试。

600 个实际 1244 维输入、原 NN 输出与实际目标全部重建匹配；无新物理积分。
原 H300 指标重新标注新协议的前 300 帧为 `NO_FOOT_CONTACT`，没有通过。
读回哈希：`ca72641ce97aeff0ec4a13dffabdc1365c6275eaa48d703647ef746d4af9b563`。

零 NN/零积分的规划诊断发现原参考长 390 帧：阶段 11 占 0–286，接近 287–327，
摆腿 330–349，计划右脚接触从 340 开始。机器人本已朝向球，却先绕到 x=-0.5 m 准备点。
这是规划时间本身过长，不能全归因于“跟踪器反应慢”。另外摆腿阶段的实际双踝参考误差
均值约 0.429/0.485 m，及时接近和动态跟踪都还需要真实验证。

增加显式可选、默认关闭的直接接近方案：仅当当前已对准目标、在球后 0.3–1.5 m、侧偏
不超过 0.2 m、处于精确默认站姿的冷启动边界，才用原有步行原语直接走向同一踢球站位。
保留原摆腿/恢复参考后缀逐数组不变，不重设身体、不改权重/PD/力矩帽，也不调摆腿幅度。
使用原生基础步长 0.016 m/控制周期，不做速度或种子网格。所有新参考先构造和检查，最后一次性安装。

## 当前状态的私有预测资格

增加独立的 CFtrack 策略复制器，不放宽已有仅 NumPy 的 547 策略复制器。
CFtrack 的 FK 模型只读共享并指纹检查，FK 数据、所有参考/私有历史以及空闲阶段锁独立复制；
仅 stateless CPU ORT 会话共享。不使用 pickle/deepcopy 外部钩子，不调用副本的 enter()。
未知资源、循环对象、活动阶段线程和非有限数据拒绝进入预测。

新预测器以同一原生身体、PD 和状态建立私有世界，每一预测控制周期都重新调用原 CFtrack NN。
请求的全部子步预算在分配前扣除，失败不退回为盲重试额度，已经积分的部分原始数据保留。
只有一次有限资格试验：160 周期预测 + 160 周期实际，以原已独立验证回合的前缀另作出处校验；
保存的原回合数据不参与当前控制。该接口通过也不构成射门精度或权重学习收益。

私有预测资格已运行完成：160 个控制周期、1600 私有子步/160 次未来 NN 与 1600 实际子步/
160 次实际 NN 完全一致，也与既有真实回合前缀相同；未重置副本历史，原身体和软件状态不变。
报告哈希 `b38356e93145547557efd33412ca629adf26cc094f4581808c1c0dfee053cd25`。

随后的零 NN/零积分几何诊断中，原局部 IK 的右膝和右踝俯仰都在 0.35 rad 总信赖域上饱和，
接触点残差仍约 24.7 mm，不能安装为合格目标。
因此增加名称独立、证书独立的 `solve_absolute_contact_pose`：求绝对物理关节构型，
保留原关节范围、每步 0.1 rad、16 次迭代和相同接触/支撑/胫部判据，不再声称满足旧的
0.35 rad 总差量权限。旧 `solve_contact_reference_pose` 合同及默认行为保留。
这只扩展 SIM 几何参考空间，不增加实际控制残差、PD、力矩帽或真实硬件权限。
端点可行也必须经任务空间表达、原 NN 跟踪和原生物理考试，不能将关节构型直接播放成动作。

该独立几何报告已完成：`e1710107ee7322ba86608660414b370c37b3d1517c35362f6d7f23c3508d84fd`。
新绝对配置接触点误差约 0.838 mm、胫部间隙约 52.4 mm、支撑脚姿态不变；最大关节参考变化
约 0.508 rad。只是几何资格，不是实际触球误差。

## 绝对任务空间参考（待私有动态验证）

新增不可变、当前策略完整状态哈希绑定的计划，来源仅为自己当前身体的 160 周期原生 NN 预测。
在预测首脚接触前一控制周期求上述绝对 IK，转换为网络支持的 **ankle_pitch** 位置/四元数参考。
IK 几何用 ankle_roll 足部碰撞面，而网络并不直接接受 ankle_roll 目标；不能隐瞒这个表达限制。
其余身体参考、历史、身体、球、实际关节目标、PD 和权重均不在此函数中改动。

49 帧、接触附近对称 C2 权重，位置朝绝对端点混合，四元数走短弧 SLERP，过去/边界/窗口外不变。
新 SIM 任务参考合同明确限制：附加参考采样线速度 ≤3 m/s、采样角速度 ≤8 rad/s，
参考脚踝到参考躯干距离 ≤1.25 m、平地脚踝参考 z≥-0.05 m；不继承旧关节参考的 0.35/4/6 证书。
这些是 **参考输入的采样约束**，不是连续物理速度、关节范围或平衡性证明。
不满足则原子拒绝安装，不剪裁或自动提高上限。

先只做有限私有预览：一个原父代预测及至多一个条件预测，共最多 320 次 NN/3200 私有原生子步，
不修改实际世界、不训练权重。保存父代和候选原始轨迹、生成过程和拒绝理由。
只有实际新参考闭环、输入读回、原 H300 和严格重放均获证据后，才可谈能力改善。
