# 任务空间学习型跟踪器：新研究分支

有界接触参考已表达正确 IK 端点，但原 547 网络的实际关节跟踪仍有显著偏差。
读回后的 FK 组合诊断：父代根部 + IK 关节误差 2.835 mm，实际根部 + IK 关节 13.511 mm，
父代根部 + 实际关节 155.642 mm，实际根部 + 实际关节 166.550 mm。
这些数不能相加为因果百分比，也不是反事实动态执行证明，但支持先攻关低层关节跟踪。
右膝比 IK 端点少屈约 0.328 rad，右髋偏航偏约 0.195 rad；随后实际右胫与球发生不安全接触。

新增独立 `SharedOmniContactPlayer`，研究外部已有 CFtrack 训练权重是否能提供更好的任务空间跟踪。
它不是将 1244 维策略假装成原 547 维策略：输入包括 11 帧任务空间未来和私有 5 帧 141 维历史。
外部源由调用方在隔离进程中锁定并初始化，适配器不运行原 deployment runner，不接触任何硬件。

- 每个球员独占策略、状态、输出和历史；所有球员的动作仍由一个世界同步推进。
- 正确检查 ONNX 输入、CPU 执行、HG/Lab 双向排列及显式 PD 参数。
- 每次观察自己的当前实际本体和实际球，不用未来球轨迹冒充测量。
- 每个共享边界只允许一次策略提议；实际世界执行了相同目标才可提交历史。
- 仅资格检查单技能 kickball，不放行外部异步阶段线程或技能链。

新的有限基线在同一标准球/身体及 0.85 力矩帽下，从明确初始站姿运行最多 600 个控制周期。
**控制器、初始条件和软件冷启动历史均是新协议**：使用外部训练时的 PD，绝非承袭 RoboNaldo 的
原 H300 证书或已验证平滑接续。原外部 0.10 m 球及摩擦/球门场景不用于本实验；
标准原生世界仍使用 0.11 m、0.43 kg 球，不修改任何运行中物理状态。
保存实际 q/v、力矩、接触、NN 输入/输出及脚踝跟踪误差，失败也保留，不挑种子或剪裁成成功。

这只是外部已训练模型的 SIM 基线验证，不代表本项目已做了新权重训练，也不能取代球队完整闭环。
外部 README 标注 CC BY-NC-SA 4.0，商业宣传使用权尚未核实；因此此分支仅作研究，不授权将其
素材/权重纳入商业宣传，也不自动提升产品支持等级。通过基本动态验证后仍需要独立输入重建及任务考试。
