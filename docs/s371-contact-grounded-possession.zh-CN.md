# S371：有触球依据的持续控球与接传衔接失败

## 结果先行

持续控球判断修正了接球结束时的所有权丢失，但没有打通下一次传球。中场在 10.22 秒及时承诺传前锋，随后转身绕球使球离脚过远，所有权正确撤销。13.42 秒后续触球仍朝错方向。因此不晋升比赛冠军，也不制作“完整比赛成功”的宣传片。

## 模块

`growth/contact_possession.py` 是独立的足球状态估计模块，不是学习模型。它仅延续真实触球产生的控球证据：

- 脚部力大于 1 N 才能建立锚点；距离本身不能产生所有权。
- 连续至少 0.3 秒球速不超过 0.5 m/s、球心到最近脚踝不超过 0.35 m、身体安全，才允许延续所有权。
- 锚点最多保留 3 秒；新的真实脚部接触可更新锚点。
- 失控、非脚部接触、多人脚部同时触球、机器人碰撞撤销所有权；必须重新触球才能恢复。
- 观测间隔超过 0.0041 秒清除连续证据；非有限值或倒退/重复时钟锁定失败关闭。

世界在 500 Hz 的真实物理子步更新状态。新开关 `controlled_possession_retention` 默认关闭且关闭时不改变配置哈希；开启要求严格物理接球握手。没有放松关节限位、85% 力矩限制、身体倾斜限制或碰撞判定。旧短时触球所有权路径保留；该模块只是增加满足上述条件的延续路径。
