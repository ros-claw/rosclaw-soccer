# S1634–S1642：从重复调参转向控制参考适配

## 结论

邻域专门训练仍未解决问题：摩擦 0.1095 和 0.1105 各训练 48 个关节配合
候选，均为 0 个严格通过。独立审计 S1639 的两组 48 个记录全部通过，
但这不是足球技能通过。

新的控制对照发现：保持原有力矩保护开启，将射门策略的**全部受限关节
位置参考**投影到模型关节范围后，三个开发摩擦条件均获得了脚部干净接触、
原生关节合格、小腿几何分离和身体稳定。然而射门误差为 1.48–1.90 米，
因此**仍未完成高精度射门，不具备宣传资格**。

只约束踝关节参考的三次实验反而出现接触与身体/关节失败，不能部署。

## 诊断与因果边界

S1637 对实际记录的 `shooter_policy_action`（PD 位置参考）进行只读分析。
固定场景里左踝俯仰参考最多超出关节范围约 1.99 rad；摩擦 0.1105 时，
右踝俯仰参考最多超出约 3.58 rad。对应的速度参考为零。

这些值**不是实际关节位置越界量**。学习策略可能借用范围外的虚拟位置
参考表达力矩，不能仅凭该现象认定软件缺陷或抖动原因。实际关节证据仍由
2 毫秒子步采样提供。本阶段采用固定其他条件的干预对照来判断影响。
