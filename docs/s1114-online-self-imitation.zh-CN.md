# S1114：在线试错与成功经验回放交替更新

日期 2026-09-13。接续 S1092–S1110。仍未达到宣传片标准。

## 实际打通的学习闭环

每轮先以当前策略在 MuJoCo Warp 中实际尝试 72 个五秒回合，完整保留成功
和失败。它们共同进入 on-policy PPO，检查行为策略似然。随后只将本轮
原生精确首传成功片段追加到经验库，进行 16 次明确标记为 off-policy
的 self-imitation 更新。固定 8 轮，最终模型考试，不选中间最好的模型。

经验库包含 8,000 个已在 CPU 资格验证的历史训练观测，以及最多 24,000 个
近期成功观测。后者只是 GPU 筛选标签，不自动获得 CPU 物理资格。每轮
保存完整回放 batch、样本索引、PPO 后/SIL 后参数及优化器状态。
开发集评估数据不进更新；训练失败仍完整保留并用于 PPO。

ROSClaw 历史 pinned Core 的 PlasticityLease 同时绑定两份数据的合成哈希，
将 PPO 和 SIL 的实际优化器步数一并审计。基础步态、父策略、归一化层
均为 FROZEN，接触学习策略是唯一 PLASTIC 项。这是训练事务证据，
不是当前 Core 版本集成验收或模型晋升许可。

## 完成的结果

- S1114：576 个训练回合，106 次 PPO Adam + 128 次 SIL Adam，总计 234。
- 43 个本轮训练精确成功回合进入经验库；最终经验库 18,750 个观测。
- 固定开发集最终精确 0/72；过程中最多 16/72，但仅对应 2/9 个独特入场
  上下文。不能把中间峰值当最终成绩，更不能当独立成功率。
- S1115：逐轮重建特征、历史、动作窗口、原始随机抽样、Monte Carlo 回报、
  滚动经验库、采样索引和全部 PPO/SIL 模型/Adam 更新，精确一致。
- S1116：新 seed 111601 的 CPU 32 上下文配对实测，安全 31→31、
  受控传球 5→3、精确传球 1→1、非脚触球 4→5、晚触球 0→0。
  **候选拒绝：没有提高精度，且部分质量指标退步。**

本轮是传球入场单技能，不是射门、扑救或 4v4 整场。没有录制并发布
“宣传成功”视频，也没有将失败模型替换比赛策略。

## 后续实验的明确变化

S1118 另开新目录、新候选：把原先训练外的 23 类几何入场全部加入，
总计 32 类 × 8 副本 = 256 世界，计划 16 轮共 4,096 个回合。
初始 logstd 从 -3.5 调到 -2.5，扩大探索，但不扩大残差/关节/力矩边界，
也不改变 0.1 m、身体安全、首次触球和晚触球判定。
这同时改变覆盖、探索和预算，是探索性候选，不是单因素因果实验。
原先 23 类现在必须标记为训练上下文，后续以新球状态扰动考核。
此处只记预声明设置，未完成的实验不填成功数字。
