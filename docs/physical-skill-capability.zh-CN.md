# 物理技能证据与战术决策的边界

`training.physical_skill_capability` 为球队战术研究提供一个**精确上下文**的物理技能证据摘要。每个样本必须明确技能、身体、策略、上下文、物理实验组和证据摘要；不同身体、策略或上下文不能混合，同一物理组或同一证据摘要不能重复计数。独立重放用于核验，不是新比赛样本。

样本结果区分成功、失败、未知，身体安全及后续可行动状态也可分别为未知。没有观测到的时间和后继状态保持未知，不把删失标为失败或成功。摘要可给出经验频率与名义 Wilson 区间，但区间只有在样本独立等假设成立时才有对应的统计含义；本模块不验证这些假设，也不自动认证输入证据。

研究者必须事先声明最低组数和区间下限。只有满足阈值、无未知结果、无未知安全及无不安全记录的精确上下文才可通过**研究筛选**。即使通过也不是实机或策略晋升许可。战术选项排序会绑定技能、上下文、身体和策略四项身份；没有匹配证据时返回 `None`，由调用方决定继续搜索或观察，而不是伪造传球或直接控制电机。报告摘要哈希只检测意外变更，不能替代来源认证或授权。

本模块不读取 ROS、DDS、硬件或场景资产，不执行机器人动作；任何动作仍受现有 SIM_ONLY 和 ROSClaw 安全边界约束。抽象 2v1 战术环境不等于真实 G1 多人体足球，能力表不会自动提升比赛水平。
