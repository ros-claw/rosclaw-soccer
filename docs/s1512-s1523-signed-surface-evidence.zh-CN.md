# S1512–S1523：从接触力审计到表面间隙证据

状态：SIM_ONLY；没有新策略晋升，没有合格的新宣传片。本记录不把两人传射开发实验当作三角色或 4v4 比赛成功。S1522 关节协调搜索在写作时仍运行，最终结果另行审计。

## 为什么继续收紧训练数据

前轮逐物理步检查已发现历史高球教师及其模仿学生存在小腿触球。进一步的几何观测表明，“没有超过 1 N 的小腿接触力”不能推出“球和小腿表面没有重叠”。接触力判据与几何分离判据应分别记录，而非互相替代。

S1513 原生 MuJoCo 检查四个教师情境，记录每 2 ms 球与左右小腿的有符号表面距离。负值表示几何重叠，不直接解释为对应大小的碰撞力：

| 情境 | 触球前后 40 ms 内右小腿最小间隙 |
| --- | ---: |
| 原始左侧高球教师 | −21.45 mm |
| 原始右侧高球教师 | −20.38 mm |
| 射手原点前后方向偏移 −0.08 m，左侧 | −3.69 mm |
| 同样偏移，右侧 | +5.27 mm |

这些数值来自 `mj_geomDistance`。采样读取 `mj_step` 后保留的、刚刚用于接触求解的几何配置；不调用 `mj_forward`，不修改 qpos、速度、碰撞体或碰撞过滤。四情境均完成完整双回放，轨迹与原参考逐数组一致。正间隙右侧样本仍未达到高球目标，不能据此称射门成功。

- S1517：在该候选加入间隙观测，131 组轨迹数组与原结果逐项完全一致。实际最小右小腿间隙约 −9.04 mm，进一步说明原接触力通过不等于几何分离。

- S1522：正在探索原 12 Nm 关节残差上限内的六个右腿协调分量。左侧起点已知存在重叠，仅作为待修复的失败起点，绝非合格模仿示范。所有失败保留；未使用留出情境训练。

## 可复用工程

新增 `sim.surface_separation_evidence.SurfaceSeparationTracker`：

1. 调用方声明几何绑定、表面对标识、物理周期、总时长和所需最小间隙。
2. 每一物理步必须提交每一对表面的有限有符号距离。
3. 缺样、重复、额外样本、缺少/新增表面对、非有限值等使证据终态失效；之后的好样本不能修复本次记录。
4. 整个声明时段结束前不能通过；任何一次小于要求的距离都会拒绝整段分离判据。
5. 返回独立的 `separated_entire_episode`，不更改原接触力、稳定性、进球和技能验收，不授权机器人、不晋升模型。

模块不包含 G1 关节索引或固定足球场坐标。它目前归属足球下游仿真证据层；其他仿真实例可绑定自己的表面对使用。几何哈希标签不能证明测量源真实，调用方仍须提供原生轨迹、实际几何绑定和采样时钟证据。

S1520/S1521 已在原生 MuJoCo 接触循环逐步调用生产模块，各 5,500 步、各完整双回放：左侧重叠样本拒绝，右侧分离样本通过该单一判据；两个情境的 131 组原轨迹数组各自保持完全一致。S1523 独立复核 15 组距离数组和两个原生集成案例，通过。并非仅运行合成单元测试。
