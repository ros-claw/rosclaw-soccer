# S938：为什么角色一直想射门，却没有第二脚

## 已核实的结论

当前 4v4 仍未达到宣传标准。S938/S939 是不改变控制输出的诊断，
不是新训练成绩。八个身体、关节、球的轨迹与 S936 完全一致。

此前“只接了一次射门”的判断不完整：实验还包含 S718 的第二次射门
适配器，使用 reference 20、S286 actor 和 S716 成败样本入场记忆。
但安装了专家，不等于它获得过一次合格入场。

另一个初步怀疑也被排除：第一次踢球执行器瞄准偏侧 +0.75 m，
但之后战术角色仍要求 `(-1.25, 0, 0)`。因此第二次射门没有被
“偏侧目标不受支持”挡住。必须检查实际调用参数，不能从第一次
执行目标推断后续角色意图。

## 真实调用中的条件统计

S938 记录 1000 次第二技能适配器调用的完整身体状态、球状态、
意图、目标、候选控球身份、前次技能终态。S939 独立重建几何条件，
逐帧核对 `motor-state.npz`，再检查八身体和足球的物理轨迹一致性。

这些是控制帧数，不是独立比赛成功率。后面的成败记忆查询尚未被
走到，因此不能把当前失败归因于记忆拒绝，更不能放宽记忆阈值。

## 下一项有边界的干预

通用 `world.planar_entry_target.planar_entry_root_target` 将某个技能的
身体坐标系接触偏移和期望朝向，转换成导航根节点目标。它不认识
G1、不授予控球权、不写物理状态，也不判断碰撞可达性。

原有“靠近球”的导航目标不保证满足某个射门技能的入场域。S940
因此只研究准备动作：保留原角色意图、当前候选控球身份、所有
对手、球场边界、邻居避碰、运动限幅和射门入场门，导航到原技能
要求的位置和朝向。第二次射门执行在这一对照中明确关闭，先检验
准备能力，避免将未资格验证的衔接直接投入比赛。

这是解析导航干预，不是新 RL、肌肉记忆训练或球技晋升。接下来
必须用真正到达的身体/球状态重新考核专家，再检验独占控制交接
与实际第二脚；不能把影子调用或几何条件满足写成射门成功。

新增组件的旋转/平移等变性、接触点重建和非法输入检查通过；
连同既有地面截球几何回归，52 项测试通过。模块 mypy 和全局 ruff
通过。全仓回归为 2484 passed、29 skipped、11 failed；逐项核对后，
失败身份集合与 S936 的 11 项完全相同，没有将这些存量失败删去。

首 640 个控制帧的身体与球轨迹保持不变。之后实际应用 320 次
受限导航准备指令；八身体保持原有安全门通过，机器人间接触为 0。
第二次射门明确没有执行。

| 恢复后 360 帧中的条件 | 原方案 | 准备方案 |
|---|---:|---:|
| 前后球位合格 | 36 | 105 |
| 横向球位合格 | 0 | 253 |
| 朝向合格 | 0 | 192 |
| 身体低速合格 | 233 | 191 |
| 球速合格 | 0 | 0 |
| 意图/身份成立且除球速外全部几何条件成立 | 0 | 68 |
| 全部入场条件成立 | 0 | 0 |

这支持“导航应服务于具体技能入场几何”的局部判断，但没有证明
完整射门提升；身体低速合格帧反而减少，不能声称所有指标更好。
S942/S943 将两个方案均延长至 24 秒，且均关闭第二次射门，分别
要求前 20 秒物理轨迹与对应原实验完全一致。目的是区分准备改善
与单纯多等待球减速，不是修改球速或降低原来的 0.10 m/s 门槛。

## S944：延长时间没有打通第二次射门

两条 24 秒回放均完成，前 20 秒各自与原方案逐字节一致；八身体
均安全，机器人间接触均为 0。但两组均没有一个完整合格的第二
射门入场，也没有执行第二次射门。

准备组在约 20.1 秒改为战术回传，几何准备随原来的 SHOOT 意图
结束而退出。这里不能强制保留射门意图来制造成功。更早在
12.8 秒就已经出现过恢复后的回传请求，所以后续考试选择的是
这条连续轨迹里**最早**满足原有阶段条件的回传请求，而不是挑一个
预先知道效果好的帧。

## S947–S949：旧传球专家不能直接承担新回传

初态来自 S943 frame 640 / 12.8 秒，目标为当时战术角色声明的
`(2.9557347855, 2.6328874532, 0)`，不是事后调整目标。
恢复实际 LSTM h/c、上一动作及对应命令后，32 路相同输入的
基础模型观测误差为 0，动作最大误差为 `5.3644e-7`，目标最大
误差为 `1.3411e-7`。这只是神经推理组件核对，不是物理迁移认证。

随后使用 1 个精确初态和 31 个新球位/球速小扰动，保留旧 1.2 m/s
传球目标、首次足部加速、无非足部接触、无再触球和 0.1 m 目标
平面门。隔离 CPU 后端仍采用旧 float32 状态/力矩计算接口，不
代表实际八人世界逐步物理一致，也没有对手或动态接球队友。

| 冻结模型/解析消融 | 身体安全 | 自身非足部碰球 | 合格传球 | 精准传球 |
|---|---:|---:|---:|---:|
| 原 S458 完整模型 | 32/32 | 32/32 | 0/32 | 0/32 |
| 只保留导航残差 | 32/32 | 32/32 | 0/32 | 0/32 |
| 只保留关节残差 | 32/32 | 28/32 | 0/32 | 0/32 |
| 两种残差都清零，保留基础步态和名义导航 | 32/32 | 32/32 | 0/32 | 0/32 |

四组初始身体、球状态和目标逐项相同，消融只改指定输出通道。
这不是新的训练或四组独立比赛。结果否定了“仅重新调用现有传球
模型就足够”的假设，并提示检查准备路径，而不是降低碰撞门。

原名义路径从根节点直接走向接触侧，初态这条线段距球心最近仅
约 0.0675 m。这个几何诊断不是机器人碰撞证明，但解释了为什么
应当单独研究绕到球另一侧，而不是继续叠加出脚残差。

## S950：绕球准备探针

新增通用 `world.annular_waypoint` 几何组件：给定接触中心和期望
接触侧，提出径向退开、圆弧绕行、最后靠近的目标点。它不操作
身体/足球，不授予控球权，不承诺全身避碰；实际执行仍由冻结的
基础步态负责。可选的调用方阶段滞回默认关闭，不是运动许可。

第一组 32 状态、8 秒准备探针关闭所有关节/导航残差，保留完整
基础模型历史，没有新 PPO 更新。32/32 身体安全，0/32 自身
非足部碰球，但也没有合格传球。原样本的阶段仍在绕行/靠近之间
反复切换，不能当作成熟准备技能或完整比赛进步。

S951–S954 比较仅阶段滞回、仅球速前馈、两者结合和原样复跑。
这仍是准备阶段的解析干预，不是学习成绩。
