# S81：三 G1 角色成长与高球组合阶段报告

## 结论先行

本阶段交付了一支 79.23 秒、1080p、30 fps 的三角色成长宣传片，并重新跑通了最新源码下的三 G1 同场传球—射门—扑救物理闭环。宣传片由三个可追溯课程组成：前锋真实脚球接触高弧线、门将高球/双臂伸展课程、三 G1 单球共享世界实战。

必须明确：当前还没有把“传球后由前锋踢出 1.3 m 以上高球，再由门将双手扑出”打成一个连续物理 rollout。最后一段的传射扑是连续单世界，但属于低球；前两段分别验证高球射门和高球扑救能力。视频保留 SIM_ONLY、未晋升和证据边界，不把蒙太奇当作闭环得分。

## 本轮真实结果

### 三 G1 共享世界

- 一只不可传送的物理球，三具 G1，共用一个 CPU MuJoCo 求解器。
- 传球距离 2.847 m，传球落点误差 0.0235 m，滚动真实性通过。
- 前锋真实触球后球速峰值 9.074 m/s。
- 门将于 8.264 s 真实接触球，射门至扑救距离 5.723 m。
- 接触前球速 8.171 m/s，接触后峰值 2.753 m/s，速度比 0.337，属于耗散式扑救。
- 8 个门将候选全部实现安全扑救；最佳候选无跌倒、无关节越界、无力矩越界，门将最低骨盆高度 0.726 m。
- 严格重放一致。
- 顶层状态仍为 `REJECTED_DEVELOPMENT`：旧门要求“基线必须漏球”，但当前基线本身也已能触球，因此候选没有证明相对增益。候选的扑救事件有效，但不允许晋升。

### 高球前锋课程

- 高弧线由前锋真实脚—球接触产生，不是球体瞬移或视频改轨迹。
- 数据驱动接触 actor 的代表轨迹球高 1.478 m、球速峰值 10.541 m/s、门线目标误差 0.0035 m。
- 这是独立定位球课程，并非来球直接射门；课程未晋升。

### 高球门将课程

- 低球、常规高球、边界高球和两个真高球案例均通过课程门。
- 课程通过率：低球 100%、必需高球 100%、前沿高球 100%、真高球 100%、安全率 100%。
- 真高球最低物理接触高度 1.3268 m；两例真高球接触高度约 1.327 m 和 1.392 m。
- 门将执行双臂上举/双手覆盖姿态，但当前证据只保证“机器人—球接触”，不声称每次都是手套单独触球。
- 该课程的来球由物理发射器生成，不是前锋射门。

## 本轮源码改进

1. `shared_world` 新增可选训练教师：把任务空间足端速度目标经实时 MuJoCo Jacobian 转成 29 维关节力矩，并保留逐帧教师力矩/力向量轨迹。
2. `shared_world` 接入已有的有界接触位姿残差和直接关节力矩残差，三种通道都由真实接触门控。
3. 场景构建器和共享世界新增通用 `passer_yaw_rad`，可研究回传、顺向直塞和边路横传，而不是把传球者方向写死。
4. 新增 `shooter_ball_initial_position_m` 直接对抗初始化，用于将定位球射门策略放入三 G1 场地做技能迁移诊断；它与发射器互斥，且不会启动传球者策略。
5. 修复训练包的循环导入：移除 `training.__init__` 对高球课程的急切导入，直接模块导入恢复稳定。
6. 修复门将证据状态语义：顶层未通过时必须写 `REJECTED_DEVELOPMENT`，不能保留“通过开发门”状态。
7. 视频证据校验器仅在显式 `allow_development_candidate` 下允许渲染“真实扑救但比较门未通过”的拒绝候选；安全、接触、事件顺序、耗散性和未晋升声明仍全部 fail-closed。

## 失败驱动分析

本轮不是简单调参。对回传、减速来球、顺向直塞、边路横传、短回做、MotionDecode/OmniContact 先验、位姿残差、力矩残差和任务空间教师进行了多组 CPU MuJoCo 对照。

关键发现：

- 原连续回传触球时，球速约为反向 1.4 m/s；前锋输出球的垂直速度约 2.18 m/s，只能形成约 0.43–0.55 m 球高。
- 静止球高球策略能达到约 1.48 m，但直接迁移到来球时降到 0.126–0.548 m，证明其状态分布和接触口袋不一致。
- 最佳安全来球专家把球高提升到 0.548 m；继续扩大足球预塑形距离会降低射速、造成非足部碰撞，或触发跌倒/关节门。
- 短距离回做能把传球—触球间隔降至 0.18–0.39 s，但两台机器人腿部有效包络重叠，导致不安全，已否决。
- 顺向直塞和边路横传能产生真实滚动，但会先碰站立腿或摆腿中段；需要显式的接球/停球 option，不能继续靠单次踢球策略硬接。

这说明真正缺少的不是更大的冲量，而是“接球状态 → 置球状态 → 射门状态”的可学习技能边界与接触几何。

## S82 下一阶段实施

### 1. 两触状态机与技能契约

建立 `RECEIVE/TRAP → SET → STRIKE → RECOVER` 四阶段 option。第一次前锋接触是接球事件，不再错误地锁存为射门；只有球速、球位、支撑足和躯干状态同时进入可达域，才切换到射门。

### 2. 任务空间停球教师与蒸馏

- 教师控制足底接触点、足端速度和阻抗，而不是直接控制球。
- 训练目标同时惩罚球反弹、非足部碰撞、停球耗时、支撑足滑移和躯干角动量。
- 用 DAgger/actor-critic 把教师轨迹蒸馏为本体感学生；部署侧只保留有界学生，不保留 train-only 教师。

### 3. 来球高射专家

- 以“来球速度、球位、目标点、左右脚、支撑相位”为上下文训练条件 actor。
- 课程从静止球开始，逐级加入 0.3、0.6、1.0、1.4 m/s 来球与横向偏差。
- Stability-Plasticity 门：保留静止球冠军作为冻结专家；新专家只有在低球精度、稳定性和高球率均不回退时才进入 MoE。

### 4. 前锋—门将对抗闭环

- 前锋目标：把球送入 1.1–1.8 m 高度、左右角分布。
- 门将目标：提高双手/单手/躯干各接触类型的覆盖，并显式记录接触几何名称。
- 采用自博弈 population，不用单一门将过拟合单一射门。
- 先以共享世界开发集闭环，再封存随机种子做 holdout；视频不参与评分。

### 5. S82 成功门

- 三 G1 一球单世界，传球→前锋实际足部触球→门将实际接触，顺序严格成立。
- 前锋球高至少 1.10 m；进阶门至少 1.30 m。
- 高目标误差不超过 0.10 m；传球落点误差不超过 0.05 m。
- 门将接触类型显式可审计；双手姿态不能替代手套接触事实。
- 三名 G1 无关节/力矩越界；允许门将扑倒，但必须进入可恢复状态。
- 开发集与封存集分别报告，未通过不得晋升。
