# S387–S389：第二个真实接球节点打通，仍不是合格整场比赛

## 已经证实的变化

在同一场不中断的八个 G1 共享物理世界中，S388 前锋模型干净接住了中场实际踢来的球。此前 S369 已打通过前锋出球、中场神经网络接球；现在反向的中场出球、前锋神经网络接球也完成了一个实际节点。

这不是八个角色都重新训练，也不是连续攻防、射门、扑救都已合格。中场的定向出球神经网络阶段本身仍未达到出球判据，实际出球发生在其结束后的原控制流程；不能将整次传球归功于神经网络。

## 学习账本

S388 完整续接 S385 的 actor、critic、Adam 和随机数状态，继续 32 次真实 PPO 更新，10992 个优化器步、15360 个 rollout、1536000 个控制步。仍是来自同一源事件的 60 个步态起点，各 8 个扰动，不是 480 场独立比赛。

开发集结果：初始 86/480 接稳，最终 184/480；身体安全均 480/480；非脚部接触 89→69。初始权重与 S385 最终完全一致，其开发集 85/480 与重跑的 86/480 存在 1 个近阈值数值差异，不将它计作学习提升。

全部 32 次 Core 学习租约审计通过，仅前锋接球模型可塑；冻结基础模型保持不变。checkpoint/rollout 哈希全部复核，首次 PPO 更新精确重放、最大参数误差 0。出现非脚部接触当步及之后的正奖励和继续学习掩码计数均为 0。SIM_ONLY，不赋予任何硬件能力。

## CPU 迁移及判据复查

S389 重复 S386 的同一组 16 个 CPU 扰动测试：S385 之前模型 0/16、S385 最终 0/16、S388 最终 5/16 接稳；非脚部接触分别为 10、5、1，身体安全都是 16/16。

这里的 5/16 是训练终态判据：首次接触之后有足够观察时间，回合最后 0.2 秒球慢且近脚。它与从首次接触开始计时的 0.5 秒窗口并不完全等价。进一步调用原有触球相对窗口评估器复查 50 Hz 留存状态，5 个中有 4 个也通过，另 1 个只是稍后才稳定。50 Hz 存档的接触力是每控制帧内 500 Hz 最大值，不能把这次二次筛查冒充完整 500 Hz 重放。

这也给后续训练提供了明确反馈：同时检查触球相对稳定窗口与回合末状态，避免只在临近结束时稳住球。不得更改老实验的原始成功标签来掩盖判据差别。

## 尚未打通的下游

S388 实战结束前，前锋出现 40 帧射门意图但都被原运动策略入口拒绝，主要是球相对深度不匹配，部分同时有侧向距离或速度条件不符。18.42 秒和 19.42 秒的新传球承诺也尚无实际出球证据。因此完整传接射链路仍为不合格，正式策略未晋升，没有拿这段接球成功替代用户要求的高质量 4v4 比赛。

后续延长连续观察，并继续接球与接稳后动作衔接学习。不能通过移球、扩大碰撞体、解除力矩/身体保护或删除失败证据来制造结果。
