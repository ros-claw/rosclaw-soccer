# S2678–S2684：实时平衡基础上的接球学习

日期：2026-09-17。全部实验为 SIM_ONLY；没有真实机器人操作，没有制作视频。

## 目的与边界

接续 S2676 修复：接球时不再用触球瞬间的关节姿态覆盖实时平衡网络。
本轮重新采集该物理配置下的数据，不把旧的固定姿态轨迹当成新环境的
on-policy 数据。重点是接稳球，而不是触球次数、跑动次数或视频表现。

本轮训练的是每个球员独立的 12 维腿部残差 actor-critic；没有重训完整
29 关节运动基础模型，也没有训练守门员。本轮结果不证明自主比赛能力。

## 新采样

- S2678：三个 45 秒课程，种子 267800、267801、267802。
- 每个课程都有独立物理重放，采样动作与随机数按生成顺序核对。
- 只在实际接球缓冲控制阶段探索，不根据未来成功与否选择数据。
- 原始数据 6750 帧；返回场内的有效比赛片段 13 段、3850 帧。
- 实际探索 120 个球员帧，与实际控制生效相交后为 72 个球员帧。
- 红方中场 54 个、蓝方中场 18 个；其余角色为 0。
- 三个课程严格接稳球均为 0，出界分别为 3、6、4 次。

这些数字直接揭示采样瓶颈：长达 135 秒的模拟比赛，红方中场有效训练
仅 1.08 秒。不能因为保存了 6750 帧就声称获得了大量接球经验。

## 真实更新与约束对照

使用同一父模型、同一新数据、同一 `team_capture_v1` 奖励和四个 PPO epoch，
比较保留旧行为的约束强度：S2680 为 250，S2682 为 25，S2684 不使用该约束。
每种训练都重新执行并核对模型权重和 Core PlasticityLease 的更新记录。

只有红方中场满足现有 32 样本最低门槛，执行四次优化器更新；蓝方中场的
18 个样本不足，保持冻结。其余六个角色也保持冻结。这是三个独立候选，
不是连续晋升的三代球队，也不是八名球员都学会了接球。

候选仅在实际接球控制阶段使用，其他阶段继续使用冻结父模型；初始进攻
和场外抛回过程保留原有策略。部署选择掩码独立保存并核对，禁止将仅在
局部阶段训练的裸 checkpoint 当作整场通用策略。

S2684 第一次尝试把 anchor 系数设置为 0，被既有校验拒绝，未执行训练或
物理复测。第二次使用接口正式支持的 `behavior_anchor=None`，未放宽校验。
第一次失败目录保留，不覆盖。

六个课程均完成 primary/replay，即 **12 条完整物理轨迹**。独立审计核对
逐数组重放、文件／报告哈希，并从原始采样顺序重建 6750 帧动作、logp、value；
三组 PPO 权重和更新租约再次重算一致。重复审计不计为新训练样本。

结论：实时平衡修复在这批探索和三个候选复测中没有再出现上一轮的跌倒，
但仍没有学会严格接稳球。**未晋升任何候选、未替换默认球队策略**。降低或
移除旧行为约束没有在这个开发场景取得成功；不能据此断言所有约束系数或
其他课程都无效。这些是公开开发课程，不是独立泛化考试。

## 可复用代码

新增 `training/capture_learning_scope.py`，并在本轮三组训练中实际使用：

1. 接受生成动作时记录的探索掩码，不在训练时伪造或重写它。
2. 要求布尔型、时间及角色维度对齐的实际接球、实时基础模型和控制掩码。
3. 拒绝在非接球阶段、固定姿态基础或外部抛球等待期进行的探索。
4. 以真实出界／抛回／重新入场事件分段，奖励不跨越球的外部重置。
5. 保留“尝试探索但未实际控制”的原记录，由 PPO 正确求交确定学习样本。
6. 返回逐角色有效样本计数。零样本只是零样本，不代表通过或技能成长。

该工具只证明数据适用范围；物理真实性、采样策略和模型更新仍须分别核对。
足球控制与训练留在下游 soccer 仓库，复用 Core 更新租约，不往 Core 塞入
足球场景逻辑。

## 后续真正需要解决的限制

1. **样本密度**：建立短时、可复现的接球课程，或完整恢复物理状态与控制器
   历史的课程分叉。截取 NPZ 的后半段不等于恢复一个可运行的世界。
2. **身体稳定与留球分开**：平衡基础修好后，球仍能缓慢滚走。原控制中的
   接球停留的基础导航目标是原地，但随后仍有避碰修正与加速度限制；不能
   因此说实际平移命令为零。S2680 接球阶段实际 xy 命令最大分量约 0.586 m/s，
   结束时球速仍约 0.482 m/s。腿部小残差并不拥有完整追球／运球动作空间。
   后续应验证接球缓冲、跟球调整和下一任务交接是否给学习器提供足够控制能力。
3. **扩大角色覆盖**：目前有效经验集中于红方中场；要用可审计的课程覆盖蓝方
   中场、后卫和前锋，不能靠给它们标上“已训练”来宣称球队共同成长。
4. **晋升必须看物理考试**：不得用 PPO 损失、触球次数或身体站稳替代留球、
   带球、传接配合和减少出界的实际结果。
