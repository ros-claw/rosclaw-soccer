# S134–S141：角色化接球闭环、因果纠偏与多目标神经接触小脑

## 结论先行

本阶段没有把“多跑几轮”当作成长。它先发现并封堵了一类会制造虚假学习成绩的训练/部署
时钟错位，再沿失败责任边界逐层下沉，最终得到一个老师退出后仍能工作的多目标神经接触
小脑候选。

截至 S141，已证明：

- `red.finisher` 能在第五个连续来球观测后选择并锁存有界 RECEIVE 控制律，随后每 20 ms
  根据新的物理观测继续修正相位；
- 旧探索数据存在“待预测动作在观测前已经生效”的因果泄漏，现行 v2 数据契约会拒绝这类
  样本进入新 actor；
- 仅修改上层站姿、接触时机和脚向无法恢复 `s131.sealed.04`，失败已被正确归因到低层
  目标条件接触能力；
- 沿实测响应梯度构造的新老师课程达到 `13/16` 完整链、`16/16` 安全，并覆盖两个原失败
  上下文；
- 蒸馏后的 `68→64→64→29` 多目标神经小脑在老师和脚本都退出后达到 `2/2` 严格右脚
  进球，而同场无接触残差基线为 `0/2`，主轨迹与重放完全一致。

最后一项仍是**消费过的教师上下文因果金丝雀**，不是新鲜留出泛化。候选永久
`SIM_ONLY`，当前不具备发布、硬件或自动替换权限。

## 为什么这一轮先“变差”再突破

### 最初看到的假象

S134 的静态搜索在两个失败上下文中运行 16 条三 G1 完整轨迹，得到 15 条安全、6 条严格
完整链，看起来已经找到按来球状态选择站位/脚向的办法。第一代 actor 随后进入新鲜留出，
却只接受 1/6、严格成功 0/6；两轮失败回灌后，第三代 actor 已积累 112 条轨迹、20 条成功
和 92 条失败记忆，但 S136 新鲜考试仍为：

| 指标 | S136 actor v3 |
|---|---:|
| 运行时决策 | 6/6 |
| 接受 | 3/6 |
| 候选严格完整链 | 0/6 |
| 冻结父策略严格完整链 | 0/6 |
| 候选安全 | 5/6 |
| 精确重放 | 6/6 |

报告被拒绝，哈希：
`sha256:edd02a01b52dbc2e220842fb22311ea0e6d225f2e9c44d937ca00bf8133755c7`。

### 真正根因：观测被动作污染

旧搜索把待比较的站位、脚向和相位参数从仿真开始就写入射手。训练特征却在传球后、第五个
稳定来球观测才采集。因此模型看到的骨盆和关节状态已经是该动作造成的结果，再从中“预测”
同一个动作。这是 post-treatment leakage：离线最近邻很容易，部署时却没有这样的答案提示。

修复后的训练干预时钟为：

1. 组织者真实足—球接触并发出传球；
2. 终结者保持统一的 `receive-ready` 角色准备策略；
3. 连续五帧确认来球，采集动作发生前的球、本体和策略时钟特征；
4. 枚举动作经 `TRAINING_RUNTIME_RECEIVE_INTERVENTION` 路由锁存；
5. 因果 option 每 20 ms 根据新的 ETA 调整相位；
6. 冻结神经接触 actor 通过真实 MuJoCo 足—球接触产生结果。

现行 discovery/repair schema 为 v2，训练入口同时要求：

- `observation_precedes_action=true`；
- 每条轨迹都观察到运行时干预；
- 请求、报告和每条 NPZ 内容哈希一致；
- CPU MuJoCo、`SIM_ONLY`、无硬件命令。

因此 S134–S136 旧数据仍作为历史诊断存在，但不能再训练新一代 RECEIVE actor。

## 分层闭环：谁为哪类失败负责

本阶段把三机协作拆成四层，避免“一个 actor 为所有问题背锅”。

| 层 | 所有者 | 输入/职责 | 权限 |
|---|---|---|---|
| 战术/角色层 | `red.playmaker`、`red.finisher`、`blue.goalkeeper` | 角色、自我模型、传球/接球意图 | 不输出力矩 |
| RECEIVE 在线层 | `red.finisher.first_touch` | 来球位置速度、ETA、本体状态、策略帧；选择相位与有界接触几何 | 无姿态、关节、球状态权限 |
| 神经接触小脑 | `red.finisher` | 目标脚速、接触相位、球状态、29 关节本体感 | 有界 29-DoF 接触残差力矩，SIM_ONLY |
| 触球后交接 | `red.finisher` | 真实接触事件 | 只选择回稳交接时刻 |

组织者和门将在终结者课程中冻结。若传球未进入支持域，终结者 fail closed；若相位已对齐且
球速足够但方向错误，失败下沉给低层目标条件接触技能；若触球后失稳，则交给接触后交接和
恢复技能。这个责任分配可复用于抓取、递物、工具使用等非足球任务。

结果完全相同，证明运行时才改站姿已经太晚。

## S140–S141：从失败响应梯度训练低层小脑

### S140：第一批目标条件老师被拒绝

`-6…-1 m/s`，16/16 安全但仅 1/16 完整链，只恢复 `.05`，因此拒绝。

靠直觉判断；实测梯度明确指向穿过零继续增加目标侧速。

## 当前边界与下一步

本阶段已经证明“错误上层路由 → 因果纠偏 → 低层责任定位 → 教师可达课程 → 数据驱动神经
小脑 → 老师退出因果增益”的完整成长链，但还没有证明新鲜泛化，也还没有一个能根据运行时
来球自动选择 `(10,+3,-1)` 或 `(9,+6,-1)` 的目标路由器。

下一阶段应预注册并只运行一次：

1. 用动作发生前的 RECEIVE 特征和 S141 成功/失败标签训练目标选择 actor；
2. 在至少 6 个未用于 S137–S141 的球位/摩擦组合上运行候选、重放、旧 specialist 父策略；
3. 要求安全 6/6、精确重放 6/6、严格完整链至少 4/6、相对父策略至少增加 1 场，并同时
   出现进球和门将扑救；
4. 失败则按相位、指定脚接触、方向、触球后稳定四类误差自动分发到对应技能，不允许在同一
   封闭集合继续调参；
5. 只有新鲜门通过后，才制作本阶段宣传视频，并继续保持 `SIM_ONLY`。

因此当前最准确的产品表述是：**多目标神经接触能力已在消费上下文中通过无老师因果金丝雀，
新鲜目标路由与泛化尚待封闭考试。**
