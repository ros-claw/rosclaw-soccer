# 接球全网络接口与持续科研循环（2026-10-24）

## 当前证据上限

接球全 MLP 初始化已经在 96 个已认证物理轨迹的 37,344 条观测上完成
离线数值验证。这不是训练：优化器更新为零，新物理步为零，球队能力没有因此晋级。
全部 8 个 MLP 参数张量可训练，但本次物理资格测试将其全部冻结。
动作仍是关节位置目标与原固定 PD，不是直接力矩策略。

## 本次实现

`SharedNativeReceivingPlayer` 将接球网络接入真正共享的原生 MuJoCo 世界，
也支持独立手工物理时钟。网络读取该接球者当前的 98 维速度策略观测与
14 维因果身体上下文，不读取队友隐藏状态、原轨迹动作或未来评分。
原 ONNX 参考和两个 Torch 网络都在当前自身观测上重新求值。

一次提议不推进动作反馈；世界实际执行后，提交动作必须逐位匹配已施加的
29 维目标，才更新上一动作、步态相位、过去接触标记。重复提议、提前提交、
时间错位、超出原动作盒、PD 增益变化等会锁定故障，不静默修补或重试。
每个控制实际计费为 A 一次网络、B 原参考一次与全网络两次，共四次。

采集器和独立复核器保留原默认路径，新增独立协议
`receiving-whole-mlp-initialization-native-v1`；这不是旧 PPO 的训练数据。
新入口检查完整初始化权重与固定 ONNX、动作尺度及上下文尺度严格相符，
使用 `weights_only=True` 载入，并拒绝被训练或被替换的初始化。

## 预注册物理资格测试

入口：`scripts/rsi_qualify_receiving_motor_native.py`。
选择已经消耗的 TRAIN 索引 0、6、24、32、60、64，每例执行两次；
包含三个物理初始条件、已知精度案例及接球退化案例。
保持 A 为实际 generation 2 / theta12、原私有噪声种子、原运动与恢复采样律。
正式任务期限与成功门槛不变，最多每世界 400 控制、4,000 原生步。

只在新世界自身网络动作执行完毕后比较旧物理证据，绝不播放旧动作。
要求初始状态、全部原生子步状态、力矩、接触、A/B 原有观测动作与采样记录
逐位相等，任务及恢复判定相同。独立进程再用独立手工原生时钟复核新接口的
完整新增上下文、实际动作反馈与物理轨迹。最多共 96,000 原生步。
任何失败保留，必须诊断后另立协议，不原地盲重跑。
通过也只证明接口没有改变这些已知场景，不证明学会接球或 Fresh 泛化。

## Agent loop 的真实保证与边界

宿主持久 Goal 保持 ACTIVE；正常实验结束不等于 Goal 完成。
一次科研循环必须读取实际证据、更新假设、声明有预算的下一步，再执行。
实验使用不可变源码、外部输出和独立 systemd 作业，便于 agent 重接时核对。
失败不是自动重试理由；同族无净增益、旧能力退化时按总纲止损转向。

只读每分钟观察器检查实际 PID、作业状态及产物；没有实际作业时保留空闲起点，
300 秒无后继会标记 `SCIENTIFIC_SUCCESSOR_OVERDUE`，不能被监控心跳抹掉。
源码开发时间可能合法触发此告警；告警不等于训练正在执行。
观察器不唤醒 agent、不替 agent 做科学决策，也不证明永久在线。
宿主关闭、机器重启或会话故障后，必须重新唤醒并核对账本、收据和实际进程，
不冒充无人值守永久运行。连续 4v4 比赛及可宣传球队视频目标仍未完成。
