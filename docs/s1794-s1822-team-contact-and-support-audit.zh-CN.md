# S1794–S1822：三人射门恢复、门将触球与支撑证据修复

## 边界

这是仿真开发记录，不是宣传片验收。没有自主 4v4、没有新的神经网络
actor-critic 晋升，也没有证明真实机器人可用。门将采用新的、明确标记的
优化平衡姿态初始化，只在 t=0 设置根姿态；随后由关节力矩控制。
原始站姿进入该控制器的失败没有被此新协议抹去。

证据根目录：`/home/dell/rosclaw_soccer_evidence`。
独立实验脚本：`/code/rosclaw/phase8_evidence/s532-delayed-handoff-cpu-v1`。

## 射门链路

S1794 的三种门将初始站位均保持站立，但前锋误差约 149 mm，胫骨几何
间隙为负，没有通过。S1796 的 8 个配置中，外层抬膝幅度形成的 4 对轨迹
完全相同：触球前由运动记忆拥有 PD 控制权，该参数没有真正进入动作。
S1799 对门将 5,500 个原生控制步骤复算，原始 LQR 力矩最大误差 0 Nm。

S1800 改为实际进入记忆控制的膝关节偏移，8 个合法配置仍全部失败。
早期 v1 有超出动作范围的请求，被断言拒绝；未裁剪成合法值冒充通过。

S1804 重新测试记忆速度反馈比例，1.5 在三人新初始化协议中通过：
左上角目标 `(-3.35, 1.75)`，球门平面误差 **25.09 mm**，胫骨最小间隙
**1.01 mm**，87 个关节、力矩和触球门控通过。其他 3 个比例没有通过。

冻结参数后，S1806 四个新摩擦条件 `.1102/.1106/.1114/.1118` 的误差分别为
**9.80 / 7.43 / 22.91 / 20.25 mm**，严格 0.1 m 精度、上角与真实门柱间隙、
全关节、非足球身体触球检查通过。最小胫骨间隙约 **0.894 mm**，仍然很窄。
S1814 对全部 22,000 个原生记忆 PD 提议精确复算，并检查 87 个关节及原生时钟。
这些是固定场景邻域的四个留出点，不是泛化成功率或整队能力证明。

## 门将：碰到球不等于扑出球

S1816-v2 用真实轨迹重建原有手套椭球与足球表面的距离，四个留出案例
最小间隙约 **44.3 / 33.4 / 17.3 / 19.7 mm**。原有表面遥测全为 NaN，
没有将 NaN 当成零间隙。重建是接触窗口采样几何分析，不是独立力测量。

S1820 固定前锋参数、显式改变门将初始横向站位：

- `-3.25/-3.27/-3.29 m` 三个案例在约 **1.752–1.753 m** 高度发生真实左手套触球；
  记录的表面距离分别约 `-1.189/-0.879/-0.516 mm`。
- `-3.31 m` 没有触球。
- **四个案例均未扑救成功**，前三个只是擦到球，球仍入门。

没有扩大手套、修改足球轨迹或添加击球根力。上述站位是开发初始化扫描，
不是自主横移能力。触球后的入门点变化也不能作为“更精准射门”的新证据。

## 起跳探索与证据缺陷

S1802、S1808、S1812、S1818 分别探索受保护的伸膝轨迹、关节蹬地脉冲、
垂直平衡反馈释放、脚底雅可比映射蹬地力；均未得到合格的起跳恢复动作。
部分大幅度候选跌倒或关节越限。不能把离线参考高度变化当成跳跃。

检查发现这些独立起跳脚本把“与世界接触、但不是脚”的所有物体计入门将
其他部位着地力，因此错误计入了远处足球的 **4.2183 N** 落地力。
这是实验观测器缺陷，不能据此声称既有足球运行时也有同样缺陷。

新增通用 MuJoCo 只读工具 `sim.support_forces.measure_support_forces`：

- 明确机器人根节点、支撑部位和地面几何，按机器人子树归属过滤；
- 排除足球、队友、对手和未指定为地面的墙体；
- 分别返回支撑部位与机器人其他部位的接触力模长之和，不冒充净支撑力；
- 拒绝非法作用域和非有限力值，不推进仿真、不修改状态。

S1822 复跑 S1818 的 8 个案例，逐元素断言除错误观测列外所有状态与控制
完全相同。修复后仍然 **0/8 合格**；最大幅度案例仅出现 2 ms 的判定离地，
同时跌倒、关节越限，必须拒绝。这次修复提高证据可信度，没有制造成功。

## 后续验收方向

优先从已验证的射门与真实触球继续，提高触球覆盖和实际挡出效果，再加入
自主移动和更多来球。参考轨迹、局部控制、实际球接触、扑救结果和视频表现
必须分别验收，不以漂亮姿态替代完整传球—射门—扑救链路。
