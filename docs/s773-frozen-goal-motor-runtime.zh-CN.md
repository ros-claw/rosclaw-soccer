# S773/S774：目标条件化小脑的冻结运行接口

## 已完成内容

新增 `providers/g1/goal_reference_motor.py`，将已有 136 维观察、30 维输出的训练模型转换为可复用的**只读、冻结、逐球员独立**推理接口。

这不是一次自动部署，也不是直接关节力矩控制。实际输出仍为 29 个受限关节目标残差，以及下一步教师参考朝向。调用方继续负责动作资格、教师历史、坐标变换、关节/力矩限制、接触证据和候选晋升。

## 接口与状态责任

- 构造时验证数值 NPZ、张量形状、文件大小和完整内容哈希，不加载 pickle。
- 契约绑定模型、冻结基础策略、参考库、坐标变换、默认关节角和两组动作限制。
- `begin_episode(target_position_xy=...)` 固定本回合目标，复制输入；回合哈希同时绑定目标和模型契约。
- 每个实例独立持有上一次关节残差和参考朝向；调用方不得在球员间共享实例。
- `propose()` 仅接受连续的第 0–199 帧。重复帧、跳帧、非法数值均锁住实例，直到显式新回合复位。
- 第 n 步消耗使用第 n 步朝向生成的教师目标，返回第 n+1 步朝向。模块不会自行修改教师或仿真器。
- 推理不依赖 Torch，不包含优化器、仿真步进或硬件传输；所有输出硬标记 SIM_ONLY。

固定的残差幅度、平滑和每步上限与现有训练契约一致；参考朝向为 0 ± 0.1 rad，每步最多 0.02 rad。不能把其他动作范围训练出的权重直接视为本接口的合格模型。
