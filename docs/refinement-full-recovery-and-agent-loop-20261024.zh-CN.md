# 恢复段直接学习与持续实施闭环（2026-10-24）

## 当前结论，不是成功宣告

持续目标仍是有物理证据的自主连续4v4及球队视频。目前没有达到。
generation2两模型各完成4次新actor/critic更新、累计12次，随后各12场
配对物理试验和12场独立复跑全部闭合，但严格成功仍为0，不晋升。
不能把优化器更新、监控心跳或局部奖励提高当成足球能力突破。

## 发现与修复

审计上一批每模型96条实际轨迹：37344个A神经控制步中，27744个踢球
动作具有随机采样概率，9600个恢复动作是确定性动作。恢复确实执行且
计入奖励，但没有直接的恢复段策略梯度。共享head的更新仍会间接改变
恢复动作；这不是覆盖完整动作链的actor学习。

旧v1协议保持：运动段采样，恢复段确定性，回报按实际恢复长度延迟。
新v2采样协议显式启用 `sampling_include_recovery`：运动与最多100个恢复
动作共享一条私有AR(1)历史和CPU RNG，不在切换时重置。正常289+100=389步
全部有实际执行动作和条件概率；失败在哪步发生，就只保留到哪步，绝不
填充、补造站立或把旧inactive尾段改标签。

正式运动时限仍300控制步，恢复资格仍100步，原始关节权限±0.2rad、
PD、场景、球尺寸、0.1m精度和3m/s来球速度门槛均不变。
新全历史MC回报为 `reward * 0.995**(n-1-t)`；恢复已经在历史内，不再
重复增加100步折扣。运动段的实际终端距离与原协议一致，新增直接恢复信用。

新v5续训类型与v3/v4区别保存，精确继承generation2实际head、已训练critic、
Adam状态与计数12及CPU RNG；不重置成新模型。仅head和critic可训练，完整
父模型仍冻结，输出仍是关节位置目标加固定PD，不是直接力矩策略。

## 预定实验链

每模型采用三个已消耗TRAIN初态（名义、前后0.005m），不是Fresh。

1. 新独立噪声12场校验，两CPU spawn worker；独立手动native时钟复跑12场。
2. 校验全部native与RNG概率匹配后，四worker采样96场、再独立复跑96场。
3. 仅全量通过的新协议数据进入准备，逐轨迹从h0核对行为均值、概率和旧critic。
4. 全96条轨迹续训最多4次带KL门控的更新，保留失败，不择优挑轨迹。
5. 新策略与原BC在相同三个初态配对评估12场，再独立复跑12场及科学复盘。
6. 如仍无精度/速度联合达标信号，转向控制接口与可观测性诊断，不无休止
   调同一失败head家族，不放宽任务门槛。

## agent loop如何保持可检查

- 持续Goal保持active，只有实际整体目标达成才完成；阶段完成不是整体完成。
- 每阶段保存源commit、输入hash、声明、预算、实际PID/计数、complete/failed。
- systemd依赖串联已声明有限阶段；前驱失败就封闭下游，不偷偷重试已计费物理。
- 观察器每分钟读取阶段状态，并将无实际活动、无合法后继超过300秒标为逾期。
  观察器只读，不会唤醒agent，也不能当成训练进展；需要宿主持续Goal接续
  分析与开发。明确区分等待真实运行任务、正在开发、前驱失败、全部结束。
- 每次接续先核对真实进程、完成文件、失败文件和恢复指针，再选择下一步；
  不能反复轮询已结束任务冒充工作。失败则诊断、版本化修复、用新输出运行。
- 重启后先核账；临时systemd任务不保证跨重启存活。保存的指针是恢复依据，
  不是永久在线承诺。不承诺平台、进程或电源中断时仍能执行。

原始数据和模型在外部证据目录，不入Git。该更改只允许SIM_ONLY本地研究；
独立复跑不等于新初态泛化，视频不代替物理验收，实验模型不自动晋升。
