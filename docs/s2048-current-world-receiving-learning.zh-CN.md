# S2048：在真实八人体仿真反馈中学习接球，未通过考试

## 结论

确实进行了在线采样和 actor-critic 更新，但没有获得可晋升的接球能力，更没有获得连续比赛宣传片。训练时出现实际脚部触球，未形成符合约束的控制；固定考试中父代、候选均为 0/4 控球、2/4 全场安全。候选保留作诊断，不替换冠军。

## 做了什么

八台 G1 共处同一个 MuJoCo 世界，冻结基础步态及八角色近球策略，仅给蓝队中场注册独占的接球关节残差模型。接球模型从既有 S364 actor-064 开始，收到真实来球、协商接球授权且身体就绪后激活一次，最多 100 个 50 Hz 控制帧。闲置时仍由原有导航和基础步态控制，不与另一踢球模型叠加。

使用当前完整世界的反馈导航，而非离线重放另一环境的导航命令。模型输出是 29 维有界关节角残差，不是直接力矩。所有试验 SIM_ONLY，没有硬件执行，也没有中途移动球、重置身体或重置比赛以制造成功。

4 轮 × 4 个训练位置，每轮只有 2 个位置满足接球激活条件，实际共 800 个学习帧。每轮 4 次优化器更新，总计 16 次；不能把 16 个完整世界试验误报为大规模有效接球数据。PPO 学习率 2e-5，输入 133 维，每轮保存父子权重、原始观测、未裁剪采样动作、对数概率、价值、奖励及 Core 更新证明。另有 4 个固定偏移位置，父代和候选各测试一次。全部物理试验均有配对重放。

训练位置为 (6.4, ±0.03)、(4.95, -0.6±0.03)；考试位置为 (6.4, ±0.08)、(4.95, -0.6±0.08)。这些考试位置后来被用于 S2054 开发，不能再作为后续方案的未见测试集。

## 实测结果

| 项目 | 父代固定考试 | 候选固定考试 |
|---|---:|---:|
| 实际激活接球 | 3/4 | 3/4 |
| 接球者实际脚部触球 | 0/4 | 0/4 |
| 严格控球成功 | 0/4 | 0/4 |
| 全世界安全 | 2/4 | 2/4 |

训练中第四个位置每轮都有实际脚部触球，接触时刻约 2.98–3.08 秒；窗口末球速分别为 3.105、1.138、0.257、0.367 米/秒，但四次均未满足完整控球条件。奖励从 2.604 增至 3.100 不代表学会控球；首触球奖励能够产生正回报，不能代替终态验证。

16 个训练世界中 13 个整体安全；接球窗口内的局部身体安全也不能替代全场安全。固定考试的三个实际激活位置，候选脚部最小球距为 0.860、1.018、0.861 米。模型根本没有触到球，终态球速与父代相同。

## 为什么没有盲目继续加训

候选第三个考试位置在约 1.26 秒激活接球，此时球位置约 (4.40,-0.33)，中场身体约 (4.33,0.80)，球速度约 (-3.24,1.12) 米/秒。之后球高速掠过，中场尚未进入接球路线。这个观测支持优先修复传球质量、提前站位和导航的判断；它不是对所有未来策略不可达的数学证明。

因此准备中的 135 维朝向 PPO 扩训暂缓，先冻结模型，比较出球准备站位深度和侧向位置。朝向输入契约已实现并测试，见 S2050 文档，但更完整的输入本身不会把不可接的传球变成可接。

## 证据与复核

外部证据根目录：`s2048-current-world-receiving-ppo-v1`。包含 `training.json`、四轮 batch、generation-000 至 generation-004，以及每次 primary/replay 的轨迹、采样和报告。大文件不进入 Git。

训练清单摘要：`sha256:95a65564c533f009d10093786eb09fa2a4bac9dd98435474c703d55f6a4b4c81`。

独立审计进程从原始样本重建 batch、物理奖励，核对原始文件摘要，并精确重放四轮优化器更新及 Core 证明，全部一致。这是证据和更新重放，不是第二套物理引擎的独立验证，也不构成晋升。

S2048 代码全量测试：3697 通过、29 跳过、11 个既有历史证据依赖失败；没有隐藏或放宽这些失败。新增采样器覆盖确定性种子、真实概率记录及边界，控球判定覆盖无接触、过晚接触、其他身体触球、碰撞、关节越界及球速过高等拒绝条件。

连续比赛的目标仍未完成。下一步先取得可复现、可接的出球与接球，再检验接球后的二次传递及两队持续对抗，不能用剪辑代替这条链路。
