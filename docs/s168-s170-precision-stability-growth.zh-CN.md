# S168–S170：射门精度、持续记忆与真实泛化复盘

## 结论先行

这一轮完成了一个诚实但尚未晋升的闭环：S168 从 S167 的三个失败场景中搜索并绑定新的完整物理轨迹，S169 在不改写 120 条旧记忆和旧归一化尺度的前提下增量吸收 93 条新轨迹，已消费回放由 S167 的 `3/6` 提高到 `6/6`；但更严格的新鲜精度考试 S170 没有通过。

已经得到的能力与仍未得到的能力必须分开表述：

- **已得到**：失败数据能进入可审计训练；旧记忆逐条原样保留；已消费六案例达到候选 `6/6`、冻结基线 `1/6`、净增 `+5`；安全和确定性复现均为 `6/6`；其中一个进球误差为 `0.0991508 m`。
- **未得到**：在新的局部扰动上维持 `0.10 m` 精度。S170 最终考试只有候选 `2/6`、基线 `1/6`、精确进球 `0`，因此状态为 `REJECTED_RUNTIME_FINISH_PLAN_PRECISION`，不可晋升。
- **工程突破**：sealed 分区不再只检查“上下文哈希不同”，而是重建运行时 actor 真正看到的九维特征，要求每个留出点与全部训练记忆保持预注册的归一化距离，并封存源策略、训练特征承诺和最小距离。

这说明系统确实会记住和复现修复结果，但当前最近邻计划 actor 的成功口袋太窄，还不能把“记住失败附近的正确动作”称为“学会稳定、精准射门”。

全部结论仅属于三台全身 G1 的 CPU MuJoCo `SIM_ONLY` 实验；未发布 ROS 主题、未连接设备、未发送任何硬件命令。

## 一、S168 如何从失败中学习

`prepared_finish_precision_repair.py` 把 S167 三个失败场景永久转为已消费开发数据。每个候选都是一个有界联合计划：接球准备站位、接触帧、足端朝向和三维任务空间目标一起变化；关节力矩仍只由冻结的 S141 神经接触 actor 输出。

## 二、S169 如何解决 Stability–Plasticity

S169-v4 actor 不是覆盖式重训，而是带严格谱系的增量记忆更新：

1. 加载 S165 父 actor，并校验 body、kick prior、roster、角色 self model、神经接触 actor 与 handoff actor 全部一致；
2. 以 trajectory digest 去重，父 actor 的 120 条记忆必须全部出现；
3. 对父记忆逐字段比较上下文、九维特征、完整动作和成功标签；任何变化立即拒绝；
4. 父记忆连历史质量分数也原样保留，新评分只用于新轨迹；
5. 归一化中心与尺度冻结为父 actor 数值，避免新增局部数据让旧决策边界整体漂移；
6. 新增 93 条 S168 物理结果，其中成功与失败都保留，以维持可塑性和失败排斥。

## 三、S170 为什么拒绝

S170 把门槛同时提高为：

- 六案例至少严格成功 `5/6`；
- 相对冻结基线净增至少 `+2`；
- 安全 `6/6`、精确复现 `6/6`；
- 至少三个严格进球误差 `≤0.10 m`，且所有严格进球都必须落在该半径内；
- 至少一次真实 MuJoCo 门将接触扑救；
- 教师与脚本接触力全程关闭。

S170-v1 的物理诊断为候选 `3/6`、基线 `2/6`、一个进球、两个扑救、安全/复现 `6/6`，但唯一进球误差 `0.441441 m`。审计随后发现第六个案例虽然 context hash 新鲜，运行时九维特征却与一条训练记忆完全相同，所以该轮被结构性作废，不能作为 sealed 结论。

修复后，S170-v2 分区对每个场景重建真实运行时特征，六个最近训练距离分别为：

`0.151084, 0.023244, 0.058109, 0.058109, 0.328177, 0.104816`

均高于不可弱化的预注册下限 `0.02`。请求还封存了 S95 lead policy、源 evidence、全部特征向量及哈希、213 条训练特征的集合承诺和逐案例最近距离。因 validator 发现 JSON 元组/列表规范化缺口，v2 结果只作为实现诊断；修复 validator 后的 v3 又在提交前审查中暴露“调用方可以弱化严格门”的接口缺口。最终实现拒绝低于 `5/6` 严格成功、三个精确进球、净增 `+2` 和特征距离 `0.02` 的配置，并以相同 v2 物理分区重新生成 S170-v4。

## 四、为什么“训练集越来越好”，新鲜集却没有同步变好

原因不是 RL 理论上应当单调进步而这里“少跑了几轮”，而是当前学习表示和接触动力学不匹配：

1. **最近邻动作是分段常数**：九维状态稍微移动就可能跳到另一套完整计划，动作随上下文不连续。
2. **成功区域极窄**：毫米级球位、摩擦和传球朝向变化，会同时改变到达相位、指定脚触球法向和射门方向。
3. **质量分数不能产生插值控制**：增加成功记忆会改变“选哪条”，却不会学习相邻动作间平滑、可微或概率化的关系。
4. **10 cm 精度比进门严格得多**：S167 的通过门考察完整链路与相对增益；S170 新增目标误差约束后，原有成功不等于精准。
5. **局部修复不是泛化**：S169 的已消费 `6/6` 是必要的吸收测试，但 S170 证明它还不足以跨到相邻物理状态。

所以正确动作不是继续把 S167 反复训练到 `6/6`，而是换模型、损失和新鲜评测协议。

## 五、本轮对通用 ROSClaw Growth 的贡献

足球仍只是压力测试。可以向通用 rosclaw 提炼的能力包括：

- **Immutable Parent Memory**：持续学习必须逐条证明旧经验未被改写，而不只是报告总样本数；
- **Frozen Feature Frame**：增量阶段冻结父模型的观测坐标系，防止数据分布变化造成隐蔽遗忘；
- **Feature-Level Holdout Freshness**：留出集在模型实际观测空间中判重和计算距离，不能只靠任务 ID 或上下文哈希；
- **Rejected Evidence as Learning Input**：失败报告不具晋升权，但其完整、安全、绑定的轨迹可进入下一轮训练；
- **Consumed Replay vs Sealed Exam**：吸收测试和泛化测试是两个不同产品状态，不混用宣传口径；
- **Authority Separation**：高层 actor 只选择准备几何、相位和任务空间目标，冻结神经小脑独占关节力矩，学习不能自行扩大权限。

这些契约不依赖足球，可复用于抓取接近姿态、移动导航局部计划、双臂交接和无人机机动策略。

## 六、下一阶段建议

下一轮不应继续无边界扩大最近邻记忆库，而应进行以下结构升级：

1. 用成功/失败记忆训练带不确定度的连续计划 actor，输出动作分布或局部残差，并以最近邻作为安全回退；
2. 将接触相位、指定脚冲量方向、球门目标误差和触后稳定分别建成多任务 critic，解决单一严格布尔标签的稀疏信用分配；
3. 对每个候选先做 support/OOD 和失败边界门控，再由冻结 MuJoCo 批量验证，只有跨种子和新鲜分区同时改善才生成新 actor；
4. 保留父 actor 做 behavior anchor，以回放蒸馏或 KL/动作偏移预算约束可塑性；
5. 建立三层考试：已消费吸收集、局部插值集、扩大分布集，分别回答“记住了吗、会插值吗、能泛化吗”；
6. 达到 sealed `≥5/6`、安全/复现 `6/6` 且至少三个 `≤0.10 m` 进球后，再制作新的晋升宣传视频。拒绝轮只制作明确标注的诊断视频。
