# S2200 起：探索配置更正与神经运控 GPU 小试

日期：2026-09-16。仍未通过连续比赛考试，没有合格宣传片；所有实验限于 SIM_ONLY。

## 必须保留的错误更正

S2200 原计划扩大原生踢球策略探索，将 `logstd` 设为 -3。但加载后的父检查点本来就是 -3，而不是从模型构造默认值误推的 -4。该更改实际没有效果；此前“标准差提高约 2.7 倍”的描述不成立。

独立比较 S2192 与 S2200 的 62 个同名 NPZ 文件，所有数组精确相同，包括检查点、推理样本、物理轨迹和训练 rollout。实际标准差倍率为 1。S2200 保留为重复对照，不算新的探索数据或能力提升。原始运行文件、日志和清单不改写。

- 原 S2200 清单：`sha256:f040c06f99acb61d0b5c326cdf2f57c30fd33c238ee8f6d79541567c309c125b`。
- 追加更正 `s2200-broader-native-exploration-v1/exploration-correction.json` 文件 SHA256：`7395fc853b36a4f207e7b686289e64047744aa614a6bb6dcc83e379509ef1676`。

新增 `training/exploration_change.py`：检查真实加载的逐维参数及实际采样器裁剪区间，拒绝无效变化、裁剪后的无变化或任一维下降；只返回声明，不修改模型、不宣称学会技能。18 项测试覆盖这些边界。相关 PPO、奖励与完整踢球学习合计 99 项测试通过，针对性 mypy 和改动文件 ruff 通过。

S2204 才是真正的 -3 → -2 初始化对照，标准差约从 0.04979 到 0.13534。采集器从检查点重建每步均值、固定种子的高斯噪声、动作和 logp，必须逐项精确一致。初始确定性物理轨迹已与 S2192 精确一致。训练尚在运行，结果另行追加；参数改动本身不算训练成果。

## GPU 小试：先验证控制器，而不是盲目扩大并行数

S2202 用固定 SONIC 默认关节姿态加受限 PD，CPU 和 GPU 都倒地；该试验不能作为平衡控制基线。其清单为 `sha256:31860e2accf5da37243bebf708161516934fcb7ef46651e9bec292a85f50e898`，失败证据保留。

S2206 改为已有冻结 RoboNaldo 神经网络步行策略，记录初始 LSTM 构造、每个副本独立历史；不在运动中重置状态。零物理速度换算为归一化命令约 `[-0.27272725, 0, 0]`，不能错误地传全零归一化值来声称静止。

在物理 GPU 2 上执行 16 个相同初态副本，每个 5 秒、250 个控制步、2500 个物理步，合计 40000 个世界物理步；另跑原 CPU MuJoCo 的独立神经运控对照。

这不是 16 个独立任务，也不是四卡新训练，更不是八人比赛通过。模型为既有预训练模型；GPU 物理使用明确记录的单体训练场景，球门与共享足球场不同，不声称共享场景接触精度已认证。最终足球考试继续以原 CPU 物理为依据。不停止其他人的 GPU 进程，不删除既有证据。随后将测试运动命令，不能由站立通过推断奔跑和触球也通过。
