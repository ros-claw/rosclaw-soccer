# S239–S245：先修正训练中的球，再继续学踢球

## 结论与边界

本轮找到一个会妨碍 GPU 学习迁移的真实物理后端缺陷：已安装的
MuJoCo Warp 3.10.0.2 对自由关节使用第一个 DOF 的阻尼计算全部六个
DOF 的被动力。项目的球明确区分平移阻尼 0.02 和旋转阻尼 0.00002，
这个实现使 GPU 中旋转阻尼放大 1000 倍，球提前减速，脚与球的相遇位置改变。

这不是新球技，也不等于完整 4v4 已通过。修复不改变球的半径、质量、
摩擦、目标位置，不给球施加额外推进力，不改训练奖励来掩盖失败。
此前 CPU 独立物理验收仍然有效；此前 GPU 训练/筛选不能被当作相同物理
条件下的验收，需在修正后的后端重新检查，不能倒填旧报告。

S244/S245 中完整场景使用远离球的无控制身体，目的是排除踢球策略；
不是人体稳定性试验。上述误差是 1 秒时位置分量最大绝对差，不是长期
轨迹或所有接触情境的误差上界。

## 工程修改

- 新增 `sim/mjwarp_contract.py`：用临时状态和真实 CPU/GPU 内核，测试
  三组正负速度下每个 DOF 的阻尼力。非有限、形状不同或力不一致即拒绝。
- `G1VectorMotorBatch` 在声明任何训练 episode 前执行该检查，并把校验
  合约哈希纳入世界身份。源代码内核哈希、阻尼参数哈希、实测力哈希均绑定。
- 提供 `patches/mujoco-warp-3.10.0.2-per-dof-damping.patch`，只修改自由关节
  和球关节的被动阻尼索引，同时覆盖首 DOF 阻尼为零、后续 DOF 非零情形。
- 不自动修改依赖、不安装全局 monkey patch、不设置给球加力的回调。
  本地 corrected 包为独立复制品；其他实验原始环境保持不动。

训练前检查只证明被动阻尼这一项。接触采样、身体安全、球门精度、CPU
独立复验和旧能力保持仍各自必需。检查本身只做 forward，不步进时间，
不产生训练 episode，不是硬件动作或授权。
