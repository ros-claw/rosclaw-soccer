# S1153–S1156：接触采样等价优化

2026-09-13。SIM_ONLY。此项是仿真数据采样优化，不是新的球技或宣传片成果。

## 改动范围

`providers/g1/contact_storage.py` 新增显式的接触存储校验。
原实现对有效槽反复做 `normal[valid]`、`world[valid]` 的动态长度索引，
再把有限性和世界编号检查结果分别取回主机。新实现使用固定形状掩码
归约和一次主机判定，不改变占用槽的有限性、世界编号边界或填充槽语义。

占用槽的 NaN/Inf 和越界世界编号仍拒绝；未占用的未初始化填充不算
物理接触。增加显式维度、dtype、设备和环境数量合同检查。采样器原有
逐物理步时钟与故障锁存保留，触球阈值、分组和最大力归约没有修改。
没有删除检查、跳过物理步、合并时间步或改动接触几何。

此函数不编码球、脚、守门员或队伍规则，接入现有 G1 仿真 provider。
它不是新的 Core 安全或晋升模块，不提供真实硬件授权。

## 实测范围

S1153 使用 CUDA 物理卡 3 的合成有填充存储，交替运行新旧校验。
在并发训练负载下，每组八次、每次 100 调用：

| 存储槽数 | 旧校验中位数 | 新校验中位数 | 比值 |
|---|---:|---:|---:|
| 4,096 | 1.808 ms | 0.379 ms | 4.77× |
| 65,536 | 1.828 ms | 0.410 ms | 4.46× |

该表只是校验函数微基准，不是完整采样或训练速度。CUDA 上另外检查了
有效槽非有限力和越界编号的拒绝行为。

S1154 在实际 256 世界、2 ms 物理步的五秒仿真中，同时运行旧、新
采样器。两种读取使用同一个正在演化的物理状态，而不是比较两个可能
数值分叉的 GPU 仿真。5,000 次采样调用、10,000 组向量输出逐元素
一致；每次读取前后 qpos/qvel/ctrl 一致，两个采样时钟保持同步。

S1156 再次进行该配对，并逐步交替新旧执行次序、同步 GPU 后记录
完整采样调用耗时。5,000 调用的累计时间为：

- 旧采样：18.853 s，平均 3.771 ms/调用。
- 新采样：12.747 s，平均 2.549 ms/调用。
- 本次调用耗时比为 1.479×，新调用时间减少约 32.4%。

该结果含接触力读取、校验、分组和归约，不含全部物理、网络推理、
优化器或数据压缩。仍是在并发 GPU 负载下的一组实验，不能据此声称
整套 PPO 训练快了 1.48 倍。查询相等也不是 CPU/GPU 物理等价证明。

## 回归与版本隔离

新增 19 个校验用例，连同原有采样时钟测试共 26 passed。覆盖随机
旧语义对照、有效的非连续存储、未初始化填充、空数组、NaN/Inf、
越界编号、错误合同和采样器故障锁存。

S1155 全仓回归：2,656 passed、29 skipped、11 failed、0 errors。
11 个失败身份与 S1134 完全相同，仍为既有外部证据相关测试；不是
全仓全绿。全局 ruff、三个改动文件格式、两个源文件 mypy、compileall
与 diff 检查通过。

开发在隔离工作树进行，正在运行的 S1146 长训练仍固定使用
`f6c9d01` 所对应的旧源码树，没有中途替换采样器。代码可以独立提交
到远端 main；本地训练工作树的同步必须等训练与检查点复查结束。
