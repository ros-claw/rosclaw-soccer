## 固定输入与模型

新数据银行已闭合：22131 行，其中原 21922 行逐字节保留，新 209 行来自案例 4 第

## 三个更新种子

共享同一继承权重与优化器起点，独立的优化抽样 RNG 为 2026103100/3101/3102。
这是三个独立优化种子，不是三个随机初始化模型。每个新增 2048 次 Adam 更新，原
1024 次与新增更新分别记账，最终优化器各槽应为 3072 步。学习率 0.0003、梯度范数
上限 1，正样本每批 256 原教师 + 256 新干预教师，另 512 旧保护状态。活跃样本权重
5，原教师零修正前段仍参与原始动作头拟合，以约束靠近动作开始点的偏差。

训练使用独立 CPU batch1 复核过的父代动作缓存，不用 GPU 批量路由结果替换它。
基础策略和父代参数不进入优化器，旧状态与非活跃状态在推理时精确返回父动作。
必须检查实际权重变化、非零梯度、真实 Adam 状态和完整 CPU batch1 证书，不能只
报告执行过多少步。物理中可能产生的后续分布偏移仍需完整考试检验。

## 必需的零更新对照

另构建一个 `geometry_only_control`：使用相同新数据导出的支撑，动作头和优化器
保持继承值完全不变，新增优化器更新为 0。它使用独立的非学习状态标识，不能被
报告成新神经模型。这样能区分：

- 经验覆盖扩大后，旧动作头被允许用于新状态的效果；
- 新数据指导下，神经参数更新的额外效果。

若只前者有效，就如实报告记忆/适用域增长；不能把它归因于权重训练。

## 验收与继续条件

先完成三更新模型及零更新对照的首脚接管 TRAIN20，独立重算自身网络和全阶段原生
物理。新模型还需三种子原 TRAIN16、DEV16 保留验证，比较既有最好编排
`[12,19,16]`、`[16,14,15]`、`[14,14,14]`，不改球路和安全门槛。
重点首脚 4/5 均成功、保留与自身物理审计通过后，才能进入新隔离 Fresh；已消费的
Fresh 不得回流。只学会案例 4 可以记录局部物理学习，但不算完整前沿通过或球队
比赛目标完成。

失败时依据自身状态反例继续教师能力、数据聚合或表示研究，不再盲目增加同族轮数。
本阶段是有物理反馈的持续监督学习，尚无在线 PPO、actor-critic 或直接力矩策略训练。
# 结果续接与 agent loop 边界

本轮使用 `rsi_review_paid_full_entry --interventional` 汇总三种子、三考试库及其独立审计，
并读取同数据、同祖先、同适用范围但零新增 SGD 的对照。对照与学习模型的物理差异单独记录，
不能把权重变化、拟合误差或门控变化当作球技提升。原有逐案例保留要求不变。

执行链是：冻结源代码 → 有限更新 → 无教师接管考试 → 独立自身神经网络和原生物理审计
→ 固定规则汇总 → agent 基于失败证据决定下一科学阶段。汇总器可以预先排队等待证据，
但不自动重跑已收费的实验，不因拒绝而无限增加 epoch，也不会自动把候选提升为冠军。

`rsi_watch_research_loop` 仅观察进程与产物；定时器、CPU 利用率和 `active` 状态均不能
保证 agent 正在思考或算法正在成长。`failed.json` 和 `failure.json` 均视为失败信号。
持久恢复指针必须在阶段变化时更新，记录已关闭实验、运行中任务和下一动作。
Goal 持续执行依赖宿主提供续接；应用退出、宿主停机或后端失联时，不宣称 agent 仍能自行运行。

本轮若未通过：保留旧冠军，消费失败记录，定位自身轨迹最早偏离和教师可恢复窗口，
再决定有限的自身状态教师重规划/数据聚合；不得用重新观看旧视频或重新运行旧成功案例代替推进。
