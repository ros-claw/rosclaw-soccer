# 干预式持续模仿学习：有限更新与因果对照

SIM_ONLY。数据准备、神经参数学习、物理效果和晋升是四个不同结论。

## 固定输入与模型

新数据银行已闭合：22131 行，其中原 21922 行逐字节保留，新 209 行来自案例 4 第
80 周期接管后的实际成功教师执行。3437 行教师、18694 行旧能力保护，263 行活跃
修正。没有使用失败教师的未执行建议，也没有 DEV 或 Fresh 拟合。这不是新增 209
个独立场景：只增加了一条在学生偏离状态上的成功恢复窗口。

同一原 R2、同一冻结能力路由父代、同一自身 288 维特征、同一 288→128→64→29
动作头、同一最终每关节 0.2 rad 权限。复用已经真实学习的主种子 v3 动作头和 Adam
历史，不随机重置肌肉记忆。

支撑规则固定为 v4 的“活跃 TRAIN 中心 / 所有非活跃 TRAIN 锚点”，半径仍为最近负
锚点距离的 0.45 倍，不调半径和门槛。本轮改变的是经验数据和神经权重，不再搜索
支撑超参数。

## 三个更新种子

共享同一继承权重与优化器起点，独立的优化抽样 RNG 为 2026103100/3101/3102。
这是三个独立优化种子，不是三个随机初始化模型。每个新增 2048 次 Adam 更新，原
1024 次与新增更新分别记账，最终优化器各槽应为 3072 步。学习率 0.0003、梯度范数
上限 1，正样本每批 256 原教师 + 256 新干预教师，另 512 旧保护状态。活跃样本权重
5，原教师零修正前段仍参与原始动作头拟合，以约束靠近动作开始点的偏差。

训练使用独立 CPU batch1 复核过的父代动作缓存，不用 GPU 批量路由结果替换它。
基础策略和父代参数不进入优化器，旧状态与非活跃状态在推理时精确返回父动作。
必须检查实际权重变化、非零梯度、真实 Adam 状态和完整 CPU batch1 证书，不能只
报告执行过多少步。物理中可能产生的后续分布偏移仍需完整考试检验。

## 必需的零更新对照

另构建一个 `geometry_only_control`：使用相同新数据导出的支撑，动作头和优化器
保持继承值完全不变，新增优化器更新为 0。它使用独立的非学习状态标识，不能被
报告成新神经模型。这样能区分：

- 经验覆盖扩大后，旧动作头被允许用于新状态的效果；
- 新数据指导下，神经参数更新的额外效果。

若只前者有效，就如实报告记忆/适用域增长；不能把它归因于权重训练。

## 验收与继续条件

先完成三更新模型及零更新对照的首脚接管 TRAIN20，独立重算自身网络和全阶段原生
物理。新模型还需三种子原 TRAIN16、DEV16 保留验证，比较既有最好编排
`[12,19,16]`、`[16,14,15]`、`[14,14,14]`，不改球路和安全门槛。
重点首脚 4/5 均成功、保留与自身物理审计通过后，才能进入新隔离 Fresh；已消费的
Fresh 不得回流。只学会案例 4 可以记录局部物理学习，但不算完整前沿通过或球队
比赛目标完成。

失败时依据自身状态反例继续教师能力、数据聚合或表示研究，不再盲目增加同族轮数。
本阶段是有物理反馈的持续监督学习，尚无在线 PPO、actor-critic 或直接力矩策略训练。
# 结果续接与 agent loop 边界

本轮使用 `rsi_review_paid_full_entry --interventional` 汇总三种子、三考试库及其独立审计，
并读取同数据、同祖先、同适用范围但零新增 SGD 的对照。对照与学习模型的物理差异单独记录，
不能把权重变化、拟合误差或门控变化当作球技提升。原有逐案例保留要求不变。

执行链是：冻结源代码 → 有限更新 → 无教师接管考试 → 独立自身神经网络和原生物理审计
→ 固定规则汇总 → agent 基于失败证据决定下一科学阶段。汇总器可以预先排队等待证据，
但不自动重跑已收费的实验，不因拒绝而无限增加 epoch，也不会自动把候选提升为冠军。

`rsi_watch_research_loop` 仅观察进程与产物；定时器、CPU 利用率和 `active` 状态均不能
保证 agent 正在思考或算法正在成长。`failed.json` 和 `failure.json` 均视为失败信号。
持久恢复指针必须在阶段变化时更新，记录已关闭实验、运行中任务和下一动作。
Goal 持续执行依赖宿主提供续接；应用退出、宿主停机或后端失联时，不宣称 agent 仍能自行运行。

本轮若未通过：保留旧冠军，消费失败记录，定位自身轨迹最早偏离和教师可恢复窗口，
再决定有限的自身状态教师重规划/数据聚合；不得用重新观看旧视频或重新运行旧成功案例代替推进。

## 第一轮物理结果与下一次有限教师重规划

三个优化种子在旧 TRAIN16 / DEV16 都保留原成绩；新 TRAIN20 的三次接触质量分别为
`[12,19,17]`、`[12,18,13]`、`[12,19,16]`，身体均完成 20/20。
同数据但零新增参数更新的对照为 `[12,18,16]`。独立自身 NN 和所有阶段原生物理审计已完成。
固定主种子相对旧最佳新增 case3 的第三次接触成功；但困难 case4/5 的第一次接触仍均失败，
第二种子有退步。因此总体晋升判定是 REJECTED，不开启 Fresh、不替换冠军，更不声称连续比赛突破。

接下来的 `rsi_replan_paid_interventions` 是显式训练教师，不是部署策略，也不是神经网络 RL。
从本轮固定主学生的真实私有 R2 历史出发，在固定第 70 / 80 控制帧分别接管。
每个边界保留纯学生控制和原教师控制，再做 2 代 × 12 候选的十二维足部意图 CEM，
每个候选在两个原有 TRAIN 条件执行，最终动作各执行两次完整复现。
总预算 112 个物理 episode、最多 435680 次 2ms 积分；CEM 分布更新和神经网络更新分开计数（后者为零）。
所有成功与失败均保存，不把复现次数当作新独立条件。

`rsi_audit_paid_intervention_replan` 逐一检查全部控制、候选、复现，独立重算当前学生自身 NN、
自身 R2 规划、足部 IK、原生接触积分、恢复站立和确定性 CEM 选择。只有审计通过的实际执行教师
动作，才可能进入后续数据聚合；不能用未执行的反事实建议或失败教师分支充当成功标签。
这仍是单体接触实验，不代表团队接球、连续传射或 4v4 已打通。

第二代数据使用独立 schema `paid.interventional_dagger.TRAIN_features.v2`，通过
`rsi_curate_paid_replans` 写入，`paid_replan_data.load_replanned_data` 重算加载。
原有 v1 加载器及其 94 条基础轨迹契约不变。v2 固定以本轮 22131 行 v1 数据为精确前缀，
绑定当前主学生使用的 v1 数据哈希、身体与冻结祖先；只选择两个接管边界最终候选的第零次复现，
且两次复现都必须有独立成功证据。全部 112 次执行的失败/成功结果单独持久化。
每条新增特征先从零展开真实混合轨迹的完整 R2 历史，再屏蔽接管前帧；不在接管点重置记忆。
相同特征的冲突标签拒绝，兼容重复标签去重。数据写入不更新模型，更不授权策略晋升。

第二代学习显式使用 `rsi_train_paid_interventional --generation 2`，绑定生成这些自身前缀的
第一代固定主模型哈希作为 warm source。完整验证第一代数据、状态和学习证书后，才借用
其六个神经参数张量和 Adam 动量。继承步数 3072，新增步数 2048，累计 5120；零更新对照
累计仍为 3072。三种子只独立抽样优化批次，共用同一祖先，不虚称独立初始模型。
数据源、checkpoint schema、训练状态和协议均有二代标识。考试仍通过统一 `load_paid_student`
加载；汇总与自身轨迹诊断显式使用 `--interventional --generation 2`。
损失函数、适用范围构造、原 R2 相对 0.2 rad 权限、冻结祖先及原始能力回归条件不降低。

## 固定第三轮：起动作精度与限幅前监督

第二代完整物理考试的新 TRAIN20 结果为 `[12,19,15]`、`[12,18,15]`、`[12,18,14]`，
零更新对照 `[12,19,17]`；原 TRAIN16 / DEV16 和身体稳定性保持，但困难首球依旧失败。
这说明增加 856 行真实补救数据并真实更新网络，仍不等于闭环会成功。

对固定主模型在原有 TRAIN 教师状态的 batch1 数值检查发现：case4 第63帧目标最大修正
为 0.000225 rad，预测 0.007432 rad；case5 为 0.000074 对 0.008991 rad。
这是教师状态上的拟合误差，不是学生自身状态的专家标签。另有 39–54 个活跃中心存在
错误饱和输出，局部限幅导数为零；仅占总活跃平方误差约 6–8%，不能宣称是唯一原因。

第三轮是一个预先固定的损失算法变更，不是半径/阈值搜索：

- 数据集仍为已审计的 v2，不新增反事实或 Fresh 标签。
- 继承第二代主模型六张量及 Adam 5120 步，新增 2048，累计 7168；零更新对照保持 5120。
- 在运行时限幅**之前**，对原始神经修正与已验证目标计算监督误差，避免错误饱和处无梯度。
- 每条监督误差除以 `max(max_abs_target, 0.02 rad)`，保留活跃5/安静1权重，使微小起动作
  不被大幅踢腿动作的绝对均方误差淹没。0.02 是损失归一化尺度，不是放宽执行权限或成功阈值。
- 运行时支持范围、最终 R2 相对 0.2 rad 限幅、冻结旧记忆和三库逐案例回归要求均不变。
- 三个预定优化种子共享同一祖先，并有同数据同几何零更新对照；不得按开发库挑种子。

显式调用 `--generation 3`，独立协议 `precision_refinement.v3` / `precision_no_update_control.v3`，
checkpoint schema v3。新增单测直接证明：旧限幅损失在错误饱和输出处梯度为零，新损失有纠正梯度；
相同绝对误差的微小动作相对大动作获得固定100倍关注。单测不证明物理成功。
本次若仍失败，停止重复追加同类 epoch 或扫描归一化尺度，重新检查表示/专家多模态及有限策略梯度路径。

## 不晋升的确定性表示对照

三轮小 MLP 的困难首球未出现增益时，另设独立的 cardinal muscle-memory **研究对照**，
不是继续叠加同类 epoch，也不改动三种子 MLP 晋升门槛。
`paid_cardinal_memory` 使用同一 v2 数据集中的活跃自身288维观测与真实动作目标，
按当前自身特征做固定的反距离平方凸插值；命中已存观测时精确返回该数据目标。
无案例编号、帧号、教师查询、IK、模拟器状态写入或轨迹游标。
它是确定性的非参数监督肌肉记忆，不是端到端深网络训练、神经 SGD 或在线 RL。

外层支持域构造、祖先与最终 R2 相对 0.2 rad 权限都与当前小 MLP 一致；未知/保护观测仍回到祖先。
零系数对照拥有相同几何，但在每个查询点精确返回祖先动作。全部目标来自完整审计的实际教师执行，
不得从失败轨迹或反事实建议补标签。相同观测的冲突目标拒绝，兼容重复只保留一个来源并记账。
checkpoint 按精确数据重构系数与几何，以 CPU batch1 检查活跃中心误差和所有旧保护锚点。

只装配一个固定确定性模型与一个零系数对照，不复制三份相同模型假称独立种子。
仍做同一固定 TRAIN20 / 原 TRAIN16 / DEV16 的 first-enabled 物理考试及独立自身 NN/原生积分审计；
此研究对照的任何成功都不自动改变 Champion、不沿用 MLP 三种子证书，也不代表未知来球或 4v4 泛化。
它回答的是：移除小 MLP 的表示拟合误差后，同一批物理有效数据是否能形成真正无教师的闭环动作。
