# S56：短时纠偏教师到保守神经“肌肉记忆”

日期：2026-08-21

状态：`SIM_ONLY / student_development_retained / NOT_DEPLOYABLE`

## 结论先行

S56 首次把 S55 的反事实教师计划转成了一个真正参与闭环的神经适配器，而不再只是动作脚本或首帧标签。

最终保留的 v3 候选使用 384 维可部署本体历史作为唯一输入，经 `384→128→64→29` 的 tanh MLP 输出 29 关节残差增量；输出头从严格全零初始化，先在四卡上学习，再由 S55 的局部作用 Jacobian 和失败/正常干扰比选出 16 个净有益通道。其余 13 个通道增益为零。

在 24 个完全未见、按六个时间窗分层留出的精确失败状态上，v3：

- 平均物理代价改善 `1.0147%`；
- 稳定缺口 `33.9583% → 32.5000%`，改善 `1.4583 pp`；
- 方向保持门通过，20 步均有限；
- 实际纠偏 RMS 为 `0.00794`（归一化残差空间）。

在同一批留出源对应的 24 条正常路线上连续运行 600 步，v3：

- 总代价回退 `0.4037%`，低于 `1%` 保持阈值；
- 前后、横向、偏航三个方向保持门均通过；
- 纠偏 RMS 为 `0.01314`，低于 `0.02` 权限阈值；
- 全程有限。

因此证据将 v3 标记为 `student_development_retained=true`。这只表示“值得进入下一轮开发”，不表示已部署、已晋升或可上真实机器人。报告仍明确给出 `deployment_candidate=false`、`promotion_eligible=false`、`promotion_authority=NONE`，并要求 CPU MuJoCo 复考。

## S55 到 S56 打通了什么

S55 已经证明：从精确失败状态出发，短时 CEM 教师能找到有明显作用权的 20 步纠偏计划。但它只保存首拍纠偏和四段开放环计划，尚不能称为小脑模型。

S56 补齐了以下闭环：

1. 从 96 个 S55 精确失败状态逐字节复现策略上下文；
2. 将每个四段计划展开成 20 个真实 MJX 物理步；
3. 每一步重新计算冻结父策略动作，再记录实际裁剪后的教师增量；
4. 同时运行 96 条正常父策略路线，各覆盖 600 步，并抽取同样数量的“正确动作就是零纠偏”样本；
5. 按源状态而不是按帧切分训练/留出，杜绝相邻帧泄漏；
6. 用 50:50 的失败纠偏/正常零动作样本训练零输出初始化 MLP；
7. 在完全未见失败状态和正常长路线中，让神经网络真正进入动作闭环；
8. 每一代候选都经过同初态、同随机流的父/子物理对照，失败即保留但不晋升。

训练语料共 `2,880` 个样本：72 个训练失败源 × 20 步 = `1,440` 个纠偏样本，以及等量正常零动作样本。24 个留出源覆盖六个失败时间窗，每窗四个，整条轨迹均不参与训练。

## 三代候选与 Stability–Plasticity 闭环

### v1：会救，但在正常路线持续添乱

v1 使用所有 29 个神经输出通道，1,500 次四卡全批 AdamW 蒸馏后：

- 未见失败状态平均改善 `6.6802%`；
- 稳定缺口 `34.1667% → 28.5417%`；
- 但正常 600 步路线代价回退 `7.7363%`；
- 正常路线实际纠偏 RMS 达 `0.16459`；
- 横向保持失败。

这说明离线正常样本上的预测 RMS 并不能替代闭环保持考试。一旦小误差把状态推离训练分布，网络会继续出力并放大自己的漂移。这是本轮捕获到的具体 Stability–Plasticity 失败模式。

### v3：数据驱动的稀疏肌肉通道

全局缩放会同时抹掉有益动作，因此 v3 用两类证据选择执行通道：

- `action_effect_jacobian`：S55 在相同失败状态对 29 个关节做中央有限差分，得到四个物理代价方向的局部作用；
- `failure_normal_discrimination_ratio`：神经输出在失败轨迹和正常轨迹上的每关节 RMS 比。

每个关节的选择分数为：

`加权局部代价贡献 × 失败/正常输出比`

只允许局部加权贡献为负（预计降低代价）的关节参加排序，保留前 16 个，活动增益为 `0.16`：

`[1, 2, 3, 7, 8, 9, 12, 13, 14, 16, 18, 19, 20, 22, 27, 28]`

这一选择可由 `derive_corrective_channel_gain()` 从 S55/S56 归档重算，不依赖手写动作时间线。

## 这对 ROSClaw growth 的意义

本轮不是只为 G1 写一个踢球后处理补丁，而是形成了可复用的 growth 模式：

`失败状态库 → 仿真特权短时教师 → 可部署观测蒸馏 → 正常零动作回放 → 未见失败复考 → 正常长路线保持门 → 只保留 Pareto 候选`

其中：

- 教师可以“做梦”：分支同一个仿真状态，比较多个反事实未来；
- 学生不能偷看仿真特权状态，只能使用可部署本体感；
- 学会做什么和学会何时不做同等重要；
- 失败候选不会被覆盖，形成 v1→v2→v3 的可审计成长史；
- 权限与能力分离：仿真中学会不代表有硬件权限。

这套结构可迁移到守门扑救、射门后卸力、抓取扰动恢复、移动底盘侧滑抑制等任务，只需替换任务效果指标、失败状态采样器和动作契约。

## 仍然不能声称什么

1. 这不是端到端关节力矩策略。模型输出的是冻结父恢复策略之上的受限 29 关节残差增量。
2. 这不是在线 actor-critic。当前是反事实教师生成数据后的监督蒸馏与离线信任域复考。
3. 监督泛化仍弱：v1 留出标签 RMSE `0.1520`，与标签 RMS `0.1490` 接近。v3 的物理收益主要来自保守、稀疏的有益子空间，而不是完整复现教师计划。
4. v3 正常路线的稳定缺口由 `49.1667%` 增至 `50.1944%`，约回退 `1.03 pp`；虽然总代价和当前方向门通过，这仍是 S57 必须专门消除的风险。
5. 尚未做 CPU MuJoCo 真值复考、跨动作/跨路线复考、400+ 新失败状态扩容或真实硬件测试。
6. 因为尚非推广候选，本阶段没有制作宣传视频，避免将开发门通过误表达成可部署成果。

## S57 建议

1. 正常路线 DAgger：把候选自己造成的漂移状态回灌为零纠偏反例，而不只采父策略状态。
2. 学习置信门：在本体历史上训练“需要纠偏/保持沉默”门，并对训练分布外状态失败关闭。
3. 消除正常稳定缺口：将稳定保持作为独立硬门，不再只包含于加权总代价。
4. 扩大失败银行：按 `40/80/160/400+` 新源逐级复考，并保持时间窗和失败类型分层。
5. CPU MuJoCo 成对复考：只对同时通过失败门、正常保持门和稳定硬门的候选执行。
6. 编译核工程化：父/子单状态 rollout 使用 20 步可复用块，兼顾较小 HLO 与较低主机调度成本。
7. 通过上述门后，才接回踢球后的完整恢复链并生成物理一致视频。

S57 已按上述前三项实施并形成四个可审计反例，详见
`docs/s57-stability-plasticity-dagger-confidence-gate.zh-CN.md`。当前仍无候选同时通过失败与正常双门，因此没有进入 CPU MuJoCo 晋升复考或视频导出。
