# S368–S369：学到的接球残差进入真实八体共享比赛

结论：首次在这条八体传球链路中，将原来“触脚后滚走”变为实测低速
近脚控制。接球后的下一次传球仍未连贯，因此不晋升完整比赛策略。

## 模块化接入，而非重建失忆的小脑

新增 `TeamMotorFoundation`，包含当前球员/控制帧、冻结基础策略及其
配置哈希、默认关节角与只读目标/增益。世界仍拥有全部物理状态、
LSTM 推理和电机保护；残差模块看不到可写模型、模拟器或记忆句柄。

`G1RecurrentReceiver` 加载受哈希/形状校验的数值权重，只管理本球员
100 帧残差滤波。最大偏移 0.25 rad、单帧变化 0.025 rad，保留基础
增益，世界继续施加 85% 力矩与关节边界。错误球员/帧/时钟/基础模型
或配置、重复帧和跳帧会锁定失效，不能自动重启；后端异常也转入世界
既有的候选故障回退路径。

它没有新建 LSTM、清空记忆或多调用一次基础策略，没有直接输出力矩，
也不自行授予技能启动/比赛晋升资格。接球启动和导航指导仍由实验
编排负责，并未宣称这些决策已经由神经策略学会。

## 适配器复核

公共模块与原实验推理，使用同一最终 S364 第 64 代模型，在四条独立
CPU MuJoCo 闭环课程上对照：全部归档数组逐位相等，qpos 最大误差零。
这证明接口接入没有改变这些课程的控制效果，不代表全域迁移保证。

## 八体实际链路

红蓝各四名角色，使用同一共享球和真实物理接触。仅蓝方中场新增接球
候选，其他七人的策略保持不变。中场必须已经接受传球握手、实际跟踪
已踢出的来球，来球靠近到 1.2 m 内并向自己运动，身体满足准入条件，
才启动接球；没有按固定时间激活，也没有把球传送到脚边。

名义场景在第 410 帧、8.2 秒入场，与实际训练早期状态相符。入场前
八体完整轨迹逐数组相同，入场时该球员真实 LSTM hidden/cell 与上一
action 完全保留。新增只读快照的基线也与旧 S351 基线全轨迹完全一致。

| 指标 | 旧方案 | 新神经接球 |
|---|---:|---:|
| 10.2 秒球速 | 1.293 m/s | 0.207 m/s |
| 同时距接球脚 | 1.332 m | 0.294 m |
| 八体全程安全 | 是 | 是 |
| 机器人相互碰撞 | 0 | 0 |

新方案在 8.942 秒有实测脚部接触，接触前球速约 1.355 m/s。
1000 个 500 Hz 接球物理步全部保存，0.5 秒观察窗和末段 0.2 秒按既定
低速/近脚阈值通过，接球窗口没有非脚/其他非地面球接触，八体均安全。
微步脚踝位置通过对应的实测关节状态作同体前向运动学重建；没有将
重建关节位置冒充另一次闭环物理试验。

## 下一处真正的系统断点

中场在接球残差仍占用运动控制时，战术层已于约 9.02 秒发出下一次
传球握手。接球技能到 10.2 秒才释放；约 11.04 秒的后续脚接触又未
形成被当前握手正确追踪的传球，之后球离开控制范围。

这里还存在固定短时接触所有权与持续低速近脚控制之间的语义差异。
下一轮要检验：运动技能忙闲信息是否应该延后新的传球承诺，以及如何
以真实脚接触和连续物理控制维持控球身份。不能仅按距离宣布控球，
也不能无限延长过去一次触球的所有权。

`world.result.passed` 在两方案均为 true，只是现有场景的基础门槛，
**不是高质量比赛认证**。本轮明确记录 `full_match_skill_qualified=false`。
尚未做跨初态的八体独立复现，不能把名义单场算成泛化成功率。
