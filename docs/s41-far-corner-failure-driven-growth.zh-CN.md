# S41：首球远角低/中/高困难课程与失败驱动成长

日期：2026-08-16
边界：全部为 `SIM_ONLY`；没有向真实机器人发送任何控制命令。

## 结论

本轮没有达到 80%，没有新门将获得晋级。

正式快速球、全远角、低/中/高均衡的 90 个新种子 CPU MuJoCo 终考中，候选首球
三层均为 0%。候选二次来球为 25.56%，与父策略相同；同时失稳率从父策略的
2.22% 升到 6.67%，峰值根部角速度达到 9.86 rad/s，因此严格返回
`REJECTED_BY_CPU_MUJOCO_EXAM`。80% 是每个高度层的绝对门槛，不是混合平均，
本报告不声称已经完成目标。

这次失败不是白跑：它排除了“只需多训练”“只需加大旧教师权限”和“只需给球更多
飞行时间”三个假设，并把下一步收敛到一个明确的架构缺口——当前站立式 actor 没有
独立的起扑、腾空、触球和落地动作空间。

## 本轮工程增量

### 1. 困难球三层均衡课程

训练环境和独立 CPU 采样器现在都支持 `hard_shot_fraction=1.0` 与
`hard_shot_height_mode=balanced`：所有样本横向绝对目标不小于 0.72 m，低球
不高于 0.60 m、中球为 0.60--1.10 m、高球高于 1.10 m。困难比例允许真正取
1.0，不再强制夹杂简单球。

新增内容寻址的困难球飞行时间课程。它只放宽球到门线的时间，不改变远角位置或低、
中、高三层内容；GPU MJWarp、CPU MuJoCo 和视频重放从同一配置重建，避免训练和
考试语义漂移。正式终考仍使用比赛快速球 0.34--0.54 s。

### 2. 可执行的目标条件化伸手记忆

此前非线性 G1 任务空间 reach atlas 只制造模仿标签，部署路径并不真正执行它。本轮
加入 Torch/NumPy 一致的运行时插值路径，以当前因果截面目标、actor 独立门控和
有界 blend 合成双臂目标；模型继续绑定 G1 Body、配置和 atlas 哈希，并保持
`SIM_ONLY`、无硬件权限。

0.35 blend 探针把平均手部最大位移提高到 0.093 m，但首球仍为 0%，出现 1.56%
失稳且峰值角速度为 6.30 rad/s，故被拒绝。这证明“够得更远”没有自动形成稳定的
全身扑救。

### 3. 神经侧扑肌肉记忆

将来源固定的双向侧扑训练种子压缩成相位与方向条件化的 29-DoF MLP，并完成
CUDA 训练、`weights_only=True` 重载及独立 CPU MuJoCo 回放。拟合位置 RMSE 为
0.00216 rad，最大误差 0.02038 rad，双侧对称 RMSE 0.00202 rad；模型忠实学会
了数据，却在困难球终考中只有 1/60（1.67%）命中，安全率 45%。

结论是：运动片段拟合质量不等于任务能力。该模型缺少目标高度、飞行时间和当前身体
状态条件，也没有与稳定行走小脑做动力学合成，不能直接执行或晋级。

### 4. 失败记忆可回放

CPU 终考现在把挑战失败与安全失败分开记录。每个漏球都保存种子、低/中/高层、目标、
意图 cue 可见性、到达时刻、根部到点误差、飞行阶段最近手距、到达时手距、横移动作
均值、部署命令符号一致性和实际根部移动一致性。这些字段可直接成为下一轮困难样本
回放池，避免只看总成功率。

## 对失败的具体解释

90 种子回放里，首球时根部通常只向目标移动约 0.20--0.28 m；低/中远角仍常有
0.45--0.85 m 横向缺口，高远角还叠加明显的垂直手距。旧教师加权到 0.66 以上会
先破坏支撑和姿态，而不是把身体安全送到截面。侧扑片段直接加速也会让骨盆跌到约
0.06--0.11 m、根部角速度超过 10 rad/s。

因此下一阶段不应继续对同一个站立 actor 重复加样本，而应实现独立、目标条件化的
全身侧扑 option：

1. 输入至少包括截面横向误差、目标高度、到达时间、支撑脚和本体状态；
2. 策略拥有受限的支撑切换、起扑和保护性落地动作，而非只放大腰臂残差；
3. 先用左右动作数据学习自然先验，再用物理 RL 优化触球与恢复；
4. 环境状态机而非 actor 决定姿态例外，并强制落地/恢复门；
5. 失败回放按低/中/高和“位置不足/高度不足/时序错位/失稳”分桶采样；
6. 最终仍回到新种子、每层不低于 80%、零失控跌倒的 CPU MuJoCo 终考。
