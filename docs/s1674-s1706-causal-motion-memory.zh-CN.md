## 实验进展与失败

S1674–S1678 比较膝踝耦合与单膝准备。单膝准备保留了更多射门高度，较大幅度
能消除小腿与球的几何交叠，但目标精度不足。S1684 的因果时间曲线搜索和
S1688 的全协方差搜索没有得到同时满足全部条件的候选。不得把参数搜索叫作
新的神经网络强化学习。

S1686 发现旧训练代价使用的贴柱代理阈值偏差约 5.18 mm；正式球门几何验收
一直使用正确尺寸，没有放宽。后续训练代价使用实际门柱表面间隙。

S1696 将较快的实测事件触发膝部准备与较低的接触策略垂直系数组合，12 个
开发场景候选中 3 个同时通过严格射门、全程关节/身体限制、非脚部接触排除
和小腿几何分离。三者误差约 1.9、25.8、38.4 mm。这是同一名义场景的
三个参数候选，绝不是独立随机测试 25% 成功率。S1697 审计通过。

实际球围 0.69 m、质量 0.43 kg，球门 7.32×2.44 m，目标 y=-3.35、z=1.75 m；
严格目标误差不超过 0.10 m，射门高度至少 1.70 m。力与力矩上限均未放宽。

S1700 选择几何余量最大的成功候选，球地面摩擦从 0.11 改为 0.1095/0.1105，
两个扰动场景均失败；触球后投影参考也未解决。名义成功很脆弱，不能晋升。

## 从成功轨迹提取动作记忆

S1702 保存 5500 个原生控制样本：29 维关节位置、速度、PD 提案、增益，另存
实际控制量和实际执行力矩。PD 提案不是执行力矩，后两者必须单独追踪。
S1703 独立审计确认记录不改变原场景，控制时钟与原生状态、粗采样证据一致。

S1704 用示范 PD 提案加当前关节误差反馈替换原 PD 提案；反馈修正限制为
每关节 ±12 Nm，原有残差策略、关节保护、执行器限制继续在下游生效。
S1705 确认名义场景 140 组数组逐元素一致。

S1706 两个此前失败的摩擦扰动下，误差变为 43.5/52.1 mm，高度
1.794/1.802 m，均满足射门几何要求、无非脚部球接触、小腿全程分离，
关节/力矩检查通过；但两次都踢后摔倒，完整链路仍然失败。
不能截去摔倒片段展示为成功。下一步验证触球后平滑退出射门记忆、交还实时
平衡控制，随后才考虑更广状态支持和神经蒸馏。

当前记忆是固定初始化、固定时间相位的示范反馈控制，只来自一个开发示范，
不是泛化策略、在线 RL 或自主比赛。公共模块的抽象和实验控制器的局限分开记录。
