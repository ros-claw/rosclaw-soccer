# 接球角色：任务条件化、自身纠偏与新能力保持

## 本轮依据

BC400 的三个固定种子已完成各 12 世界及独立原生复核，功能接稳为 8、10、10，
原追球教师为 6；精准联合成功三个候选均为 0，而投影教师为 4。
同架构、同种子、固定训练归一化的更新前参数对照分别为 0/12，独立复核仍应逐一核验收据。
这些只覆盖三个已消耗的微扰初始条件，不是广泛泛化或球队比赛证据。

首个种子的实际自身轨迹显示：案例 6、24 飞行阶段，大多数控制若查询投影教师
会要求守住接球平面，但学生仍提前靠近球；其接触时身体位于准备锚点上游约
0.70、0.64 米。自身关键阶段对教师建议的归一化命令 MSE 约为 0.49、0.45。
这是事后在自身当前状态上查询的建议，未在这些世界执行，不能解释成教师已经救回该球。
它说明全局约 0.006 的教师状态验证误差不足以证明自身闭环精准接球。
另有合成反例证明原112输入在不同已通信任务条件下存在歧义，不能靠增加 epoch 消除。
方向在原96 bank固定，因此不能仅凭该反例断定上述自身失败的唯一原因。

## 新的 118 维角色观测

保持原112个因果身体/追球提议特征，增加身体坐标系中的实际通信目标相对位置3、
通信传球方向3。没有未来轨迹、最终误差、案例编号、随机种子或成功标签输入。
新6维通过零初始化的 6→128 投影加入父代第一隐藏层预激活。
保留父代六个已训练张量与原112归一化，初始化严格等于父代函数；
在所有消费的旧/自身观测上逐位验证后才允许优化器更新。
角色输出仍受原vx/vy/yaw边界约束，下层29关节运动网络和固定PD仍不更新，
不是直接力矩、全身端到端 RL 或意识的证明。

## DAgger 与真实成功自回放

复用已独立认证的96个教师世界及三种子各六个自身世界，丢弃仅用于复核的重复副本，
不重跑物理。自身世界的当前状态上计算冻结教师建议，明确标记为未执行建议。

监督标签规则为：

- 已有精准成功保留学生实际执行命令。
- 其余功能成功，在非关键平面阶段保留学生实际命令，保护其超越旧教师的发现。
- 精准关键阶段使用当前状态上的平面教师建议。
- 失败状态使用当前状态上的恢复建议，但不把建议当作已验证的物理成功。

成功结果仅选择离线标签，不进入策略观测。
关键阶段由当前教师分支与**过去已见接触标记**确定，不使用未来首次接触时间。
每批128行旧训练回放、64行自身关键阶段、64行全部自身状态。
所有失败轨迹保留；原验证噪声组不参与训练归一化或采样，仍不是 Fresh。

## 真正继续而非重置

三个种子各再执行固定400次更新。原六张量 Adam 动量与步数从400继续至800，
新的任务投影从0至400，原私有批量 RNG 原样继承；不重置父代优化器。
所有七张量须实际有限更新，保存完整检查点并严格安全载入。
物理执行新增独立类型 `receiving-neural-task-command-dagger-native-v2`，
不得放入旧29维 PPO，也不得把本轮离线纠偏叫在线 actor-critic。

## 必须补上的验收

训练入口：`scripts/rsi_train_receiving_task_dagger.py`。
物理入口：`scripts/rsi_qualify_receiving_motor_native.py --command-stage task-dagger-v2`。
先保持相同A权重、目标、身体、期限与随机性，逐例比较父代BC400与新策略的
受控接球、旧能力保持、0.1m精准联合成功、安全及完整恢复，再独立原生复核。
若仍丢精准能力，应分析新策略自身状态误差与身体响应，而不是盲目再加epoch。
必须扩展不同初始状态和隔离Fresh；本地阶段改善不能替代最终连续4v4球队视频。
