# S1081：完整轨迹 critic 与抗扰动诊断

日期：2026-09-13。接续 S1060–S1078，仅下游 Soccer 仿真研究；
不代表最新 ROSClaw Core 集成、真实机器人授权或整场比赛通过。

阶段结论：完整轨迹 critic 已实现、实际训练并精确重放。新种子
CPU 相对父级有局部改善，但相对上一轮候选**没有提高精确传球
次数**；尚未达到宣传资格，不发布成功宣传片、不晋升球队模型。

## 实际开发

`FullBodyPPOUpdateConfig.critic_all_active` 新增显式布尔选项，默认
关闭。开启时，actor 仍只使用因果触球窗口内的样本；critic 则
学习全部有效轨迹，包括球离脚后到达目标的过程。死亡后的填充
样本不参与优化。整条轨迹仍需通过初始策略似然和价值一致性检查。

每个完成的 epoch 将全部有效 critic 样本随机打乱、分配至原有
actor minibatch 数目的组，每个样本恰好使用一次。组内分块反向
传播以限制内存，每组损失按该组样本数归一化；actor 和 critic
梯度合并后仍使用原有全局 0.5 梯度裁剪和同一次优化器 step。
额外抽样消耗随机数，因此后续探索不是与旧实验逐位配对的噪声。

这是“价值学习范围”的改变，不是给球飞行后的动作追认触球
功劳，也没有改变关节/导航限幅、0.1 米精度或非足部/迟触判据。
默认关闭路径的旧 RNG 与更新顺序保持不变；S1080 从 S1073
原始记录精确重放了全部 8 轮模型、Adam、随机动作及特征历史。

新增测试覆盖完整 critic 能学习仅在窗口后出现的特征、被排除
动作的符号不影响更新、窗口后似然仍须验证、死亡填充不训练、
非布尔配置拒绝，以及固定随机种子的更新可重现。

## S1081 训练设置

50 Hz 控制周期：576 个训练 episode、144,000 个控制步。
保留 S1073 的父级、零初始化修正网络、seed=106801、长回传
gamma=0.995 / lambda=0.999、Adam 1e-4 和精度塑形。

更新；不是直接力矩策略，也没有使用新 MotionDecode 模仿损失。

成功仍仅对应 **2/9 种基础入场**，不能当成 72 场独立考试。

## S1085–S1088：区分仿真差异与抗扰动不足

先用上一轮 S1073 最终模型做零新增扰动的 CPU 对照，全部 32
入场保留。初始→候选：身体通过 31→31、受控传球 3→4、精确
传球 0→2、非足部 6→6、迟触 0→0。S1086 的匹配输入、观测
历史、目标平面及触球计分审计通过。

S1087 核对全部 9 个训练基础入场：CPU 与 GPU 对应的初始 q/v、
目标、身体/受控/精确标签完全一致，候选都在入场 4、5 精确
传球。没有证明全轨迹逐位相同，也不是独立、分层的新场景
GPU 标签资格认证。其余 23 个入场没有因此被算作通过。

但同一候选在 S1076 的球 XY ±0.015 米、XY 速度 ±0.03 m/s
扰动考试中精确传球为 0。该对照支持这组案例的脆弱性主要
来自入场扰动，不能只怪 CPU/GPU 后端差异；它没有分离四个
扰动坐标各自的作用。

S1088 对全部 9 个对应的初始观测做神经响应诊断：新学习修正
的范数约 0.014，但输入扰动带来的修正变化范数仅
0.0000249–0.0000690；父级输出变化为 0.00373–0.0247。
这表明**首帧**新修正在这组输入附近更接近固定偏置，而不是
强烈响应球状态变化。不是所需控制修正幅度的证明，也不是
整个触球窗口的雅可比分析。初始接触区间速度/力特征被显式
标为尚不可用，旧特征中的球速度仍然可用。
