# S1198–S1204：三轴足端学习完成，尚不足以接管比赛

本轮是 SIM_ONLY 的局部首传学习，不是八机器人宣传片验收。
代码基础为 `522aeb2`，冻结原有行走模型，由神经网络输出三维足端
虚拟力，再经当前姿态的雅可比和限幅映射到所选腿的关节目标。
它不是直接输出全身力矩的端到端小脑，也没有证明自主足球能力。

## 实际执行和结果

S1198 完成预先固定的 16 轮、4096 条训练回合、1024000 个控制帧，
5740 次 Adam 更新；累计 49 条随机训练回合满足精确首传标准。
这一累计数不是最终策略成功率。训练使用 32 种既有身体入场状态，
每种复制八份，不是 256 个独立身体状态。

最终固定开发测试：256 个副本中，身体通过 256、受控首传 32、
0.1 米精确首传 8；球仍在场内 248，非足部触球 31，晚期重触 7。
不能挑选中间一轮较高的数值替代预定最终模型。

CPU 新扰动种子 `120001`，同样是已训练的 32 种入场状态，不是
未见过的身体状态。初始与最终模型使用完全相同的初始物理数组。

| 模型 | 身体通过 | 受控首传 | 0.1 m 精确首传 | 非足部触球 | 晚期重触 |
|---|---:|---:|---:|---:|---:|
| 初始零均值足端头 | 31/32 | 4/32 | 0/32 | 4/32 | 1/32 |
| 固定第 16 轮 | 32/32 | 5/32 | 1/32 | 2/32 | 1/32 |

两者球在场内均为 32/32。这个幅度不足以证明可靠改善，未晋升，
未接管共享球队，未生成宣传片。这里的误差是传球目标平面误差，
不是球门高死角射门误差；身体通过也不等于动作自然。

## 学习与物理映射复核

S1199 逐轮重建了全部 16 次采集/更新批次的当前 qpos 几何、选脚、
作用窗口、父级动作、实际足端力映射、随机采样、参数和 Adam 状态。
所有比对通过，父级参数保持冻结。它复用记录中的接触与支撑力，
不是独立再运行完整 GPU 接触物理。

S1201 原生 CPU 成对审计重新从记录的 2 ms 数据计算离脚资格、
目标平面和结果，平面误差重建差为零。S1203 分别对初始和最终
CPU 策略的全部 8000 个控制帧重新计算当前运动学、策略均值/
value/likelihood、父级目标、导航残差和非零足端映射，均一致。
这些检查证明记录和实现相符，不证明比赛成功。

## 保留的测试脚本故障

S1202 v1 的 GPU 审计成功，CPU 初始运行在结束的冻结参数断言失败。
原因是完整 checkpoint 加载替换了临时构造的零输出父级网络，
而断言还绑定加载前的随机隐藏层参数。v2 改为加载后对照已审计
的初始 checkpoint，并要求最终模型的父级与该初始父级一致。
v1 和 v2 初始 CPU 物理归档 SHA-256 完全相同，未修改控制或物理。

v2 后续成对审计还遇到路径迁移遗漏：字符串模板中的 `{arm}`
仍指向 v1。v3 仅修复该模板路径；最终成对和两项完整应用审计
均完成。旧失败运行及日志保留，不覆盖成“通过”。

## 下一实验的依据与限制

S1204 只读取训练数据，没有使用 CPU 考试拟合模型。首轮到末轮的
开放窗口虚拟力中位数约 7.54 → 7.83 N，所施加关节目标相对名义
目标的最大分量中位数约 0.00578 → 0.00600 rad。没有样本达到
59.9 N 的近上限区间；所有训练环境都存在动作作用窗口。
这表明不是“接口从未打开”，但不能据此断言小幅修正是失败根因。
虚拟力不是实测关节力矩，脚尖距离也不能替代物理接触归属。

接下来 S1205 是固定四轮、初始高斯 logstd 从 -2.5 改为 -1.5 的
有限探索试验。60 N、关节目标、每步变化、力矩及原始结果门均不变。
使用新种子 `120501` 对照初始与固定第 4 轮，不挑选中间模型。
本报告落盘时该试验正在运行，没有结果或晋升承诺。

无论局部结果如何，后续必须检验完整准备、连续传接、无重置共享
球队链路。不能无限延长局部训练，更不能把零星首传成功剪成整体
4v4 比赛的能力声明。
