# 全部已学运动记忆固化：下一轮结构对照

## 为什么不再重复同一种训练

完整实际学生状态银行的混合模仿（v2），以及每个任务只选一个合格
动作方案的模仿（v3），均未获得合格的整体增长。

v3 三种子在相同的 80 个传球任务上分别为 19、21、20 次受控传球，
基线为 23 次；相对基线新增/破坏分别为 4/8、4/6、5/8。
全部原生执行与独立重放已经结束且吻合。两个机器人均未摔倒，
但有 1/80 次传球者未通过完整 100 控制步神经恢复稳定检查。
接球者的功能性接球数分别为 33、32、30，不能取代包含传球者合法
脚部接触条件的整体分数。原静态目标精度组合指标仍为零。

95023 丢失旧上下文 4、20，95024 丢失 8。95025 保持全部 17 个
已学首次触球上下文，另学会 6，这是有价值的局部正例；然而它的
传球回退不能忽略，因此不是合格的整体候选，也没有更新 Champion。

以上为已消耗开发集的结果，不是 Fresh、历史 52 场或自主 4v4 成果。

## 可被推翻的新假设

现有双循环模型虽冻结了较早的基础网络，但后续学会的运动技能仍在
被更新的 plastic 分支里。仅冻结早期父代，不等于保住全部已学技能。
本轮假设：冻结已经训练好的**完整双循环模型**，在它的实际私有
状态特征上学习独立的小网络，可以减少重写运动记忆造成的动作偏移。

`ConsolidatedMotorAdapter` 是该假设的研究原型：

- 慢记忆包含原模型全部分支；独立复制、全部冻结、保持 eval。
- 新头为 `288 → 128 → 29`；输入为自己的归一化观测与已学隐藏特征。
- 每条历史从私有零 h/c 开始，不借教师隐藏状态，不输入任务编号。
- 原型默认新头请求 ±0.04 rad。完整实际特征验证后发现，所选 29 条
  合格教师历史均需要更大修正，最大约 0.1583 rad。因此独立训练协议
  显式采用新头请求 ±0.2 rad；合并后仍受**原来相对原始运动基准的
  ±0.2 rad 总限制**，不是在旧模型动作上额外放开 ±0.2 rad。
- 输出仍是 29 维关节位置目标，不是直接输出力矩，也不是在线 RL。
- 零输出层初始时保持旧动作与 h/c 逐位一致，同时保留可学习梯度。
- 非有限网络输出在 tanh 限幅前拒绝，避免 Inf 被伪装为有限输出。

冻结权重不保证训练后的物理行为不退化。残差同样可能破坏旧动作，
必须重新通过旧 17 项、旧成功传球及独立原生重放。

## 实施与验收次序

1. 软件验证：零头恒等、私有历史、无存储别名、冻结参数无梯度、
   新头可更新、原始权限不扩大、非有限输入拒绝。
2. `scripts.rsi_qualify_consolidated_motor_adapter` 在完整 274 条真实历史
   上重算自己的特征并导出；所有原始正负标签不变。它只证明计算
   和谱系，不执行物理、不训练、不证明足球能力。
3. 预注册三种子新头训练：保留原 65023 的 17 项运动记忆和 23 条
   成功传球，学习有物理证据的 29 条纠正方案。新参数使用新 Adam；
   不重置、篡改或冒充继承模型的旧优化器步数。
   本次协议固定种子 105023/105024/105025，每种子 2048 次新头 Adam
   更新，学习率 0.0003，只训练 4 个新参数张量；每步 2 条教师历史、
   4 条旧运动历史、1 条已成功传球历史。全部循环特征从自身完整真实
   历史重算；头部是逐步无状态网络，补齐的 minibatch 行损失权重为零，
   不冒充实际时间步。训练用的旧运动/传球目标为精确零新增修正。
4. 冻结模型，再运行相同的实际传球、历史保持和独立物理重放。
   若只降低拟合误差、仍无一致物理净增益，就否定该假设，不扩大同族扫描。
5. 仅合格候选才有资格进入新封存 Fresh；之后才研究连续技能与球队调用。

持续目标与持久化 next 指针负责接续 agent 工作；只读 systemd observer
仅观察进程和产物，既不唤醒语言模型，也不替代上述科研决策。

## 计算证据进度（2026-10-23，尚无新头物理结果）

完整 274 条历史已完成：103,092 次自身特征计算和同量独立旧模型
恒等对照，原始正负标签保持不变，物理步数与优化器步数均为零。
随后三个种子各自完成 2,048 次新头 Adam 更新，旧模型权重及输入
文件通过结束校验。这里不是按训练损失挑一个种子；全部三个都要
进入独立 CPU 重算、相同物理考试与历史保持检查。

新 `consolidated-adapter-v1` 加载路径保持旧 DualRecurrentMotor 加载器
及其旧预算不变。它校验完整训练谱系、原始 17 项锚点、全部更新历史、
四个新参数的权重和 Adam 状态，并使用 `weights_only=True` 加载。
独立 CPU 检查比较逐步真实观测的私有循环推理与此前独立重算的
特征路径；它不复演优化器，也不宣称物理成功。

共享仿真球员、独立运动和神经恢复仅显式接纳该新类，不开放任意
duck-typed 对象或子类；原课程、300 控制步时限、接触规则及 100 步
恢复检查不变。小型编译世界的适配测试不等于 G1 足球考试通过。

### CPU 重算发现并修复的真实缺陷

首次三个 CPU 独立重算中，105023 完成全部 103,092 步；105024 与
105025 都在累计第 14,130 步被严格边界拒绝。定位到历史 40、第 113
帧（均为零基）：原始参考逐位相等，特征误差约 3.58e-7，独立动作
路径误差约 4.77e-7；但总修正出现 `0.20000001788139343`。
这是 float32 的“先相减、再相加”舍入超界，而不是物理考试失败。

修复不放宽 ±0.2 边界：对相加后的总修正再次严格 clamp，最终动作
直接由原始 nominal 与投影后的总修正生成。零头仍采用旧模型完全
相同的算术并逐位保持；新增正负边界反例测试，同时检查最终动作
确实消费了该投影。原失败、已完成结果与训练权重全部保留。
使用新冻结源码和新输出目录重做三个 CPU 重算，不改运行中的源码。

为避免验证完成后空等 agent，增加一次性、预先声明的物理后继入口：
`scripts.rsi_run_consolidated_adapter_native_exam`。它只能调用既有的
`pass80` 或 `retention44` 协议；要求完整、同源码的 CPU 证据和未使用
输出目录。可通过 systemd After/Requires 排在 CPU 任务后，前驱失败
则不执行。它不重试、不改评分、不晋级 Champion，也不自动选择科研路线。

同一入口支持 `pass80-own` 与 `retention44-own`，仅在完整原生生产结果
及其声明绑定到指定模型和生产源码后，启动既有独立重放器。重放端可
使用另外固定的源码提交，但必须显式保存原生产 head；它不筛选成功
场景，完整 80/44 世界都必须重放。该后继同样只执行一次，输出目录
已存在、前驱失败、世界数不全或模型不符都拒绝启动。

历史保持独立重放首次被底层 `paid_run_teacher_audit` 的旧模型类型
白名单挡住：三个候选均在零 native / neural 步退出。修复为显式接纳
冻结 CPU 的旧双循环类与新固化记忆类，仍拒绝可训练对象、任意对象
和子类，仍从独立零 h/c 重算。新增专门测试，失败输出不删除；修复
后使用另外冻结源码与 `retention44-own-v3` 目录完成全量复验。不能用
该工程修复把尚未完成的独立验证写成通过。
