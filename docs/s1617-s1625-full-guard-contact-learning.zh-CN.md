# S1617–S1625：双角色保护后的重新学习与失败归因

## 结论

截至本阶段，**没有新的合格宣传射门，也没有完成 4v4 宣传比赛**。
两轮各 60 个候选的参数学习均为 0 个严格通过。约 1.3 厘米的目标误差
不能抵消小腿参与击球的失败；该候选保留用于诊断，不允许晋升或宣传。

本阶段是原生 MuJoCo 的教师参数搜索（CEM），不是新训练完成的神经小脑、
在线强化学习或持续 actor-critic。模型固有能力与离线固定起始姿态、时序
优化必须分开描述。

## 固定实验协议

- SIM_ONLY，11 秒双角色传射；原生物理步长 2 毫秒，每角色 5500 次关节检查。
- 传球人与射门人的既有触球前关节保护都开启；关节容差仍为 1e-5 rad。
- 使用 v27 结果契约。旧 20 毫秒采样通过不能替代原生子步验证。
- 球周长 0.69 米、质量 0.43 千克；不回退到历史偏大的球。
- 不提高现有电机、残差力矩或任务空间力上限，不修改运行中的球位姿或速度。
- 当前目标为门线坐标 (-3.35, 1.75) 米，精度 0.1 米。
  这是既有高位近门柱任务，不应称为球门最顶部死角。
- 合格传球根据首次射门接触时的位置判定，不能用上游经过接球点替代。
- 非脚部球接触阈值仍为 1 N，检查整回合，不能只看首次触球。

## 精准但不合格的原因

S1622 g04-c10 首次射门接触位于 7.354 秒，由右脚完成。
随后 7.358、7.360、7.362 秒，右小腿产生约 302.54、249.34、70.34 N
的球接触法向力，报告的最大穿入深度约 8.28 毫米。这不是只有画面上的
接近，也不是无力几何重叠。因此不能将最终精度全部归功于合格脚法。

下一步围绕这个明确的失败测试脚姿、抬脚协同和接球时序，查找脚部干净接触
与高位精度是否能共同成立。继续保留双角色保护及全部接触标准，而不是为了
好看关闭小腿碰撞、放宽关节检查或只挑首次接触画面。

## 球滚动与内部画面检查

S1619 对 S1613 三个摩擦环境的稳定传球窗口（约 5.86–7.30 秒）复用滚动
真实性检查：每例 73 样本、约 2.182 米，滑移比中位数约 0.0151–0.0155，
滚动比例均为 1。自由关节角速度先从球体坐标旋转到世界坐标，再计算表面速度；
独立四元数矩阵复算一致。这只证明这段稳定传球，不证明整场所有接触与滚动。

S1623 生成内部动作对照图 `pose-contact-review.png`，只用已记录位姿重放，
展示旧关节失败、高度不足和当前偏靶三种被拒绝案例。**不是合格宣传片**。
