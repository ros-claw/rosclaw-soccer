# S2026：把任务距离和高度交给学习器

## 原有学习输入的缺口

近球残差 actor-critic 的 56 维输入含目标的二维单位方向，但不含目标距离
或高度。同方向、不同射程的任务可能产生相同观察，因此单靠追加 PPO 轮数
不能让网络可靠区分这些任务。上游射门基础策略另有目标条件，不等于这层
残差网络已经获得这些信息。

新增版本 `task_geometry_v2`：保留原 56 维，追加球到目标的水平距离 / 5 米、
目标相对球的高度 / 2 米；沿用有限幅值输入边界。输入来自当前测量和当前
任务，不使用未来球轨迹。模型的版本、形状与哈希一起绑定；旧模型默认仍为
`direction_v1`，原哈希和归档格式不变。

`with_task_geometry()` 是显式结构迁移：输入矩阵追加两行零权重，其他权重
复制，记录父模型哈希。这不是 RL 更新，也不表示任何足球成绩提升。
PPO 必须验证版本对应的观察列，更新后的子模型保留该版本。

## 验证

- 定向测试包含非零 actor/value 的迁移输出一致、归档往返、维度错误拒绝、
  新通道可经实际 PPO 更新、未训练角色权重不变、缺失版本证据拒绝。
- S2026 全量：3644 passed、29 skipped、11 个既有外部归档绑定失败。
- 三个修改源文件的 scoped mypy、Ruff 均通过。
- 真实八台 G1、25 秒中央开球、冻结 S1954 g004，迁移后执行并精确重放：
  `/home/dell/rosclaw_soccer_evidence/s2026-task-geometry-migration-v1`。
- 对照 S2020 中央 parallel：所有公共列除扩维的 `residual_observations`
  外逐元素相同；观察前 56 维也完全相同。新加一个明确的版本代码列。
- 仍仅有原来的单次射门，完整比赛门没有通过；不晋升、不称宣传片。

下一步是在独立训练协议中使用新输入，配合对传球速度、接收完成和场内
连续性的实际检验。结构迁移的保真不能替代训练后的保持测试。
