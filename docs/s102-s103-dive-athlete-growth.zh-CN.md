# S102–S103：29-DoF 神经飞扑小脑与目标条件残差权限闭环

## 结论先行

本轮把 S101 的“侧向移动运动员”推进成了一个可进入真实足球物理链的 **29-DoF 神经飞扑命令专家**，并完成了如下闭环：

1. 从已经通过 CPU MuJoCo 接触门的 S90–S92 轨迹提取目标、时序和来源证据；历史视频像素不参与标签或评分。
2. 在 4 张 NVIDIA RTX A6000 上以 DDP 训练左右严格对称的 29-DoF 神经解码器。
3. 对神经输出做独立 CPU MuJoCo 双侧考试；被蒸馏的候选教师本身失败，神经候选经平滑后反而通过，失败没有被隐藏。
4. 将通过考试的模型接入同一个三 G1 世界，真实运行传球、前锋触球射门、门将手套接触、球改向、腾空与落地链。
5. 统一使用 75% 神经残差权限时只通过 2/4 个高角；随后基于失败扫描出按目标选择的非零权限表，再次运行四角各两次，最终 **4/4 通过且严格复现**。

这是一个可审计的稳定性—可塑性进展：旧控制器提供稳定基线，神经专家提供可学习动作，环境拥有的权限门根据失败证据限制神经影响。它不是“把一段好看的动画叫作学习”，也没有把一个偶然成功镜头提升成策略。

## 为什么需要这一轮

S90–S92 已经有真实手套接触和短时腾空，但动作主要来自源动作、状态机和若干标量参数。它们能够证明物理事件，却不等于形成了可训练、可复用的运动记忆。S102 的目标是先建立一个有清晰输入、输出、来源、模型权重和独立考试的神经动作面；S103 再验证这个动作面能否进入足球闭环。

这里刻意把问题拆成两层：

- **动作候选层**：网络能否输出完整、有限、左右对称的 29 个关节位置目标。
- **任务权限层**：在不同来球目标下，网络应该拥有多大残差权限，才不会破坏原有扑救与落地能力。

如果第一层都没有独立通过，就不能进入带球实验；如果第二层没有回执绑定，就不能证明比赛里真的用了该模型。

## 数据、教师与许可证边界

### 使用的数据

训练入口会加载 6 条已经通过的 S90–S92 CPU MuJoCo 轨迹，并逐条检查：

- evidence 必须 `passed=true`；
- `SIM_ONLY`、无硬件命令、非商业边界不能改变；
- 原始轨迹字节哈希必须与 evidence 一致；
- 必须存在真实球接触、飞扑 option 窗口、29-DoF 关节状态和骨盆状态；
- 像素不进入训练和评分。

其中 S92 左内、左外两条低落地角速度轨迹用于训练上下文；其余四条仅作为审计参考。成功轨迹中的 achieved qpos 只提供“这个目标和时序曾在物理中成功”的条件与来源，不直接当作关节命令标签。

### 教师来源

动作命令来源于本地固定版本 Humanoid-Goalkeeper 的官方飞扑 atlas：

- commit：`976a81ff19b7306bafbe923d2890066b68a85271`
- license hash：`sha256:6c8cd1cdbe7accec4f63b6c3afb45ce0ffae9ed6abc0ca55acf5900b37970a82`
- 激活上限：`SIM_ONLY`
- 商业使用：禁止

最新的 achieved-state 关节门发现官方种子在踝关节软限位附近存在动态超调。代码没有降低关节门，而是构造左右严格镜像的 physics-margin 教师：仅将左右 ankle-roll 目标分别投影到 `+0.20/-0.20 rad`，其余 27 个关节目标保持不变。

重要的是，这个投影教师在真实 CPU MuJoCo 中仍有约 0.003–0.007 rad 的动态超调，因此它仍然是失败教师，而不是合格策略。经过神经解码器的连续逼近和平滑后，候选才通过独立物理门。报告明确保存了 `candidate_repaired_rejected_teacher=true`。

MotionDecode 本轮没有直接作为动作标签。现有 MotionDecode 数据的身体模型、关节语义和接触条件尚未完成可证明的 G1 重定向；在这之前强行混合反而会污染小脑。它仍是后续模仿先验候选，而不是本轮成绩来源。

## S102 神经小脑

### 输入与输出

网络输入为 10 维连续上下文：

- 归一化动作 phase 及其平方；
- 一阶、二阶相位正余弦；
- 目标横向距离；
- 目标高度；
- 动作持续时间；
- 预期接触 phase。

网络直接输出 29 个有界关节位置目标。输出以 G1 ready pose 为中心、逐关节尺度归一化并经 `tanh` 限幅。当前不是关节力矩策略，也不能绕过 MuJoCo 的位置伺服和安全门。

### 左右对称

模型只学习一个 canonical 半空间。另一方向不是再训练一个网络，而是使用经过测试的完整 G1 解剖镜像矩阵交换左右关节并施加正确符号。训练与 CPU 考试的最大左右对称误差均为 `0.0 rad`。

## S103 进入真实传球—射门—扑救链

### 统一 75% 权限为什么失败

第一轮把所有目标统一设置为 75% 神经残差权限。四条都真实手套接触，接触覆盖、左右手与严格复验也通过，但只有左外和右外通过全部门：

- 左内：手套接触，但球没有形成合格扑救结果；
- 右内：球被扑出，但腾空约 0.14 s、骨盆上升约 0.026 m，略低于原有严格门；
- 左外、右外：全部通过。

因此候选被记录为 `REJECTED_DEVELOPMENT`，没有降低 0.15 s 腾空或 0.03 m 上升门。

### 失败驱动的权限扫描

离散扫描显示动作质量对残差权限呈明显非单调关系。例如右内角 50% 全部通过，25% 和 100% 均会触发不同失败；左内角只有很小的非零残差窗口保持了扑救和稳定。冻结的目标条件权限为：

| 目标 | 神经残差权限 |
|---|---:|
| 左内高角 | 5% |
| 左外高角 | 75% |
| 右内高角 | 50% |
| 右外高角 | 75% |

这张表不是硬件策略，也不是声称已经泛化的连续网络。它是本轮失败证据导出的、可审计的 SIM_ONLY 权限候选。请求文件记录权限表；每条仿真结果回执记录实际 checkpoint hash 和实际 blend；组合晋级门逐项比对二者。

## 对 ROSClaw 的通用价值

虽然实验载体是 G1 足球，形成的模式不是“足球专用大 actor”，而是可以继续抽象进 ROSClaw Growth 的通用闭环：

```text
通过的环境经验
  → 来源/许可证/身体/状态证据绑定
  → 候选动作专家训练
  → 与任务解耦的独立物理考试
  → 小权限进入任务链
  → 失败分类与权限扫描
  → 按上下文分配可塑性
  → 双跑与安全门晋级
  → 内容绑定回执
```

这里体现了稳定性—可塑性原则：冻结父代不是拒绝学习；让新模型直接拥有全部控制权也不是成长。更可靠的成长方式是保留已证明的稳定技能，用独立考试限制候选，再让环境根据失败证据逐步授予影响范围，并且始终可以追溯“用了哪个模型、多少权限、为何晋级”。

## 尚未完成与下一阶段

本轮没有声称以下能力已经解决：

- 端到端直接关节力矩 actor；
- 在线持续更新的 actor-critic；
- 从任意连续来球状态自动泛化的神经权限策略；
- 扑倒后完整翻身、起身、回到 ready 并二次扑救；
- 真机授权或 ROS/DDS 电机命令。

下一阶段 S104–S106 应按以下顺序继续：

1. **Successor 闭环**：把每次扑救的落地末态接入已有 Absorb / Get-up / Ready 专家，要求在固定时间内重新获得可移动状态；允许为了扑救摔倒，但必须能恢复。
2. **连续权限模型**：把离散 lane 表提升为基于来球拦截点、到达时间、支撑状态和本体置信度的单调受限路由器；离散通过点作为安全锚，未知区域默认回退。
3. **失败优先课程**：扩大速度、高度、左右横向和初始门将位置分布，优先采样当前失败带，不重复刷简单球。
4. **小权限 actor-critic**：只在仿真中训练受限残差和 successor 切换，奖励同时包含真实扑救、接触时机、腾空、关节余量、落地冲击、恢复时间和遗忘保护；新候选必须与父代做回归对照。
5. **模仿先验接入**：只有在 MotionDecode/SONIC 动作完成许可证审计、G1 retarget、足接触重建和独立物理考试后，才作为自然动作先验进入训练；不能以视频观感替代物理门。

当前晋级范围仍严格限定为研究用 `SIM_ONLY`。这一步证明了模型可以进入球链并在四个高角上形成可复验增益，但距离“真正完整、自主持续学习且能二次扑救的球星门将”仍有明确的工程距离。
