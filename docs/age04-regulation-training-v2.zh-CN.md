## 为什么仍然是 DEVELOPMENT

旧报告只给一个总 `passed`，会把不同问题混在一起。v2 增加独立的 Age-4 多轴门：

| 评审轴 | 结果 | 主要证据 |
| --- | --- | --- |
| 来源与严格复现 | PASS | strict replay、Body/实现/轨迹哈希绑定、SIM_ONLY |
| 目标精度 | PASS | 门线误差 0.00807 m，进门并留网 |
| 跑动到触球连续性 | PASS | 无停顿，handoff 到触球 0.926 s |
| 动态稳定 | **FAIL** | 助跑最低骨盆 0.659 m；峰值倾角 0.496 rad |
| 踢后恢复 | PASS | 不摔、不后退，3.334 s 收敛 |
| 力矩权威 | PASS | 实际饱和 0，投影比例 0.571% < 1% |

唯一失败码是 `DYNAMIC_STABILITY_GATE`。最大前倾发生在助跑约 0.94 s，最低骨盆发生在减速约 2.96 s；它们不是触球后的抖动。触球后的最终速度、后退量和关节速度都已经通过恢复门。

当前课程考的是标准球门内部的指定落点 `(y=1.32 m, z=1.04 m)`，不是门框几何角点。因此 Age-4 门按课程落点评分，不把“离门框角点距离”或“球最终压网位置”错误地混入门线精度；但它完整保留核心的物理安全、连续性、恢复和动态稳定要求。

## 代码层面的改进

### 1. 可审计的关节力矩权威投影

新增逐关节力矩权威投影。它在硬限的 98% 内执行，记录：

- 投影前峰值需求；
- 投影发生步数和比例；
- 最大修正力矩；
- 投影后的真实饱和情况。

这不是把饱和计数隐藏掉：报告同时保留投影前的 1.514 倍需求。候选只有在投影比例不超过 1%、投影后实际饱和为 0 时，权威门才通过。

### 2. 保方向的触球任务投影

教师或 actor 输出的任务空间附加力，先根据各关节剩余力矩余量求一个共同缩放系数，再经足端 Jacobian 转为关节力矩。共同缩放保持力的方向，避免逐关节裁剪把射门方向扭曲。

最终 actor 的共同缩放比例为 1.0、投影步数为 0，说明它不依赖这层保护才完成射门。

### 3. 成功—失败约束的 actor 选择

蒸馏仍要求至少 2 个精确成功和 2 个失败负样本。候选代价不再只看落点误差，还惩罚：

- 权威投影比例；
- 投影前超过硬限的需求。

最终 actor 绑定 8 份严格证据，其中 3 份精度成功且任务力保留比例不低于 95%，另外 5 份作为失败或权威边界样本。actor 直接输出二维任务力，再由测得的足端 Jacobian 转成右腿六关节力矩；它是有界的数据驱动触球肌肉记忆，不是动画补帧。

最终 actor 哈希为 `sha256:9e334527dd000fef4f6dd3cc39c63a11c97cf2f8fe919b1a3e5b3131ff505ada`。

### 4. 多轴 fail-closed 评审

Soccer 层新增独立评审，任何非有限值、缺失的严格复现、教师未关闭、饱和、摔倒或超阈值都会让对应轴失败。只有全部六轴通过才是 `PASS`；当前五轴通过但动态稳定失败，因此明确标为 `DEVELOPMENT`，没有降低核心稳定阈值。

## Stability–Plasticity 实验

为改善助跑前倾，本轮还评估了多个更稳定的 SONIC 计划。最有代表性的 seed 29 把峰值倾角从约 0.496 rad 降到约 0.298 rad，但高球技能的门线误差扩大到约 2.30 m。

随后依次扫描了：

- 瞄准偏置；
- 骨盆偏航；
- 脚部偏航；
- 踢球技能接管相位；
- seed 10、28、29、52 的稳定计划池。

所有候选都保持零实际饱和且未摔倒，但最好的稳定候选仍有约 1.59 m 误差。它们被保留为负证据并拒绝晋升，默认继续使用精度技能岛 seed 0。这正是 Stability–Plasticity Dilemma 的具体体现：更稳的新本体状态不能直接复用旧触球技能，下一轮必须联合学习助跑稳定残差和触球 actor，而不是只换一个看起来更稳的计划。
