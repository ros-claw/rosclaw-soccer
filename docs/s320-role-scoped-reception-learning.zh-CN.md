# S320：只训练需要学习的角色

## 工程能力

`update_private_actors` 新增显式 `trainable_agent_ids`。它是不可空、排序且唯一的现有球员集合。训练范围独立于物理控制的 active mask：冻结学习的球员仍按真实轨迹记录控制行为，不能通过篡改 active mask 伪造冻结。

每次更新的 Core plasticity 上下文绑定这一范围。未选中的角色不创建优化器、不修改参数；选中角色仍必须满足真实 on-policy 样本校验、最小样本数、KL、梯度和更新预算约束。不给参数时保留旧路径；显式选择全体球员与旧路径产生完全相同的模型参数，但更新上下文包含显式范围。

单元测试实际执行梯度更新，验证指定角色改变、其余七名逐数组不变、输入轨迹不变、重复更新完全一致，以及无效范围拒绝。此能力解决的是“谁允许学习”的边界，不代表运动技能已经学好，也不会自动晋升策略。

## 实际训练

本地证据：`s320-role-scoped-reception-ppo-v1`。初始模型是 S231 generation 2 的八私有近球策略；每个球员为 56 维观察、32 隐层、12 维腿部关节位置残差 actor-critic。不是直接力矩网络，也不是本轮重新训练 SONIC。

训练配置：

- 只更新 `blue.finisher`、`red.finisher`；六个其他私有 actor/critic 逐数组冻结。
- SONIC 基础模型、已有全身射门模型和动作参考冻结。
- 严格物理 handoff、接球上下文优先、地面摩擦 0.40、球员安全分离目标 1.20 m、到达半径 0.10 m。
- 两轮真实 CPU on-policy PPO；每轮四个完整八身体课程，红蓝分别使用球位偏移绝对值 0.08 / 0.10 m，轨迹有探索。
- 每轮每个可训练角色最多八个优化步骤，gamma 和 GAE trace decay 均为 0.997。
- 旧摩擦 0.05 下两条成功传接轨迹作为显式行为回放，KL 系数 100；它们不再是独立留出数据。
- 每轮重建 Adam，不能称为持续保存动量的优化器；checkpoint 保存实际推理参数，原始 on-policy 轨迹和更新审计均保留。

训练结果：

| 轮次 | 身体安全课程 | 真实接球课程 | 实际更新角色 |
| --- | --- | --- | --- |
| 1 | 2 / 4 | 0 / 4 | 红蓝前锋 |
| 2 | 3 / 4 | 0 / 4 | 红蓝前锋 |

第一轮原始轨迹和参数完整重放更新，模型哈希及审计一致。两轮其余六名球员参数均完全不变。这里的 2/4 到 3/4 来自不同探索轨迹，不能单独视作训练改善的因果证据。训练中未出现真实接球成功，更不能据此宣布突破。

另做确定性开发基线：扩大球员分离后，蓝方 0.10 m 课程保持身体安全并完成真实接球；红方对应课程仍在接球时出现非脚部先碰球。基线没有使用新更新模型。

## 验证状态

代码全量验证为 1453 passed、29 skipped、11 failed；11 个失败仍为既有历史外部证据与当前源码绑定问题。ruff check 和 mypy 431 文件通过，变更文件格式通过。

物理评估另由 `examine.py` 执行：四个未用于梯度的 0.09 / 0.11 m 新球位，以及两个明确标记的旧球性回放；父模型和候选分别重复两次，共 24 次八身体仿真。每一对要求完整轨迹精确重放，按逐课程身体安全、非脚部干扰、合格传接和完整比赛门检查，不以平均分掩盖退化。

24 次物理评估已完成，每个策略／课程的两次轨迹完全一致。父模型和候选均有 6/6 个身体安全课程，但合格传接从 1/6 降为 0/6、诊断真实接球从 2/6 降为 1/6、整段没有非脚部干扰的课程从 2/6 降为 1/6。完整比赛仍为 0/6。

候选丢失了红方旧球性 -0.10 m 课程的合格传接与非脚部干扰门，保留检查明确拒绝继续替换。没有更换默认世界或冠军，没有把候选训练结果制作成宣传视频。

这证明角色范围和精确更新重放已打通，但当前奖励、训练分布和接球身体技能还不足。特别是只冻结其他角色的权重，并没有冻结它们在采样时的随机探索；下一步需要把“谁探索”与“谁更新”都明确绑定到角色，以便从稳定、真实触球的传球前缀中训练接球队员，而不是让所有人的探索同时扰动课程。
