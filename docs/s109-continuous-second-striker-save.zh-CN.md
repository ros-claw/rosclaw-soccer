# S109：四台 G1、双实体球、第二前锋高球与门将连续二扑

## 结论先行

S109 首次在同一个 MuJoCo 时钟、同一个世界中跑通以下完整链路：

> G1 传球 → 第一前锋射高球 → 门将第一次手套扑救 → 门将实测恢复并重新就绪 → 第四台 G1 右脚踢第二颗实体足球 → 门将第二次高位手套扑救 → 双脚支撑并恢复准备姿态。

正式候选和独立重放的结果、逐帧轨迹摘要及所有门控完全一致。14 项硬门控全部通过。没有球炮、没有在仿真开始后写入球或机器人的 `qpos/qvel`、没有重置、没有瞬移，也没有使用视频像素评分。该成果仍严格限定为 `SIM_ONLY`，不构成真机授权。

## 这轮真正解决了什么

### 1. 数据驱动触球 actor 过去只对第一台 G1 有效

触球 actor 用足端雅可比把二维任务空间动作解码为 29 维关节力矩。旧实现把雅可比列硬编码为 `qvel[6:35]`，即默认世界里只有一台 G1。第四台 G1 虽然进入 actor 激活窗口，但它自己的足端雅可比非零列位于另一段 DoF，硬编码切片得到全零力矩。

S109 将解码接口改为显式接收当前智能体的 29 个 actuated DoF 索引，并在共享世界中按角色传入。新增回归测试构造后置机器人雅可比，确认输出不再错误落到第一台 G1。修复后第四台 G1 的 actor 峰值从 `0 Nm` 恢复为 `61.966 Nm`。

### 2. 已学习的“肌肉记忆”过去被角色名锁死

第一前锋使用三层触球能力：

1. 证据训练的任务空间触球 actor；
2. 接触相位附近的关节目标残差；
3. 接触相位附近的直接关节力矩残差。

后两层以前只在 `role == "shooter"` 时执行。S109 将其改成可按角色路由，并为第二前锋保留独立的遥测。第二前锋最终复用了 S96 训练并封装的 upper-corner torque muscle memory，而不是重新写一段只服务于第四台机器人的动画补丁。

### 3. 第二前锋也有独立、受约束的技能参数

共享世界现在允许第二前锋拥有自己的有界踢球参数，包括挥腿幅度/速度、脚尖 yaw/pitch、loft synergy、接触相位，以及门将面对第二威胁时的拳击权威。参数仍由 `ShotParameters` 统一验证，不能绕开安全范围。

这避免了为了第二脚高球而破坏已经合格的第一脚射门，也为后续 population search、actor-critic 或离线策略蒸馏提供了清晰动作空间。

### 4. 不是“力越大越好”，而是闭环选择接触甜点

门将第二次接触的探索结果很明确：

- 默认较弱拳击可以碰球，但球仍向门内前进；
- 加入过大横向拨球会让手离开接触口袋，直接漏球；
- `120 N` 上限会改变手掌姿态，虽然发生碰撞，但仍未完成解围；
- `90 N`、横向分量为 `0` 时，手套既保持在预测口袋，又能把球的世界 x 速度反向。

最终动作不是手工给球施加外力。`90 N` 是门将关节控制器中经过雅可比转置解码、关节安全投影后的操作空间权威；球的速度变化来自 MuJoCo 中手套碰撞体与实体球的接触。

## 如何通俗理解这个实验

可以把它想成门将连续经历两道题。

第一题由原来的传球手和射手完成。门将扑完以后，程序不能把它“摆回标准姿势”，只能让它用自己的恢复控制慢慢站稳。系统看到它真的站稳、双脚有支撑、身体朝向正确以后，才把感知记忆清空，允许第二道题开始。

第二题不是把球凭空发射。另一名一直在场上的 G1 真的走完踢球策略，用右脚碰到另一颗从开场就放在草地上的足球。脚碰球这一刻才启动门将的第二次来球记忆。门将根据球的真实飞行作出反应，手套在 1.44 米高度碰到球，并把原本朝球门飞的速度变成朝场内和侧面飞。最后它还要重新站稳，考试才结束。

所以本轮的突破不只是“视频里多踢了一脚”，而是把 ROSClaw 的已学习技能从单角色特例推进到可在同一世界里复用的多智能体能力，并用真实接触、状态连续性和严格复演闭合了证据链。

## 尚未完成的部分

- 正式通过目前只有 `left-inner` 一条连续链，尚未构成四角、多摩擦、多脚的 population qualification；
- 第二前锋仍从固定站位执行冻结 FreeKick 策略，不是完整远距离跑动接球射门；
- 本轮复用并组合了既有数据驱动 actor/肌肉记忆，但没有在线更新神经网络权重；
- 所有结果仍是 MuJoCo CPU 仿真，不能直接外推到真实 G1；
- 目前证明的是“第二前锋射高球、门将扑出”，下一阶段应加入接球来球、左右脚切换和多门将策略人口，而不是继续单点放宽门控。

建议 S110 以本轮同钟双球架构为固定基线，开展多 lane、多脚、摩擦/质量扰动的攻击—防守联合 population，失败样本写入 Growth ledger，再训练角色无关的接触 actor v2 和门将迎球手速度策略。
