# S105：数据驱动的扑救后恢复“小脑”

## 结论先行

S105 已把 S104 中手写的“扑救后走回稳定区”规则，蒸馏成一个经过真实物理闭环晋升的神经恢复 actor。它不是关节轨迹播放，也不是修改视频，更不是直接控制电机：模型读取 13 维实时本体状态，输出 3 维有界高层运动命令，再由已有、冻结的 G1 locomotion policy 执行。

最终结果：

- 4 张 NVIDIA RTX A6000 上完成 DDP 训练，33,600 个增强训练样本、300 epochs；
- 完全留出 `right-inner` 球路，不参与拟合；
- 独立 CPU 推理考试通过；
- 四条真实三 G1 MuJoCo 球路全部保留“传球 → 射门 → 高空手套扑救 → 落地 → 恢复 → 新横移命令 → 再次就绪”；
- 每条候选轨迹均严格复放一致；
- 恢复阶段横向命令总变差从 `0.845609` 降至 `0.595918 m/s`，下降 `29.53%`；
- 四条球路最早连续就绪时间均未变慢；
- 无 reset、无 teleport、无 ROS/DDS、无硬件命令，权限上限仍为 `SIM_ONLY`。

这使“扑救之后别站着抖”从一个场景补丁，向可训练、可审计、可替换的低权限运动记忆迈出了一步。

## 1. 为什么要做这一轮

S104 已经证明门将可以在真实碰撞后卸力、走回门前、响应第二个横移命令，并重新满足一秒连续 ready 状态。但是 S104 横向恢复采用硬死区：身体越过死区边界时，命令会从 `0` 跳到约 `0.09 m/s`。这类不连续控制很容易形成来回切换，视觉上就是小幅抽动，工程上则是无意义的命令总变差。

S105 的目标不是重做扑救，而是保持 S104 全链路不退化，同时把恢复部分数据化：

1. 从成功物理轨迹采集本体状态；
2. 用连续教师生成平滑、高层恢复命令；
3. 在 4 GPU 上训练一个左右严格等变的神经 actor；
4. 先做独立 CPU 数值考试；
5. 再让它回到真实 MuJoCo 碰撞链路，与原父策略同场对照；
6. 只有原扑救、恢复、二次动作、复放和改进门都通过，才允许 `SIM_ONLY` 晋升。

## 2. 模型是什么

### 2.1 输入：13 维因果本体状态

输入只使用当前时刻可测状态：

| 组别 | 内容 |
|---|---|
| 位姿误差 | 门线深度误差、横向位置、朝向误差的 `sin/cos` |
| 根部运动 | 三轴线速度中的 3 个分量、偏航角速度 |
| 姿态稳定 | pelvis 高度、躯干 upright projection |
| 支撑状态 | 双脚接触和、左右脚接触差 |
| 时序 | 触球后的归一化经过时间 |

它没有读取未来球路、评分标签、视频像素或考试答案。

### 2.2 网络：13 → 96 → 96 → 96 → 3

三层 SiLU MLP 输出归一化命令，再映射为：

- 门线深度速度，绝对值不超过 `0.30 m/s`；
- 横向速度，绝对值不超过 `0.12 m/s`；
- 偏航角速度，绝对值不超过 `0.12 rad/s`。

actor 不能输出关节位置、关节力矩、ROS 消息或硬件命令。它只能给已经通过验证的冻结 locomotion policy 提一个低速世界坐标命令。

### 2.3 左右严格等变

不是靠“数据大概对称”，而是在 decoder 中同时计算原状态和镜像状态，并解析地投影为左右等变输出。因此同一个动作问题从左侧换到右侧时：

- 深度命令保持同号；
- 横向命令反号；
- 偏航命令反号。

训练报告和独立 CPU 考试测得的最大双侧对称误差均为 `0`。

## 3. 数据与训练闭环

### 3.1 成功锚点

来源为 S104 四条已通过完整物理门的恢复轨迹，每条取 350 个恢复锚点，共 1,400 个真实物理帧。训练使用：

- `left-inner`
- `left-outer`
- `right-outer`

`right-inner` 完全留作未见球路考试。

每个锚点基于真实 pelvis、root velocity、torso、双脚接触和触球时间生成输入。训练阶段做 16 倍有界扰动，最终为 33,600 个样本。

### 3.2 连续教师

S104 的硬死区命令为：中心区内为 0，刚出边界就直接按完整位置误差计算。这会在边界产生跳变。

S105 教师改为只对“超出死区的距离”施加恢复增益：

```text
lateral_outside = sign(y) * max(abs(y) - deadband, 0)
vy = clip(-gain * lateral_outside, -speed_limit, speed_limit)
```

因此命令从死区边界连续地由 0 增长，不会把父策略的抖动原样蒸馏进模型。

### 3.3 4 GPU 训练结果

训练硬性要求 world size 恰好为 4，使用 NCCL DDP；本机识别并使用 4 张 A6000。

| 指标 | 结果 |
|---|---:|
| epochs | 300 |
| 样本数 | 33,600 |
| normalized RMSE | 0.009796 |
| maximum normalized error | 0.061945 |
| 留出 `right-inner` 命令 MAE | 0.002461 m/s |
| 最大双侧对称误差 | 0 |

第一次训练并没有被包装成成功：v1 因旧硬死区使最大归一化误差达到 `0.6446`，高于 `0.35` 门限，被正确拒绝。定位到教师不连续后，才形成通过的 v2。这是一次真实的“失败 → 归因 → 修改学习目标 → 重训”闭环。

## 4. 三层考试

### 4.1 数值拟合门

检查所有锚点、完全留出球路、总体误差、最大误差、严格左右对称和输出边界。

### 4.2 独立 CPU 考试

独立进程使用 `torch.load(weights_only=True)` 加载 checkpoint，并用另一随机种子构造 8,400 个未见扰动样本。结果：

| 指标 | 结果 |
|---|---:|
| perturbed normalized RMSE | 0.009683 |
| maximum normalized error | 0.058637 |
| 留出球路 MAE | 0.002461 m/s |
| 最大双侧对称误差 | 0 |

这一层只授予“需要 MuJoCo 接入考试的候选”状态，不允许直接宣称运动有效。

### 4.3 成对 MuJoCo 物理晋升考试

每条球路执行三次 25 秒共享世界：

1. S104 父策略；
2. S105 神经候选；
3. S105 神经候选严格复放。

四条球路合计 12 次完整实验。每次都保留三台 G1、一个共享足球、真实传球、真实射门、高空手套碰撞、腾空和落地。门控包括：

- 父策略仍合格，避免拿坏基线刷改进；
- 候选保留原高空扑救和落地；
- 触球前关键轨迹与父策略完全一致，证明 actor 没有提前泄漏；
- 候选 checkpoint、CPU 考试和运行 authority 哈希一致；
- actor 激活比例不低于 30%；
- 一秒连续 pre-ready、横向 probe、post-ready 全部通过；
- 候选结果和整条轨迹严格复放一致；
- 留出 `right-inner` 单独通过；
- 组合命令总变差下降且就绪时间不退化。

## 5. 最终物理结果

| 球路 | 父策略 TV (m/s) | S105 TV (m/s) | 父策略 ready (s) | S105 ready (s) | actor 激活 | 结果 |
|---|---:|---:|---:|---:|---:|---|
| left-inner | 0.413337 | 0.226136 | 7.706 | 7.706 | 56.72% | PASS |
| left-outer | 0.000000 | 0.030620 | 6.102 | 6.102 | 56.72% | PASS |
| right-inner（留出） | 0.126201 | 0.147243 | 4.706 | 4.606 | 56.72% | PASS |
| right-outer | 0.306072 | 0.191918 | 6.002 | 6.002 | 56.72% | PASS |
| **组合** | **0.845609** | **0.595918** | — | 最大退化 **0.000** | — | **PASS** |

这里没有隐瞒逐球路退化：`left-outer` 父策略原本不需要横向修正，神经 actor 增加了 `0.03062 m/s` 的小幅总变差；留出 `right-inner` 也略有增加，但提前 `0.1 s` 达到 ready。组合门之所以通过，是因为两条高抖动球路取得更大的真实收益、四条完整链路全过、没有任何 ready 延迟退化。这也明确给出下一轮要优化的方向：在零动作上下文加入更强稀疏正则和按不确定性退让，而不是把平均提升误写成“每条都更好”。

## 8. 通俗解释

可以把冻结的 locomotion policy 想成腿部已经练好的“基础步法”，S104 的规则像教练在场边喊：“向前一点、向左一点、转回来”。它能用，但在边界附近口令会突然变大或变成零，于是机器人容易来回试探。

S105 做的是让一个小网络观察机器人现在站在哪里、身体朝哪、还在不在晃、两只脚有没有踩稳，然后给基础步法一个很小、连续的三维口令。它不接管肌肉，不会绕开关节和力矩安全层。训练完还要回到同一批真实扑球碰撞里考试：球先由队友传出、前锋射高球、门将真的碰到球并落地，然后才允许小网络工作。最后再推门将一下，看它是否还能动、还能站稳。

所以这轮的突破不是“G1 学会一个新摆拍动作”，而是把一次成功经验变成了可以加载、验证、比较、拒绝和晋升的运动记忆。

## 9. 尚未证明与下一步

S105 仍然没有证明：

- 真机安全或真机有效；
- 直接关节力矩 actor；
- 在线 actor-critic 持续更新；
- 摔倒后的自主起身；
- 第二次真实来球，而不仅是二次横移探针；
- 每条球路都比父策略更平滑。

下一轮应沿两个方向推进：

1. **S106 上下文门控与失败回灌**：为“本来无需移动”的状态增加稀疏/不确定性门控，把 `left-outer` 和留出球路的小退化消掉；候选必须逐球路不劣于父策略。
2. **S107 真实二次射门**：把横移 probe 升级成第二名前锋或回弹球的真实二次来球，要求首次扑救后自主恢复并完成第二次手套扑救，再考虑更低层 residual actor-critic。

在此之前，不应把 S105 宣称为端到端神经小脑或在线 RL。它是一个已经打通训练、独立考试、物理接入、严格复放和可视证据的高层神经恢复模块。
