# S2606：回球后保留性训练与传球动作接通

2026-09-17，SIM_ONLY。继 S2604 拒绝退化候选后，继续做两组真实 PPO
参数更新及实战对照，另外隔离验证上层传球意图到完整踢球动作的接通。
这不是已实现连续比赛或新冠军的报告。

## 先诊断，再决定训练对象

父策略 45 秒课程中，红后卫最后十秒有 475 帧 PASS 意图、495 帧近球残差
激活，但没有新增完整踢球选项。当前课程配置确实为 `pass_enabled=False`；
`continuous_rearm_enabled=True`、`per_player_options_enabled=True`。
因此不能把这一层的能力关闭误诊为全部由小脑网络不足引起。

同时，红后卫多次距球约 0.3 米但留不住球；蓝中场主要是身体接触。
接近、宣称传球、实际足部接触、控球、对方接应必须分别记录。

## S2606：同数据、同父策略的两组更新

使用 S2600 的两条父策略 on-policy 采样记录，仍剔除外部回球和死球阶段；
不是额外采集了两条训练课程，也不是把候选自身未采样的数据冒充 on-policy。
分别测试：

- 原奖励下仅更新一轮。
- 更新四轮，加入系数 1000 的旧行为 KL 保持约束，参考原父策略 45 秒记录。

保持其他超参数、物理、射门模型、门将和接球专家不变。真正更新的仍为
蓝中场、红后卫和红中场，其他角色不因“球队训练”的名称而被声称学到了技能。
每个候选重训一次，最终参数和 Core PlasticityLease 审计完全一致。
两候选分别执行 45 秒实际物理课程与独立重放，共四次；均通过原安全检查。

| 策略 | 回球后足部接触帧 | 控球帧 | 全程完整踢球选项激活 |
| --- | ---: | ---: | ---: |
| 父策略 | 4 | 28 | 1 |
| S2600 无锚点四轮候选 | 0 | 0 | 1 |
| S2606 单轮候选 | 0 | 0 | 1 |
| S2606 带锚点四轮候选 | 3 | 16 | 1 |

带约束候选相较上一失败候选保住部分能力，但仍弱于父策略；两个候选都不晋升。
旧行为 KL 降低不等于物理技能保留，更不等于稳定性—可塑性难题已经解决。
这是公开开发课程，不是多位置、左右脚或速度变化留出集上的泛化成绩。

## S2608：独立检验传球动作入口

不更换任何球员权重，仅在外部回球已实际重新进入场内的活球阶段，临时开放
现有完整踢球桥的传球能力；死球及最初攻击阶段不变，原姿态、安全和球权
触发条件不放宽。独立记录每帧有效开关，旧报告里的静态 options hash 只代表
覆盖前配置，不能冒充有效覆盖配置；覆盖脚本和掩码另行绑定摘要。

该对照用于判断“没有触发动作”和“触发后动作质量不足”是否是不同故障，
不能把一项布尔开关作为已经训练出新的传球技能。

结果：后卫在 35.80 秒激活完整传球选项，35.90 秒出现足部接触；36.72 秒
又出现后卫的非足部接触，球速约 6.65 m/s，37.82 秒出界，未形成成功接应。
38.42 秒红后卫与红中场的接触力峰值约 574.20 N。八名单体姿态检查通过，
但整队报告累计 1023 个机器人接触计数（不是 1023 次独立冲撞），而父策略为 0。
所以整队安全门失败；明确拒绝默认启用该覆盖，更没有用“只是碰撞”放宽标准。
主执行与独立重放精确一致。新出现的第二次动作是诊断进展，不是球技突破。

本轮共六次物理执行：四次 PPO 候选实测、两次传球桥对照。所有失败保留。
S2610 独立检查五组历史/本轮对照原始数组及报告摘要，重新计算实际活球阶段
的触球帧、控球标签、近球距离、近球意图和动作激活次数。

## 公共训练入口加固

新增 `training/returned_ball_learning.py`，按实测出界→外部释放→重新入场
状态序列提取独立活球训练片段，验证时钟、事件顺序和所有列的帧对齐。
返回副本，防止训练修改原始轨迹；允许外部抛球失败后再次出界，但不把它
计入活球经验。它验证的是事件记录，不冒充对物理几何的独立验证。

`physical_rewards` 对带回球事件的输入强制要求单个“实际重新入场起始、
不含再出界/释放”的片段。忘记切分整个 45 秒轨迹时直接拒绝，防止外部回球
被奖励给球员，或 GAE 跨越球位重置。旧无辅助训练保持原语义。
新增 15 个测试，与现有 PPO、角色保持和更新重放测试合计 70 项通过。
新增保护后再运行 S2602 独立审计，4500 帧动作和历史 PPO 参数、Core 租约
仍精确复现，证明已经正确切分的既有训练没有被改变。
配置实际 G1 资产后的全量回归为 4287 passed、18 skipped、11 failed，
耗时 89.71 秒；11 项仍是既有 S78/S79/S80/S94/S104/S105/S107/S108/S113/S114
历史证据绑定失败，没有改动验证器或旧凭据消除它们。新增文件及改动文件
ruff、格式检查、两文件定向 mypy、compileall 和 diff 检查通过。

这层改动在六次物理执行全部结束后才加入，不修改已运行世界的源码；
物理实验源码摘要仍为 S2594 的 `8a917486e304990253010a73bd957ed39c966116bb35a2ec23758f62d438d1fd`。

## 下一步优先级

先做防止后卫与接应者占据同一挥腿空间的传球准入，以及从实测身体状态
启动的短传控制课程；将成功条件定义为“足部送球→接应者真正留球→双方
无碰撞并能继续运动”。不能只将射门策略的目标改近就默认具备精准短传。
父策略回球课程和已有传接射门保留性考试都要继续跑。上述仅为下一步，
本轮尚未训练出合格短传模型，也未实现自主连续比赛。
