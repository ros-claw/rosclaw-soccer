# S352：真实循环态驱动的 GPU 收球小脑试训

完成四轮实际 on-policy PPO，每轮 128 个 MuJoCo Warp 隔离接球环境、
60 个 50 Hz 控制步、600 个 500 Hz 物理步、64 个优化器步骤。
每轮采样加更新约 4.4–4.7 秒；不能与八体 20 秒课程直接算同任务加速比。

新模型是围绕冻结 RoboNaldo 循环行走基础策略的 29 关节目标残差：
133→128→128→29 actor、独立 critic，偏移 ±0.25 rad、单步 ≤0.025 rad、
平滑系数 0.2。不是直接力矩输出策略。新 actor 零均值初始化，未加载
旧 SONIC 踢球残差当成兼容模型，未替换原有任何角色或射门权重。

## 实际课程和约束

初始数据来自实际蓝中场接收队友脚传球的两帧（8.6/8.8 秒），完整恢复
身体/球 qpos、qvel、上一帧 action、LSTM 隐藏态/记忆态。
两种身体状态各 64 个副本；训练扰动球位置 ±3 cm、速度 ±0.1 m/s。
**不是 128 种独立真实身体经验**，而且隔离课程中没有其他七人。

使用原测得的受限导航指令作为训练提示，真实脚触球后因果地置零导航指令。
没有解析脚接触老师，没有中途重置身体/球，没有直接球力。
摩擦 0.4，电机上限 85%，关节保护边距 0.08 rad。
所有接触逐 2 ms 测量；真实 Core 单焦点学习租约审计约束模型更新，
基础行走参数及归一化统计冻结，循环态本身仍正常演进。

## 结果：不通过，未晋升

零残差基线：128/128 身体安全、脚触球、无非脚接触，但停不住。
四轮后的确定性两情境考试：128/128 身体安全，只有 64/128 脚接触，
另 64/128 出现非脚接触，0 可控停球。重复副本不能当独立成功率。
新模型显然不能替换旧模型。

复盘还发现两个课程问题：

1. 未控住的触球终端罚分比完全没碰到更重，可能推动策略回避触球。
   下一轮单独测试奖励次序，并保持安全/非脚惩罚。
2. 终端训练奖励少了完整 0.5 秒接触后观察条件，而最终评估有此条件；
   本轮未出现任何成功，但规则不一致仍必须修正，不能留作日后漏洞。

下一轮新增统一的 `controlled_reception_mask` 与终端奖励，训练与评估复用
同一接触时钟条件；脚距离改用与共享世界相同的踝部位置，而非碰撞几何中心。
这轮只有工程上打通了 GPU 神经小脑学习链，没有宣称球技已经变好。
