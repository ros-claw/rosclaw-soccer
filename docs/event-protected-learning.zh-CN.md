# 事件保护的持续学习

## 先保住已学动作，再学习后续动作

S885 的恢复奖励降低了部分平均代价，却同时改变触球前的射门动作：新样本精度成功数从冻结基线 29/32 降到 26/32，旧上下文也退步。只调整奖励权重，不能保证旧动作保持不变。

新增 `training/event_protected_actor.py` 分开保存冻结策略和可学习策略。输入为原始状态与一个明确的二元事件特征：事件前的动作均值只来自冻结副本；事件后来自可学习副本。价值网络可以整段学习，探索标准差全局冻结，避免通过共享方差间接改变前缀动作分布。

两副本开始时参数完全一致，输出仍经过原动作平滑、增量限制和仿真力矩保护。模块没有接触检测、机器人身份、世界时钟、控制接口或策略晋升权限。非机器人、5 维输入 / 2 维动作的测试也验证了此机制，并非把 G1 名字写死的新脚本。

## 不承诺什么

- 这不是持续学习的完整解法，也不是零遗忘或全场安全证明。
- 事件特征必须由采集器根据已经发生的观测生成，并独立核验；调用方填入 `1` 不是运动授权。
- 冻结条件动作均值与探索分布，不代表随机采样等于确定性执行。
- 相同初始状态、历史和外部输入下的前缀可比较；多智能体后续行为改变会产生不同输入，不能无限外推前缀不变。
- 事件后的自身接触、平衡、球路和旧任务成功率仍可能退步，需要全程物理复考。
- 神经网络分支选择不是完整技能切换协议；尚未接入多人运行时，更没有硬件能力。

## 首次原生实验

S901 使用 S843 冻结权重、S869 真实导航历史和参考中心 -0.337 rad。额外特征仅在上一批物理步已经观测到自己的脚触球、接触后超过 0.2 秒、球与身体平面距离超过 0.35 m 且未出现已知自身非脚接触或安全失败时激活，之后在该小段内保持激活。未使用未来接触、实验编号或全场固定帧触发。

输入为 136+1 维，输出为 29 个关节目标残差及一个参考朝向，不是直接关节力矩策略。PPO 配置增加精确的 `(137, 30)` 契约，没有放开任意维度或修改旧动作边界。

计划为 4 次原生 CPU MuJoCo / CPU ONNX PPO 更新，每次 32 世界、200 控制步。首次更新的同组评估中，精度成功保持 23/32、速度成功保持 28/32，平均恢复代价从 4.189961 降到 3.681105；独立检查确认事件前 q/v 精确一致。这是开发样本上的阶段信号，不是独立成功率、自然性或宣传片结论。

S901 完成两次更新后，系统盘剩余空间跌破原定 4 GiB 保护阈值，触发断言停止，没有降低阈值继续写满。原记录保留于 `/home/dell/rosclaw_soccer_evidence/s901-warm-protected-successor-ppo-v1`。S902 在 `/code/rosclaw/phase8_evidence/s902-warm-protected-successor-resume-v1` 接续：复制并校验历史文件，用 `weights_only=True` 加载最后更新前检查点，恢复优化器和 Torch RNG，精确重放最后一次更新并验证 actor-002，再执行剩余轮次。续训不覆盖旧实验，也不清理其他任务文件。最终效果以完成后的审计为准。
