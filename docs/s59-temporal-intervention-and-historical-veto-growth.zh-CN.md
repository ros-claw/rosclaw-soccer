# S59 时序介入与历史能力否决器：恢复小脑持续学习实验报告

日期：2026-08-21
状态：`SIM_ONLY / NEW-192 RETAINED / OLD-96 NARROW REJECTION / NOT_DEPLOYABLE`

## 1. 结论先行

这一轮取得了真实但尚未完成的突破：恢复纠偏小脑从“单帧置信度一高就持续干预”升级为“连续证据触发、有限时租、冷却退出、历史能力否决”的时序控制器。最佳候选 v12 在新 192 路由上同时通过失败恢复门和正常行为保持门：

- 失败状态平均代价改善 `+1.3993%`，方向性、稳定性和有限值检查全部通过；
- 正常路由代价不是退化，而是改善 `0.4942%`；
- 正常路由纠偏动作 RMS 从早期候选的约 `0.0315` 降到 `0.009934`；
- 全部输出有限，候选始终受 `SIM_ONLY`、有限时租和动作幅值上限约束。

但 v12 在冻结的旧 96 路由复试中仍未整体通过。失败恢复改善 `+1.1889%`，正常代价回归 `+0.6391%`、动作 RMS `0.009880`、稳定性均通过，只有正常路由第一个方向性效应指标超出容差：候选 `0.086035721`，父策略 `0.083663978`，差值 `0.002371743`，而允许值是 `0.002`，超门限 `0.000371743`。因此本轮只能保留为开发候选，不能晋级、部署或接入真实硬件。

这不是“多跑了一些训练”的结果，而是对 Stability-Plasticity Dilemma（稳定性—可塑性困境）的架构拆解：主门负责识别新失败，历史否决器只缩小动作权限而不能制造新触发；最低权限地板又避免旧知识把新恢复技能完全压死。v9 的失败也证明，把新旧正常域简单混入同一个二分类器会同时损伤恢复能力和正常稳定性。

## 2. 本轮要解决的问题

S58 的纠偏学生已经能在局部失败状态给父策略提供有益残差，但存在三个系统性问题：

1. 单帧门控会被瞬时相似状态误触发，形成持续抖动或不必要的动作注入；
2. 只在短采样点上训练正常负样本，会漏掉 600 步正常轨迹中真正接近决策边界的状态；
3. 在新 192 路由上学习后，候选可能忘记冻结旧 96 路由上的正常行为。

本轮目标不是针对“足球脚本”打补丁，而是给 ROSClaw 增加可复用的持续适应基础件：任何带有父策略、纠偏残差、失败域和历史正常域的技能，都可以复用同一套时序授权、困难负样本挖掘、历史否决与冻结复试协议。

## 3. 新增的通用能力

### 3.1 有状态的时序介入租约

新增 `CorrectiveTemporalLeaseConfig` 与 NumPy/JAX 一致的状态机：

- `required_open_steps`：必须连续看到足够强的失败证据才允许开启；
- `maximum_lease_steps`：一次介入有硬上限，不能无限接管父策略；
- `cooldown_steps`：租约结束后进入冷却，防止反复开关造成抽搐；
- `exit_threshold`：证据消失时可提前退出；
- `maximum_slew`：限制门控权重单步变化，避免动作突跳；
- 非有限输入、非法配置、缺少部分租约参数均 fail closed。

最佳候选采用连续 2 步证据、14 步最大租约、600 步冷却、开启阈值 0.95。该状态机作用于纠偏权限，不改变父小脑的所有权。

### 3.2 全轨迹困难负样本闭环

新增完整 192×600 正常轨迹扫描，并按来源局部、窗口不重叠的规则挖掘最危险的正常片段。训练采用两轮边界刷新：

1. 用第一批困难负样本拟合临时门；
2. 让临时门重新扫描全轨迹；
3. 挖掘新的边界样本并再次训练。

样本选择索引、完整轨迹内容、父动作、选择模型和来源身份均写入哈希证据。训练集与 holdout 按来源拆分，不允许同源帧泄漏。

### 3.3 历史能力否决器

新增第二个独立门 `historical veto`。它只使用新失败训练来源与冻结旧域的训练来源拟合；旧域 24 个 holdout 来源从拟合中隔离，保留作真正复试。

最终控制语义为：

```text
主置信门 ──决定是否积累证据、是否开启有限租约
历史否决门 ──只把已获准的纠偏幅值乘以 [minimum_authority, 1]
最终纠偏 ──父策略 + 有限租约 × 主纠偏 × 历史幅值 × 总权限
```

这里有两个关键不变量：

- 否决器只能保持或降低主纠偏权限，不能自己触发介入；
- 最终纠偏始终不能超过源候选的动作权限。

v12 的历史最低权限为 `0.5`，总权限为 `0.8`。这使旧域可以压制不必要的纠偏，同时新失败一旦被主门确认，仍至少保留源纠偏的 40% 总幅值，不会被历史记忆完全“冻死”。模型归档显式记录新语义位和最低权限；旧模型没有语义位时按旧行为解释，保持可验证的向后兼容。

### 3.4 跨域回放与反例

新增确定性的 1:1 跨域正常回放混合器，保证新旧来源唯一且可追溯。实验 v9 表明，虽然工具本身可复用，但把两个域直接塞进同一个主门不是正确策略：失败改善跌到 `+0.1486%`，正常代价回归升到 `+3.5367%`，新域双门同时失败。

这个负结果被保留为工程证据，因为它排除了“只要增加旧数据就不会遗忘”的错误路线。

## 6. 通俗解释：小脑到底学会了什么

可以把父策略想成机器人已经会的“基本站稳和恢复动作”，纠偏学生像一个新长出来的反射回路。

早期版本只要某一帧看起来像跌倒，反射回路就抢着出手；这容易在正常动作中误判，造成抖动。时序租约要求它连续确认两次，而且每次只能帮 14 步，帮完后必须冷静 600 步，所以它更像一次短促、受控的肌肉反射。

困难负样本是在正常走完 600 步后，专门把“最像失败、最容易被骗”的片段找出来复习。历史否决器则像旧经验形成的保护性直觉：主反射认为该出手时，旧经验可以说“这里以前是正常动作，力气小一点”，但不能凭空命令机器人动作。

稳定性—可塑性困境就是：旧经验太强，机器人永远学不会新招；新学习太猛，又会忘掉原来会的动作。v12 的 0.5 地板相当于规定，旧经验可以劝它收力，却不能把真正的新恢复反射完全堵死。这正是本轮比单纯增加训练步数更重要的进步。

## 8. 为什么本轮没有制作宣传视频

本轮改的是恢复纠偏小脑的底层时序授权，并且冻结旧域还差一个方向性门。此时直接剪一个“成功片段”视频会掩盖尚未通过的复试，不能作为闭环证据。

只有在旧 96 冻结门通过、独立 CPU MuJoCo truth exam 通过、再接回传球—射门—扑救全链路后，才适合制作对照视频。届时视频应同时展示：同一失败状态下父策略与候选的恢复差异、正常动作不受干扰、连续多次恢复，以及完整足球链路中的实际收益。

## 9. 限制与不能声称的内容

- v12 没有通过冻结旧 96 路由的全部门，不能晋级；
- 尚未执行独立 CPU MuJoCo truth exam，不能声称跨后端真实性；
- 尚未接入足球完整链路，不能声称扑救率、射门率或站起率已经因此提高；
- JAX/GPU 在不同独立进程中的父基线统计存在轻微漂移，需要补做可重复性审计；
- 这是残差式数据驱动小脑与持续学习门控，不是已经替代父策略的端到端关节力矩 actor；
- 权限上限是 `SIM_ONLY`，没有真实机器人授权。

## 10. 下一阶段建议

1. **学习效应通道预算**：对旧域越界的第一个方向性效应构造序列级损失和通道拉格朗日约束，不再做全局增益扫描。
2. **候选访问分布回放**：在冻结旧域的完整正常轨迹上收集“候选真正访问过”的困难负样本，训练来源与旧 24 holdout 继续严格隔离。
3. **多快照、多失败簇验证**：加入不同父策略快照、起始姿态和失败类型，验证否决器不是只记住一个域。
4. **重复性加固**：固定 XLA/JAX 确定性选项，至少三次独立进程复试并报告均值、方差和最坏值。
5. **独立 CPU truth exam**：旧域全部通过后，再用 CPU MuJoCo 重新计算，不复用 GPU 判定缓存。
6. **回接完整足球闭环**：通过后接回扑救—落地—站起—再就绪链路，以真实扑救率、恢复时间、二次扑救率和正常动作干扰作为上层指标，并输出长视频对照。

下一轮的正确突破口不是“训练更久”，而是让纠偏器对旧域的具体效应通道负责，并把它在闭环中真正访问到的状态重新纳入学习。这样才有机会把 v12 的窄幅拒绝变成可复验的全门通过。
