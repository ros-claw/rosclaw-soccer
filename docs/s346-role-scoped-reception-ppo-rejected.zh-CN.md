# S346：接球角色实际 PPO 更新，被物理保留考试拒绝

本轮确实训练了神经网络 actor/critic，但没有取得可靠提升，因此保留旧权重。
不能把“梯度更新完成”当成“球员变强”，也不能为留住新权重放宽接触判据。

## 做了什么

- 两次实际 on-policy PPO 更新，每轮四条 20 秒八机器人 MuJoCo 轨迹：
  红蓝两侧各原位置及 3 cm 初始球位扰动，共八次训练采样。
- 只允许红蓝中场的私有 actor/critic 更新；每条课程只有焦点中场探索，
  其余七个角色确定性推理。学习样本必须同时满足实际控制激活与探索掩码。
- 每次更新八个 epoch；蓝/红中场学习样本数分别为第一轮 50/128、
  第二轮 52/113。没有用重复帧数量充当独立成功案例数。
- 六个其他角色参数逐字节冻结，SONIC、S286 身体残差模型、参考动作均冻结。
  旧成功传接球轨迹作为系数 100 的 KL 行为复习，不能替代物理保留考试。
- 首次更新独立重算，权重哈希与更新审计完全一致。
  actor/critic 权重连续保存，但 Adam 每轮重建，不宣称优化器持续恢复。

八次探索采样中六次身体安全；每轮都有一次不安全课程。
这些失败轨迹保留，未从统计中删除，也不作为合格演示。

## 确定性物理考试

再运行红蓝 × 旧/新权重四条原球位课程，同一安全约束和接球判据。
旧权重两侧轨迹均与 S345 组合候选逐数组精确复现。

| 课程 | 身体安全 | 三秒内真实接球 | 全局纯脚触球 |
|---|---|---|---|
| 蓝队旧权重 | 是 | 是 | 是 |
| 蓝队两轮新权重 | 是 | 否 | 是 |
| 红队旧权重 | 是 | 否 | 否 |
| 红队两轮新权重 | 是 | 否 | 否 |

红队六秒比赛窗口中的晚到 PASS 仍伴随先前非脚触球，不能叫合格链路。
新权重丢掉蓝队原有成功接球，未获得补偿性改进，判定
`REJECT_CANDIDATE_RETAIN_PARENT`。没有替换全局模型，没有合格整场 4v4。

## 为后续学习留下的数据

所有十二条实际课程额外保存六个已注册身体模型球员的控制前状态：
`qpos[1000,6,43]`、`qvel[1000,6,41]`、帧号、时间、身份和模型契约哈希。
已验证控制前第 n 帧关节位置/速度和球速度逐字节对应主轨迹第 n−1 帧，
明确 `PRE_CONTROL`，避免训练时混淆前后控制状态。
这不包含两位门将的完整状态，也不含 MuJoCo 求解器暖启动等引擎状态，
**不是完整仿真断点**。

action 未随当前传感器一起换坐标。此问题已用真实归一化和关节映射元数据
构造反例；尚须实际物理 A/B 才能判断修复收益，不能直接归因所有抖动。
