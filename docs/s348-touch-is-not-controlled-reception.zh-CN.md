# S348：碰到球，不等于停住球；开始检验接球后的可控性

S345 蓝队的真实纯脚接球证据仍成立，但不能解读为已具备连续配合。
逐帧复核：9.08 秒接触峰值约 1.244 N，球速几乎没降；接球后尾窗最大球速
1.334 m/s，离最近脚最大约 0.618 m。实际只是擦到，球继续滚走。

## 模块化补充考核

新增 `growth.reception_control.measure_reception_control`，不依赖 G1 关节数
或私有模型，接收同步物理时间、球位置/速度、双脚位置、脚接触力、
禁止接触标记及身体安全序列。它只做停球测量，不发动作、不晋升模型。

默认要求真实脚触球、来球速度至少 0.4 m/s，完整观察 0.5 秒，最后 0.2 秒
持续满足球速不超过 0.5 m/s、最近脚距离不超过 0.35 m，期间无禁止接触、
身体安全。缺帧、非有限数据、时间倒序等拒绝；短视频截断不能当成功。
单元测试覆盖擦球、逃逸、非脚/对手干扰、摔倒、无接触与不完整窗口。

这是 `STOP_CONTROL` 子技能指标，不替代已有比赛门控，也不把合法的一脚
传球或直接射门称为失败停球。后续学习应明确自己要练哪一种接球技能。

## 现有接球老师几何对照

四组预声明蓝队课程，只调整既有配置中的接球踝横向偏移，神经权重冻结。

| 偏移 | 完成课程 | 身体安全 | 实际脚接球 | 可控停球 |
|---|---|---|---|---|
| 0.18 m 旧对照 | 是 | 是 | 是 | 否 |
| 0.14 m | 是 | 是 | 是 | 否 |
| 0.12 m | 是 | 否，257 次机器人接触计数 | 是 | 否 |
| 0.10 m | 否，运行时配置拒绝 | 不计 | 不计 | 不计 |

0.18 m 对照与 S347 旧控制轨迹逐数组精确复现。
较小偏移没有改善停球，候选不采用。不能只看到接触更早便宣布进步。

0.10 m 暴露配置边界不一致：初始 committed 偏移允许 0.10 m，但运行时
复制到 receive 偏移后要求至少 0.12 m。保留失败日志，将初始校验收紧到
两者交集，提前拒绝，不通过扩大运行时范围规避保护。

## 下一个真正需要学习的阶段

一旦接收者脚触球，原世界会清除接收租约、保存当前关节姿态，随后约
0.2 秒冻结接触老师和可学习腿残差。这样即使只是擦球，也立刻停止收球控制。
下一轮显式、默认关闭地验证：保留身体支撑基线和所有关节/力矩保护，
在该窗口继续受限脚接触控制与角色残差，让模型有机会学习接稳，而非只碰到。
