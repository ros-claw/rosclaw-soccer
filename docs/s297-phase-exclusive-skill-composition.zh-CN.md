# S297：接球模型与全身射门模型的阶段隔离

## 实现

新增默认关闭的 `motor_idle_residual_fallback` 实验配置，进入配置内容哈希。启用时必须同时提供私有残差和全身运动后端；缺少后端在加载资产前拒绝。

| 当前状态 | 旧私有残差 |
| --- | --- |
| 没有注册全身模型 | 保留原有行为及门控 |
| 注册模型但未提出全身目标，显式启用回退 | 可以使用；仍需近球、角色、身体与接球保持门控 |
| 模型已提出全身关节目标 | 禁止并清空残差滤波历史 |
| 模型故障 | 整场禁止该球员残差回退，模型故障保持锁定 |
| 未启用实验配置 | 保留 S294 的整回合角色隔离 |

这里的“空闲回退”只是正常技能组合，不是故障恢复许可。共享世界仍独占 PD、关节保护和 85% 力矩上限。全身模型只输出关节目标提案；没有真实硬件动作。

## 物理验证

外部 `s297-phase-exclusive-motor-integration-v1`：六场实际八人单球仿真均通过基础身体门；每帧核验全身模型激活期间，私有残差激活与实际残差均为零。红/蓝镜像不是独立随机成功率。

单独 `fault-probe/result.json` 使用声明为测试的提案器，不冒充学习模型：前 5 帧旧残差实际非零，随后 5 帧全身提案接管并清空残差，第 10 帧故意抛错。共调用 11 次，此后不再调用；整个剩余回合残差为零、故障保持锁定，结果不得通过。这证明的不只是掩码标志，而是包含非零历史的实际动力学执行。

## 没有把接口通过当作球队通过

- 新射门场景仍没有成功的后续传接球。
- 蓝方原中场课程有一次严格接球确认；红方原课程在新组合下发生非脚中断，旧技能没有全部保住。
- 原课程前锋仍未进入新移动射门模型：球已很近、前进速度不足，不满足训练过的交接域。没有扩宽域或重置身体来强行录成功视频。
- 配置改变、重新接入旧权重不是新 RL 收益。没有自动晋升或发布宣传视频。

## 后续训练

S298 从保留的 S231 第 2 代私有权重继续，而非零初始化。采用实际红蓝 4v4 混合课程：新射门后攻防、中场接传、后卫出球、门将脚部分球。训练前锋的私有接球阶段，但冻结 S286 全身射门 actor、基础模型及参考；全身模型激活时不做第二套残差更新样本。

各角色只有达到既有有效样本门槛才做 actor/critic 更新。Core 单焦点更新租约绑定冻结组件，第一批实际更新须逐权重重放。训练中失败回合保留，不能把探索时偶然接到球当成确定性策略已学会。最终另考已知保留点和未用于梯度的球位，任何收益都不能抵消安全退化。
