# S2118–S2134：接球之后开始射门，但尚未成为连续比赛

日期：2026-09-15。全部为 CPU MuJoCo、SIM_ONLY，无真实机器人命令。

## 结论与边界

本阶段确实训练了一个新的导航神经网络：成功接球之后，用受限速度增量调整身体位置，再交回原生射门技能。已在同一个八机器人世界里保住中场和前锋的首次接球，并出现前锋后续强力出脚。**未完成稳定、准确、多回合的自主比赛，不具备连续宣传片资格。** 不把剪辑、重新开场或者球门穿越单一指标当作球队突破。

另一项工程改动是可重复接球的技能实例交接：只有旧实例正常退役、原生技能空闲、新的接球承诺在退役之后产生，才允许创建全新同契约实例。不会重置走路基础模型的 LSTM，不可借重试清除故障。实际世界测试中还没有出现第二次合格承诺，不能宣称机器人已经反复接传。

## 学习到底学了什么

S2122 是离线行为克隆，不是在线 RL，也不是端到端关节力矩小脑。输入为导航的实际因果观测，输出是速度增量，平面范数至多 0.25 m/s、转向至多 0.4 rad/s，继续经过原速度、加速度与避碰约束。接球仍依赖冻结的全身残差模型，走路和射门基础模型未训练。

训练误差从约 0.01950084 降至：256 步约 0.00010005，1024 步约 0.00006702。误差更小的模型在物理考试中反而新增自身身体触球，说明拟合误差不是足球成绩。仅把 256 步版本作为下一步诊断参考，未提升正式能力状态。

Core 的更新租约和完成审计实际绑定 `blue.finisher.navigation`；近球策略、接球模型、走路基础权重保持冻结。独立复核重新训练两次候选，权重与统计逐项相同，并验证教师及两个候选的 6 份物理文件及轨迹摘要。重放相同数据不算新增独立训练轨迹。

本阶段没有新增 MotionDecode 人类示范训练，不能把单条仿真导航轨迹称作人类动作先验。循环接球的单元测试也不能代替物理世界的二次接球。

## 下一步

优先补齐三项实际缺口：毫米级来球变化下的接球鲁棒性；相对于球和射门方向的正确支撑脚站位；让现有门将上肢模型真正参与前锋射出的球。当前连续比赛默认未启用 `keeper_reach`，战术扑救意图不等于手臂已在执行扑球。正在进行同场 teacher/已有 learned keeper 的对照，结果另记，不能提前宣称扑救成功。

场地仍为既有训练场，球门为 3×2 m，不宣称成人标准赛事。最终必须展示同一物理世界中持续发生的有效协作与攻防，而不是把短时身体安全、意图次数或者一次穿门包装成比赛成功。
