# S11：大规模强化学习门将与根坐标闭环报告

日期：2026-08-13
范围：SIM_ONLY；4×NVIDIA RTX A6000 候选训练；单线程 CPU MuJoCo 晋升考试；未连接真实机器人。

## 结论先行

本轮取得了一个基础控制突破，但没有训练出可以晋升的高扑门将。

- 找到并修复了长期污染门将横移的根因：门将复用了射门动作首帧约 73° 的全局根朝向；再叠加门将的 180° 场地朝向后，实际初始 yaw 约为 -107.5°。横移命令因此被旋转成明显的前后漂移，并造成左右不对称。
- 修复后门将实际朝向约为 179°，1 秒射门下左右侧移约为 ±0.47 m，成为真正的对称横移；低角球由两侧完全碰不到改善为两侧均出现真实接触的开发探针。
- 4×A6000 新训练处理 22,937,600 个并行样本，代理奖励从 0.3781 升至 0.8532，代理扑救率 0.8562，恢复代理率 0.9608，四卡最大参数差为 0。
- 但是严格 CPU MuJoCo 25 场冻结考试中，安全掩码 RL 候选为 3 次接触、2 次真扑救；同实现父代为 4 次接触、3 次真扑救，二者均无安全违规。候选退化，晋升门返回 `REJECTED`。
- 所以本轮可保留的是根坐标修复、因果观察、左右镜像课程、困难负样本、深度位置伺服、小幅任务空间记忆和严格证据闭环；本轮 RL 权重不可成为 Champion。

## 为什么过去的门将显得“傻”

门将的小脑收到的是自己的局部速度命令。理论上，面对射手时局部横向命令应变成球门线方向的左右移动。但工程中门将生成时使用了三层旋转：场地朝向、动作参数朝向，以及任意球动作文件自带的根朝向。最后一层本来只属于射手，却也被门将继承。

通俗地说，教练喊“向左一步”，门将脑中的地图却斜了约 73°；它会一边向左、一边向前或向后。强化学习看到的是被扭曲后的结果，因此即使代理奖励上升，也无法稳定学会真正的左右扑救。

修复方式不是再加一个动作补丁，而是让每个角色拥有独立的根姿态契约：门将只继承已验证的骨盆高度和关节编号，不继承射门动作的全局位置与朝向。该契约已加入回归测试。

## 本轮工程实现

### 1. 门将独立根姿态

- 新增门将中立根姿态构造：位置只保留合格 G1 的骨盆高度，局部四元数固定为单位旋转。
- 保持场地层的 180° 朝向，使门将面向射手。
- 新增单元测试锁定该契约，避免未来数据动作再次把全局 yaw 注入门将。

### 2. 因果小脑与安全动作分工

- actor 继续只读取可见球历史、本体重力/速度、关节状态和上一动作，不读取射手隐藏相位。
- 增加深度位置伺服，抑制扑救过程沿球门前后方向漂移。
- 神经残差在正式安全候选中屏蔽腿部；合格行走小脑拥有腿，神经策略负责腰臂，阻尼最小二乘 Jacobian 负责小幅末端伸手。
- 任务空间伸手加入跨帧记忆、衰减、换侧清空和真实关节范围投影。
- 手掌接触包络统一为透明的手形椭球碰撞体，评分依然只认 MuJoCo 真实接触和球速变化，不认像素或距离阈值伪接触。

### 3. 大规模 PPO 候选生成

- 4 卡 DDP，每卡 4096 个并行样本，1400 次迭代，共 22,937,600 样本。
- 左右场景相邻镜像采样，镜像损失覆盖横向速度、腿、腰和左右臂映射。
- 困难负样本集中采样真实物理中容易失败的中远侧低/中高球。
- 高球代理加入“屈膝加载—末段伸展”的时序目标；MotionDecode 动作库继续提供姿态先验。
- 当前 fast world 仍是相位条件的单步分析世界，不是完整多步刚体动力学；训练报告保持 `multi_step_episode_training=false`，不做虚假声明。

## 失败消融与学到的边界

1. 重新开放小剂量腿部残差后，快速探针中的一个左上角场景发生关节/高度安全失败。因此正式考试使用内容寻址的腿部安全掩码派生候选。
2. 将任务空间记忆增大至 0.8–1.2 rad，可以增加低球接触，但部分场景骨盆跌至约 0.07–0.15 m，直接否决。
3. 静态工作空间搜索证明高角目标几何上可达，右手可到目标约 8.2 cm；但大幅预抬双臂与现有行走小脑叠加会跌倒，说明“静态可达”不等于“动力学可执行”。
4. 代理奖励 0.85 与正式扑救率下降同时发生，证明当前快世界奖励仍存在明显现实差距。继续无脑扩大样本只会更快拟合错误代理。

## 下一轮真正突破所需工作

1. 把快世界升级为多步接触动力学训练：动作、骨盆、足底接触、手球距离和落地恢复必须在同一 episode 中传播，而不是独立相位快照。
2. 训练一个门将专用的全身 actor-critic：底层输出关节目标/力矩，上层输入因果截球点；不能继续让通用行走策略独自承担跳扑。
3. 用 CPU MuJoCo 失败轨迹训练残差动力学/奖励校准器，每轮 GPU 训练前先验证代理排序是否能预测真实排序。
4. 增加双球连续扑救和落地起身指标，使策略无法用“扑到一球后倒地”换取奖励。
5. 只有当 25 场冻结集、密封 holdout、人形动作评分、二次扑救和恢复时间全部过门，才允许 Champion 晋升和宣传视频。
