# S2042–S2044：踢球技能交接的配对消融

结论：本轮没有合格连续比赛，也没有晋升新模型。旧高球参数没有直接迁移成八人比赛高球；仅修正参考位置不足以解决接球、对手拦截与完整攻防。

## S2042：复用旧高球参数，而非声称新训练

保持 S2040 蓝方准备射门位置 `(2.85,-1.3)`、全体自主及相同球门。比较旧参数、较晚进入动作、组合与增加 loft。四例严格重放：

| 配置 | 安全 | 出界时间（秒） | 最高球高（米） |
|---|---|---:|---:|
| 仅晚进入动作 | 否 | 3.32 | 0.12 |
| 仅旧高球参数 | 是 | 1.88 | 0.22 |
| 晚进入＋旧参数 | 否 | 7.36 | 0.33 |
| 组合＋更高 loft | 是 | 13.68 | 0.24 |

全部完整比赛拒绝，不能把旧三人演示的参数标签当成当前比赛能力。

## S2044：把参考重定位与填充历史分开

新增默认关闭的 `reference_rebase_only`。只把参考动作的平移原点绑定到实际进入帧；不改机器人/球的物理状态，不调用额外推理，不填充观测历史。它与旧 `observation_warmstart` 互斥。默认配置哈希保持历史值。

参考 torso 在第 205 帧相对第 0 帧的位置差约 `(-0.0161, 0.1578, 0.0118)` 米。跳过前 205 帧但仍使用第 0 帧参考原点，会保留这段参考位移；这是一项待验证的交接因素，不意味着它是所有抖动的原因。

| 初态 | 交接配置 | 安全 | 场内时长（秒） | 最高球高（米） |
|---|---|---|---:|---:|
| 前锋准备好 | 旧默认 | 是 | 1.94 | 0.220 |
| 前锋准备好 | 仅参考重定位 | 是 | 1.94 | 0.212 |
| 前锋准备好 | 参考重定位＋重复当前状态历史 | 是 | 25.00 | 0.229 |
| 中央球 | 旧默认 | 是 | 7.06 | 0.428 |
| 中央球 | 仅参考重定位 | 是 | 10.78 | 0.431 |
| 中央球 | 参考重定位＋重复当前状态历史 | 是 | 8.74 | 0.464 |

六例均严格重放、完整比赛门均拒绝。25 秒只说明尚未出界，不能证明连续有效配合。“重复当前状态历史”不是实际过去五帧，报告中不得称为真实观测历史恢复。

准备初态的旧默认与 S2040 对照的全部 212 个轨迹列逐位相同，证明默认关闭路径没有偷偷改变旧实验。单测覆盖历史数组/动作/实测关节不被改写、错误帧、非有限位置、错误旋转、SIM 边界、旧配置哈希。相关 26 项测试通过；新增选项仍默认关闭。
