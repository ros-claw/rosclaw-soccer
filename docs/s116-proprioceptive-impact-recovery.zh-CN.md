# S116：本体感冲击恢复与局部稳健资格闭环

## 结论先行

S116 修复了 S115 暴露出的真实问题：门将已经用手套扑到第二颗高球，但在触球后持续后退、摆动，终场无法恢复为可继续比赛的 ready 状态。根因不是“手臂没碰到球”，也不是射门 actor 失效，而是不同入射轨迹触发了不同恢复路由：控制点会进入侧扑落地捕获，相邻点更靠中路，没有侧扑、也就没有落地捕获，冲击后的动量只能由普通恢复策略慢慢消散。

本轮新增了一个失败数据驱动、由本体状态门控的下肢/腰部冲击恢复反射。它不读取球路编号，不按足部俯仰常数匹配，也不改变手套碰撞体。触发必须同时满足：已经发生真实手套接触、处于接触后时间窗、双脚都重新获得地面支撑、根部线速度未超过安全包络。触发后只短时接管腿和腰，将测得的着地姿态连续收敛回反馈站立目标；手臂和既有学习型 recovery athlete 保留各自权限。

结果是：`0.1261 rad` 控制点保持完整通过且新反射零接管；S115 失败的 `0.12605 rad` 密封邻点现在真实手套接触后由反射接管 61 个控制帧，八个终态 ready 子门全部通过。两者共同获得 `QUALIFIED_CONTROL_AND_SEALED_HOLDOUT_SIM_ONLY_CANDIDATE`。但是更难的 `0.12615 rad` 第三邻点仍然失败，因此本轮只证明局部两上下文稳健性，不能声称已经得到广域策略、硬件资格或端到端神经小脑。

## 为什么门将扑球后会后退和抖动

第二次手套接触发生在约 `17.55 s`。球把线动量和角动量传入手臂—躯干链，脚底接触又把这些扰动变成地面反力。S115 的两个几乎相同球路却落在恢复状态机的不同侧：

- `0.1261 rad` 的预测横向截点约为 `-0.458 m`，触发平衡侧扑；侧扑已有落地捕获，所以终场稳定。
- `0.12605 rad` 的预测横向截点约为 `-0.094 m`，走中路接球；没有侧扑就没有落地捕获，恢复 actor 在冲击后持续做位置修正，形成后退和摆动。

因此问题不是简单“阻尼不够”，而是恢复权限与身体状态不一致。盲目提高全身阻尼会让扑救僵硬，过早抓住姿态又会在脚尚未稳定时把扰动放大。

## 从失败到机制

本轮保留了失败搜索记录，没有只展示最后一次成功：

| 尝试 | 结果 | 结论 |
|---|---|---|
| 接触后立即捕获 | 支撑和速度改善，但朝向门失败 | 不能只看静止，必须保留面向球场能力 |
| 延迟 `0.25 / 0.45 / 0.60 s` | 多次出现严重失稳或跌倒 | 双足尚未形成可靠支撑时不能强行接管 |
| 延迟 `0.80 s`、速度门 `0.40 m/s`、持续 `0.80 s` | 双足支撑升至 `0.94`，仍未全部 ready | 状态门正确，但恢复时域不足 |
| 同一状态门、持续 `1.20 s` | 八项 ready 全通过 | 形成当前局部冠军 |
| 额外偏航缩放 | 回归变差 | 已从正式源码完全移除 |

这组搜索把“触球后抖动”变成了可学习数据：接触时间、双足支撑、根部速度、姿态、最终八门结果和接管帧数都进入证据。当前阈值仍由失败轨迹搜索得到，并不是新训练出的神经网络；这点必须如实区分。

## 工程实现

### 1. 通用本体状态门

`G1GoalkeeperConfig` 增加可选的接触后本体捕获契约：

- 默认关闭，保持旧行为；
- 必须同时启用既有接触稳定和落地捕获，配置不完整时 fail closed；
- 延迟、有效时间窗、最大根部速度和持续时间都有有限范围验证；
- 只根据物理测量触发，不根据试验名、球路 ID 或评分结果触发；
- 每个第二威胁重新装填时清空局部状态，避免跨 episode 泄漏。

### 2. 最小控制权限

反射只控制腿和腰，不覆盖手臂扑救。原有平衡侧扑仍使用自身较短的落地捕获时长，新反射使用独立时长，避免为了修复中路球而改变已通过的侧扑路径。既有学习型恢复运动员继续在包络内工作，状态门只是为冲击后的确定性着地阶段提供安全路由。

### 3. 可审计遥测与资格绑定

轨迹新增 `goalkeeper_proprioceptive_capture_active`，探针记录真实接管帧数。控制和留出请求的配置哈希被独立写入组合资格证据，防止用同一证据换参数冒充密封留出。视频清单同样绑定该帧数，但像素仍不参与评分。

### 4. 向后兼容

旧轨迹没有本体捕获字段时，诊断保持旧 schema 行为；旧阶段证据仍可验证和重渲染。只有新轨迹声明该遥测时，视频验证器才强制逐值绑定。

## 对 ROSClaw 自进化架构的意义

足球只是压力测试，这一轮沉淀的是可迁移能力：

1. **失败分解**：把“任务成功但身体未 ready”拆成接触、支撑、动量和恢复权限问题。
2. **本体感闭环**：动作不再只依赖预设时间线，而由身体接触和速度状态决定。
3. **最小权限组合**：反射、学习 actor 和任务技能按身体部位及状态包络组合，避免一个新能力覆盖全部控制权。
4. **稳定性—可塑性**：保留控制能力、修复一个密封失败、继续用更难失败阻止过度晋升。
5. **因果证据**：触发状态、接管帧、配置哈希、源码、轨迹和资格结论共同进入内容闭包。

同样模式可用于机械臂受碰撞后的抓取恢复、四足滑倒后的落足捕获、无人机阵风后的姿态恢复；足球参数不应进入 ROSClaw Core 的通用 Growth 或 Practice 接口。

## 当前不是什么

- 不是端到端神经网络小脑；
- 不是持续在线更新的 actor-critic；
- 不是直接由新策略覆盖所有关节力矩；
- 不是硬件可执行资格；
- 不是已经覆盖随机球速、球位、摩擦和多方向扑救的 80% 成功率。

当前是一个由失败数据搜索出来的、状态门控的本体反射，并与既有学习型恢复 actor 组合。它解决了一个真实闭环缺口，但还只是迈向数据驱动小脑的一层安全基础。

## 下一阶段 S117

下一步不再手调第三个角度，而要把 S114—S116 的成功/失败轨迹做成恢复训练集：

1. 用接触冲量、根部速度、角速度、双足压力、骨盆姿态和目标 ready 轨迹训练低维 residual recovery actor；
2. actor 输出下肢/腰部目标残差或受限力矩残差，固定反射作为安全教师和回退策略；
3. 对足部俯仰、球质量、摩擦、球位、入射速度和接触相位做域随机化；
4. 使用 CVaR/最差分位数选择候选，而不是平均奖励；
5. 同时检查控制保留、多个密封留出、严格回放、无饱和、无关节越限和终态 ready；
6. 只有 learned actor 在未见邻域超过规则教师，并且不破坏已有冠军，才允许进入新的 SIM-only 晋升层。

S116 的准确结论是：**原失败邻点已经真正恢复，局部闭环取得突破；更难邻域仍失败，广域神经小脑尚未学会。**
