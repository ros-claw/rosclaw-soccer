# S2722–S2732：主动随球接收、角色课程与 PPO 复验

2026-09-18；全部 SIM_ONLY。本文接续 S2720，不把教练课程当成自主比赛，也不将控制修复称为神经网络突破。

## 已落地的控制改进

发现并验证了一个可复现的衔接问题：真实触球后，足部仍在尝试卸力，身体导航却请求原地保持，容易让球离开可控区域。保留主动平衡，在这段时间继续原有受限导航，可改善部分接球案例。

项目现在提供默认关闭的 `IndependentTeamWorldConfig.loose_ball_capture_follow_navigation`。启用要求同时配置真实接触保持、接触控制及 live foundation；不允许以整数冒充布尔配置。仅在实际捕获阶段、主动平衡存在且任务为 RECEIVE/PRESS/INTERCEPT 时取消导航保持，RECOVER、射门、传球等任务不获得这项豁免。

`growth.loose_ball_capture.hold_capture_navigation` 将这项调度判断独立出来。改变的是导航是否保持，不是接触是否发生，也不改变捕获时钟、球状态、碰撞体、位置/速度阈值或电机控制权限。原有移动速度、加速度、避碰及关节保护仍在下游执行。关闭时保留原配置哈希和既有行为。

原型曾通过实验脚本做消融，现在实现已进入项目源码，不需要运行时替换 `_movement_command`。八个角色的正式实现分别与原型进行全轨迹逐数组对比，全部完全一致，并再次独立物理回放。

## 实验设计与证据边界

每堂课是在八人 MuJoCo 世界中，显式给一名真实球员分配接球任务。双方前锋、中场、后卫和门将都有独立课次；其余角色不冒充受训者。是并行单球课堂，不是同场多球比赛。

沿用既有两秒接球契约：必须有自己的真实足部接触，接触后至少有半秒观察，身体和碰撞安全，无其他角色或非足部接触破坏，末尾十帧球距脚不超过 0.35 m、球速不超过 0.35 m/s、球高不超过 0.20 m。没有放宽成功条件。某个两秒窗口通过，不代表整堂六秒课程持续控住球，更不代表完成接后传带射。

所有均为公开开发课程，不是私有留出集或比赛晋升证据。重复相同几何但换种子，不当作新的独立场景；独立回放也不重复计入学习样本。

## 分阶段结果

### S2722：检验历史学习资产是否真的起作用

将历史上用成功示例拟合的拦截选择器接入显式接球课堂，保留原数据支持域、身份、观测、动作上限和仿真边界；不伪造传球接收租约。

16 个课程中，0.75 m/s、原侧向来球的八名球员均通过首个接球窗口；1.25 m/s 八例均失败，身体安全 16/16。然而逐帧记录显示选择器**没有一次实际介入**：当前状态未被它接纳。故不能归功于历史神经网络迁移成功，也不能据此扩大它的支持域。

### S2724：找到实际起作用的因素

删除学习选择器，保持冻结策略、相同几何、同样关闭一脚射门教师，仅对比触球后“停止导航”和“继续导航”。

| 同一组 0.75 m/s 来球 | 接球通过 | 身体安全 |
|---|---:|---:|
| 停止导航 | 1/8 | 8/8 |
| 保留主动平衡并随球导航 | 8/8 | 8/8 |

这是控制衔接的因果消融结果，不是 PPO 增益；也不能泛化为全球速、全方向 100%。

### S2726：正式实现及新一轮强化学习

正式实现的八例与 S2724 原型全数组相同。随后以 S2700 的冻结研究策略为父策略，采集 32 个新探索课次：八角色 × 两档球速（0.75、1.0 m/s）× 两个侧向位置（±0.08 m）。

产生 **4,912 个实际合格角色学习样本**。八名球员的私有 12 维腿部关节角残差 actor-critic 都进行了 PPO 更新；底层行走网络冻结。设置为 16 epochs、gamma=0.999、lambda=0.999，保留旧行为锚点。采样 latent/log probability/value 按原种子逐帧重建检查，整个更新重复执行得到相同权重与审计结果；各角色 Core Plasticity 审计通过。

这不是新训练的端到端全身力矩策略，也不是在线比赛期间直接换电机控制器。候选哈希：`sha256:8247ba5e81b57785b843e7eeed243be514cb943e74b16f7ec441c83c18137ec3`。

首个实验封装 v1 因构造配置时未同时启用主动平衡依赖，在进入物理前被拒绝。失败目录和脚本均保留；修正封装顺序后使用新 v2 目录，未降低配置检查，也未把失败启动计为物理执行。

### S2728、S2732：扩展考试与侧向卸力消融

S2728 预先固定 32 个配对场景：两侧 0.75 m/s 来球各八例、1.0 m/s 和 1.25 m/s 原侧各八例。父子策略使用完全相同的接触教师、正式随球选项、物理场景与评分规则。训练采样中的偶然成功不替代确定性均值策略考试。

S2732 在较差的另一侧来球上，冻结所有 PPO 权重，仅比较接触教师偏航偏置 0 和 +1 rad；原基线为 -1 rad。这是控制参数搜索，不是新的神经网络训练。最终逐组结果见本地 `s2730-native-follow-audit-v1/audit.json`；任何失败的角色与球速都保留在分层汇总中。

## 如何理解这一轮

像人接球一样，脚往后收时，身体不能完全钉在原地；但身体跟上也不保证脚的角度与时机正确。本轮先证实并修复了前一处矛盾，后续课程又暴露了左右侧和速度问题。因此应先建立稳定的成功示范，再从这些示范与失败中训练，而不是把相同错误的轨迹无限放大。

目前保存的是“冻结小脑 + 受保护导航 + 接触教师 + 私有残差学习”的可审计组合，没有宣称球员已经获得自主比赛能力。
