# 参考学生：从物理验证接到数据训练

## 本阶段边界

这不是再扩大旧的微小后置力矩残差训练。本阶段复用ROSClaw Core已有
`recurrent_residual_imitation`数值学习器，学习父代运控之前的双腿参考
修正；父代保持冻结，但根据学生改变后的当前身体和参考重新推理。
还不是在线RL，也没有证明学生自己的运动效果。

训练适配器不读取仿真、硬件或文件；调用者必须认证原始物理来源。
独立阶段脚本负责绑定完整16体、整批审计、密集接触诊断和三身体
接口验证，不能只拿几条成功轨迹绕过失败、源场景划分或控制权检查。

## 固定的数据与学习协议

- 固定新16端点全部保留：8课程、4基础场景簇，控制和教师不增大簇数。
- 复用原预声明簇级划分：三训练来源、一验证来源；所有扰动与控制族
  同源同划分。验证状态不进入梯度，亦不进入归一化，不选最佳验证轮次。
- 只有原评分通过、安全、无>1N非足碰球的局部教师端点获得训练权重。
  整批门仍有否决权；非足碰球、退化或来源证据不足则输出拒绝，不拟合。
- 失败保留但不使用为负梯度；这一步尚未实现从失败直接做强化学习。
- 全300帧因果GRU，135输入/64隐藏/12腿输出。状态每例重置；前30帧
  动作关闭。输入含过去教师参考是离线teacher forcing；真实学生必须
  换成自己的上一动作，不能宣称离线序列误差就是闭环表现。
- 归一化仅拟合合格训练教师，标准差下限0.05，时间维保持原单位，
  输入裁剪[-8,8]。标签非零时离线损失权重5，其他可训练帧权重1。
- 种子2026101902，固定128个Adam步骤，lr0.0004，batch至多4例。
  不修改Core原0.2数值输出上限：将参考标签乘0.2/0.35，导出后仍
  用既有0.35rad解码器。不是偷偷放宽运动幅度。
- 目标是原始参考的离线MSE，不是投影后执行误差；关节范围投影和
  学生身体分布漂移的影响必须由后续真实闭环考试揭示。

16体生产、整批读取、密集诊断，以及三身体控制权生产和整批读取。

只有控制权确实存在、完整教师诊断要求进入学生闭环研究时，才调用
数值拟合器。否则记录`REFUSED_BY_ORIGINAL_PHYSICAL_EVIDENCE`和0更新。
固定总预算无新物理、无新Foundation推理、最多128优化步骤。失败
留存、一次性开始标记、不隐式重试。新数值模型仍无运行/硬件权限。
