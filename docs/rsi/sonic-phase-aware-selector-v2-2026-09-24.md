# RSI-M0 第二代：从小腿先碰失败学习左右脚路径（SIM_ONLY）

上一代单阈值选择器在 1.8 m 留出集脚先入门 4/4，却在 1.9 m 降到 2/4（父策略 1/4）；后两个球位分别右/左小腿先碰。此失败不能被视频中的“球进门”覆盖。

针对 1.9 m、横向球位 0.12 和 0.16 m 的开发试验，接近方向 +0.10 m/s 均使**右脚先触球并入门**，峰值球速 2.998 和 2.861 m/s。`rsi_sonic_contact_selector_v2_train.py` 先独立核对旧留出集和两次右脚物理轨迹，再将失败样本作为新一代训练证据，蒸馏出有界的二层规则：近球距沿 v1 规则；远球距的较高横向球位选右脚可达的 +0.10 m/s。冻结 v2 模型 `/data/rosclaw_overflow/rsi-sonic-contact-selector-20260924-v2.json`，哈希 `sha256:440792b8a555595736cdbe246b39df16cdfdbaa3b353c5f1ccd4ea82704d059b`。这是物理教师数据驱动的**接近方向选择器**，不是新的神经运动网络或 RL 权重。

新的 2.0 m 球距四门课程在模型冻结后运行：`/data/rosclaw_overflow/rsi-sonic-contact-selector-holdout-20260924-x200-v2`，manifest `sha256:8d41e7a73b260c5e7f3fa5e7cab5ed1045be62022b5911bc2369fe7c88dc7c7d`。独立 500 Hz 接触/球门审计为 `sha256:c06edace2fdf21be72715904b03c1a172f9d56f109b52f3a9181fa4edb29325b`。

严格成绩 **候选 2/4、父策略 0/4**。这证明右脚切换在新球距上有效，但左侧两门仍失败，**拒绝晋升**。视频不能把那两次小腿碰球剪成进球成功。

后续开发定位更细：对 y=0.04/0.08，右脚路径在横向速度 0 或 +0.10 m/s 时都能脚先碰，但方向分别偏向球门两侧。中间速度 0.04/0.06 m/s 分别在这两个球位取得右脚先入门，说明这里需要**连续落点控制**，而不是不断添加离散球距分支。这些是已用于下一代建模的开发样本，不再作为 fresh 成绩。下一代应把本体步态相位/左右脚可达性与球相对位姿一起作为观测，训练受限连续 actor，再换全新球距和球初速留出集；仅拟合一个距离分支无法解决自然步态与主动摆腿。
