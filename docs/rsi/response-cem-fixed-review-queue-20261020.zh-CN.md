# CEM后继物理复核与固定队列

## 已验证的复核代码

封存复核器提交 `4b43687dcfed406d38bd9d66e1988c36a1879521`。新 `rsi/recorded_entry_review.py` 重积分记录关节目标，对每一原生子步的PD请求/限幅/实际力矩、根和关节/球状态及接触记录作精确比较；同时验证记录神经动作到目标的原29关节排列和缩放，重建原进入门、真实交接状态、手腕隔离和右腿参考变形。它不运行或验证encoder/decoder/planner网络数学，导航阶段的规划参考也不独立重建，不能据此称为完整独立神经推理证明。

已实际执行外部认证资产集成测试：一个零C原失败记录、一个非零C记录，各重积分3000步，合计额外6000原生步，动作映射/原生物理/参考重建一致。和边界/预算/生成测试一起65项通过、0跳过，耗时11.04s；这是新复核器的开发验证，不是新足球能力提升。JUnit外部证据 `rsi-recorded-entry-review-smoke-20261020/junit.xml` SHA256 `cba6132c2034c628dbed60a4701f40c3d9475a294e75940cb2fd0f1f4bd32a95`。全仓Ruff、修改文件格式、展开reader F821/F822、模块定向mypy通过；不宣称全仓pytest/mypy/格式通过。

## 固定的后继队列，而不是只观察

新增 `scripts/rsi_response_cem_review_gate.py` 是一个有明确输入和动作白名单的后处理入口，不是任意科研调度器。由systemd的`After=`等待四个**已启动**的CEM生产者一次性结束；不使用`Requires=`启动或重启生产者、不轮询重跑、不修改其文件，也不取消仍健康运行的任务。

四个终态全部成功后，先校验旧教师六个成功条件、原16个条件、生产者源码/输入/输出SHA和实际完整预算。只有生产者报告达到至少7/16、旧成功无退化、无新增不安全时，才允许分配四个已封存的记录控制复核任务。这个门只决定是否花CPU做复核，**不证明成绩真实，不批准候选，不自动晋升、不触及硬件，也不生成后继科研假设**。

若未达门，记录 `CEM_FAMILY_REJECTED_STOP`，不自动多跑几轮同族CEM。若达到门，记录 `REVIEW_CPU_AUTHORIZED` 以及每个实际启动的复核服务名/输出目录/生产者complete哈希。门本身complete只表示调度完成，`review_jobs_completed_or_verified=false`；必须再检查各复核器真实终态和结果。部分调度失败保留已写入的逐个launch收据，不重复启动已有任务。未知异常/终态异常仍阻断，不自行改评分、参数或源代码。

11项门逻辑测试与相关预算/生成/复核边界合计67项通过；5/16、6/16拒绝，净增但有旧成功丢失/新增不安全仍拒绝，未知/重复/不完整条件拒绝。当前CEM成绩以生产者和独立复核后继证据为准，本文不预先声明队列已启动或门已通过。

这使“当前实验结束→固定已审查的下一验证阶段”不必等待LLM即时响应；但它不等于Agent永远在线，也不使只读观察器获得科研或硬件权限。更长远的研究方向仍由持续Goal结合实际证据推进。
