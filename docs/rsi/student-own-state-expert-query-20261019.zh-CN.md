## 如何还原实际缓存时钟

原Euler 2ms积分后，qpos已推进，而xpos/J相关缓存还属于上一个
子步计算的位置。因此在50Hz帧t（t>0）中：

- 当前关节状态：原`canonical_qpos[t]`。
- 原缓存位置：密集回放的`qpos_before_substep[10*t-1]`。
- t=0直接用原初始位姿。
- 接触相位只消费已经完成的前一帧及更早六通道接触，不偷看
  当前帧将要发生的碰撞，更不读未来结果。

只在scratch MjData上调用运动学与CoM位置管线，再恢复原当前
广义状态但不刷新缓存，查询雅可比和原有连续有界IK。没有
`mj_step`、`mj_forward`、新Foundation、优化器或真实硬件调用。
[MuJoCo官方API](https://mujoco.readthedocs.io/en/stable/APIreference/APIfunctions.html#mj-jac)
说明雅可比所需的最小位置管线是`mj_kinematics`后`mj_comPos`。
原积分、控制器、球质量/尺寸、世界与考试均未改动。
