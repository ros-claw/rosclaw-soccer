# RoboNaldo 小脑进入共享球队场景：接通并改善恢复，比赛尚未达成

本阶段是 SIM_ONLY 实验，不是新一代球队能力达成，也没有训练新模型。
保持原 M0 的 300 控制周期及 0.1 m 任务阈值不变。本实验是独立的最长
652 周期完整动作诊断，不能拿其结果替换原考试。

## 实现

- `SharedRoboNaldoPlayer` 把每个球员自己的实测 HG29 关节、根部、躯干与
  共享足球状态交给原 547→29 神经网络。五帧历史由各自策略独立持有。
- 不按单机器人数组下标猜测共享身体位置；使用已有命名身体与关节布局。
- 策略只提议关节目标。所有球员由 `SharedNativeMotorWorld` 同一时钟推进，
  每个 20 ms 控制周期共十个 2 ms 子步，而非每人各推进十步。
- 提议/实际执行提交一一对应；共享策略状态、重复提议、改写目标、PD 不匹配、
  非有限输出及失效后重试均拒绝。软件冷启动不宣称已解决平滑技能衔接。
- 保存真实神经网络输入、原始输出、推理掩码、实际目标及逐子步物理轨迹。
  前十帧是原策略热身插值，推理掩码为假，不冒充神经网络样本。
- 独立审计器不用上述球员适配器或共享世界时钟，重新读取实测身体状态、
  重跑原神经网络、手工计算 PD 并推进 MuJoCo。它不是另一个物理引擎。

## 实验与结果

固定四个球位：x 为 0.97/1.03 m，y 为 −0.03/+0.03 m。
足球实际半径 0.11 m、质量 0.43 kg，初始中心高度 0.11 m。
先四例单球员，再四例双球员；第二球员在 y 方向移开 8 m，两人观察同一个球。
不替换失败球位，不放宽既有共享世界的身体健康条件。

| 项目 | 实测 |
| --- | --- |
| 源世界 | 8 个，19,830 个 native 子步 |
| 独立手工控制循环 | 8 个，19,830 个 native 子步 |
| 逐元素一致 | 8/8；全量 qpos、qvel、力矩、关节目标最大误差均为 0 |
| 源实际网络调用 | 1,915；不是控制周期数，也不是训练更新数 |
| 单球员真实脚球接触 | 4/4，均在第 263 控制周期，右踝身体接触 |
| 单球员健康完成全动作 | 0/4；分别在 454/590/430/457 周期终止 |
| 双球员健康完成 | 0/4；远离球的第二球员均在第 13 周期触发失败 |
| 本轮优化器更新 | 0 |

单球员能踢出球，不代表后续恢复合格。双球员试验也不是传球演示；它说明不能
让离球很远的队员盲目运行同一个踢球技能，角色必须选择合适、可执行的运动策略。

原独立先验场景有 2/4 诊断成功，不能外推为球队场景成功。静态对照发现：
两场景的命名机器人碰撞几何、关节/质量惯量和求解器选项相同，但地面接触
软硬参数、球接触参数、显式接触对和球自由关节阻尼不同。原先验的球六自由度
阻尼均为 0.3，球队球为 0。它们是明确的动力学域差异，尚不是证明某个参数
导致失败的因果消融。禁止为了通过而直接改成更有利的球队物理参数。

## 下一项技术验证

优先测试踢球后切换到已有速度条件神经运动控制器，以及用真实已执行动作维持
该控制器的影子历史；与持续踢球控制、冷启动切换进行固定球位的配对比较。
切换必须只改变软件控制器与显式 PD 参数，不能改写身体、球、时钟或接触状态。
远离球的队员用合适的移动/等待技能，而不是强行踢球。完整恢复合格后，再增加
来球与接球角色，才有可用的教师链路供学习，而不是重复训练已有窄分布失败家族。

## 同阶段后续：神经恢复切换已有实测改善

随后实施了上述固定对照。使用相同四个球位、身体、足球和接触参数，在第 285
控制周期（实际脚球接触在第 263 周期）切换到已有 98→29 速度条件神经控制器。
不重置身体、速度、球或时间。只显式切换软件 PD 参数，力矩上限保持相同。

| 对照组 | 健康完成 652 周期 | 说明 |
| --- | --- | --- |
| 原持续踢球先验 | 0/4 | 前述已冻结源数据，未重写或删掉失败 |
| 速度策略冷启动恢复 | 4/4 | 第 285 周期才开始其自身历史 |
| 实际动作影子历史恢复 | 4/4 | 提前独立推理；历史中的上一动作回填真实执行的踢球目标，不使用被丢弃的影子建议 |
| 双球员异构技能 | 4/4，两人均健康 | A 踢球并恢复；B 用独立速度策略等待，不运行远球踢球策略 |

新增源实验 12 个世界，78,240 个 native 子步。随后用独立手工控制循环再跑
12 个世界、78,240 个子步，完整 qpos/qvel/力矩/关节目标 **12/12 逐元素一致**，
健康结论也一致。仍是同一个 MuJoCo 引擎，不宣称跨引擎认证。
单球员两种恢复组在切换前的全部 2,850 个物理子步也与原先验字节一致，
因此不是改进了起始状态、踢球前动作或环境才得到恢复提升。

原始轨迹显示，第 5.7 秒之后 A 的最大平移：原先验四例为
1.714/4.642/0.265/1.866 m（按球位索引顺序），恢复组为约 0.153–0.209 m。
沿初始朝向的最大后退从原四例 0.228–2.378 m 降到恢复组不超过约 0.017 m。
恢复组 A 未测到关节越界。这些是固定四个起始条件的诊断值，不是广泛独立
分布上的成功概率。

**没有解决的问题**：这四球通过 x=5 m 平面时，对 y=0、z=0.11 m 的误差仍为
约 0.288/0.570/0.346/0.869 m，明显不满足 0.1 m；恢复没有改变这些球路。
冷启动切换的最大单关节目标跳变约 1.21–1.36 rad，影子历史组仍约
0.93–1.03 rad，尚不能称为自然、漂亮的衔接。B 等待不是接球或主动协作。
