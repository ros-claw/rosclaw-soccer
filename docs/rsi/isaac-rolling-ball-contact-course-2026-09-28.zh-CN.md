# Isaac 动态滚动球触球课程（开发记录）

状态：`SIM_ONLY / CONSUMED_DEVELOPMENT`。这是从单 G1 静球虚拟门线课程向真实来球接触迈出的一步，**不是**传接射链、球队宣传或策略晋升。球门仍为轨迹计算的虚拟门线，没有立柱、球网碰撞。

## 发现与修复

旧仿真只给球初始平动速度，没有角速度；球在落地后先滑动、因摩擦损失速度，不能当作“滚动传球”。新增 `--ball-rolling-start`，球半径 0.11 m，初始角速度按无滑移关系 `omega_x=-v_y/r`、`omega_y=v_x/r` 设置；同时逐控制帧记录球的线速度、角速度以及触球前地面滑移。物理验证：`v_x=-0.5 m/s` 的 50 帧短跑，正确自旋的预触球地面滑移均值约 `0.000032 m/s`、峰值 `0.00150 m/s`，球在第 49 帧仍以约 `-0.493 m/s` 滚动。错误符号试跑峰值约 `0.999 m/s`，该失败证据保留在 `/data/rosclaw_overflow/rsi-rolling-ball-smoke-20260928-v1/`；修正后在 `...-v2/`。

无自旋的动态球开发课（球初速 `±0.5 m/s`）虽然四例都有足够大的球位移，其中 3/4 有膝/小腿先触球，不能算踢球。速度 `0.8/1.0/1.4 m/s` 的迎球扫描也没有纯脚联合射门成功，说明原问题不能通过单纯调快跑速解决。这些课程都已消费，不作为新鲜保留集。

正确滚动后，用同一 1.2 m/s SONIC 跑动和四个已消费开发球位：

| 初始球 `(x,y)` m / `v_x` m/s | 纯脚触球 | 虚拟门线完整球越线 | 主要失败 |
| --- | --- | --- | --- |
| `(2.4,+0.1)` / `-0.5` | 是 | 否 | 越线 `y≈+1.60 m`，偏出 |
| `(2.5,+0.1)` / `-0.5` | 是 | 否 | 击球后位移仅 `2.62 m`，未到门线 |
| `(2.5,+0.1)` / `+0.5` | 是 | 是 | 仅此开发例达成低平虚拟进门 |
| `(2.6,+0.1)` / `+0.5` | 否 | 是 | 脚后约 10 ms 膝部也碰球 |

四例在机器人接触前的地面滑移峰值均约 `0.00150 m/s`；记录的是物理结果，不能将“球越线但膝碰球”冒充成功。源码诊断字段补充期间运行的 `rsi-rolling-contact-dev-{a..d}-20260928-v1` 触发了源码漂移硬门，全部仅作失败诊断；上表来自**源码稳定重跑** `...-v2`，四个进程退出码均为 0。

## 学习边界与下一步

本轮建立了同一控制帧的球平动/转动、本体足膝位置与速度、500 Hz 接触标签；`extract_precontact_samples` 只取第一撞击之前的数据，并且相对速度改为同帧实测球速度，不再用有限差分制造时间泄漏。训练/评估必须以真实脚接触、非脚零接触、出球方向/力度、身体安全联合判定。下一阶段可在已消费课程上优化动作相位/方向，再预声明新来球速度和球位的 Fresh 集；通过后才串入双 G1 传接、三 G1 射扑，最后挑战连续球队场景。

当前仍没有新的小脑权重或可宣传的连续球队视频。只因滚动球的触球率提高，不得放宽后续全链路门槛。

## 追加：已消费迎球速度扫描

固定 `(x,y)=(2.5,+0.1) m`、向机器人滚动 `v_x=-0.5 m/s`，扫 1.0、1.1、1.3、1.4 m/s SONIC 指令；此前 1.2 m/s 已见。1.0/1.1 虽越虚拟门线但膝先触球，判失败；1.3/1.4 均纯脚触球、骨盆最低分别约 0.704/0.689 m、零关节投影，并完整越过虚拟门线。1.4 的球位移约 6.86 m，门线 `y≈+0.847 m`。这是单点开发探索，不能据此推广到新来球。
