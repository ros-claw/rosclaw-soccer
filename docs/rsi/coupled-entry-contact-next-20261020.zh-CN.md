# 后继协议：完整物理结果条件化的接近—接触组合教师

## 不是扩大导航扫参

固定导航命令族已止损。接触权限配对第一次救回了一个远球位，但统一启用破坏了近球位，故不能直接推广。后继只研究在当前完整本体和神经历史上，能否用完整任务前瞻**选择是否适配接触参考**，从而保留旧成功并实现合格集合净增长。没有新的增益、相位、期限或脚部偏移常量扫参。

## 候选、任务和预算

仍为原四个已消耗球位，不能只做刚救回的远球位。六候选是三条已实际验证的固定反馈规律 `nominal_feedback / damped_feedback / strong_damped_feedback` 与两种参考 `OFF / (0,-0.025,-0.025)m` 的笛卡尔积。三条规律在此前记录中曾进入技能；其余反馈旧失败完整保留。本轮只对这个明确选项库做可行性检查，不宣称穷尽控制权限或不可达性证明。

每个候选从同一实际第 20 帧出发，复制 warm native state 与完整 NN 历史，执行自己的 SONIC 接近、真正的技能交接、自己的参考适配和原始 PD 到第 299 帧。使用原完整任务评分选择，全部无资格时明确回退原名义规律/OFF，不把回退称安全或成功。实际机器人只获得选中的**反馈规律与偏移请求**，不是未来关节目标、状态、参考缓存或标签。

四课程×六完整前瞻×2,800 = 67,200 新预测原生步；若每课程同时运行原名义/OFF 控制和选择后教师，各一个真实 H300，则实际 24,000，新总预算 91,200。0 优化器更新、0 新独立课程；H300、30–90 帧交接门、MotionDecode 窗口/腕隔离、球/世界/PD及研究资格不变。

## 必须验证

- 每个实际前 20 帧与历史原名义全数组精确一致。
- 名义反馈/OFF 候选的完整剩余未来与原名义全数组精确一致。
- 选中组合与随后实际重新推理/积分的完整 280 帧全部物理、NN、参考、命令、阶段和交接报告精确一致；分支不能污染原身体/导航状态。
- 保存所有候选失败和实际回退；完整声明、源/资产/历史独立回放身份在导入前固定，结束再核对。
- 对实际结果分别报告进入技能、真实脚接触、完整球路资格，以及 rescue/regression/非脚接触，不以平均代价或单例代替新成功集合。
- 独立记录控制重积分与修改参考重建，明确它不是独立 SONIC 数学实现。

如果得到无旧成功丢失的净增长，再扩展同状态扰动稳健性；单个球位速度刚过门槛尤其不能直接训练/晋升。教师多扰动有效后才进入三个学生种子、历史保持与 Fresh。若组合预测不能保留近球位，先调查前瞻/执行一致性；若始终只有相同成功集合，就改控制权限或技能参考机制，不继续叠分数权重。
