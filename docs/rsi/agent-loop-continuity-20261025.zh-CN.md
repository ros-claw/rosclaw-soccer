# 持续实施：agent loop 与科学闭环分离

主目标是有证据的连续自主球队比赛，不是进程常驻、累计步数或漂亮字幕。

## 续跑合同

1. 当前线程的宿主 Goal 保持 active/unmet；未达到总目标不能用完成标记结束。
2. 每阶段实际实施、执行测试或物理实验，再检查结果。只写计划、心跳、报告不算接续。
3. 外部 `next.json` 指向最新不可变阶段快照，记录源码、输入、证据、所有任务真实终态和可执行下一步。阶段结束必须更新，不继承过期 running 状态。
4. systemd observer 只检查实验进度，不能唤醒模型、选择下一实验或证明模型在开发。真正接续依赖宿主 Goal 调度；不可伪称 watchdog 保证 agent 思考。
5. 同机制三轮失败，记录 Plateau 并转向不同动作权限或先验问题，不追加同类 PPO、放宽考试或删除失败。
6. 中断后从证据恢复，先核查进程与文件，不盲目重复积分、不热改在跑源码、不丢弃拒绝的候选。

宿主 Goals 在回合结束、线程空闲等安全边界决定是否接续；网络、服务、额度和用户中断仍可能打断，不能承诺绝对不间断。参见 [OpenAI 官方说明](https://developers.openai.com/cookbook/examples/codex/using_goals_in_codex)。

## 本次闭环落点

三种子四周期共 242 世界、869130 原生步、22686 次实际自有神经动作；12 次数值接受均被物理保留门拒绝并回滚，最终均为原模型 30/40。该输出层 PPO 家族 Plateau，没有球技净增长。
