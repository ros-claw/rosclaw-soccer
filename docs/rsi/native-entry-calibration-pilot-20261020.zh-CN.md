## 新机制：实际身体的位移模型，不再直接套人体源位移

固定使用上一轮 right-law0、right-law3 的历史配对轨迹，law4 不参与拟合。取源语义事件前 10 个控制帧：原始交接后 140 帧、短窗口交接后 65 帧。两条分支在交接前完全相同；取样时必须尚无机器人—球接触。私有 MjData 只做运动学计算，不对真实执行数据调用 mj_forward，也不产生积分。

读取右脚原有两颗前足支撑球的中点，计算相对交接时根位置的实际世界 XY 位移。对两个“短窗口减原始窗口”位移差拟合一个常量最小二乘模型，只有两个系数。新站位 = 历史站位 + 拟合位移差。样本、审查、模型、CSV、世界和站位配置均绑定哈希，模型明确标为未验证估计，而非新窗口历史触球证书。

预先固定的数据约为：law0 差值 (0.204549, -0.156859)m，law3 (0.208682, -0.168397)m。因此拟合站位约 (0.416390, -0.128610)m，与人体源几何站位 (0.512309, -0.162981)m 不同。不得按新实验射门结果再扫窗口、偏移或挑样本。训练残差大于 2cm 时在物理分配前拒绝。

## Agent loop 的接续责任

长期 Goal 保持 active。后台科学任务负责声明过的“拟合→执行→完整重复→原始审查”；只读监控负责进程和依赖观察，不能冒充唤醒 Agent 的调度器。下一 Agent 回合必须先读最新检查点、核实终态：运行中做必要开发；已结束就审查并实施下一机制；失败就保留原始计费、修复明确原因，不能无条件重启同一物理实验。每轮写清下一项可执行动作和否定结论，不把“等着”写成研究进展。

终点仍是证据充分的原生物理自主连续球队比赛，不是此单情景校准、小模型拟合或视频制作成功。宿主断电、会话被终止、服务不可用不能保证持续执行；依靠检查点恢复，不声称绝对不间断。
