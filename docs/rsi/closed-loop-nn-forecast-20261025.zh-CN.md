# 从20ms距离代理转向神经闭环接触/恢复预测

前一族96个实际世界没有净增长，已停止。本项先建立不同的预测语义，不追加局部距离增益变体，也不把预测资格当作球技增长。

## 必须保真的状态

在原策略已经propose、真实世界尚未advance的边界，复制完整MuJoCo数据，以及纯SIM FreeKick的所有软件字段（含测量状态、输出、参考、5帧历史、上一动作和策略时钟）。类型保持原类，不重新enter、不重置历史、不重放未来目标。

只允许共享原始CPU ONNX Runtime会话；Torch/AR自有采样会话、未知资源、可调用字段和循环对象不被深拷贝。复制前验证有限的纯数据图；复制后校验值相同。预测调用之后检查原世界边界与原策略完整软件指纹不变。

未来每一控制周期都由复制策略在复制身体的实际预测状态上重新运行原NN，再交给同一`SharedNativeMotorWorld`执行10个2ms PD子步。浮动根、球、增益和力矩上限不被改写。神经观测沿用原先已验证的缓存时钟，不自行“修复”原先验的FK路径。

额外第一步动作只允许有界腿部目标和一致的float32编码历史，修改轴须满足物理关节限和原动作限。复制世界实际提交以后才改变复制策略的上一动作；原世界不变。无干预分支不重新编码。

## 首项冻结资格实验

- 使用已消费的9号原策略场景，原接近程序、原身体和原考试不变。
- 实际执行1世界、最多3600原生步。
- 在全局80、100、150、220控制帧提议后，各预测64控制周期：最多4×640=2560预测原生步、252次后续NN调用。
- 每项预测的64组后续NN关节目标、640个qpos/qvel/torque/ball-force原生样本，必须与随后真实执行全部逐元素相同。
- 整个实际世界所有原数组还必须与已有原策略轨迹逐元素相同。
- 每项请求全额占用预测预算，非法目标和提前预测物理失败也不返还预算。失败不能填充为满时限。新增优化器更新0。

夹具测试覆盖非零时间、多周期实际神经/物理一致、独立复制与预算耗尽、复合动作历史、非法请求计费、未知资源拒绝、无待执行提议拒绝。它们不是G1资格；以上G1实验通过以后，也只说明预测执行器/历史可信，不说明候选控制有效。

## 随后的可证伪研究方向

下一有限教师实验必须用接触后球路与身体恢复后果而不是单帧脚距来选择动作；可以研究实际动力学对关节目标的响应，而不假设当前FK Jacobian等于PD目标到未来脚部的响应。先冻结时间域、候选预算和任务评分，仍用旧H300/239/60考试及历史保留检查。

如果可信的神经闭环预测仍不能获得可重复救回，则回到接触条件化运动先验，不再为旧20ms代理追加变体。有效教师、多扰动资格、学生与Fresh考核依次进行；本项不完成最终自主4v4比赛目标。

## 接触窗口结果教师：单次干预、完整神经未来

冻结下一项均衡16场配对：已消费公开银行0–3、10–13、20–23、30–33，各重跑原B和新C；原接近参数仍逐场特权，不是自主接近策略。

C只在首次实际足接触和任何非足接触之前、全局帧≤239、最近实测脚面间隙≤0.06m的第一个控制边界做**一次**有限搜索。每个候选只改该边界一个腿俯仰关节目标±0.03rad；轴为HG0、3、4、6、9、10，使用原动作限、float32动作编码、修改轴物理关节限。不可行候选跳过且记录，其他轴不投影。未来每周期恢复由原NN闭环产生目标。

先预测未改变的父代，时间域为`min(64,300-current_frame)`。若父代已经得到健康、足部干净、出界约束合格且完整的60帧高质量球路窗口，保持父代，不为更高奖励改变已有结果。否则预测至多12个单轴候选，只在候选**确实观测到**完整60帧、前向≥1m、侧/前≤0.3、无预测非足接触/身体失败/出界时选用；多个合格候选按原`first_touch_reward`、最小目标变化、固定枚举顺序选。全部未合格则保持父代。

此处`window_pass`只表示预测时间域内完整窗口通过。它不伪造未观测的后续H300安全，也不证明360帧恢复。没有接触、迟于窗口或提前物理失败时质量是缺失，不补零、不填充300帧。实际旧H300/239/60考试和360帧身体检查最终决定rescue/regression。

实际选择后不再有第二次干预，因此选中预测分支的全部未来原生状态/接触力和NN目标，应与之后实际执行逐元素相同；该同分支检查在每个C实际结果写盘前强制执行。无干预分支整条实际轨迹仍须等于旧原策略。所有候选的原生预测数组、失败与动作历史来源均保存到Git外，预测计数与真实执行严格分开。

预算：32实际世界≤115200原生步；每个C最多13次预测×640步=8320请求步，全16场≤133120预测请求步；提前失败也按完整请求域占用预算，实际已积分步另报。新增优化器更新0，无自动扩容或反复调幅。至少2个不同场景救回、无旧task/safety/body退化才扩展40场与独立扰动；否则拒绝，不蒸馏不晋级。
