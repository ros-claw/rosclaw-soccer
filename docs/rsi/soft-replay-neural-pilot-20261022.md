# 从窄状态记忆转向平滑神经反馈：离线试验声明

独立复测已拒绝新增记忆的局部泛化：原训练32场景26次成功，但新的32场景只有
2次，等于零修正对照。实际自轨迹重构发现31/32场景在首次触球时新增记忆增益
为零，剩下一场增益约0.297且仍发生禁止接触。继续增加同一门控内的网络训练
轮数，不会自动改变这些零增益状态。

本试验使用已经因果重构的29706行 TRAIN、1266个动作修正行和28440个回放行。
不新增训练标签，不使用已观测的未见测试32场景训练标签，也不将它再次称为
未见考试。旧 DEV16 不进入训练。父代是当前201条记忆模型，非旧 Af46。

新 head 是 own288 →256→128→64→29 的 SiLU 网络，均值、方差只由 TRAIN
计算，标准差下限0.1。输入仍为当前本体归一化160维与真实历史128维，不加入
场景编号、时间游标或教师。该试验不解决缺少显式球速观测这一潜在瓶颈。

删除硬锥形几何门控，改成平滑有界反馈：修正最多0.4rad，与父代相加后仍受
相对R2的0.2rad总限幅。每步512行实际修正与512行旧能力回放，回放损失权重2，
Adam 6144次有效更新，余弦学习率3e-4至3e-5，梯度裁剪5。
三种固定种子2026102209/10/11，种子0为主试验，其余是复现，不按成绩挑最好。

这是一次明确的取舍：从“每个旧锚点逐位不变”的强约束转向可测量的回放保持
损失。它可能泛化，也可能造成灾难性遗忘或闭环漂移。离线完成文件记录全部
锚点的CPU batch1误差和最大旧动作变化，不能替代旧场景原生复测。

此阶段仅离线拟合，状态明确为 NOT_RUNTIME_ADMITTED，没有放宽旧模型加载器、
冻结双模型未见测试的准入规则或自动晋升门。必须后续添加独立的精确检查点加载、
自轨迹审计和新协议物理对照，才能讨论运动收益。不能把新SGD更新数当作成功。
本试验也不是在线RL、持续actor-critic或直接力矩输出。

后继验证入口现已增加：只有独立重构的 CPU_VERIFIED receipt 可经专用类型加载为
原生仿真实验候选；fit-only receipt 仍拒绝。R2/当前父代冻结，不允许递归叠加新
神经层，归一化、初始权重、Adam槽6144步、模型和数据身份、CPU逐行证书均重算。
`runtime_admitted=false` 仍表示没有产品 Runtime 或真机准入，不阻止这条明确的
SIM-only 研究入口。物理复测仍未完成，不能据此宣称保持或进步。
