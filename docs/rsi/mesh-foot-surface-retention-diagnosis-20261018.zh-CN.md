# 毫米级错球不是碰撞器漏检：raw4 保持失败的几何读回

## 证据与范围

原始三种子研究保持不变。对已提交的 baseline receipt0000 与 seed1
receipt0024 另做零积分读回，使用其完整 3000 个积分前 canonical 姿态，
而不是有一个控制周期缓存延迟的足部观察值。冻结诊断源
`2df3b27bdd1e6854be9aa34bc53bf851059af987`；外置结果
`rsi-mesh-raw4-foot-surface-gap-20261018.json`，封印
`sha256:091c608800df155afd3d6e4d56bc820281d1f3fbc0cedccb24ca9e41434d75bf`。
配置、原始 world/trace/receipt、既有配对读回及诊断源码的文件哈希均绑定。

工具加载原始 MJB，在 scratch MjData 上仅调用 `mj_kinematics`，
没有 `mj_step`、动力学重演、力求解、训练或任务标签修改。
对编译后的脚面网格取凸包，用独立 NumPy 最近三角形算法测量球面间距，
再与原生 `mj_geomDistance` 交叉核验。测的是本世界的凸碰撞表面，
不是声称可视凹网格的每个细节都参与接触。

两个完整轨迹各 6000 次脚面距离查询，原生与独立算法最大误差分别
1.96e−12 m、1.38e−12 m；大于 1e−6 m 的分歧为零。球心进入脚面
凸包的状态均为零。负间距与软接触允许的小幅穿透一致，但几何本身
不用于重建冲量，也不覆盖原有力证据。

最接近时，baseline 脚面最近点到球心的世界向量约
(0.0863, 0.0388, 0.0297) m；学习后约
(0.0112, 0.1076, 0.0290) m。两者不是同一时刻或同一球位，不能把
向量相减解释成某个关节必须补多少。至少可以确认：学习后球确实从
脚面旁边错过，不能以扩大碰撞体、放宽触球阈值或重标标签来“救回”。

结合已封印的力矩传输/闭环分歧读回，这个有限配对支持：微小残差在
触球前通过闭环改变姿态和原控制器输出，最终造成原有技能退化。
它不是全局稳定性证明，更不证明所有 seed 都会退化。

## 下一科学决策，而非自动晋升

1. 三种子研究完整结束并独立读回，统计每个seed救回、回退和新增不安全。
2. 并行的固定16体catalog研究继续；不能从当前少数失败提前断言不可达。
3. 若需新接触控制，区分踝/足body原点与真正脚面接触点。现有连续摆腿
   IK输入是body原点，固定vertical offset也不等于球高度目标；新设计应
   先验证表面点、对应Jacobian与实际时序，再声明新物理实验。
4. 新学习必须保留原技能约束与真实闭环复测。不能从KL很小推导动作
   保持，也不能仅用更大梯度、更多相同IID噪声或放宽安全门代替学习设计。

所有结论 SIM_ONLY，新增积分、优化更新、教师资格及硬件授权均为零。

不改变球心到表面的法向间距，但这绝不表示自旋与后续滚动无关。
