# Expanded40的独立记录控制原生复核

复核源另行封存，不改正在运行的0a381f99生产源。调度器固定After四个已实际启动的生产单元，只接受四个成功终态、四个唯一shard、完整40声明、各10个原有课程和每课9个候选；认证所有原始产物及输入哈希后才派工。它自己不积分、不调用NN、不决定晋升。

不按成功筛选复核：包括失败、入口超时、共同前缀早触球及两脚不一致的案例。失败数据同样需要成为可信的学习材料。四个native进程分别在原始世界从标准初态重演每课20拍共同前缀、九个完整280拍预测、真实执行过的旧六选基线与新九选方案。共享端点只执行一次，不虚增。每课新增原生复核28,200..31,000步，对应生产实际计数；最大整40为1,240,000步，不能将上限报为实际执行。

每次逐位检查完整物理数组、神经action→关节目标映射、实际交接状态、原始/镜像参考、腕部隔离、进入反馈与时序；按完整共同前缀重算安全和首次触球归因，重算原suffix评分及前缀安全掩码、脚侧、选择/共享语义及配对救回/退化/新增不安全。克隆复核不得修改公共前缀donor；完整身体步计数也须相同。复核结束再次检查来源和输入哈希。

记录控制不是重新执行NN数学：encoder/decoder/planner不重新推理；上下文/原生克隆/参考/评分有共享实现，不声称第二套独立控制数学。输出独立原生重演证据，不以它替代学习参数因果验证、Fresh或球队比赛。中途失败保留完整病例数、本病例已完成子步、当前身体已尝试/已积分子步与原生末态，不将部分执行冒充零成本，也不静默重试。

`ALL40_NATIVE_REVIEW_DISPATCHED_NOT_VERIFIED`只表示派工完成。必须检查四个native子进程真实成功终态和各10病例复核收据，才能读取原生资格结果。其后才判断Expanded40预注册的跨类别净增益，以及学生投入条件；这里永不自动晋升Champion或硬件。
