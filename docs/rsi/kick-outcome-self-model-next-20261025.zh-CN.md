# 下一步：从本体状态学习动作结果，而非再加一条经验规则

## 为什么换方向

已验证的动作权限搜索能使公开40状态从旧基线1/40达到逐场上限30/40，但未形成可泛化的控制器。固定原型在新40状态仅12/40；本轮速度反馈与最近参考姿态规则又使30/40退化为15/40与9/40。这些规则的直觉没有转化为身体的真实成功。

不再对这两个反馈增益作同族追加搜索。需要利用已经保存的大量成功与失败，学习“这个身体、这段真实历史、现在要求这个参考动作，会发生什么”。这只是预测性的具身自我模型，不是意识证明，也不是新的电机控制器。

## 先做可审计的数据重建

使用两个已关闭16状态搜索以及已关闭40状态搜索的全部原始候选，保留失败，不只选优。相同初始球位/速度必须放在同一数据分组；慢/快域重复执行、同课程候选和重执行绝不能拆进训练与验证两边。重执行只证明复现，不增加独立样本数。

对每个实际进入踢球策略的轨迹，从真实五帧 `KickMeasuredSample`、实际入场 q/dq、入场参考相位与固定目标，重建该547维神经策略的首次观测。注意源控制循环的 torso/ball FK 缓存对应最后一次原生步积分前姿态，不能直接用积分后 qpos 假装同一观测；应使用已保存的前一原生 qpos 在独立检查数据对象中计算 FK，不推进物理。

调用同一个冻结 ONNX 模型，要求重建输入产生的首个 HG29 目标与原保存目标完全一致，才能收录。重建失败必须保留并修复，不能悄悄删掉。没有实际入场的轨迹单独记录为接近阶段失败，不能给它补一个虚构的入场观测。

候选预测输入拟为真实547维观测加显式参考相位和任务剩余时间，共549维；不能把最终球路、成功标签、课程ID或未来动作放进去。标签来自已经核对的真实物理结果：是否安全、是否脚触球、是否在冻结H300内达成完整高质量球路。

## 学习与验证

首个实验只训练动作结果 Critic，不训练 Actor，不允许预测值直接驱动机器人，也不绕过现有教师和运动门控。这样既利用数据发生真实神经学习，又不把尚不可靠的动作教师偷偷晋级。

训练前冻结按初始状态分组的划分、三组随机种子、训练步数、损失、输入归一化和验收。归一化只能看训练组；必须报告类别不平衡下的基准、Brier/校准、危险误判、按未参与训练的初态分组的性能，而不只看样本级准确率。

保存网络、优化器、RNG、数据银行哈希、身体/先验/观测语义绑定和实际梯度计数。离线预测改善仍不证明踢球改善。只有预测可靠后，才用它在明确预算内对参考相位/进入动作排序，并在新冻结的真实物理对照中验证救回、退化和安全；更不能称为完整4v4或可宣传球队成果。

这条线与继续研究更强的全身运动接口并不冲突；它应帮助判断当前身体何时做不到，而不是为无限搜索提供另一个借口。只有可复验的物理改善才能回流到 ROSClaw 的技能能力模型与后续学习决策。
