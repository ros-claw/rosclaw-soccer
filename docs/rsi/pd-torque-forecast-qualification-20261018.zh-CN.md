# 力矩域接触教师准备：真实G1零修正预测核验通过

## 验证了什么

冻结源d4ac55c5，模块 `physics/g1_pd_torque_forecast.py`。
绑定原DF编译世界、原29关节具名顺序、原PD与硬力矩上限。
每次从调用者完整MjData复制出自有状态，含求解器warm start，
在副本推进10个2ms子步。预测只使用当前帧已知的PD虚拟目标和恒定
关节力矩修正，不读取未来原轨迹或预先知道任务结果。它不写活体状态、
球外力或浮动根部，不生成执行许可；目前未接入native教师。

源四端点为raw8、raw56、context0、context1原option4收据，已由
此前G2/18体及四体终态审计完整绑定。每条重新执行原300帧PD控制，
核对全部3000子步PD请求、力矩、执行器力、骨盆及300帧状态、球、
六接触峰值。各在固定0/74/75/77/78/80/85/90/99/100帧额外预测
一次，共40次预测、400预测积分子步。

全部预测使用**零附加力矩**，与实际重建同一帧的全部十子步q/v、
控制、执行器力、骨盆，以及 `mjSTATE_INTEGRATION` 完整末态均
逐字节相同；调用者状态未被预测改变。原四条PD全程对照容差1e-8。
这里的实际重建不是重新运行NN策略，也不是更高的足球成功率。
