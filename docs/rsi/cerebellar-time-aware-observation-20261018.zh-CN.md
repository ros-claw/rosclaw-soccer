# 小脑 v2：当前姿态＋有限任务时钟

## 为什么改

v1 的 97 维输入包含目标误差、关节速度、根姿态、根速度和上一实际施加的
力矩残差，但没有绝对关节角。同样的目标误差可能对应不同支撑姿态。
任务有固定 6 秒期限，状态价值和可行动作还取决于剩余时间；不能在
actor-critic 中把任务截止当成可无限 bootstrap 的时间截断。

## 模型和执行

- v1 模型、默认初始化和 97 维顺序不变，新增模型必须显式 `time_aware=True`。
- 新 schema `soccer.rsi.cerebellar_torque_residual.v2`，结构 127→64→64→29，
  14,237 个参数，隐藏层 tanh，最终潜变量经 tanh 和既有力矩边界。
- 前 97 维逐元素保留；追加当前 29 关节角除以 2 rad（clip ±10），再追加
  `(3000 - before_integration_substep_index) / 3000`。
- 第 0 子步的剩余比例为 1；第 2999 子步在积分前还剩一个物理步，为 1/3000。
  这是新明确声明的 500 Hz 时钟，不能冒充旧 50 Hz 帧级 observation adapter。
- 输入不含球的真值状态、未来触球时间、未来奖励、地面力或求解器约束力。
  仿真本体状态也不等于已经验证了真实机器人状态估计器。
- Native bridge 每次实际 2 ms 调用只递增一次时钟，整个 episode 保留 RNG
  和实际施加残差历史；v2 拒绝漏传时钟，v1 拒绝擅自加入时钟。
- 完整 trace 新增 int64 时钟记录。独立 Torch 审计从 raw 当前状态、实际
  历史和固定任务索引重建 127 维特征，拒绝重置、错位、浮点冒充整数时钟。
  随后仍须原有独立 CPU 物理重演，不能仅靠数值网络审计认可物理能力。

## 已验证和未验证

单元测试覆盖 v1 精确模型哈希回归、v2 语义封存、不同姿态/剩余时间响应、
NumPy/Torch 一致、RNG 错误输入不扣样本，以及两个版本各自 3000 子步的
确定/采样 capture 数学审计。合成数值 fixture 不包含新物理实验。
本轮相关 14 组回归合计 440 passed；改动文件 Ruff/format/compileall 通过，
4 个改动源文件定向 mypy 通过。这不是全仓测试或全仓类型检查结论。

目前新版本没有足球训练更新、没有物理提升结论，也不声称已解决稳定性。
运行中的 512cd75 v1 三体对照和 5ea3c37 动作选择考试不受此改动影响。

## 紧接着做什么

先读取 v1 自适应三体对照的真实终态，确定当前身体反馈、采样概率和独立
重演一致。随后开展有有限预算的 v2 actor-critic：使用实际当前身体闭环
轨迹而非旧目标回放；actor 与 critic 都使用新时间输入；保持任务期限与
安全标签；记录实际更新步数、全部失败、多 seed 训练与旧技能 retention。

不能因随机策略失败就永远不给学习机会，也不能把随机前向称为 RL 更新。
任何 warm-start 数据转换必须明确行为分布和出处，不能把旧轨迹简单改名
成新模型的 on-policy rollout。首批采集和每轮评估须单独声明并留账。
