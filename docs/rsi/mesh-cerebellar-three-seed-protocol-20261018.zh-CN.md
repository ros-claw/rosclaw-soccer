## 预注册新工作

使用同一个数值审查世界、从零输出层新建三个 V2 actor，绝不把旧世界模型
改标签作为新模型。Foundation、旧运动均值、任务规则和力矩上限保持不变。
这是 127→64→64→29 的 500Hz 有界力矩残差，不是独立的全身运动策略。

总预算 44 次新物理执行，顺序固定：

1. 8 个零残差对照：原始四例和四个奇数 context。
2. 每个种子四个偶数 context 的 on-policy 采样，共 12 个完整轨迹。
3. 每种子四步有界 PPO actor-critic 更新。拒绝的 KL 步如实保留，零接受
   更新也是合法实验结果，不自动重跑或放宽限制。
4. 三个更新后的 actor 全部冻结后，每种子四个奇数 context 加原始四例，
   共 24 个确定性评估。保留原始失败案例，禁止只留下成功例。

每次执行 3,000 native 子步，另有独立 CPU 物理回放和 Foundation 输入输出
核验；采样保留实际高斯潜变量和对数概率。新世界要求显式绑定经独立读回
的数值审查，不授予任何硬件或策略晋升权限。

## 稳定性与可塑性

只用原始四例中实际通过的两例构造保持锚点：每例 300 个 50Hz 帧首输入，
共 600 个，不冒充 500Hz 采样或新教师轨迹。旧 KL 限制保持不变。
对 collection 和 anchor 的相同输入分别记录实际更新前后力矩差的均值、
最大值和关节 RMS，区分参数变化、控制变化和物理改善。

全部失败、非足碰撞、未触球和有限时域删失结果均入账；数据认证失败则
停止该有界活动并保留错误，不隐式重试。独立终态审计仍是必需的后继阶段。

## Agent loop 接续规则

持久目标负责继续 Agent 工作，systemd 负责有界实验生命周期，观察器只报告
进展和停滞，不冒充自动学习。每阶段以证据而不是进程退出码作为完成依据。
学习结束后比较三种子的救回、回退、保持率和真实接受更新步数，再决定
下一份公开开发协议；不能凭视频挑选、删除失败或无限重复同一个预算。

本文件是协议，不是训练完成报告，更不是连续自主比赛或宣传片达标声明。
