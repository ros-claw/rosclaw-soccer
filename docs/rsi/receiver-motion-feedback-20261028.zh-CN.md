# 接球运动反馈 v2 仿真探索

已审计的 72 条轨迹中，球自身运动在接近量变化中占据较大部分。v2 采用接球机器人先运动、再球运动的顺序分解，仅用前者作为距离变化反馈；实际脚触球、非脚触球和失衡的事件项保持不变，严格终局标签单独保留。球位置仍决定反馈方向，此顺序分解不构成因果反事实，也不能证明接球自然或安全。

先导出相同的 72 条已审计物理轨迹，独立从原始状态与力重新计算；数值一致后才设计单独的 v2 学习试验。不得覆写 v1 数据或候选，不把离线更新、密集奖励或已有开发上下文当作严格成功；必须保留全部种子、零残差基线及未参与开发的物理验证。

独立复算通过后，固定种子 92401、92402、92403 各训练三步价值网络及一次受限 actor 更新，反馈权重 0.2、严格终局权重 1、折扣 0.99；保持与 v1 相同的 5,201 个旧状态锚点、最大 0.005 弧度偏差和 0.02 平均条件 KL。只比较预先列出的所有模型，不据训练数据挑最好的一例；逐个独立检查权重，并在相同条件下与 v1、零残差进行新的 MuJoCo 物理对照和重放。所有数据是开发集且无严格成功正样本，学习指标和数值信任门不等于物理能力证据。
