# Plateau后的G2：脚部任务空间与小腿间隙动作权限

## 为什么不是再跑一轮同类PPO

三个独立种子、每种子4轮的事件奖励输出层PPO已完整执行并审计，12次数值接受全部被真实物理保留门否决。按用户《实施建议1013》，本实验族Plateau，停止追加同族预算；目标仍是实际足球能力，不是更多审计绿灯。

本次明确观察到的非足接触几何都在左右小腿。原策略在某些成功场景已经非常接近碰撞边界，固定历史上极小动作差也会演化成新的接触。下一项G2要检验**不同动作权限**，而不是放宽干净足触球考试、缩小碰撞体或改球质量。

## 优先复用的现有部件

- `SharedNativeMotorWorld`：原生2ms物理、实际PD、0.85硬力矩界和控制时钟。
- `SharedRoboNaldoPlayer`：原类型神经先验、真实历史、目标提交。
- `sim.foot_target_ik.bounded_foot_target_delta`：已有的脚部局部DLS与膝部退让任务，不另写IK框架。
- `kick_contact_inspection`及实际MuJoCo Jacobian：定位真实小腿/脚部几何和作用方向，不假设膝中心就是碰撞点。
- 新`SharedTargetForecaster`：复制完整独立数据对象，复用**同一个**共享PD执行器做一个控制周期的持目标预测；所有尝试与积分子步计费，禁止改实际世界或隐藏力矩层。

旧`G1PDTorqueForecaster`/`G1JointTaskKinematicSampler`针对另一套无前缀、特定足部mesh的模型，不能偷换名字就宣称兼容当前`a/`、球在前的身体布局。当前布局应继续用`NativeVelocityLayout`验证实际地址；几何Jacobian只暴露腿部关节列，排除浮动根和球的自由度。

## 先完成预测原语的真实身体资格检查

新预测器的夹具测试已证明：在非零绝对时间的两身体共享世界上，不改捐赠世界；预测与随后实际执行的qpos/qvel/torque/ball_force逐元素一致；预算耗尽和模型变更会拒绝。

这还不是G1标准资产验证，更不是教师有效性。下一小项使用已经消费过的9号原策略场景：从神经接管直到360帧，每个控制周期先独立预测10个原生步，再实际执行完全相同目标；要求所有预测原生数组逐元素相同，整个实际轨迹还必须与原保存轨迹逐元素相同。上限3600实际步+3600预测步，新增优化器更新0。只能据此说明预测执行器一致，不能计作球技救回。

## 接续的C类任务空间实验设计

在原接近与神经目标上，基于**当前实际状态**的脚/小腿几何，研究有界局部足部位置保持与小腿退让。先用实际Jacobian验证提议能否按预期改变间隙，之后才用短时物理预测比较候选。预测未来不能进入学生观测，也不等于已经发生的真实动作。

至少满足这些约束后才分配G2物理预算：

1. 不移动根或球，不改模型、增益或扭矩硬界；只改变明确、受限的关节目标。
2. 保留足部目标/支撑的约束与修正幅度、变化率上界；不能用“把腿撤走不踢球”冒充接触改善。
3. 实际提交后，神经历史反映实际执行的复合目标；非零修正后的历史语义与旧先验分开声明。关闭分支必须保持旧浮点路径逐元素相同。
4. 每次预测都从独立完整状态拷贝开始，计入预算，不修改真实轨迹；选中预测还需与随后真实一步核对。
5. 冻结一组均衡16状态的B/C对照，预声明全部控制参数与预算。报告救回、退化、非足接触、身体健康、请求→执行→间隙变化，保留失败。
6. 逐场特权上限只证明动作可达性，不是自主策略；有效后再扩展40状态及独立扰动。教师未过资格门，不蒸馏、不长期RL。

若任务空间指令不能产生可重复的实际间隙/触球改善，或持续只有退化，则否决该接口，回到动作/运动先验问题，不再扫一串“退让增益”。新学生还需补齐真实任务剩余时间观察；现有547维先验不能冒充已经满足这一合同。完整球队比赛目标保持未完成。
