# GPU 自身状态闭环：传输诊断，不是足球突破

## 为什么做

此前 v983/v985 在 GPU 上执行的是基于归档关节目标的 PD 反馈，
不是完整神经策略根据 GPU 自身观测重新决策。不能拿这种回放宣称
GPU 足球闭环或在线 RL 已打通。CPU MuJoCo 仍是最终物理真值。

新增 `sim/mjwarp_own_state.py` 是一个单世界、刻意缓慢的诊断适配器：

- 初始条件由调用者准备，随后仅上传控制量，GPU 持有物理状态。
- 每次 GPU step 后用官方 `get_data_into` 导出自身求解的状态、
  运动学中间量及接触约束力；没有用 CPU forward 伪造 GPU 观测。
- 不替换全局 MuJoCo API，不修改几何、关节、摩擦或求解器选项。
- 约束溢出在导出器静默截断前被拒绝；非有限输入、float32 溢出、
  宿主 qpos/qvel/time 被覆盖或导出失败均使实例不可重试。
- 不接入现有 CPU 采样队列，不产生可晋升的学习标签。
