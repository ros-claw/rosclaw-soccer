# 双腿运动学习：从跑动指令切换转向真实关节控制

状态：实验进行中，SIM_ONLY，未晋升。不是完整球队成绩。

## 可复用的实现

- 冻结 SONIC、冻结已验证的摆脚 actor。只训练一个 36 参数双腿运动基元：
  三个相位控制点，每点对应双腿的 12 个关节。
- 相位来自同帧球与骨盆的前后距离；不使用未来碰撞、课程编号或事后标签。
- 最大额外关节修正 0.16 rad，每步目标变化限制 0.012 rad；若关节限位
  投影要求更小的动作，安全约束优先于平滑性。已观测接触后缓慢释放。
- 逐帧独立重算：冻结摆脚目标 → 双腿残差 → 实际身体目标。球、身体、
  动作和报告分别哈希绑定；篡改目标、测量、碰撞事件和策略合同均被拒绝。
- CEM 使用真实物理回报，而不是分类标签：每代 8 个动作模型、3 代。
  三个已消耗课程，每个模型分别独立一机一球运行；每个课程固定物理 GPU。
  共计划 84 个物理回合，但只有 **3 个不同课程**，不能当作 84 个新球位。
- 运行前冻结 clean Git worktree；运行中不改代码。保留每代政策、回报、
  轨迹和中心参数，重启时复核承诺与现存结果，不覆盖实验。

这是一种低维、数据驱动的策略搜索，不是神经网络、PPO 或端到端力矩小脑。
先证明动作有控制权及任务收益，再做上下文神经模型和更大课程，避免
在一个实际不起作用的控制接口上盲目增加训练量。

## v303 与 v304 必须区别

v303 的动作包络在球—骨盆距离 1.4→0.25 m 之间生效。实际轨迹显示，
`20261446/lane0` 的右膝/小腿误碰发生在距离约 0.25 m 时；动作此前已经
衰减到接近零。初期候选可以改变先前脚部轨迹、减小出界，但尚未救回
误碰。这是早期检查发现的控制时序疑点，**不是“无法学习”的证据**。
完整三代结束后，g2-c7 实际救回了误碰：先前的双腿准备动作可以影响
稍后的触球，不能因为触球瞬间残差为零就否定其因果作用。

v304 使用 **明确的新策略 schema**：距离区间 1.4→-0.35 m，使触球阶段
仍有控制作用，释放由真实接触事件触发。它复用 v303 的限幅、平滑和
限位计算，不修改原基元文件或旧策略哈希，不重解读 v303 历史证据。
v304 是保留的显式时序消融能力，尚未开展物理训练；不能在运行中
替换 v303 包络。鉴于 v303 已获得开发收益，**先开展 v305 冻结模型
扩大验证，再决定是否需要改变时序**，不盲目重训练。
v304 可以从完成且哈希绑定的 v303 最佳模型热启动，保留学到的参数，
同时保留零残差物理对照和原中心候选。被拒绝模型只能作为新实验的
训练初始化，不因此获得部署许可；不完整前代或承诺不匹配会被拒绝。

v304 开发门也更严格：三个课程全部达到现有高质量触球标准，保留 0.8
组的两个成功球位以及 1.2 组的新增成功，不允许通过停止球或弱触球
“救回”碰撞分类。仍不自动打开新留出或晋升球队策略。

## 后续闭环与终点

1. 验证零残差的身体与球轨迹和原基线逐字节一致（v303 三例已通过）。
2. 训练与分析完整代际结果：动作控制权、脚/膝误碰、球轨迹、失衡及旧成功。
3. 若开发门失败，利用失败时序修正动作模型；不循环刷同一组高层增益。
4. 通过后才冻结模型，预注册新球位与保留旧课程，检验泛化和重加载。
5. 再接入滚动接球、二触带球、传球、射门、守门的长链路及角色运行时。
6. 最终标准仍是各角色有效接应、争球、控球与高质量攻防的连续球队比赛。
   单次动作、三个课程或一个开发门，均不能替代该终点。
