# 踢后恢复：完整旧矩阵诊断与20毫秒物理干预

## 发现、排除与下一步

本轮不增加新的足球成功率宣称，而是查清“原球路合格为何仍可能
动作不顺”。已经完成的八个公开扰动初态、八种选项共64次规划
身体及八次选中复试全部重新认证，随后做了真实CPU MuJoCo
局部动作干预。当前三个神经学生的44场考试保持冻结、独立继续。

发现：原任务通过不能代替平顺性或后续可行动状态验收。八次
选中复试全部通过原球路任务，但触球后1.2秒内最大关节速度
步间L2变化从5.93至20.02 rad/s不等，七次峰值主导关节为踝俯仰。
这些是离散速度变化，不是瞬时加速度、jerk或主观自然度评分。

排除了一种过于简单的解释：八次峰值对应的十个物理子步内，
记录的力矩命令均未触及既有硬上限，六个身体—球接触力均为0。
这不能排除地面／自碰撞，也不能证明速度突变全由Foundation造成。

下一步值得投入的是支撑与地面接触条件化的诊断／学习，而不是
给所有关节无条件加同一个平滑补丁。下面的局部物理结果已显示
保持旧目标有时有利、有时有害；“统一平滑必然改善”并不成立。
若支撑测量与有界受控干预仍不能产生可重复改善，应继续检查
Foundation参考、PD执行和接触求解，不能仅增加训练epoch。

仍完整保留，不给缺失尾段伪造0值。选中复试均具备完整窗口。

## 2. 动作与响应时间轴

新增`rsi.postcontact_action_transition`，只读数值轨迹，无控制入口。
对每个接触后窗口选择最早的最大速度变化区间，并明确：

- `joint_velocity[k+1]-joint_velocity[k]`对应持有`target[k]`的十个子步；
  不能把未来的`target[k+1]`归因给已经发生的响应。
- 验证最终目标逐位等于pre-motor目标加实际12维腿部残差；有完整
  有界捕获时，再核对Foundation导航目标加任务空间增量。
- 保留29维变化向量及各分量，不将L2范数相加当成贡献率。
- 保留原力矩、执行器力差异、PD请求和六个球接触力；未记录的
  地面接触／支撑相位明确为缺失，不猜测。

72次身体全部检查，61次有完整有界动作链捕获，11次为原A的

## 3. 实际局部物理干预，不是只读相关性

另行预先持久化声明，固定使用上述八个旧选中复试的峰值时刻。
该时刻是从旧结果事后选取，不能当盲测或普通时刻的无偏估计。
不读取、选择或改变正在进行的神经考试结果。

复用已有CounterfactualMotorReplay、原compiled world、原PD参数
及MuJoCo 3.12.0 CPU。完整回放每条原轨迹的3000子步；在预定
时刻复制包含求解器状态的MjData，再分别执行20毫秒分支：

1. 原实际目标，对照克隆必须与原始测量一致。
2. 保持上一拍pre-motor目标，当前残差不变。
3. 保持上一拍残差，当前pre-motor目标不变。
4. 有捕获时，单独保持上一拍Foundation导航目标。
5. 有捕获时，单独保持上一拍任务空间增量。

合计8次完整原轨迹回放、24,000物理子步；34个局部分支、340
物理子步，其中8个原目标对照、26个干预。不是34条完整策略
训练／考试轨迹。所有对照克隆与原全程延续均通过既有1e-8
数值一致性校验。原Foundation调用0、优化器更新0。
目标替换是局部未准入干预，不是通过控制护盾的可部署策略。
