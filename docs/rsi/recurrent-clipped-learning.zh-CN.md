# 循环策略梯度与持久 MC critic

该路径使用 Core 的 `recurrent_clipped_actor_critic` 做实际神经网络
梯度更新；不是给模仿学习模型替换权重后继续沿用 BC 收据。
当前仍是离线数值学习组件，不是已经完成的在线强化学习闭环。

演员保留原冻结 proposal 均值，加上 135 输入、64 隐状态、12 输出
的 GRU 残差。幅度系数固定 0.2，原关节限幅、限变化、PD 和物理
边界不变。critic 是 135→64→1 的神经网络，仅拟合 MC 回报，
不会进入演员观测或执行动作。其当前权重作为下一代 critic 初始
状态保存，不能每代悄悄重新初始化。Core 同时修复了 int64 最小值
绝对值溢出可能绕过输入幅度检查的问题；Growth 回归 562 项通过。

每次拟合前核验全部序列的实际 AR(1) 潜变量条件密度；每次更新后
核验全部行的边缘均值及条件均值 KL。超界则共同恢复演员、critic
与优化器状态。完整序列复位，冻结优势和回报仅进入损失；负优势
样本也产生策略梯度，不再把所有失败仅保留在零权重证据中。

新 `recurrent_clipped_mc_motor.v1` 包含当前演员/critic、上一代
演员/critic 参数及其来源模型哈希，并只存一份冻结的基础模型。
下一代不嵌套整份前代模型，避免学习代数增加导致历史模型递归膨胀。
来源哈希和数值收据校验不等于签名可信来源或物理证明；实验流水线
仍须核验实际上一代产物、输入轨迹、执行审查及 Foundation 记录。

native 执行与独立审查已接入该模型家族；当前学生探索采样也支持
它。均只接受固定 reference 实现，不接受任意工厂或回调替换动作。
所有候选继续 SIM_ONLY，fresh、部署、晋升和硬件授权均为 false。

第一轮新增 3 项测试通过，分别覆盖实际演员/critic 更新和第二代
接续、完整 300 帧执行及探索、重新封印的错误来源/参数/配置/权限。
完整扫描检查每帧状态只推进一次，critic 修改不改变运控输出，动作
保持原边界。局部 ruff 和 mypy 通过；旧路径回归正在复查。
随后 63 项旧路径回归全部通过。这些是合成数值/执行契约测试，尚
不是新策略的 native 物理资格。

下一轮预先声明：使用完整已认证旧 160 条轨迹、40 个场景各 4 次
抽样，不按成功/失败筛选；同场景其余三个抽样的平均回报作为首轮
冻结 MC 基线，再统一标准化优势。此基线不使用当前抽样的回报来
计算其基线；critic 同时拟合所有原 MC 回报。它不是 TD 或 GAE。
初始 GRU 零输出，与旧 H1 的数值行为密度逐行一致，才允许首次
离线策略梯度试验；不能宣称旧数据是新 GRU 采集的 on-policy 数据。

后续必须完成新家族 native 独立资格，再采集实际学生自己的完整
探索轨迹，再接续当前演员和 critic，复验完整旧考试及保护门控。
收益只能由新实际物理执行说明，训练损失和 KL 约束不能保证球技
提高，更不能说明自主球队已经成熟。
