# 真实成功路径与零动作锚点：新一轮研究

## 为什么改变训练目标

完整同接近对照是NAV4/8、IK4/8、学习学生2/8。IK救回一课也损失
一课，总体并没有优势。原来相对旧接近0/8的提升不能全归因于
关节参考。因此旧的单教师/counterfactual拟合路线在完整三方检查
后正常NO_FIT，报告2111640033，实际更新0。没有降低门槛重开。

新假设不是更多模仿IK，而是学习何时保持NAV不干预、何时使用
已经真实成功的纠正动作。只有实际执行过的成功路径可提供监督：

- NAV实际通过时，选择NAV自己的300帧输入和实际零修正动作。
- NAV失败、IK实际通过时，选择IK自己的原始输入和执行参考。
- 双方失败仍全部保留，不伪造成功、不提供正监督、不称负向RL。
- 原训练来源77/78/93、验证来源96不变，验证不参与方向选择、
  归一化、梯度或最佳checkpoint选择。H300/post60及安全门不变。

不能把一个路径的动作接到另一个路径的状态上；不能把成功路径
的并集5课当成一个已经会做5/8的机器人策略。

## agent loop 的实际承诺边界

研究Goal保持active；每阶段用不可复用输出目录、冻结源码、终态
和机器可读收据交接，恢复指针记录下一项真实计算。不把一个
观察timer声称为自主学习循环：进程退出后仍要分析结果并改变
假设/接续代码。服务Restart=no，故障保留，不自动无限重试。
平台停机或对话调度无法承诺永不间断，但断点和计算状态可核验。
不得为了“不断运行”把已否定路线重复训练，或以循环日志代替
身体能力增长。没有达到宣传级整体效果，整体Goal就不能完成。
