# B 接球 motor 的实际采样数据：预声明

只有三组 96 条源轨迹、各自独立物理/神经/采样概率回放及完整配对复核均完成且绑定零身份基线，才导出 72 条实际随机采样回合；零采样父代单独保留做历史保护，不把它伪装成相同采样策略。每回合逐控制周期保存 B 自身 `98+14` 实时输入、同一身体同一时刻的原 ONNX 参考动作、原网络均值、实际执行的采样动作、该动作的原始归一化条件 log-probability，以及原始随机数状态承诺。只使用采样发生到真实交接或 H300 截止/身体失败之前的实际周期，不拼接交接后动作、不重置隐状态、不借用另一机器人或父代历史。

在采样源轨迹已生成、部分源结果已观察，但独立回放和完整复核尚未结束时，为下一轮可推翻的 actor/critic 研究固定逐回合终局收益为 `+2×健康且≤0.1 m回传 +1×真实接球交接 +0.25×交接后的实际脚部回传 -2×任一身体失败`。这不是在源采样之前的奖励预注册。上述量均来自同一回合真实共享物理，非人工指定球飞行；收益仅作为未来价值/优势目标，不改原始正式考试。每个接球控制周期先设即时收益 0，最后一个接球周期得到该回合终局收益；回报及独立持久化的失败、非脚接触、双方身体状态必须同时保留，不能以平均收益覆盖安全或旧成功退化。由此形成的是物理采样数据，不是已经发生的 PPO、在线 RL 或模型优化。

对独立采样概率逐轨迹复算并绑定原生回放、原始受控动作和完整 24 原始情境；三个种子和源/回放不能计为独立初态。训练之前必须评估是否存在足够跨情境的真实正例，同时对旧健康回传与身体稳定设硬保持，防止为了少数新正例遗忘原能力。任何离线更新仍需先冻结模型、重新做真实自身状态的确定性物理配对与独立回放，才能声称 motor 改进；不允许直接将旧采样结果或预测器分数当成训练成功。
