# 完整字节校验的现有入口优化：单场原生非干扰预注册

seed-only接口的真实全模型基准已经证明局部生成约3.1倍，但
现有原生采样入口仍接收外部完整view，不能擅自绕过这条验证。
本改动仍完整快照调用方文档，再逐字节比较私有冻结mean生成的
完整预期文档（含类型、critic、父代、采样法、来源与权限）。
相等后只从私有快照恢复返回模型，不再反复恢复/重序列化调用方
的同一个mean。调用方在快照后改变seed或权重，不能影响返回值。

不按对象id缓存，不仅比model_hash字符串，不丢未使用critic，
不接受任意validator回调。原bind、原独立CPU、Foundation和
采样参考审核保留，原native kernel与默认动作数学不改。

## 固定验证

先完成原有及新增完整模型/解码回归、数字类型与快照后输入变更
测试，再冻结源码。仅重跑group4、默认C控制、模式2的一场身体：
相同冷启动、原采样seed、同模型和编译世界、H300与原门不变。
对照复用已完成32场中的group4 baseline，不重新执行对照。

必须通过3000独立CPU子步、300次Foundation重算、270个draw
重构、独立参考审核与300帧encoder消费复核，并与旧成功对照
**全部trace数组**的key、dtype和数值bit-exact一致，而不是只看
成功标签。不一致就拒绝性能改动，不放宽浮点容差以换通过。

新身体预算1。初始化与参考compiler耗时单独记录，不能算成
网络训练；整个episode与资格审核时间另记。性能改善不是球技
改善，该试验不产生新教师、Fresh、晋升或硬件权限。

外置runner `rsi_byte_preview_native_noninterference_20261017.py`。
本文件为预注册，当前尚无新入口的原生物理非干扰结果。

软件回归：41项原有/生成预览及完整解码器测试通过（803.84秒）。
随后清理未使用导入，额外运行数字类型保持及快照后输入竞态
测试，1项通过（19.11秒）；Ruff、format与单模块mypy通过。
这些不代替新入口的物理非干扰结果。
