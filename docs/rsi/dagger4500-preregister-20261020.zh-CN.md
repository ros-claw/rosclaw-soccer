# 第一代同状态纠偏训练与无教师物理考试

## 起点与证据边界

原 direct29 GRU 三种子9000次实际更新均未通过40课闭环。种子17固定作为
机制试验起点，不在3个失败种子中按新结果挑选。其已训练3000步，不叫未训练网络。
同状态采集固定0.9教师+0.1学生，已完整40课、120000原生步：12/40合格，
相比原教师13/40损失第7课，无新增合格课。辅助性能不是学生成绩，也不是突破。
保留40课全部成败；本轮**必须等全部40课学生网络、教师网络和原生物理独立复验**
之后才分配训练模型，不以首个成功课或身份探针代替完整复验。

## 冻结课程

原32训练/8验证整课拆分不变。合格且前缀安全、首次触球仍可归因于20拍后控制
的辅助端点允许提供actor标签；失败、不安全、已在前缀触球的课程不作为actor
模仿正例，但仍保留在价值辅助学习、失败分析与考试分母。当前辅助正例10训练、
2验证，原正例10训练、3验证。记录的数据不是12个新的独立课程，而是已有课程
中的新实际状态轨迹。特征必须逐字节从当前q/v和真正执行的t−1混合动作重建；
标签是当前状态的教师建议，不是上一动作，也不是旧轨迹此时刻的旧目标。
新观察若与原正例完全相同，拒绝把它称为新纠偏训练。

## 固定优化预算

- 固定种子17，完整继承原step3000的参数和仅用训练课计算的归一化缓冲。
  不重新拟合归一化，不用验证集统计，也不修改128维GRU或29动作尺度。
- 新Adam lr=1e-4，额外1500次真正的optimizer.step，累计计数4500。
  初始快照的计数3000，最终4500，分别记录，不将继承更新算成新增更新。
- 原合格训练课actor MSE和新合格训练课同状态actor MSE各权重0.5，保留旧示范
  作rehearsal，避免只适应新分布而遗忘旧分布。全32课各自价值辅助MSE均分、
  总权重0.1，target仍为合格标记×0.99^(299−t)。这是监督辅助value，不是TD或PPO。
- 梯度范数clip=1；有限参数/梯度/损失检查；每100步落盘损失和验证误差，
  每500步保存权重；纯参数变化必须>0。加载weights_only=True，不加载任意pickle。
- 仅GPU0一个独立进程、显存上限10%，不停止其它GPU任务。1500步是本轮一次性
  机制试验，不按验证误差提前挑checkpoint或反复扫epoch。

## 自动但有限的物理闭环

固定cycle先等待独立数据复验真实终结成功，才启动训练服务；训练真实结束后，
读取并绑定完成哈希，再启动**无教师**40课初始/最终各一端点。初始是继承的
step3000，不是随机网络；从20拍后仅学生自己的29动作驱动原生PD。
完整80端点240000原生步，所有失败保留；随后新进程重算学生网络与原生物理
全部80端点，再新增240000步。保持原世界、PD、限幅、H300/post60。
三阶段均是独立服务、记录真实PID和退出状态，任一失败停止该固定链，
不重启上游、不自动重试同一输出、不自动晋升，不冒充无限自主科研。

纯学生有可复验净增益，才进入下一轮降低教师依赖/扩大同状态覆盖；仍0/40则
诊断实际反馈误差和控制表示，不直接续更多相同离线轮数。近球40课仍非原远球
M0/52/Fresh，更不代表4v4持续比赛。最终宣传球队目标不缩小，视频只在真正
物理能力达标后产生；本轮不产生宣传承诺、硬件许可或数据集再分发许可。
