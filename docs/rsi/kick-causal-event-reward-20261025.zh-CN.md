# 因果事件奖励与非足接触诊断

## 本轮改变什么、不改变什么

上一轮真实运动PPO候选从30/40退化到25/40，已否决。完整历史重建又表明：即使在旧轨迹上的平均KL很小，也不能保证新的接触闭环稳定。因此不直接增加相同训练的轮数，先修正信用分配并核查接触。

新增训练目标`causal_kick_event_reward.v1`。正式H300考试、接触力阈值、60帧球路、H360身体健康标准、原机器人/球/增益/力矩界全部不变。新回报不能与旧终端回报的数值直接比较，更不能作为球技提升证明。

## 冻结事件语义

| 实际发生事件 | 结算控制帧 | 训练分量 |
| --- | --- | ---: |
| H300内首次脚触球 | 实际首次足部力>1N的控制帧 | +1 |
| 完整60帧球路可观测 | 首次足触球+60，且必须<300 | 前缀版既有`first_touch_reward`减1 |
| 首次非足接触 | 实际非足力>1N的控制帧，限H300 | -10 |
| 首次身体高度/直立度失败 | 实际十个原生子步中最早出现失败的控制帧，含恢复期 | -10 |
| 首次球横向越过4m | 实际越界帧，限H300 | -4 |
| H300无脚触球 | 真正观测到299帧后 | -3 |
| H300内足触球但60帧窗口删失 | 真正观测到299帧后 | -2（连同此前+1共-1） |

质量奖励只使用到当前帧为止的实际最小身体高度、横向偏移和球路；若此前已观察到非足接触、身体失败或越界，不再奖励球路。不能把未来球路提前放到触球帧；没有实际到达截止时刻的短轨迹不补造“未触球/删失”处罚。重复接触不重复计首事件。

采用有限回合、折扣1、末端不bootstrap。理由是若继续用0.99折扣，较晚的安全处罚可能被折得过小。足触球与质量奖励的总正收益最多4，任一非足/身体失败成本10，其他分量非正，因此整回合不安全总回报最多-6，不允许用更远的球路购买违规。事件发生后的动作不分摊过去的球路收益，但仍需承担后续真实身体失败。

此规则由实际球坐标、每控制周期10个2ms身体姿态和接触力计算。策略输入仍是原547维，不加入终端标签或未来量。

## 数据回算与几何诊断协议

冻结后回算全部88条已有真实轨迹：8条自有探索、40条原策略、40条被拒候选。不新增物理执行或梯度更新。每条先验证来源哈希、原正式标签、身体地址和力矩界，再回算事件奖励；对实际前缀独立计算并逐元素比对，保留所有失败。奖励改变不应改变任何正式标签。

对5个非足接触退化，从已保存的实际力索引取前一个原生qpos恢复几何。MuJoCo的碰撞计算属于积分之前的位置计算阶段；只在独立数据对象上调用运动学与碰撞检测，不积分、不求解并冒充新的接触力。[MuJoCo 3.5计算管线](https://mujoco.readthedocs.io/en/3.5.0/computation/index.html)、[函数定义](https://mujoco.readthedocs.io/en/3.5.0/APIreference/APIfunctions.html)。几何候选接触与已记录的聚合非足接触力分别报告；若多个身体同时接触，不能伪称聚合力唯一属于某一身体。

前置测试覆盖前缀不变性、最后合法球路窗口239→299、240帧触球的删失、短轨迹不补时限、恢复期身体失败、迟发处罚不能被长球路抵消、错误原生索引和输入数据拒绝。下一步只有证据回算完成后才冻结新的多轮训练，不晋升旧候选。
