# 同一身体的真实助跑与影子历史交接：动作权限试验

共同PAiD足球身体的冻结速度模型已完成8个条件、双完整重复及独立48,000子步
重放，约1m/s时可保持身体稳定。这只证明运动基础，并不证明跑动射门。

本试验开始连接这些能力，不把几段重置视频拼成连续动作。两种初始课程分别从
原球位的后方1.6m、1.2m开始，速度命令0.8、0.6m/s。每个世界先做50个速度模型
准备控制，再做100个实际向前控制；最后80个控制期间，R2同时读取真实观测并
积累自己的影子历史。它的建议不会执行，也不被伪装成已执行的教师前缀。

影子观测中的“上一个动作”必须来自实际速度模型关节目标，经过原HG关节顺序、
R2偏移和缩放逆变换得到。只有真实时间推进20ms且对应10个原生物理子步完成、
状态没有被篡改时，影子历史才可提交。交接后的R2从参考第80帧继续，携带自己的
实际历史，不借用另一次教师轨迹的LSTM状态，不重置机器人、足球或时钟。

每种课程对照三条路径，各完整独立重复两次：

- 原地使用当前参考策略，从同样较远的初态尝试触球；
- 速度模型助跑、真实影子历史、R2后缀；
- 同样助跑和影子历史，后缀由预先固定的原case4脚部任务空间教师执行。

这属于SIM特权教师/动作接口研究，不是新的学习策略或已经自然流畅的球员。
教师参数不在结果出来后挑选，不做CEM或SGD。最大55,080个原生子步、6,000次
完整模型查询；教师的额外头部查询和IK另行计数。原正式H300考试不延长，也不
把本试验分数混入旧52场或Champion。

全过程记录实际执行控制器、速度模型推理、R2影子建议、实际R2动作、教师计划、
每2ms状态/力矩/接触和真实恢复。第一触球发生在哪个控制阶段也保留，不把走动
碰到球解释成R2射门成功。普通无触球、身体失败和球路删失都保留为物理结果。
基础设施异常另外保存最后状态和已完成物理前缀。

若助跑路径无法带来可重复的触球，应区分进入位置、步态相位、关节目标/PD交接
突变及R2历史分布问题；一次固定教师迁移失败不能宣布任务不可达。若有真实物理
成功，再做独立完整世界重放和更广的来球扰动，然后才可用于新的在策略数据学习。
