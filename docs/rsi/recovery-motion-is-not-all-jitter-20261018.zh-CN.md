# 恢复运动不等于全是抖动：前两例真实500Hz诊断

## 修正过度解释

此前读到group4恢复窗根部角速度RMS约1.38rad/s，不能据此直接把整个
数值解释为“身体抖动”。正常摆动、航向改变和真正的平衡振荡都可能贡献
角速度；必须与倾角、位移和任务意图分别比较。

本诊断不改变已冻结的训练奖励，不更改安全或M0标签，也不证明动作自然。
当前三种子实验仍在运行，下表只是最先完成的两例零残差对照，优化更新0。

## 实际测量

每例取触球帧之后60个完整帧的600个2ms积分前canonical状态；不使用
缓存body观察代替当前qpos/qvel，不补造删失窗口。

| 测量 | group4 | group8 |
|---|---:|---:|
| 原M0结果 | 通过 | 球路失败 |
| 最大世界竖直倾角 | 7.995° | 9.272° |
| 窗口航向净变化 | −22.758° | −15.145° |
| 根部局部z角速度平方占比 | 78.212% | 37.072% |
| 根部世界x净位移 | +1.3494m | +1.5104m |
| 根部世界y净位移 | +0.0097m | +0.1820m |
| 冻结恢复成本 | 0.50069 | 0.21962 |
| 冻结训练return | 7.65274 | 3.05413 |

局部z角速度分量占比不严格等同于世界yaw能量占比，不能混用坐标系。
本窗口里两例均向前净移动，不能从其它旧视频的后退现象推断这两例也在
后退；净位移为正也不排除短暂后退或局部振荡。

group8的身体成本更低，但球路失败。这说明“运动更少”与“足球技能更好”
并非同一目标，单一角速度成本不能替代球路、安全和后继行动能力。

## 对训练决策的意义

当前恢复成本作为固定小试的辅助目标继续执行，不能观察结果后热改权重。
待三个种子更新及保留评估全部结束，分别检查：

1. 接触方向和落地后球路有没有净改善。
2. 身体倾角、航向变化和移动行为如何变化，是否只是变得僵硬或少动。
3. 减少角速度的同时是否保留继续跑动、追球和下一次交互的能力。

若未来要建立更自然的运动目标，应比较相对任务意图的偏差、支撑/接触
连续性、参考动作和后继状态，而不能简单把所有角速度、所有移动都归零。
这只是后续假设，不是本轮已实现或通过的新技能。

软件验证：新增8项合成数据测试覆盖yaw与倾斜区分、零运动、删失、无触球、
航向退化与非法四元数；小脑相关84项回归通过，单模块mypy及Ruff通过。
测试数不是物理成功数，当前也没有完整球队展示可宣布达标。
