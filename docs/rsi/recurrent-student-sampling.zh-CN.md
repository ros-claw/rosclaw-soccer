# 循环学生自己的探索采样

当前实现将已经验证的 GRU 学生均值与固定 AR(1) 探索连接，而不是
继续从其冻结父策略采样。仅供 SIM_ONLY 训练，不授权部署或晋升。

每个实际执行边界只调用一次学生均值，推进一次隐藏状态。记录实际
均值、抽样潜变量、条件高斯对数概率和采样掩码；frame30–299 采样，
此前不推进循环状态。固定 std=0.1、rho=0.9；每集独立复位。
概率针对潜变量，不是裁剪后关节动作或力矩的概率。原有动作限幅、
限变化、最终关节裁剪和 PD 控制不变。

native 执行器保存这些字段；独立审查器从完整模型、原始观测和种子
重新计算所有隐藏状态、均值、抽样和概率。未知字段、缺失字段、
非有限数值、越权标志及重新封印的错误探索配置均拒绝。
不能通过把非零强化学习参数塞进模仿学习收据来伪造模型来源。

17 项新增测试通过，包括真实拟合学生、完整 300 帧扫描、独立 AR
概率重算、未来观测不影响过去、状态不重复推进及返回数组独立拥有。
旧循环策略、工厂、探索和物理审查相关 46 项回归通过；局部 ruff、
格式和 mypy 通过。这些测试不是 native 物理资格，不证明踢球改善。
