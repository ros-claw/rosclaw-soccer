# 六例脚面控制实验的审计后自动接续

## 目的和边界

补齐实验→整批独立审计→密集接触回放→成功/失败比较的执行链，
不把 systemd 心跳当作 Agent 学习。长期 Goal 接续 Agent 的分析、
开发和下一轮假设；只读观察器不具备唤醒 Agent 的能力，也不会
自行训练。系统断电、会话被终止或外部调度失效不能由本程序保证
永远在线；冻结源码、一次性标记和恢复指针用于恢复，不丢弃失败。

当前实验仅把既有 catalog2 接近控制与既有材料点脚面 IK 组合。
不是新神经训练，不是小脑模型已晋升，也没有球队比赛突破。

## 严格接续

`rsi_stage_surface_receding_contacts.py` 仅接受新的固定六例作用域。
要求原生生产和独立审计两个服务真实正常退出，认证全部原始
receipt、源码、初态、准备输入和上游完整十身体研究。不能只用
成功的 C6/C7；膝接触失败的 108/141 等也必须保留。

1. 写入一次性开始记录，输出六例与 catalog2、None 两族的配对表。
2. 六条已记录控制的密集回放，新增18000个物理子步，无新 NN。
3. 复用旧十条及旧十二条回放，认证旧66000子步产物但不重跑。
4. 合并28个端点，严格选择作用域内6课程×3控制族的18个端点。
5. 提取足/膝等非足接触、向下冲量、Newton残差，输出研究决策。

作用域是六个派生课程、三个基础场景簇；28端点并集是十个派生
课程、五个基础场景簇。重复回放、配对控制、轨迹帧均不增加独立
场景数。维持 H300/触球后60帧旧评分，不把删失、失败改成通过。

出现退化、新不安全或>1N非足接触即拒绝整批教师；无净增益则要求
机制复盘，不能继续无限同参数试跑。即使有净增益，也只提出跨簇
复现和学生自身闭环验证的后续要求，所有数据准入、训练、晋升、
硬件授权仍为 false。研究决策不是自动修复或宣称成功。

## 可恢复与防重试

服务启动前外层标记、程序内层开始标记、失败文件及最终报告分离。
子任务预检或物理失败留下原始异常；定时器不会再次执行相同实验。
只有分析失败并冻结新的、明确改变假设的声明后才能开展下一阶段。
运行及排队源码都保持冻结，不在长进程已导入后修改其模块。

固定回放的模型分配和积分主体保持原933505fe版本的AST校验值
`94a24c5e8430401162225a0f3ac0dee8ad270f7078942972163ce290fdec46fd`。
测试覆盖固定预算、整批端点、标签篡改、重复、场景数、非有限力、
Newton残差、研究门控和子任务失败后禁止隐式重试。软件测试不能
当作物理成功；实际服务配置及完成证据保存在仓库外证据目录。
