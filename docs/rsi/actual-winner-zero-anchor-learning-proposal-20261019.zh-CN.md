# 把“保持有效基线不乱改”也作为正样本

## 因果对照带来的真正学习问题

新NAV零参考整批原生/独立CPU于04:39:31正常终态，完整封印
5e44c138d2c5…。8个positive中NAV4/8、原IK教师4/8、新神经学生
2/8。NAV成功为c0/c1/c6/c7；IK成功为c0/c1/c4/c7；学生只保住
c0/c7。此时NAV整批来源审计和27000步密集诊断尚在接续。

这说明IK成功不等于IK动作相对基线有优势。此前只模仿通过的
IK轨迹，会在本来已经能自然接近/触球的场合，也要求网络产生
关节修正。过去动作反馈消融虽然救回部分能力，却没有解决这个
目标选择错误；更低MSE不等于更多物理成功。

因此旧的“单IK教师+当前学生counterfactual建议”128步拟合路线
保持否证，新的matched-support后继仍应正常零更新。不能降低
该路线事先冻结的两训练来源优势条件来重开训练。

## 不同的研究假设：实际胜出路径+零动作稳定锚点

新`select_actual_winner_paths`目前是纯数据选择器，未运行新训练。
每个完整匹配课程，先看原M0成功、安全与密集非足接触：

1. NAV实际成功且无非足接触：选NAV自己的测量状态与实际零修正
   作为正监督。两者都成功也优先不干预有效基线。
2. NAV失败、IK实际成功且无非足接触：选IK自己的测量状态和实际
   关节参考，作为局部纠正示范。
3. 两者都失败：保留两份真实失败，不把失败伪造为零标签成功，
   暂无正监督；以后若做critic/负例学习须另有明确合同。

严禁把IK另一条轨迹的动作直接贴到NAV轨迹上。此首轮只用各自
实际成功执行的state/action，不使用当前学生未验证成功的专家建议。
后续若需要on-policy DAgger，仍要声明counterfactual标签的证据上限。

按当前primitive结果，候选数据路径应为训练来源77的两条NAV零
锚点与来源93的c4 IK纠正；验证来源96是NAV路径。最终必须以
完整来源/密集接触审核为准。这样选择出来的五条成功路径不是
一份可执行策略，更不是已经获得5/8；模型能否在自身身体中
同时实现它们，仍然未知。
