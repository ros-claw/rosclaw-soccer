# 数据驱动小脑前置：同状态reference标签已实际重建，未开始学生训练

## 为什么要做

现在可改变触球结果的脚面控制在固定运动基础输出后、父代残差策略前
修改关节参考。未来若让网络学习这一层，训练标签必须是同一次实际
执行、同一身体状态与时刻的目标修正，不能把两个已分叉的策略轨迹
按帧相减并称因果力矩标签，也不能偷用成功/失败结果作运行时输入。

## 实际发现

原始capture中的`foundation_neural_joint_target_mujoco_rad`来自torch
float32计算；实际navigation.commit_batched_action以float64默认姿态
及scale提交目标。两者最大相差约1.28e-7rad。数值虽小，但如果目标
是精确的动作因果记录，就不该把这两个字段静默视为逐位相同。

用原始float32神经raw action、固定关节排列及原提交公式，已实际
重建18个历史端点、5400帧的导航目标；12条有原navigation capture
的轨迹与capture逐字节相同，连同taskspace增量也逐字节相同。
另6条None原轨迹没有这个额外capture，因此明确只是由相同提交公式
重建，不声称独立capture逐位证明。所有17个非腿关节修正均为零，
腿修正最大不超过原0.35rad容差；未剪裁、未拟合、未改原轨迹。

raw4的原None成功轨迹实际上没有这层参考修正；未来学生不仅要学
“何时踢”，也要学“何时不要额外改动作”。若一律套用新的主动踢法，
就会丢掉这类旧成功。这个发现支持有条件的动作学习，而不是全局
扩大力矩上限或所有状态都启用同一个补丁。
