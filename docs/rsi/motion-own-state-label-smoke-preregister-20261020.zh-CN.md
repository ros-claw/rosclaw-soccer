# 学生自身状态上的教师纠正标签：仅仿真开发预演

三个 PPO 小型对照均未获得物理净增长，停止重复同族参数实验。
下一步检查：监督学习看到的教师状态，与学生实际闭环状态的差异，
能否通过保留肌肉网络的 motion64 own-state 纠正数据来补足。

先声明两个课程：2（教师原任务成功、学生失败的静止球），15
（移动球，学生确定性失败，但已观测到真实成功探索样本）。
不以两个案例代表完整 40 或原 M0/Fresh，不直接开始长期 DAgger。

`rsi_label_motion_own_states.py` 复用 seed29 BC 已独立验证的真实
运动轨迹，逐帧重新积分原学生实际动作。学生神经网络本身此次不重算，
明确叫物理重执行与标签提取，不再算新学生 rollout 或能力考试。

教师在同一个实际身体状态、球状态、实际上一动作、同一 930 维
肌肉历史上计算建议。记录实际 ONNX encoder 的 64FSQ 输出、
1247 维标签输入、decoder 建议；教师建议绝不替换学生的执行动作。
后缀与原学生的全部物理数组必须位一致，并且每步教师 decoder 的
930 维当前历史也须与原学生历史位一致；禁止用教师自己没执行的
建议动作去污染下一步历史。新代码只包裹原推理调用，不改输入输出。

教师可用固定动作未来参考，但这些是标签特权，学生观测仍仅当前
108 维；不能把 future reference 加到 actor。教师初始已在其它轨迹
中通过一些任务，并不能保证它在这些学生走偏的状态上仍能救回。
本预演只验“同状态建议是否能正确生成与记录”，不验建议可恢复性，
不作合格教师的新认证，0 优化器更新、0 晋升。

如果提取失败：保留部分标签、物理步数和错误，不重置身体伪造完整
序列；先查接口/参考/可达性，禁止把失败当有效监督数据。预演成功
后再扩展完整 40，保留 32/8 分割，并在训练前审查哪些纠正标签有
物理依据、如何与旧成功动作记忆保持兼容。也应利用本轮成功探索
6、15 做自模仿对照，而非仅依赖能力有限的教师；不能将成功动作
与矛盾参考直接平均而破坏原成功技能。

所有 raw labels、checkpoint 和视频在仓库外；现有 source、失败
候选、世界/球/PD/H300/post60 与旧成绩不变。报告必须区分数据接通、
参数更新、物理改善三层，不能以提取成功冒充球技提升。
