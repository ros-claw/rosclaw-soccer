# 显式速度控制神经策略：先资格验证，再测实际身体

前置负结果：SONIC位置目标方案24000个原生步完整审查后合格0/3；G1 mode0不直接编码参考根XYZ。当前复用本地 Unitree/mjlab 参考提供的冻结速度策略，检验是否能建立更有效的移动控制接口。不是新训练的权重，更不是已达到足球或球队突破。

## 真实接口和来源审计

参考 ONNX 为 float32 `obs[1,98] -> actions[1,29]`。输入顺序：身体角速度3、身体投影重力3、身体坐标系速度指令3、步态相位2、相对默认29关节位置、29关节速度、上次网络原始动作29。模型不能套用 SONIC 的64维token、Isaac动作顺序、动作尺度或历史转移。

配套XML的29关节顺序必须与规范HG顺序一致，配置`joint_ids_map`严格为0..28。所有输入缩放均1，历史长度1，动作不剪裁，目标按配置逐元素float32乘法再float32加offset，最后转换为MuJoCo需要的float64；不是随意更换浮点运算顺序。

源码审计发现：步态相位每次观测计算均推进，包括静止时；指令范数小于0.1时仅将相位输入sin/cos归零。上游`reset()`还计算一次观测，因此首个实际推理之前已推进一次相位。适配器显式复现这项生命周期，不把构造/重置观测计算当NN推理。

身体角速度由独立私有MjData上的当前q/v运动学和Jacobian计算，不读取实际数据里可能属于旧求解时刻的缓存。原身体不调用mj_forward或修改状态。世界指令先按当前yaw转为身体指令，不能让机器人转身后仍把世界XY当身体XY。

## 资格阶段：0原生步、最多8次NN

冻结模型/配置/XML、参考观察和动作源码、本项目源码与父代失败审查身份。在四组固定合成当前状态上顺序推理，再用第二个CPU ONNX session完整重算，比较98维输入、29维原始动作、目标和相位。此阶段不创建动力学执行身体，不是四条物理轨迹。

编译一个只依赖标准C++和Eigen的独立数值fixture，复算相位、Quaternionf投影重力、输入拼接、上次动作和float32目标映射；不包含或执行DDS、SDK、机器人部署器。要求观测最大误差≤2e-6，目标float32结果逐值完全相同；不通过则禁止分配原生移动实验。

模型参数和默认姿态、部分PD增益与旧SONIC不同。所有原生实验必须另行声明配置，不能悄悄替换旧身体参数后声称历史保持或严格配对提升。旧物理考试、Champion和权限均不改。

## 后续原生响应协议

资格闭合后，使用既有十五条固定移动指令银行：前后/左右0.1与0.3m/s、零指令、验证速度0.2m/s和对角线；球在(3,3)m，隔离接触干扰。仍为同一编译世界、球0.11m/约0.43kg、每控制tick十个2ms原生步、完整H300。采用此策略配置声明的初始关节姿态和固定PD，与原SONIC不同之处单独记账。

每条全程重新做神经推理，再由独立进程重新分配session和身体完整重复。新的记录字段明确保存98维velocity观测和HG29动作，不伪装成`neural_action_isaac`或用SONIC的动作解码器验收。保存全部子步请求/实际力矩、连续q/v、重力/角速度、指令、相位和接触证据；跌倒、响应差也保留，不能筛掉。

预计15×3000×2=90000新原生步，0优化器更新。一种初始世界的十五种干预，不是十五个Fresh世界。若实际响应有效，才考虑细化站位学习和连续踢球交接；不同动作表示、历史与PD的跨策略交接必须独立验证，不能直接套用原SONIC同Foundation历史接口。

原生实验前固定响应研究门：所有子步实际根高度与求解时刻高度均≥0.65m、直立度≥0.9、机器人—球接触≤1N；脉冲最后一秒的平均世界XY速度距请求≤0.08m/s；末一秒平均速度范数≤0.05m/s；停令后根位移≤0.15m。逐指令报告，不用平均数掩盖方向失败。这些是移动响应研究门，不是足球考试门。

实际资格验证已闭合：八次NN、独立C++观测最大误差0、float32目标逐值一致、第二会话顺序观测/动作/目标重复一致。仍为0原生步，不能据此宣布会移动。原生采集器在分配身体前再次核对正在使用的actor和私有角速度数学源码与资格源逐文件哈希一致。
