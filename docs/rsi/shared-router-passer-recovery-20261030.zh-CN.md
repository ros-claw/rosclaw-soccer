# 双 G1 传球者恢复：已消费开发场景的配对结果

该可选研究路径默认关闭，不修改现有比赛策略。它在一次真实足部传球和传球动作结束后，将传球者从现有站立策略以固定 20 控制周期平滑过渡到自己的 600 步速度网络；切换前速度网络逐步跟踪本体实际目标，过渡期间和之后仍使用自己的执行历史。接球者、球及两个身体持续位于同一个 MuJoCo 世界，没有重置球或复制轨迹。

8 个先前消费的共享场景各比较原 router 与恢复组合，并各自同代码重复运行。基线逐数组匹配此前 router 轨迹，恢复启动前的物理轨迹一致。两条基线轨迹在共同观测时间域内传球者失稳，恢复组合在相应共同时间域未失稳并各自运行至 600 控制步；另外 6 对在共同时间域均未记录身体失稳。两个未交接场景在原 300 步任务截止时只完成 11/20 过渡步。

宽松交接触发基线与候选均为 2/8；严格要求双方健康、足触顺序正确且无非脚碰球的交接均为 **0/8**。因此未丢失严格成功是空条件，不表示接球安全或成功；接球者非脚干涉仍是主要未解决问题。数据来自已消费开发场景，重复不是独立初态；此结果不是 Fresh、完整球队比赛、真实机器人结果或策略晋升，更不是学习模型突破。

回读确认恢复速度网络实际目标和自身动作历史一致；两名机器人已有动作历史也分别核查，传球者关节目标反算到动作使用事后披露的绝对容差 `1e-6`，最大误差 `4.77e-7`，不是逐位相同。所有真实物理及动作原始数组、审计与失败记录留在外部证据目录。研究源提交 `cd6569ad7851115c02e53880bcc71afefb5cd46b`；主回执 SHA-256 `e5b52500f25208099b1ac6c95dd98520a3b938fe5583947aa2f469f8683575df`，重跑回执 `8a3b077844fcfac5d73f7fec8f5b190d7f03b371df6d4c89428194a4bf64f635`；配对审计 `ec86b3f56f0af3fae2601fe4a60078ecf6aeaac704531cb8f24d2239c4549ff6`。
