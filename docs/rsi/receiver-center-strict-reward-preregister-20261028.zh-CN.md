# 中心课程严格接球奖励：采样结果出齐前固定

本奖励只供之后的 SIM 研究，既不修改正式验收，也不覆盖任何历史奖励。依照完整物理记录，每条采样序列的终端分数为：双方全过程无非足触球、双方健康、A 脚先于 B 脚且原交接成立时 `+2`；传球者出现非足触球 `-1`、接球者出现非足触球 `-1`、任一身体不健康 `-1`。不得给没有任何碰球或没有交接的序列正奖励；没有触球且健康是 `0`，不是成功。发生非足触球或身体失败时不能得到正分。

奖励在本次三个采样服务结束前声明，但在看到中心身份源日志后制定，不声称完全事前盲注册；完整 72 个采样回合及三种子结果未被用于选择它。只有独立回放和概率审查完成后，才允许重新读取完整原生碰撞、核对所有回合并写出新的研究数据，旧数据不可覆盖。一个终端奖励可能给较晚动作不理想的信用，后续只能称为有限回合可行性训练，不能当作因果逐事件奖励。

不允许仅以无触球负反馈训练并宣称接球提升：至少应存在多个不同条件的干净正例和失败例，以及实际执行动作、条件密度和健康保持锚点；否则在优化器前停止并改变课程/动作空间。即使符合数据准入，仍要先固定学习率、三种子及评估协议，并在原 ±0.55 m 和新未见情境进行双 G1 实际物理与独立回放。仅 SIM_ONLY，无晋升或真机授权。
