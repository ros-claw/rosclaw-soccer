# 尾部回放：针对旧技能关键动作误差的单主种子试验

前一版平滑神经残差的三种子均完成6144次更新并通过独立CPU检查，但原生
TRAIN20三脚生产结果分别为 `[13,17,13]`、`[14,18,11]`、`[13,18,13]`，
当前父代为 `[14,19,17]`。第三种子还出现一个身体不稳定场景。正式逐相位物理
审计仍在接续；这些是必须保留的负面结果，不是只看拟合均值就能宣称进步。

已测到平均旧状态修正MSE约2.8e-6至3.0e-6，但最大旧动作变化0.16至0.18rad。
普通MSE同时平均了28440个旧状态和29个关节，会弱化少量关键动作误差的梯度。
因此下一项改变的是采样与损失，而不是把6144次更新变成更多轮。

v2与v1使用相同的数据、网络、三种子声明、学习率、6144次Adam更新和动作上限。
v1默认配置和旧检查点解释保持不变。v2每步512个回放行由256个均匀样本和256个
困难样本构成；每256步在全部TRAIN负锚点上重新推理，找最大实际最终关节变化
的512行作为困难池。额外将每个回放样本的最大关节变化取平方，再对最坏32行
取均值，权重2加入目标。原来的主动样本MSE与权重2的回放MSE仍保留。

困难池只用于离线优化，实际模型不接收场景编号、动作游标或困难池索引。
全量挖掘24次、额外682560行前向推理单独计数，不算新增独立数据或新增SGD。
真实原生复测的失败状态没有伪装成执行过的成功教师标签。

先只运行预先指定的主种子0进行快速否证；只有看到有效物理提升再运行其余两个
固定种子作复现，不从三者中挑最好。必须同时关注主动拟合、最坏回放误差、旧
物理技能与新物理任务，而不能仅看尾部损失下降。旧v4未见测试的模型锁不放宽，
原32场景已经用于TRAIN；任何泛化声明须另行冻结模型并声明新测试。
