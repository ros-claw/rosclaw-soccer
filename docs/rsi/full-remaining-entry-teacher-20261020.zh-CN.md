# 完整剩余任务前瞻教师：实验前协议

## 为什么换方法

[短视入口实验](predictive-ball-entry-20261020.zh-CN.md)实际退步，已拒绝。它正确预测了导航，却看不到交接后的球路和身体碰球。因此这轮不调评分权重或增大训练轮数，改为从自己的完整本体与神经历史出发，预测至原任务 H300 终点。技能调用不能只追求“准备好了”，必须考虑执行技能后的结果。

这依旧是 G1 下游物理研究，不是 ROSClaw Core 已实现通用成长，也不是原 RSI-M0 914 父代的全模型考试。四个球位都是旧开发课程；没有 Fresh，没有新训练模型，没有冠军晋级，没有真实机器人。

## 保持不变

原 MuJoCo 世界、29 个关节、PD/力矩边界、SONIC CPU low_latency 模型和原编码器布局，球半径 0.11m/质量 0.43kg；同一个 MotionDecode 源、参考窗口 `[286,767)`、120Hz 声明、50 个入口插值间隔，显式隔离六腕参考，交接期限 30–90 帧、误差 0.04m，H300 不延长。

四课程 `(0.35,-0.10), (0.50,-0.10), (0.35,-0.22), (0.50,-0.22)`，每个执行名义控制与完整前瞻教师两组。每组是重新执行自身神经推理的实际 H300，不以旧目标轨迹代替策略。名义组全数组须与旧实验证据精确一致。

## 有界前瞻与执行

1. 同一本体执行名义控制第 0–19 帧；在第 20 帧搜索一次，其他时刻不再搜索。
2. 七候选：**逐帧本体反馈的原名义控制**，以及原六个有界命令各保持第 20–39 帧、其后恢复名义反馈。后六候选的命令仅由当前状态生成。第 91 帧起仍然超时零命令。
3. 每候选复制当前完整神经历史、导航缓冲与 warm-start 物理状态，执行自身 SONIC 推理到第 299 帧。仅共享合格 CPU ONNX 会话与只读编译模型。
4. 分支每帧按自己的测量检查原交接门，真正执行导航→参考的原子交接，保留历史与时钟。参考以分支当前本体生成；其后仍然不按球重新定向，这是当前动作控制的明确限制。
5. 原机器人只接收选中的**命令规律**，重新推理并重新积分完整剩余 280 帧。绝不移植预测关节目标、身体状态或参考缓存。

七个预测各 2,800 新原生步，每预测组 19,600 步；四组共 78,400。八个实际完整本体共 24,000。整轮预算 **102,400 新原生物理步，0 优化器步**。预测中继承的 200 步前缀不重复计费；其内部 H300 review 并不意味着预测新增 3,000 步。

## 固定研究选择标准（非原 M0 考试）

完整预测后缀任意机器人非脚部球接触超过 1N、骨盆低于 0.65m、竖直度低于 0.9，否决候选。覆盖整棵机器人刚体树，地面不计入机器人。

只有真实脚触球不晚于第 239 帧、到任务终点球前移至少 0.5m、绝对侧偏不超过 0.3m、最大前向球速至少 0.5m/s，才有本轮研究选择资格。这里前移和侧偏明确测到任务终点，**不是**旧考试的触球后 60 帧球路；观察资格仅说明有完整 60 帧可用，不能借此声称原考试通过。

有资格者按 `侧偏² + 0.02*末60帧平均根部水平速度² + 0.02*触球后最大根部漂移² − 0.01*min(前移,3)` 选最小值，固定序号解平局。若七个都无资格，仍执行名义反馈，显式标记无合格候选，不当作安全或成功证据，不删场景、不改分母。

## 必需因果校验和失败转向

- 所有实际第 0–19 帧必须与旧名义组全部数组精确一致。
- 每个预测组的第 0 候选，其完整第 20–299 帧必须与旧名义组精确一致，确认完整前瞻没有换任务或丢神经历史。
- 选中候选完整 280 帧必须与原机器人随后真正执行的所有物理、神经输出、参考、命令、阶段数组精确一致，连交接报告也须一致。不能只比较成功评分或有效前缀。
- 每个候选前后检查原本体完整积分、其他全部身体字段及全导航字段哈希。失败异常也检查并记账，不能重复使用被污染状态。
- 保留全部七候选与实际实例，包括超时、倒踢、小腿碰球等反例。原始物理、参考、神经与命令数组在 Git 外，开跑前固定源码/数据，结束复核身份。

若只保住两个旧成功，却不能救回远球位，说明“仅改一个早期导航命令块”的动作权限或参考接触适配不足，不能继续同族无穷扫参；下一步审计脚—球相对状态、支撑相位和接触参考是否可重定向，按 1013 的 B→C 对照研究接触权限。如果找到新干净结果，先扩展同状态扰动可靠性，再考虑学生三种子、保持与 Fresh。该轮成功也不等于球队比赛突破。

MotionDecode 与相关研究数据的授权不自动涵盖商业宣传。未另行解决许可前，不以这些派生动作生成可商用宣传片；纯 SIM_ONLY、没有硬件授权。

## 上轮反例的补充：相同入口位置不代表相同接触

只读原始记录诊断（不增加原生步、不执行新神经策略）发现：名义球位 0 在交接时根部水平速度约 `(0.461,-0.475)m/s`；失败的预测球位 1 约 `(0.012,-0.198)m/s`。二者球相对根部位置很接近，约 `(0.213,0.006)` 与 `(0.213,-0.006)m`，但运动历史不同。

两者第一次都是右脚接触，不是误把左支撑脚当成踢球脚。记录中的球位 1 于第 218 帧第一次脚接触，刚接触后的球自由关节前向速度约 `0.104m/s`，整段最高仅 `0.129m/s`，随后第 241 帧非脚部再次碰球，最终球倒退。因此准确说法是“弱前向触球后被身体再次碰回”，不能仅凭最终负位移断言第一次脚击球向后。

在对应接触步的积分后本体做只读 FK，右脚连杆原点相对球的高度分别约 0.083m 与 0.136m，侧向差约 0.022m 与 0.064m。这只是姿态线索：连杆原点不是网格接触点，积分后 FK 也不是求解器接触几何证明。但它支持下一步检查脚—球接触高度、偏心量及身体动量，而不继续只优化入口距离。
