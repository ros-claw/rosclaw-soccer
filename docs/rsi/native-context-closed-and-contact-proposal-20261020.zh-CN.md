## 新假设：条件化接触几何，不是继续扫常数

停止无条件上下文族；不扫描0.12限幅、blend长度、导航gain、既有固定C偏移。旧六选项教师在16条件中6个合格，仍非可靠教师，原证据保持。新假设是同一个有界任务空间接口的**输入选择方法**：读取自身暖启动候选0的真实原生预测轨迹，从实际脚—球相对几何提出一个修正向量，而不是按课程ID/成功标签查表。

与旧负结果区别：不把J转置任务力矩除Kp后在线叠加目标；不做触球后全身单坐标搜索；不宣称扩大权限。它只修改右腿六个参考关节，仍经过原接触参考DLS、SONIC自身状态推理和原PD/native执行。参考FK接近不代表动态接触有效。

### 下一轮有限协议（执行前须另封存源码与全银行预检）

1. 同一16公开诊断条件、同一MotionDecode截段、手腕隔离、进入门、H300/post60、球/世界/原SONIC、原三条导航律，原M0/52/Retention/Fresh不变。
2. 每课真实运行自身20拍前缀；对原三条律分别预测一个零C完整后缀。几何函数只消费该后缀自身记录和本次交接帧，不读取其他课程或真实后续标签。每条律最多生成一个向量；无生成条件时记明确不适用，不伪造候选。
3. 用原生模型做只读FK，取右脚前两个5mm支持球中心中点（不是可视网格接触面）。固定局部窗口91..209；只选脚相对球朝+x接近速度大于0.2m/s的时刻，以脚中点到球后表面期望点的距离最小选帧，相同距离取最早。期望点为该时刻自身预测球心减 `(球半径+0.005,0,0)`；半径必须从模型读出0.11，不更换尺寸。
4. 将选帧世界位置残差用该帧自身实际根姿态转回根局部，再除原sin²窗口权重，得到恒定幅度请求。作为**声明的提案信赖域投影**，统一缩放到每分量≤0.04m且范数≤0.06m；不裁剪状态、关节限位、考试或球轨迹。权重≤0.1、之前已发生非脚碰球、没有候选时刻或交接过晚时拒绝生成，不改相位凑结果。阈值本轮固定，不根据结果扫参。
5. 在另一份自身暖NN/身体克隆中，最多三次完整后缀预测新向量；原三条零C候选与三个新向量共同按既有合格/成本选择，最多六个完整预测，不采用任何未来目标/状态。实际执行从未改变的本体与导航状态重算所选律和向量，全部18数组及交接报告需与选中预测一致。供参考的旧固定LOWER教师是**保持性比较对象**，不把其失败课标签用于生成或选择。
6. 每课最多6×2800预测步 +自身3000实际步，16课最多316,800新增实际/预测原生步；独立审核另计。无合格候选时明确未认证回退，不宣称教师通过。每例保留原方案质量、救回/退化、前置非脚碰、生成向量、是否投影、FK窗口/残差、实际球方向/力/稳定性及完整预测/实际一致性。
7. 必须至少保持旧教师6/16且有所净增、不得丢失旧成功或新增不安全，才值得独立完整回放并扩大扰动；这也不等于原M0/Fresh或比赛能力。若没有净改善，停止这个几何提案族；不接着扫描投影半径/速度阈值/相位或重复更多epoch。通过可靠多扰动教师门之后才谈学生训练/三种子/PPO。

现已实现纯几何函数 `rsi/contact_geometry_proposal.py`（自身记录只读FK+确定性向量），14项几何/拒绝测试通过，模块定向mypy通过；它不积分物理、不调用神经网络、不写实际目标。后续新增完整执行器 `scripts/rsi_probe_contact_geometry.py`，自身20拍前缀、3个零C未来、最多3个自身几何候选、既有评分选择、原本体实际执行及全部18数组/交接报告一致性核对；78项相关测试通过。浮点投影如因舍入超过声明边界，只向内缩小一个ULP直至合规，不扩大限位。

封存前只读FK兼容检查已实际消费48条旧自身预测轨迹（16条件×3律）：19条能生成几何提案，27条未通过原交接门，2条已有前置非脚碰球而拒绝生成。没有新增物理步、NN调用或优化器更新；它也表明晚期接触修正不能解决大部分没有进入技能的轨迹。运行时必须重新做自身预测，不将这19条历史向量做课程ID查表。完整执行是否成功，以后继封存批次逐案例证据为准，不预先宣称净收益。

## Agent loop的真实边界

产品Goal保持active承接后续工作；有限实验内部按已封存队列自动处理下一槽，独立进程保存原始记录/逐槽终态，60秒只读观察器发现退出/停滞，恢复清单区分完成、已知拒绝、未知致命故障及未启动。每阶段先读证据并决定继续/停止机制族，不能只让监控循环看同一批已结束任务。

观察器不能唤醒大模型，也不能替科研决策；不能承诺平台关闭、断电或会话调度中断时推理仍在进行。保存源码、哈希、队列与恢复点，才有可恢复性；正在运行的仿真、权重优化和下一轮Agent推理必须分开报告。目标未达不以一个诊断阶段完成来结束Goal，也不靠自动重跑同一个失败方案假装进化。
