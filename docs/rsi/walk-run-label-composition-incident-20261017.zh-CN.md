# 走／跑对照中断：资格与成功标签分离

## 结论

旧实验第 4 次执行完成了原始轨迹，但提交资格时触发 Fatal。
原因不是轨迹缺失，而是消费者把历史 CPU `high_quality`（球路质量）
直接等同于 M0 `task_pass`（球路质量与身体安全的组合）。
历史 CPU 审核将骨盆门另列为 `safety_passed`；因此“球路好但身体
不安全”是合法失败样本，不应被误判为基础设施合同错误。

修复组合为 `high_quality and safety_passed`，仍要求与原始轨迹
重新评分一致。旧评分函数、M0 安全线、控制器和物理参数均不改。
独立 CPU 的 3,000 子步、270 次采样重构、300 次 Foundation 重算
必须完整；骨盆最低值必须有限、与原始轨迹一致，安全标志必须与
冻结阈值一致。该函数不替代调用方对见证文件和审核报告的认证。

## 实际复核结果

原执行源 `9817ee026acb9ee52e29291cd085f4093549af20`。
16 初态 × 两种运动模式的原实验只完成了 3 条资格提交；第 4 条
为 group4/mode3，原始 300 帧执行已保存。原账本仍是 Fatal，
4 次尝试全部保留，没有清零或将旧失败自动解冻。

冻结原源码的独立复核已完成，新增的是重放而非重新执行策略：
3,000 CPU 物理子步、300 次 Foundation 重算、270 次采样重构及
15 次运动参考 ONNX 调用。其结果为：

- 首次脚触球：第 201 帧。
- 触球后 60 帧前向位移约 3.2691m，横向位移约 0.02027m。
- 骨盆最低 0.617779m，低于原 0.65m 门。
- 历史球路质量为真，身体安全为假，M0 `task_pass` 为假；
  `UNSAFE_CONTACT / SAFETY_VETO`，奖励仍为 -10。

复核报告为外部证据目录中的
`rsi-walk-run-label-failure-reaudit-20261017/complete.json`，封印
`sha256:dea32ae6554d9602b8918858a2c6c83baf28b639042b923590ed172499fb6e66`。
旧轨迹、旧报告及旧账本未改写。

低骨盆首次发生在第 121 帧的子步 1，早于第 126 帧脚端 IK 启动，
也早于第 201 帧触球。因此不能将该案例完全归因于踢后收腿，
也不能仅靠踢后释放残差宣称已经解决。
