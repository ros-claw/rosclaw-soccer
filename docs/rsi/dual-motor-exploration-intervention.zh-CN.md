# 双循环小脑：探索幅度配对实验

本实验检验的不是“训练更多是否必然更好”，而是：此前 0.005 policy-unit
的条件采样是否不足以发现可学的接触动作。它是 TRAIN 诊断，不是 Fresh 考试。

## 冻结的比较

- 两组使用同一份已完成独立 native44 复试的候选及其 checkpoint hash。
- 两组使用相同 retention-run64 场景与同一代的 16 个随机种子，共各 64 次。
- micro-v1：sigma=0.005；contact-v1：sigma=0.02。两者均使用归一化的
  box-truncated-ar1 条件概率，rho=0.9；采样密度、审计和 PPO 必须一致。
- 动作权限仍是相对冻结 nominal 的 ±0.2 rad，不扩权、不截断已采样动作。
- 每次执行完整神经站稳尾段；身体失败保存实际终止，不伪造后续控制。
- 每组四个独立原生 CPU 仿真进程；组间串行，以免混淆资源竞争与效果。
- 每组全部轨迹独立原生重放，失败和成功均保留。不按“最佳随机种子”选取。

同种子的两组因动作不同会进入不同的闭环状态；这是配对干预，不是两组
独立场景，也不能把 128 次称为 128 个独立球位。原有正式考试不修改。

## 读数与否证

逐 context、逐种子比较 healthy_quality、实际身体失败、非足部接触、完整
触球后窗口、球前进/侧偏和退步；计算 rescue/regression，而不只比较均值奖励。

如果较大探索幅度仍无法在 context4/20 产生可复现的合格动作，不能继续
无限增大随机噪声或 PPO 轮数；应判定本项探索假设未获支持，返回已有物理
教师与学生闭环的动作/观测分布差异，研究适用域隔离和控制接口。

如果较大幅度产生新的合格轨迹，也仅允许把完整审计后的银行用于一次有界
的下一代学习。学习后的确定性 native44、历史保护及独立复试仍必须通过。
采样成功不是参数学习成功；critic 误差下降不是物理能力晋级。连续比赛及
可宣传球队视频仍是未完成的总目标。

## 持续执行的边界

Goal 主机负责接续 Agent；systemd 负责已声明的有限仿真作业，观察器只观察，
不具备唤醒 LLM 的能力。必须同时保留最新作业绑定与恢复指针，不能用旧任务
仍显示 active/exited 掩盖队列已空。安全或证据合同失败禁止盲重试，但不能
成为停止科研工作的理由：下一步应诊断或切换有证据支持的实验。
