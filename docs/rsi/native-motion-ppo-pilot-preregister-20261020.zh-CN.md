# 原生接触经验驱动的运动意图 PPO：开发性先导实验

## 为什么做

此前直接 29 关节学生的 120 次训练后测试全部违反身体平衡阈值。
保留 SONIC 肌肉解码器、训练 64 维运动意图后，120 次训练后测试均通过
高度和直立阈值，但最佳足球任务仅 2/40，验证集仍 0/8；教师为 13/40。
监督拟合本身不足以学会接触时机。因此下一步需要自己的真实接触经验、
失败反馈和策略更新，不能再将标签损失下降叫作踢球提升。

## 固定边界

- 仍是已有近球 40 课程开发协议，32 train / 8 validation。
- 固定 H300、前 20 帧 Foundation 接管、触球后至少 60 帧；世界、球、
  PD、力矩上限、考试阈值全部不改。不是原远球 M0、Fresh 或 4v4。
- seed29 是根据已经看过的开发集结果选的起点，并非盲选或新独立验证。
- 冻结 108 维观测的编码器、GRU 和原 SONIC 肌肉解码器；只更新
  意图 actor、critic、探索标准差。不是直接学习力矩。
- 观测仅有自身当时的本体和球状态、上一实际动作；不含未来参考、
  奖励、课程编号或特权几何。几何距离仅用于环境端奖励。
- 前缀在重放中复算物理、但不复算 Foundation 神经规划，明确记录。
- SIM_ONLY，无硬件、自动晋升或宣传授权。

## 实际采样与验收

`rsi_motion_ppo_pilot.py --mode collect` 对预先声明的训练课程运行完整
300 帧。前 20 帧只预热新策略记忆，不消耗探索随机数；其后每帧
64 维独立正态噪声作用在 FSQ 量化之前，初始标准差 .02。
token 经冻结肌肉网络产生 29 关节目标，由原生 PD 和 MuJoCo 执行。

记录完整物理、当前输入、隐状态、均值、标准差、噪声、量化前样本、
log-prob、奖励。每个回合必须用新身体、新肌肉历史、重置的随机数流
重新计算整条链，与原始记录逐数组位精度比对；绝不直接重放后缀动作。
私有 MjData 距离观测还须验证不改变实时求解器的 integration state。
失败回合不重置成成功；执行故障阻止该批进入学习。

先用课程 0 的单回合开发 smoke 验证链路，再以四个独立进程分摊全部
32 个训练课程（每个 8 个）；验证集不能进入梯度。独立进程不是
Python multiprocessing，不对未经验证的 spawn 工具链作假设。

## 奖励与 PPO

奖励只服务于当前足部首次触球协议，不是通用足球规则：非足部触球
（胫骨、胸、头、门将手在其它协议中可能合法）在此仍按原门控惩罚。
跌倒或非足部接触各锁存一次 -5，并停止后续足球正向 shaping，
但继续跑完物理。每帧时间成本 -.001；未触球时给有界的接近足球距离
变化；首次足部原生接触 +.5，加有界的接触帧前向速度增量。
只有接触之后才奖励相对触球位置的前向进度并惩罚横向偏差，避免把球
初始滚动当作球员功劳。最终原考试且因果首次触球成立 +5；跌倒或
非足接触终态 -3。考试从不由奖励替代，也不修改阈值。

使用完整 300 帧 recurrent 序列重新算似然和 critic，不用旧隐状态
偷渡更新后的模型；仅 20:300 参与损失。GAE gamma=.99、lambda=.95，
固定任务终态 bootstrap=0。PPO clip=.2，value 权重 .5，梯度裁剪 1，
Adam 学习率 1e-4，先导批仅 4 次更新；冻结初始策略的高斯先验 KL
权重 .01，entropy 权重 .0002。似然作用于实际采样的量化前连续动作，
不是把离散 FSQ token 当成高斯样本。

保留真实 checkpoint、优化器、Torch RNG、输入和源码哈希；验明 actor
与 critic 参数实际变化、冻结模块不变。更新完成不等于通过：随后要
对全部 40 课程运行确定性新策略并独立重放，与既有 2/40、0/8 及
平衡/非足接触等失败分型对照。若恶化保留失败，不晋升；若只奖励上升
也不宣传。再根据物理失败选择下一阶段，而非无脑无限堆算力。

## Agent loop

监督器记录真实进程终态、阶段证据和明确的下一依赖。计时器只是观察，
不等于训练；进程结束必须由 Agent 读取结论并推进下一阶段。
产品 Goal 保持 active，除非最终目标达成或用户明确要求暂停。
重启后先核对阶段 receipt、源码/权重哈希和活跃 PID，不重复启动已有任务。
本先导模块不是完整持续自主球队，也不以本组件完成来结束总目标。
