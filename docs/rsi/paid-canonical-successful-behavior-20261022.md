# 完整成功行为选择：固定协议与未完成边界

## 动机

上一轮确定性 own288 动作记忆在独立 MuJoCo 重放中首次改善 case4 首脚，
三组旧考核共 52 个上下文没有配对损失；case5 仍失败。
原 case5 教师的 1.2 秒横向代理误差为 0.74475468 m，距离既定 0.75 m
边界仅 5.25 mm。该指标不是球门平面落点精度。
继续提高同一小 MLP 的训练轮数已经没有物理收益，不能重复宣称训练进步。

## 本轮固定变更

只读取已经完成全部试验、双重复及 ownNN/IK/native 审计的 TRAIN 教师。
每个尚未晋升的新技能，按两次完整重复中最坏绝对横向偏差最小选择行为；
其次比较最小前向进展，再优先原行为，最后较早接管。
选择发生在数据准备阶段，绝不把 case ID、控制帧或轨迹游标交给运行时策略。

预计 case4 保留原行为，case5 选择学生执行 70 帧后专家接管的完整成功行为。
保留全部原文件与备选行为的结果、哈希和来源；只在一个新 schema 的物化训练集
中替换原来未晋升的 case5 教师块。其余 93 条轨迹与受保护旧动作逐位不变。
同观测不同标签必须拒绝，不平均、不删除受保护负锚点。

前 70 帧明确是“成功行为中的实际学生动作”，不是专家动作；接管之后才是实际
执行的专家动作。未执行的教师建议不能充当标签。从第 0 帧重建循环状态，
检查上一实际动作、R2 名义动作以及接管前后全部 h/c，不能在接管处重置记忆。

## 考核及停止重复规则

冻结干净源码后物化数据，再拟合一个确定性 cardinal 动作记忆及同几何零系数对照。
神经优化器更新为 0：这是数据驱动非参数表示实验，不是神经 SGD 或在线 RL。
旧数据与旧模型加载协议保持原样；新协议显式使用 checkpoint v2。
最终 R2 修正界限仍为 0.2 rad，局部相对修正界限为 0.4 rad，几何比例仍为 0.45。

学得候选执行 TRAIN20、旧 TRAIN16、DEV16，对照执行 TRAIN20；所有考核均从
首脚启用学生，包含三脚及站稳恢复，双重复，并独立重建 ownNN 与全部原生物理。
之后做 own-policy 接触偏差诊断，不拿教师轨迹代替学生执行。
接受研究进步必须新案例真实改善且旧成功无配对损失；失效即保留反例并改变下一
个科学假设，不因超时重跑、不扫描阈值、不放宽安全边界。

## 持续 agent loop

每轮依次：读取持久断点 → 检查实际进程与终态凭证 → 分析配对收益/损失 →
选择有因果差异的下一实验 → 冻结/检查/启动 → 独立审计 → 保存下一行动。
定时器仅观测，不会替 Agent 做科研决策；Goal 的宿主续接才负责恢复 Agent。
不能把 active/exited、零 PID 或单纯心跳当作训练在运行。

本轮不是连续自主 4v4、完整跑动射门、可靠接球、角色协作或宣传片验收。
不授权真机，不自动晋升 Champion，不继承已经消耗过的 Fresh 考核。
单一接触问题的改善也不得长期代替球队小场景与团队技能链路的后续开发。
