# 参考进度权限与保留式小脑学习

## 问题与实验边界

上一轮31条触球轨迹集中在第263–265控制周期，增加受约束力矩探索没有找到
明显更早的触球。先检验父技能的参考进度是否是一个有效控制权限，而不是继续
盲目增大同一个探索族的训练量。

这轮仍是CPU MuJoCo、同一29关节G1、同一0.11m/0.43kg球、同一身体惯量、
PD增益和力矩上限。积分500Hz，策略控制50Hz，观测和实际动作历史仍按物理
时钟推进。只改变RoboNaldo参考索引及内存中独立副本的关节参考速度，整数
有理数进度避免浮点累积越界。原资产没有修改；初始化后没有改写球或root。

新父控制器另有哈希，不能把旧BC的父代身份悄悄改成“本来就一样”。速率1
先与原父代四个球位的全部19字段逐元素一致，独立重跑也必须一致后才接续。
这不是加速播放动作文件：原547输入神经网络每个真实控制周期重新推理。

独立重跑加入只观测、不改变力矩的Core教师采集器。先在原速四例证明：

完全相同。然后对选定的加速16例采集104320个真实native状态/力矩样本。

接续原102输入→GRU96→29关节绝对力矩actor，不重置模型、390次BC的Adam
历史、critic、历史锚点或观测归一化。三个预声明采样种子各执行128次新actor
Adam，总BC历史518次；本轮critic/alpha/SAC更新均为0。这是有历史保留约束

## 再诊断，而不是把失败全部归咎于GRU

在已严格重跑的零干预观测上，复现真实warmup和OOD清零日程，对照训练的16步
窗口与持续隐藏状态。持续Torch推理与Core NumPy推理的最大归一化差异小于
0.00000696，不是推理实现互相不同。

三组按案例等权的短窗口MSE约0.0000763–0.0000776，持续状态约0.0000918–
0.0000933，增加约两成。历史分布差距存在，但两者误差都小，不能据此断言它
单独导致了19/48健康的灾难性闭环结果。还必须考虑低增益力矩误差对动态平衡
的敏感性、闭环状态偏移、动作时段权重和教师强迫数据覆盖。

本轮全部已闭合物理共372次世界执行、2177800个native步，实际不同球位仍仅
16个；包括重跑与教师采集，不是372个独立训练任务。新actor更新共384次。

下一项已启动的有界实验是同三组失败权重、同父控制器、同16球位，检验0.125/
0.25干预比例，分别相当于原8%hard父代偏离包络的1%/2%有效偏离上限。它检验
“当前学习动作还有多大稳定控制权限”，不是新训练或新身体能力，也不降低0.1m
目标。复用先前真实零干预身份，不重复零干预物理；每一档仍要独立重跑。只做
这一轮权限校准；若两档仍无独立净收益，不再不断扫比例刷最好结果。

## 本轮接续机制

`rsi_run_reference_clock_campaign`真的逐阶段启动源执行和独立重跑；
`rsi_run_clock_candidate_pair`对每个模型自动执行零干预16例、独立重跑、全干预
16例、独立重跑。它们不是只检查PID的监视器。

每轮绑定提交、计划、输入哈希与独占锁；完整已闭合阶段可读取后接续，不重复
计费；部分产物或完整性失败保留现场并阻断接续，不盲目restart。身体失稳若
可独立复现，是失败数据而不是完整性错误，仍应保留进下一轮分析。

只读observer继续检查真实执行、进度和接续义务，但不唤醒agent，也不声称能
自主发明下一轮科学方案。跨轮继续由宿主active Goal负责；电脑断电、宿主停机
或平台不调度时不能保证计算继续。不得把“服务活着”算成训练或球技突破。
