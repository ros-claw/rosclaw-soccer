# 旧技能保护核与广域神经反馈：验证一个新假设

前两个神经版本均未取得合格的物理提升。均值回放主种子 TRAIN32 为26/32，
但旧TRAIN20三脚退化为 `[13,17,13]`；尾部回放虽将最坏旧锚点动作变化从0.175
降至0.0057rad，旧技能仍退化为 `[13,16,12]`，TRAIN32也降为23/32。
这说明离线小误差不能代替闭环保持证明。

本试验不再增加SGD轮数。固定第一版已完成6144次更新的主种子神经网络、当前
父代和全部TRAIN数据，用新的状态门控比较“保护旧技能附近”与“允许新状态反馈”
能否共存。它是推理架构改变，不是新神经训练，更不是在线RL。

门控只接收当前 own288 本体特征。在已重构的TRAIN中，取到主动修正样本与旧
能力样本的最近精确欧氏距离，分别为 `dp`、`dn`。定义：

```
r = dn / (dn + dp)
g = clip((r - 0.1) / 0.9, 0, 1)
动作 = clip(当前父代 + g × 冻结神经修正, -0.2, 0.2)
```

旧锚点以及足够接近旧能力的保护核内，`g=0`，直接逐位返回父代，避免浮点乘法
引入微小动作漂移。主动示范锚点 `g=1`。不同于此前正样本紧支撑锥，新状态即使
不在示范小邻域内也可能有非零反馈。代价是扩大了未经物理验证的动作区域，
**没有OOD安全或泛化保证**。最终相对R2动作上限仍为0.2rad，SIM_ONLY。

0.1是预先固定的无量纲保护比率，不是0.1米精度目标，也不是对测试成绩扫描。
精确cKDTree只优化最近邻查询速度，`eps=0`、单线程，不做近似索引；样本来源、
正负标签、归一化和冻结神经权重都由既有因果TRAIN及检查点哈希绑定。
不接受场景编号、帧索引或教师游标。

构造证书将检验所有29706行的门控、旧动作逐位保持、实际batch1输出和独立暴力
距离核对。随后必须重跑旧场景、训练接触场景及新声明的泛化测试。旧v4未见测试
锁定的两模型不放宽，也不能把训练32场景分数包装成新泛化突破。

与此同时，同一PAiD足球身体上的冻结速度模型已完成8场、双重复及独立完整世界
物理重放，可稳定跟随约1m/s，但停步漂移约0.325m。这是开展真实连续技能衔接
的基础，不代表已经会无缝跑动射门或自主比赛。
