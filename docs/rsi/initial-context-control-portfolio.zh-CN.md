# 初态条件化控制组合：仅研究原型

## 为什么做

实测表明统一参数存在局部收益与退化：第一反馈代候选 2 挽救球位
0、24，却损失原成功球位 8、32；触球后控制保住 C 的五个成功，但
仍损失原 A 的 4、8。不能据此证明统一控制不可能，也不能继续仅按
总成功数挑一个全局参数并忽略保持。下一可证伪方向是从完整物理
对照矩阵中学习按当前状态选择控制选项，再在未参与拟合的公开状态
和扰动中验证，而不是事后挑视频。

## 已实现的最小模型

`rsi.initial_context_control_portfolio.InitialContextControlPortfolio`
使用固定一近邻规则，拟合每个训练初态的安全控制选项：优先合格任务
结果，再按原奖励排序，同分固定按选项序号。无安全选项则保持未知。
这是非神经监督拟合，不是在线 RL、actor-critic 或关节力矩网络。

输入只有初态实测的世界坐标球-根 x/y 与球 vx，以及执行绑定哈希；
不输入新任务的未来接触、结果、场景编号或成功标签。训练历史结果
只作为监督标签。绑定必须由调用方覆盖身体、完整父代/采样协议、
世界、初始机器人状态与评分合同；绑定不符返回 UNKNOWN，不默认
执行父代。超出固定邻域也返回 UNKNOWN，不当成零成功率。

三维尺度固定为 0.6m、0.32m、1.4m/s，最大坐标邻域半径为 1。
未做超参数搜索，邻域内的一近邻选择也不是校准概率或物理保证。
只允许已消耗的公开研究分区，不接受 Fresh 拟合。训练矩阵要求每个
初态都有所有选项的结果，禁止重复初态或重复证据撑大样本。

模型导出包含完整案例、选项内容哈希、拟合选择和非授权声明，支持
完整 JSON 重载；修改算法字段或宣称教师合格会被拒绝。模型不校验
外部文件身份，也不执行技能；实际拟合调用方必须先认证原收据、
原始轨迹和复核封印。候选参数仍由已验证的显式仿真控制接口约束。

## 不能宣布什么

- 训练初态上选择到已有成功，是回代/记忆结果，不是新物理成功。
- 第一代五臂的事后并集 12/16，不是这个模型的未见状态成功率。
- 这不是通用接球模型；高质量首次触球不等于成功接住球。
- 即使训练集全部安全，也不能当成查询状态的安全保证。
- 没有新闭环执行、独立回放、保持与扩展/扰动证据，教师资格始终为假。

## 后续固定检验

先冻结完整拟合矩阵及模型，不混入尚未完成的候选。新查询只取前缀
初态，不读取其未来标签；相同的世界、初态、采样协议和原父代对照
需重新核对。每个选中控制必须实际执行完整 H300，并通过 CPU 动力学
回放和 Foundation 重算。逐初态记录旧成功损失、安全退化、删失与
未知，未知不能从分母静默删除。

若未参与拟合的状态不能获得净收益，或旧能力/安全退化，该组合方向
失败，不自动进入长期 PPO。不允许以训练回代成绩替代 G3/G4/G5。
