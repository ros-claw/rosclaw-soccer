# 当前动作记忆上的恢复数据与保持合同

两组 current-prefix 接管完成后，数据准备必须重新认证所有来源与独立审计，
不能从 stdout 的成功行直接生成专家标签。新数据版本为
`paid.growing_motor_memory.TRAIN_features.v1`。

冻结的父代不是早期 Af46，而是已经通过两个首脚难点的 201 项动作记忆模型。
历史 21,922 个 own288 观测重新计算这个**当前模型**的实际输出，将其作为
零差值保持锚点。与旧理想教师目标的差异必须不超过 2.1e-6 rad；原始旧数据、
旧目标和旧轨迹清单完整保留，不伪称新保持标签仍是原教师动作。

周边开发集原有四个成功场景优先保留其实际学生行为。对其余场景，只有接管 80
或 96 两次完整重复均完成高质量触球且恢复健康时，才允许作为新的行为来源。
若两种行为都成功，按最坏横向偏差、最小前向进展、较早接管顺序选一条，
不把冲突风格平均；全部未选行为和失败依然留在可审计来源档案。

新轨迹始终从第 0 帧重建 R2 h/c，检查上一实际动作链。接管前是当前学生实际
执行的成功前缀，不是专家；接管后才是实际执行的专家动作。未执行的教师建议
不可成为标签。新修正目标为实际动作相对**当前冻结父代**的关节弧度差。
最终 R2 ±0.2 rad 和相对 ±0.4 rad 权限不变。

已有或新选择的完全相同特征若出现不同目标，必须拒绝；不删除保持锚点、不平均
冲突标签。兼容重复只保留一份，记录原始帧号和去重数量，不膨胀样本数。
完整数据须能从原始成功行为、当前父代及固定选择规则逐位重建。

这次明确消耗周边开发银行作为下一代 TRAIN，未来对同一 32 场景的改善只算学习
及保持证据，不算新的泛化考核。原始 DEV16 和所有 Fresh 的特征仍不准参与拟合。
后续还需要新分布测试和实际物理收益；物化数据完成不算模型已经成长。
新模型不能静默放宽旧 checkpoint/data loader，须使用显式的新父代类型与格式。

这一阶段还只是受控触球的持续学习证据。不得代称完整接球、无缝助跑、球门命中、
多角色自主比赛、商用宣传授权或真机权限。
