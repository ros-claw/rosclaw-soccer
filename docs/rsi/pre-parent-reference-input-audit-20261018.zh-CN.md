# 面向参考策略学习的输入重建：不是再次训练小力矩残差

## 已真实完成的工作

新增 `pre_parent_reference_features.py`，复用现有50Hz当前身体状态
编码器，不复制一套几何/姿态转换。每帧135维：原有身体与球相对
状态、修正前的导航目标、上一帧实际参考增量、上一帧已完成接触力，
以及本帧剩余任务时间。初始历史动作/接触力为零。

这里特别修正的是**新接口的设计**，不是发现并宣称旧已执行模型
存在泄漏：当前教师的接触增量是待学习标签，不能作为本帧的
`nominal_target` 输入。学生输入必须使用此前已由SONIC提交的导航
目标。父代motor在学生给出新参考后重新计算，不能贴上教师旧轨迹
的父代输出，更不能把不同轨迹相减当作同状态监督。

新模块只重建输入/标签，不拟合模型、不导出训练银行、不修改任何
在跑的生产源码。球与身体输入仍来自原SIM当前运动学观测，不宣称
真实视觉、接触传感器或部署感知已合格；没有未来碰撞时刻、任务
得分、教师族、课程ID或事后路线编号作为输入。

## 下一步如何真正进入学习

1. 当前十身体全部结束、完整审计和全身接触诊断完成，逐课程检查
   净救回与退化；不因先看到C6/C7通过就免去剩下八个身体。
2. 只有作用域和可重复性得到支持，再用独立新研究声明组织数据。
   历史轨迹只作已消耗开发数据，不作Fresh。三控制族的同一课程
   必须落在同一数据分组，不能将相邻帧或配对轨迹拆到训练/验证两侧。
3. 复用Core已有 `CausalResidualMemory` / recurrent imitation 算法，
   为**新的参考动作语义**增加适配与独立重建。旧 recurrent motor
   虽也有135维，但最后一维是phase，不能偷换语义继承旧权重。
4. 学生在自己的当前身体上生成参考，父代重新推理；先做零输出
   全轨迹非干扰复现，再做有界闭环学生。离线损失下降不是能力。
5. 教师可而学生不可时，才能把重心放到on-policy DAgger/观测分布；
   保持旧成功，再进入三独立训练种子和新的隔离物理考试。不得
   自动激活Champion，不把本轮数据重建称在线RL或小脑训练完成。
