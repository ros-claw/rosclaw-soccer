# R1 发球脚归属时序诊断协议

状态：`SIM_ONLY / CONSUMED_DEV / NO_PROMOTION`。

已封存 R1 中心成功和六个 ±2 cm 失败：发球教师以最近脚逐帧选择，中心球位在前 100 帧中约第 50 帧由右脚转左脚；x-02 / x+02 相应切换约第 44 / 53 帧。中心的承诺后有效左脚接触在第 84–85 帧；邻近球位没有形成同等链路。这个时间相关性不足以证明因果。

唯一新干预：保持原 `0.80 m/s` 脚速、`0 s` stroke 和全部世界/战术/射门配置，令现有 SIM-only 教师 `preferred_foot="left"`。只跑中心 `(1.92,-0.80)`、x-02 `(1.90,-0.80)`、x+02 `(1.94,-0.80)` 三个已消费开发球位，种子均 `207200`、时长 8.7 s。结果须同时满足六机安全、承诺后发球脚接触、无中断脚到脚接应、接应后在真实门框内物理射门；中心不能退化。任一球位失败均保留完整轨迹，不能由初始右脚碰球或球速峰值代替传球成功。

若三球位不能全通过，停止“固定脚归属”路线；若全通过，也只允许进入新的未见球位和来球干扰的 Fresh 考试，不直接晋升。此实验是构造多样成功教师样本的尝试，**不是**数据驱动学习、最终执行策略或可宣传视频。

## 已执行：硬拒绝，并发现中心成功的前置依赖

中心、x-02、x+02 三个固定左脚对照全部 `0/3`，最大球速均仅约 `0.000518 m/s`，球几乎不动，也没有形成承诺后的脚到脚接应。三个完整报告和轨迹分别在 `/data/rosclaw_overflow/rsi-r1-left-foot-commitment-20260928-{center,xminus,xplus}-v1/`。这证伪了“直接固定有效左脚可扩大成功盆”的假设，**停止**该参数路线。

再从原中心父代 50 Hz 球位和 500 Hz 接触流核对：传球请求在 `0.420 s`，此前右脚于 `0.380 s` 偶然先碰球；球从第 18 帧约 `(1.9234,-0.8007)` 滚到第 84 帧约 `(2.1051,-0.8098)`，之后左脚于约 `1.716 s` 完成被接触链认可的发球，接应脚于约 `3.008 s` 触球。固定左脚后连前一次右脚预触都消失，球静止。**推断**：当前单点父代强依赖预承诺右脚触球造成的球位重排；但固定左脚也改变整段身体反馈，因此不能从此单一消融量化“右脚预触的唯一因果贡献”。

工程判断：这个父代不是已学会一般球位发球的证明。下一门应让发球角色从多种球位、初速和左右足几何中完成**承诺后的首触**，并保留非脚碰球、身体稳定、随后接应和旧中心保留门；不要再在这条极窄成功轨迹上继续追射门参数。
