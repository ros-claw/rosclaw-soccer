# 持续实施循环与小脑身份复盘（2026-10-22）

目标仍未达成：没有可靠、可宣传的自主连续4v4比赛成果。本记录不是验收通过。

## 循环的真实边界

宿主平台的 active Goal 负责接续 Agent 推理；systemd 管理已声明的仿真任务；分钟监控只观察，不会自行唤醒模型、提出科学假设或决定晋升。不能把定时器在线当成“自进化在线”。

本次新增全局 dispatch 状态：

- 已全部结束：`AGENT_SUCCESSOR_REQUIRED`，要求认证结果、声明后继阶段。
- 失败、观察异常或疑似停滞：`AGENT_REVIEW_REQUIRED`；不得静默重试已计费的物理轨迹。
- 有实际运行/排队工作：`DECLARED_WORK_LIVE`，仍不代表学习收益。

每次阶段转换保存冻结提交、输入承诺、实际步数、失败记录和外部恢复指针。平台退出、断电或服务故障不能靠提示词保证永不中断；恢复依靠这些检查点，而不是假称在聊天关闭后仍能自主思考。

## 实际完成与未完成

本轮已完成继承基础小脑的8世界对照：2组退后距离/速度 × 直接参考动作或速度模型加自身R2影子历史 × 2次重复，共33,920个原生物理步。四个条件的重复不是8个独立条件。该试验无梯度更新。

与原current201相应8世界比较，所有保存数组逐元素相同：初态、网络输入/输出/隐状态、身体和球的每2ms轨迹、接触力、速度模型、站立阶段。结论仅是：在这些轨迹上，去掉外层残差未改变行为。不能说外层残差在全部任务中无用，也不能宣称训练取得新进步。

两种距离下均未摔倒、站立阶段稳定；较远条件仍出现非脚部触球，较近条件通过既定粗粒度接触质量规则。规则的横向阈值为0.75m，并非用户要求的0.1m目标精度，也不是高死角、进球率或完整比赛验收。

## 独立审计暴露的身份错误

旧试验把 `actor.base` 命名为 `published_R2`，此名不正确。加载链会从原始ONNX构建网络，再加载历史蒸馏/训练检查点。`base` 只是对象层级，不是权重来源保证。

独立审计直接从发布ONNX构建网络，在第1个网络输出就发现不相等，物理步数为0；该失败被完整保留。这是审计有效拒绝错误身份，不应放宽为近似相等。

更正方式：

- 旧闭合轨迹和声明保持不变，不篡改历史标签；新审计记录身份纠正。
- 来源链由显式证据哈希绑定，不依赖文件夹名称。
- 未来运行器区分 `current201`、`inherited_base`、`pristine_published_R2`，拒绝歧义旧选项。
- 新运行器写入 `motor-identity.json`，列出继承基础与原始网络不同的张量，完成回执绑定其哈希。
- 真正的原始模型对照包括触球后站立网络也使用原始权重，避免暗中借用已训练的站立能力。

当前进行两个有区别的任务：修正身份后的继承基础独立整世界审计，以及真正的原始发布网络8世界对照。结果待核验，不提前声称收益。

## 后继科学决策

原有离线固定状态的均值回放、尾部困难回放、负样本保护核均未通过保持性验收，不继续靠增加同类epoch或扫门限掩盖平台期。

认证上述对照后，应从真正起作用的已训练小脑出发，围绕实际接近球的自身状态采集成功/失败及专家干预，开展on-policy模仿/DAgger，再验证保持性和新情境。基于实际物理前缀的专家搜索与完整复演先于新一轮网络训练。单次试验通过或代码测试通过均不得晋升为球队能力。
