# 整体动作参考跟踪：阶段入口，不是踢球突破

## 持续实施的实际机制

产品 Goal 保持 active，终点仍是有证据的连续自主球队比赛，而不是某次
模型拟合变好。官方 Goals 文档说明：工具执行轮结束、线程空闲且没有
待处理输入/工作时，产品才检查自动续接。阶段轮结束不等于目标完成。
每一轮应执行实际开发、实验或分析工具，并持久化下一步，避免无工具
的状态汇报轮导致自动续接被抑制。

参考：<https://developers.openai.com/cookbook/examples/codex/using_goals_in_codex>。

本地 systemd 观测器只读取进程、完成文件和依赖状态，不能唤醒模型、
自行开发或选择新的科研方向。有限实验服务可以独立完成已声明的队列，
但不能据此承诺断电、产品关闭或额度耗尽后仍会持续推理。

工程循环应为：声明可证伪的问题 → 固定代码/数据/预算 → 运行 → 独立复核
→ 接受或保留失败 → 明确下一实验。连续失败应更换方法，不能放宽验收。

## 为什么转向整体动作

触球后的短时力矩与速度响应模型已有局部诊断收益，但尚未证明球队运动
能力提升。下一步隔离验证：完整29关节动作参考能否由冻结 SONIC 在自己
的身体反馈下跟踪，而非继续只修补触球后的力矩。

新模块 `sonic_reference_preparation` 要求显式来源频率，线性重采样关节与
根部位置、SLERP 旋转，保留29个通道。根部位置和航向做明确参考重锚定，
并用一秒参考入场连接当前实测姿态。物理身体不重置/瞬移；根部XYZ不被
此 SONIC 编码器用于笛卡尔跟踪，重锚定也不是脚底/地面校准。

姿态入口、连续性、关节范围与四元数检查保留，源动作不裁剪、不静默
放慢，不自动修改既有编码布局。依赖现有 `training` 与 `diagnostics` extras。

## 首次真实数据入场发现

固定来源足球 `BGI_Shooting_00001.csv`，SHA256
`5d7f68046daa9159faa6f4ce0fc439ad58205325fe9aecd923a060600916db73`。
993帧，声明120Hz，完整重采样414帧，加50个入场间隔合计464帧。

全片段被现有连续性合同拒绝：重采样后最大根部位移约0.2782m/20ms，
最大关节跳变约0.5902rad/20ms。原始根部突变在982→983帧；关节突变
也存在于更早区域。不是物理失败，也不代表整个数据集无用；没有据此
平滑或放宽阈值。检查本身物理积分0、优化更新0。

## 独立的首四秒可行性协议

`scripts/rsi_probe_timed_reference.py` 预声明两臂：实测初始姿态保持、
原来源0..480帧首四秒。两臂都经过同一个冻结低延迟 SONIC 编码器/解码器，
使用各自实际身体的本体感历史和原PD/力矩限制，不播放qpos。

采用现有H300原生身体，每臂300×10个2ms积分，总6000；球静置10m处，
不是任务目标。动作臂含50个入场间隔、201帧源参考，然后显式终态保持。
首四秒是几何入场隔离窗口，不能代表完整片段或完整射门，不能给它贴
M0通过、进球成功或自然动作已解决的标签。

输出原生q/v、控制、实际力矩、接触和参考/神经动作，报告实际关节跟踪
误差与根部状态。数值/求解异常保留failure；跌倒的有效物理结果也保留。
后续独立记录目标重积分后，才能讨论跟踪结果；没有预先声称会成功。

代码与资产在导入前及完成后固定；不可热改运行源。模型没有优化更新，
因此即使跟踪成立，也只是接通已有神经小脑，不是新训练或在线强化学习。

MotionDecode 本地许可限制为非商业研究/原型并要求署名。本轮只做内部
研究，不复制动作到MIT仓库，不据此制作商业宣传或发布派生权重。

## 动态窗口银行：下一项实际试验

固定取来源目录按名字排序00001..00016，不追加替换。每个来源只选择
12个腿关节角速度范数第一次达到最大值的时段，取以该时段为中心的四秒
窗口（受来源端点限制），保留所有29个关节，不修补手腕或改变时间。
这只定位运动较强的参考，不代表该峰值是有效射门，也可能暴露来源突变。
选择后仍须通过相同姿态连续性检查；失败不回退到安静段。

新 `sonic_motion_window` 负责无物理的选择和入场，
`reference_tracking_episode` 负责一个完整H300的自身体感神经跟踪，
`rsi_probe_dynamic_motion_bank.py` 负责全部16项声明、先入场后物理、
保留拒绝项和所有有效物理结果。它们不把足球细节放入Core通用能力。

只读预检中00005和00006窗口入场，另外14项拒绝；还不是动态执行结果。
两条各3000步，总计划6000步。球仍在10m处，先检验摆腿能否执行，再进入
脚球接触训练。不能以几何入场证明动态成功、不能删除跌倒结果。

## 动态窗口结果与明确的手腕参考消融

动态窗口两条均完成6000个新增积分，冻结c855bf60。00005/00006关节RMSE
分别0.11569/0.10902rad，骨盆最低0.73650/0.73715m。源c117c2b9独立复算
再积分6000步，16项入场、2条参考和全部原始物理数组逐位一致。
证据为 `rsi-dynamic-motion-bank16-20261020` 与
`rsi-dynamic-motion-bank16-verify-20261020`。不是训练成绩或完整踢球验收。

最大腿关节角速度不一定定位射门，可能选到收腿或来源突变。因此新试验
改用来源FK的根坐标系内脚踝前向速度作为运动线索，不使用仿真成绩或
真实未来球状态选择相位。此线索仍可能是迈步，不自动等于踢球标签。

00001来源的右脚线索在526→527帧，约2.013m/s。围绕它固定四秒窗口
286..766帧。完整原参考仍会因手腕不连续被拒绝；本次显式消融只将六个
手腕参考通道保持在实测入场角度，腿、腰、肩、肘、根部和时间不改。
`sonic_wrist_quarantine` 保留原数组/消融数组/入场哈希及移除的变化量。
这不是修复或认证原始数据，也不再声称是完整29关节来源模仿。

不同于偷偷滤波，本试验单独声明来源修改、重新固定源码和输出，保留
原窗口被拒绝的记录。物理身体任何关节都不直接设置，仍由SONIC依据
自身体感产生29关节目标，经原PD/力矩限幅积分。

## 九场固定触球先导协议（未先验声称成功）

`rsi_probe_foot_contact_reference.py` 先运行一个球静置10m的消融参考臂，
再对四个固定静止球位各运行“初始姿态保持”和“消融动作参考”两臂。
球位x=0.35/0.50m，y=-0.10/-0.22m，均保留标准半径0.11m、质量0.43kg。
共9个H300身体、27000步计划预算；4个球位、1条来源，不是9条独立课程。
没有根据先跑出的结果增删球位或动作，没有新神经优化更新。

新增可选全接触记录：每个原生2ms子步保存所有body与球的接触力范数，
包括地面和非脚部。机器人非脚接触由机器人body树整体分类，不只膝盖。
开关默认关闭，原记录字段和控制律不变；合成身体两种开关对照验证所有
原物理字段逐位一致。统计明确采用接触求解器时刻、积分后自由关节速度，
不与其它研究的缓存物体速度混用。

只报告第一次脚接触、第一次非脚机器人接触、球前向速度/位移/高度等
原始诊断，不把它升级为M0进球、自然动作、小脑新训练、球队或硬件资格。
来源许可边界不变，尚不能据此制作商业宣传。

## 九场实际结果：拒绝“固定参考就是足球策略”

源b81fb23d完成9个身体27000个新增积分，源ad5a5a38独立进程再积分27000步，
原始物理数组（含全body原生接触记录）逐位一致，来源消融、相位、参考与
统计均重建。所有四个球位，两种控制臂都没有超过1N的脚或非脚机器人触球；
球水平位移和前向速度均为0。结果不通过，不能据此继续宣称动作模仿已解决
足球技能。

但要准确定位失败：静置球臂的右脚实际抬高到约0.251m，参考FK约0.268m，
确实产生了摆腿；实际最大根坐标系前向脚速度约1.30m/s，参考约1.92m/s。
世界坐标右脚踝中心最大前伸只有约0.087m，预设x=0.35/0.50m球位没有触球。
脚踝中心不是碰撞表面，以上FK本身不代替碰撞测量；零接触由原生记录确认。

另做只读负对照：四个不同球位的300帧神经动作、关节目标、机器人本体q
都与球在10m处的动作臂逐位相同。这里的固定参考控制器只消费运动参考和
本体感，不直接消费球状态；在无碰撞时当然不会调整动作去找球。这不是
ROSClaw全局从来不看球，而是本轮新接入的模仿跟踪支路缺少任务条件层。

下一阶段应处理球状态→入脚位置/姿态与时机→参考和残差控制的闭环。
优先复用现有导航、同一身体的神经历史交接、球条件134维运动观察和已有
PPO接口，先定位各自的数据/接口契约，不能不加判断地换成新训练算法。
尤其不能把球移到盲动作恰好经过的位置，就宣称球员已经会主动射门。

本轮新神经优化更新仍为0。正向收获是接通数据参考、全身反馈跟踪与完整
接触证据，并反证单独固定参考不足以解决足球任务；不是球技或球队突破。
证据：`rsi-wrist-reference-contact9-20261020` 与
`rsi-wrist-reference-contact9-verify-20261020`。
