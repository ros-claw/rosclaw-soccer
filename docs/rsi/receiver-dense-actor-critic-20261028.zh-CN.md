# 接球失败轨迹的密集反馈学习声明

使用 72 条已执行、密度已审计的接球采样轨迹及原始 MuJoCo 物理数据。严格接球正样本为零，因此该试验不是严格成功率训练，也不改动现有的正样本训练准入门。仅作仿真探索：按控制周期将物理密集反馈乘 0.2，加上原始严格终局反馈；按 0.99 折扣计算蒙特卡洛回报。球自身运动可能改变距离，首次脚触球奖励也不等于合法接球，必须防止奖励投机。

对每个固定种子训练价值网络三步，再执行一次基于实际采样密度的有界 actor 梯度；使用旧能力的 5,201 个健康锚点和完整轨迹条件 KL 约束，超界自动回滚。记录每次尝试、参数是否更新和数据哈希。全部 72 条数据均用于开发，锚点也来自既有条件；没有独立测试集，不依据训练回报选择成功案例。模型必须通过独立权重校验、原技能保留、未参与优化的双机器人 MuJoCo 实验和严格接触/失衡指标，才可声称仿真效果改善。离线更新不是在线强化学习，不授权真实机器人。
