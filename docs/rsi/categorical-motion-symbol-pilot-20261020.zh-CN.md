# 从连续均值到显式离散运动符号：有界三种子先导

## 为什么换表示，而不是继续缩步长

组内留一actor学习后整40从4降到1。后继动作记忆保护进行了2次实际
CUDA更新，第3次提案的13个alpha都不可行，完整回滚。自动后继完成
整40与独立神经/肌肉/native重放，共240000 native；成功仍是0、10、
15、16，4/40，身体40/40、非足18、validation0。无救回、无遗忘，
必要增长门不通过。它验证了“不忘”，没有验证“会学”。

旧连续raw均值最大约.001的变化，曾使原成功轨迹43–65帧离散Token
改变，身体分叉与首个Token变化帧一致。仅Gaussian KL小不保证离散
部署动作保持；硬保持又把当前Adam方向限制到非常小的实际步长。

本先导直接预测原FSQ32的类别，而不是继续用MSE/直通量化梯度或
Gaussian密度代理部署时的离散选择。这是可证伪的新表示实验，不
是已经获得突破，也不能将失败唯一归因于量化。

## 架构与初始化

- 冻结已消费开发集的4/40研究锚点，不称为canonical Champion。
- 原本体观测108、原循环记忆和当前FK保留；actor输入为归一化当前
  108、冻结锚点当前raw均值64、当前可测几何26，共198维。
- 新分类头198→128 ELU→64×32 logits；所有类别对应原合法符号
  `(class-16)/16`，不混合不兼容动作，不改肌肉decoder/PD/世界/球。
- 旧锚点确定性符号的logit先验为4，其余0；新头输出层权重和bias
  初始全0，故初始argmax严格选旧符号。旧GRU隐藏状态由当前自身
  物理历史推进，actor不接收课程ID、标签、未来参考或成败。
- 分类和旧连续策略不是相同policy-gradient算法。这里是监督动作
  表示先导，不声称在线强化学习或actor-critic训练。

## 固定数据和训练预算

使用原40银行，只取8个非冲突的成功train教师课程
2、6、12、22、24、32、34、36；加研究锚点成功train记忆0、10、15、
16。相同课程有不同合法计划时优先保留自身记忆，不平均两种标签。
12条完整H300序列仅12个已消费上下文，不是新物理数据。原所有失败
和验证集证据保留，不加入本成功示范监督，不伪造其成功标签。

标签来自原生已验证动作及实际ONNX运动编码；训练监督20..299帧。
按序列/帧/维度平均CE，自身记忆权重2、教师权重1。固定seed17/29/43，
每个1000次Adam、lr3e-4、clip1，无调参扫描、无中间checkpoint择优。
只更新新分类头；父代、critic、归一化、肌肉网络全部冻结且结尾逐
张量字节核对。GPU缓存只含这些实际当前观测的冻结输出。记录符号
准确率和整帧64符号准确率，后者也不等于闭环物理成功。

## 原生闭环与否证

1. 源/数据/世界/父代哈希在分配模型前验明并封存，输出路径不复用。
2. 先以initial零头在四个旧成功课程0、10、15、16实际积分H300，另
   独立重算分类器/肌肉/native全过程；与原锚点所有物理字段、本体
   观测、循环隐藏状态、Token和肌肉历史逐字节一致。增加24000 native。
3. 初始probe未通过则阻断所有candidate考试，保留故障，不改门槛。
4. 各训练终点在完整40上独立执行并逐步独立重放，各240000 native；
   仍用原prefix20、H300/post60和原评分。3个终点都报告，不挑一例
   成功镜头、训练loss或某个中间模型冒充整体结果。
5. 研究必要门仍为成功>4、0/10保持、身体40、非足≤18；即使满足，
   还要隔离Fresh、远球/旧52和比赛衔接，不自动晋升、不拍成球队成果。

若训练符号拟合很高但原生仍退化，则支持自身分布/示范恢复性不足，
而不是继续堆CE epoch；若连训练记忆都无法拟合，则检查分类头容量、
输入可辨识性和类别学习。若旧动作保持但无救回，则离散化保护不是
充分突破条件。三种子均无净增长则停止本族无界重复，回到可证伪的
控制/示范覆盖或动作表示研究。总Goal保持ACTIVE，不把本先导当终点。

SIM_ONLY；外置数据/运动资产的非商业许可限制不因新分类器消失，
本实验不授予商业宣传或真实机器人权限。
