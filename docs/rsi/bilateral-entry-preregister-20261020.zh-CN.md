# B组：接触脚与进入位置的闭环对照（执行前规格）

## 为什么值得试，什么会推翻它

旧三种接近律×两接触偏移教师有6/16成功，CEM和同时间速度交接均未扩展成功域，停止各旧族。本轮不是再调gain/曲线，而是1013建议B组明确包含的接触脚与进入位置：单侧动作和其进入几何是否限制了靠近球的可达性？用对侧运动数据增强而不是改实际身体状态来检验。

原生481帧/20对身体FK审查发现：六对腿完全镜像、原生关节限位无越界；14对上肢/手有10微米误差，原因是编译模型肩节点局部Y为0.10022/-0.10021。第二封存审查传播这处原生偏移，所有40身体未解释误差≤1.624e-15米，旋转误差0。原全身1e-6严格反射门保持false，动态资格false，不修改模型或放宽门。本研究是带已知编译不对称的**受限动态可达性实验**，不是宣布全身镜像/左脚技能认证。复用该具体审查的哈希及原始世界/源文件绑定，不把FK当作运动成功。

## 冻结控制与预算

1. 原16公开近球扰动条件全部执行，原世界/0.11米0.43kg足球/PD/限位/冻结SONIC低延迟模型与584布局、H300/post60、进入门30..90和原评分均不变。与原M0/52/Retention/Fresh和团队比赛区分，不改考试。
2. 每个世界先用原右脚历史进入先验和原导航执行自身20拍共同前缀。从同一本体与神经历史预览六个旧右脚锚点，并要求全部18数组与原认证锚点一致。原六候选保留可选。
3. 再从同一自身20拍状态分别按原三律0/3/4执行三个左脚候选，不跳过失败条件，不依据课程ID/旧成功标签挑脚。只反射源参考：左右关节交换，roll/yaw反号，pitch/knee/elbow同号，根Y/四元数按矢状面反射。原50间隔桥接、286:767窗口和120Hz→50Hz时序不变；不使用已停止族的更短交接、不叠加右腿C修正，左脚候选C恒为0。
4. 进入几何只对原历史右脚先验的Y符号反射（X不变），且显式新合同描述“推导的镜像先验，不是历史执行过的左脚运动”。从第20拍开始，原反馈律用自身当前状态追该进入目标。当前实测q/qvel、身体、球、控制历史一概不反射、不迁移、不重置。源参考腕部在实际交接时仍按自身测量隔离。
5. 每课严格9次完整280拍预测，共25,200原生子步；所选模式从原共同前缀独立重新执行280拍，实际H300=3000子步；每课28,200、16课总451,200。独立复核另计。没有CEM更新、没有actor/critic梯度更新；这是为找到可学习物理控制权限的教师研究，不得写作神经网络已经学会。
6. 使用原qualified/cost选择，完全同分时保留低索引旧候选；无合格时执行原名义且明确未认证fallback。实际轨迹18数组及报告必须逐位等于选中的自身完整预测，交接不能改身体状态。预测不能把未来目标数组塞给实际控制器。
7. 新左脚候选逐个记录实际足部球接触的原生力、首次接触侧与时间，所选实际H300另记完整接触侧。左右脚参考标签是意图，若先接触的是右脚/双脚或未触球，不能称为左脚踢球成功。原评分不因脚的标签改变；新增成功还须检查是不是导航期间提前触球，区分进入几何作用与对侧踢球作用。

## 结果规则

至少7/16、保留全部旧6且无新增不安全，才值得对完整候选进行独立记录控制物理复核和扩大至40不同条件。每律应报告交接率、真实触球率、触球后合格率、非脚接触、稳定性与成功/失败对照。任何新成功只属于公开静止近球诊断，不能自动晋升或上宣传片。

若仍6/16，停止“直接镜像现有单侧参考+固定反射先验”这条族；不继续扫左侧偏移/增益/N来制造进展。这不意味着左脚动作不可学习，而是表明简单数据增强不够。下一方向应进入真正球条件化的闭环接触权限或已有有效教师上的扩展扰动与神经蒸馏，不继续无限增加参考插值补丁。若工程失败，保存已执行子步与故障，不能把失败当作未适用样本删除。

MotionDecode与现有权重许可边界不变，SIM_ONLY，无真实硬件。执行前源封存、完整课程零actor admission、结束哈希复查；四个独立systemd进程，不使用multiprocessing。观察器不是学习器，不能用其存活证明科研在运行。
