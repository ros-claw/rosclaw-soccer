## 失败机制一：脚触后实际小腿碰球

重放完整 3,000 子步，匹配原 qpos/qvel、力矩、接触力、球位和高度，
并被动记录真实碰撞几何：首次脚触第 77 帧；右小腿 mesh（geom26，
归属 `right_knee_link`）首次超过 1N 的接触在第 92 帧子步 8，
接触点高度约 0.182m，首次记录约 96.15N；共记录 22 个接触子步。
这不是“膝中心”直接碰球，也不是额外放大的球形碰撞体。

由约 0 跳至 1.4m/s，第一次小腿接触约晚 0.30s；这提供了时序线索，
不等于已证明该命令跳变是原因，不能据此宣布减速补丁会解决球技。

## 失败机制二：远处滚离球的时距

在最后可完整测量球路的第 239 帧，球—根部前向间距分别约
0.65145m / 1.36169m。该间距不是脚表面距离，也不能单独证明
整个控制接口不可达；它说明当前执行尚未进入触球条件。
