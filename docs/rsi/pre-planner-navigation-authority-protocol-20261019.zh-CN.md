# 下一控制权限：规划前导航，而非更多同IK模仿

## 为什么研究这个，而不是重复旧实验

当前同接近zero的c0/c1均通过，学生c1失去能力；c2/c3均无足触球，
c4在151帧足触但前向0.638887m、侧向0.311131m而失败。原IK教师
在前两个来源没有额外任务净收益，不能继续将这些教师标签当成
已有跨训练来源优势。不是宣称所有12D参考都无用，而是否定继续
盲目模仿这一个教师族的依据。

复查现有代码确认导航命令在Foundation之前进入SONIC planner：
默认300帧内只有0/20/…/280十五个规划事件；默认不支持batched
command-event重规划。新规划从事件帧+10改写尚未执行的参考，
但encoder读取十个stride-one未来姿态。因此不能把“参考写入+10”
误当固定200ms身体延迟；最早影响还取决于规划器输出的上下文
前缀、encoder消费和Foundation跟踪，必须实际测量。

复用现有`NavigationObservation`/`NavigationDelta`的values-only
思想、冻结的Foundation与父motor。旧3v3/Isaac导航实验和10月16日
portfolio的世界不是当前mesh世界df743dfc，不能继承其成功标签。
此前mode2/3、纯Foundation、2.0速度和简单快重规划的研究及失败
也不重跑，不把提高请求速度/刷新频率当作解决方案。

## 固定第一项权限实验（尚未接入原生入口）

`PlannerNavigationPulse`是已实现的纯数值适配器，不是训练模型。
只接受OFF或固定横向请求-0.08m/s，控制帧[100,160)生效，覆盖
100/120/140三个既有规划事件，160回到基线。前向和yaw不变，
横向仍限±0.2m/s，总速度仍在原1.5m/s包络；不改mode、lookahead、
重规划频率、关节与硬力矩限制。OFF和非活动帧保持原tuple全部位，
包括signed zero；不是新增无界pulse参数扫描。

拟固定3个已消费训练课程，不拿验证来源96选参：

- g28/c2、来源78：NAV无足触球，研究接近/足位可控性。
- g76/c4、来源93：NAV足触但球路失败，研究结果可控性。
- g12/c0、来源77：NAV安全通过，作为成功保护对照。

每课先OFF再固定pulse，OFF必须全300帧复现该课原9体zero的全部
原数组，不能只比帧0。计划6native+6独立CPU共36000个2ms子步，
再6条原力矩18000步密集诊断。仍是3课程/3来源，而非12个独立
课程。全量基线收据需等正在运行的9体/审计/密集诊断实际闭合，
不使用未终态前缀冒充完整来源，不热改当前5f3源码。

必须使用同原zero腿部参考、同父mean与世界，不能同时启用IK、
新小脑、run、postcontact或其它干预。不从零参考改成纯Foundation：
后者还移除了父motor，会重新引入混杂。

## 必需的实现与证据链

当前只有纯适配器和16项数值测试通过，原生入口/完整执行/审计
尚未实现，实验未排队，也没有新身体成绩。后续必须补齐：

1. default-None不改变旧内核算术；新的显式SIM-only、零参考与父
   身份校验，拒绝混用和真实硬件。保留原默认AST变异守卫。
2. 记录原baseline、请求残差、投影后命令与原始15个规划事件，
   由独立标量规则重建整300帧，不调用生产compose自证。
3. 先写intent、固定源/输入/预算，验证确切spawn入口与未定义
   名称，再分配最多两个本项目完整工人，入场可用内存≥56GiB。
4. 实测命令→规划参考→encoder→Foundation原动作→父motor重算
   →执行力矩→脚/身体/球响应的第一个分歧与幅度，不能只说请求非零。
5. 完整独立CPU、Foundation、planner/encoder审核、原M0/H300/
   后60帧/安全门和全部失败/删失保留，不能拿漂亮新场景代替结果。

若命令确实产生身体控制但本固定pulse无任务改善，只证明权限，
不将其当教师或无限扫描同族。若出现安全或成功保护退化，也不能
晋升。只有跨训练来源出现可重复净收益、扰动保持后，才研究
低维导航/相位的有界神经actor-critic；按真正消费的规划事件定义
动作与信用，而不把未被planner消费的50Hz请求虚构成300个动作。
连续球队/传射扑救、至少3训练种子、Fresh及52课程净增长仍未达成。
