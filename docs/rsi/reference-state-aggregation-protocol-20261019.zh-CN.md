# 有限自身状态聚合：拟议数值输入与下一实验决策

## 假设与证据边界

首个学生已完成完整身体、审计和密集复核：positive0/8，教师4/8，
并出现旧技能损失。原因不只是离线拟合不够：固定教师身体上的
自反馈误差增加，以及学生实际到达状态与专家参考偏离都已记录。
去过去动作依赖的模型5ff3c004正在自己的13体考试中，冻结源码
d63418a5、PID3135275；这个实验不能改动、提前删除或重启。

新的研究假设：如果模型仍在原专家可达课程失败，那么把**学生
实际到达的状态**与**同状态专家建议**聚合到原示范中，可能改善
身体闭环。查询器已逐位复现8教师，实际查询原学生3900帧且缓存
误差为零；但专家建议从这些学生状态继续向未来成功尚未证明。
因此这只是有限数值研究候选，不是自动取得物理合格标签。

## 输入必须保留什么

拟议输入29条完整序列，8700帧，但绝不是8700个独立场景：

- 原16条教师/None全部保留，不删失败。
- 原13体学生考试全部保留，包括OFF、零参考、失败、不安全和保持。
- 学生输入直接来自原捕获的135维actor特征，保留它自己实际执行
  的过去增量；不能从专家建议反算输入，也不能把另一条教师轨迹
  的同帧动作当标签。目标减NAV的减法可能与actor历史有浮点差异，
  因此对非过去动作的123维逐位核对，过去动作取实际捕获值。
- 标签来自同一身体、同一NAV、原2ms缓存时钟下的专家查询。

仅做**拟议数值监督选择**：原合格教师12/13/76及对应原学生状态
构成6条train序列，1620个正权帧，仍只有20261077/20261093两个
train来源。原验证93及对应学生状态为2条验证序列，来源20261096
严格排除梯度和归一化。其它21条仍保留，不是负梯度失败样本。
所有来源的扰动和控制器必须在同一分区。

原查询记录的`eligible_for_training=false`不改写。独立拟议批次用
`experimental_numeric_supervision`说明这是一种新的、显式承认风险
的研究选择；`dataset_admission_authorized`、`teacher_qualified`、
runtime/hardware/promotion权限全为false。数值构造器要求显式标签
上限`RESEARCH_ONLY_COUNTERFACTUAL_EXPERT_ACTIONS_NOT_VERIFIED_SUCCESS`。

本阶段`rsi_prepare_reference_state_aggregation.py`只重读、认证、
重建和持久化拟议数组，不拟合、不积分、不重推Foundation。
后续拟合必须另行声明，不能从“准备完成”推断开始训练或已学会。

## 后续决策，不无限扫同一族

先看正在运行的新13体完整身体结果与审计/密集证据：

1. 若新学生局部技能已有可靠收益、无positive新增不安全，优先
   做独立训练种子、泛化、适用域和保持，不机械叠加同数据拟合。
2. 若在专家可达positive课程仍退化，可声明**一次**有上限的
   聚合模仿学习消融，保持135→64→12和过去参考零权重，复用Core
   的因果序列学习器，严格执行来源级隔离，再做独立身体考试。
3. 若主要是域外保持失败，如负向来球32零参考本身已不安全，
   先审查接近策略适用域/原父代fallback，不能只用接触网络加epoch。
4. 如查询/聚合不能改变自身身体失败，记录反证，转向更充分的
   多来源教师或动作接口研究，不为未通过候选自动扩展无限训练。

还必须补足学习因果基线：现13体positive学生与原None对照包含
接近策略差异，而当前只有raw4/32做了同接近的零参考。若新学生
有局部正结果，在宣布“学到”的更强结论前，应另声明对应8个
positive的同接近、同归一化零模型身体对照。不能把旧plan18单
探针或不同接近策略的None控制说成全部8课程的零学习基线。

本轮合成测试确实运行2步数值优化以验证批次接口，但不是实际
8700帧训练成功。最终仍需至少3独立训练种子、保持、Fresh、
CPU物理复试和技能衔接。完整球队连续比赛/宣传视频目标未达。
