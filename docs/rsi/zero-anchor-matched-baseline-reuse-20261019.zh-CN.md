# 新零锚点候选与已录制NAV的比较

新候选采用自己的训练路径归一化，不能把旧模型整体当成新模型，
也不能跳过原匹配检查。新增显式比较profile
`actual-winner-versus-recorded-zero-comparison-v1`，原profile行为不变。

只有实际actual-winner来源、完整13体学生/9体零对照、相同父模型、
世界、原教师、接近候选和正向来源计划允许进入此分支。各自zero
必须精确由各自student的归一化和原seed2026101902初始化产生。
不能把非零学习学生、IK或任意零头模型偷换成已验证的NAV。

两个zero模型都须通过现有own_model验证，参数必须精确等于原
135/64/12初始化，head_weight/head_bias严格为零；执行源码、
Core记忆、输入特征和解码器来源均须相同。归一化不同可能改变
hidden state，但有界有限hidden乘零head再加零bias，输出仍为零；
原投影包含零，原解码器在零动作时不加零向量，29个导航目标的
位模式（含signed zero）保持不变。此论证仅针对零参考对身体的
作用，不是隐藏状态等价，更不是新非零学生的轨迹或成功等价。

合成300帧测试同时运行两种差异很大的合法归一化，要求隐藏状态
确实不同、每帧请求/投影严格零且导航目标逐位相同；另拒绝非零
head、改动隐藏参数、种子、世界、父模型或未重封的模型。

正式比较仍认证原生、独立CPU、OFF全33数组等价、整个密集接触
收据和来源文件。原9体NAV物理证据并未省略；只是没有为一个
已证明等价的零控制再分配9体。新13体中的原计划两组zero/student
对照仍实际运行。所有失败/无足接触/不安全和旧技能退化都保留。

新比较不能授权优化、晋升或硬件，不能把验证通过当Fresh。此
profile只减少无信息的重复基线计算，并让新假设接受真实反证。

本地实际旧NAV模型1a9812dc与新候选75ced940派生的零控制
0aec10de已通过该纯数值等价检查，证明哈希278fe8f7；这仍不是
新学生物理结果。相关37项合成回归通过，新两个比较模块的
定向mypy通过；整仓mypy的既有债务不据此宣称解决。
