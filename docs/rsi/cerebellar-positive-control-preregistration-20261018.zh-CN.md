# 神经力矩层非零激活对照：声明

零头模型已完成48,000子步配对验收，独立读回重构24,000个因果
本体输入及PD力矩。它不证明非零输出已进入实际动力学，所以
学习前必须再做一个固定的正向激活对照，避免网络“旁路运行”。

本实验不训练、不优化技能、不挑表现好的输出方向。使用原八个
旧扰动初态选中复试及此前已固定的峰值时刻，不读取新44场考试。
源代码固定为已有`4155dc7`，原世界、PD、限幅与目标均不改变。

每个源轨迹从原初态完整重放3000子步。在固定时刻复制同一完整
MjData，分别执行20毫秒的三个神经分支：零头、正固定输出头、
负固定输出头。正模式的第j关节输出为
`0.1*CAP_j*(0.2+0.8*j/28)`，j=0..28，负模式相反；CAP沿用
`min(2 Nm, 4%原hard_limit_j)`。只修改末层bias为对应归一化
输出的atanh，末层权重仍为0，因此这些模式不具备状态适应性。
模型封印和完整参数在物理前持久化。optimizer_steps仍为0。

每个子步实际运行原神经网络，记录输入、请求／实际残差、PD后
力矩和执行器力、canonical身体状态及原球接触。三个分支目标
与起始状态相同，显式历史从0开始并在十个子步内传递，不将
局部模式切换说成完整策略行为。

验收：零分支必须与已有原目标分支相同；正负非零请求必须与
声明模式一致并实际进入硬限幅后的力矩链；对应终态关节速度
必须与零分支有可测差异。仅有推理值非零或文件哈希改变不算
动作权限。需要独立重算输入、网络、PD及实际增量。

预算为八条原完整轨迹重放24,000子步，24个局部分支240子步，
其中全部240子步实际神经前向。失败保留、不自动重试，不清理
旧失败或修改其他考试预算。没有新Foundation调用、学习更新、
Fresh、完整任务改善或教师准入。SIM_ONLY，无真实硬件权限。

正负激活对照通过后，才能开展基于实际物理经验的可学习输出。
不能把手工设置bias说成训练或进化，不能将非零动作变化直接
说成平衡更好、动作更自然或球技提升。
