# Isaac 接触失败前沿：局部动作课程审计

状态：`SIM_ONLY / CONSUMED_DEVELOPMENT / NO_PROMOTION`。第二轮新鲜保留考核见 `isaac-reactive-contact-holdout-protocol-2026-09-28.zh-CN.md`，结果已拒绝。此处仅对**已消费**的两个失败点 `(2.35,-0.08)`、`(2.45,-0.12)` 做动作灵敏度试验，不产生新的保留样本。

基底是 SONIC 前进 `0.5 m/s`、球观测触发 `+0.08 m/s` 侧移、右膝有界 `+0.12 rad`。第一次每个球位分别改用 `+0.04/+0.12 m/s` 侧移；四回合均站稳，但 **0/4** 达到整个回合纯脚触球。第二次维持 `+0.08 m/s` 侧移，分别叠加 `-0.08/+0.08 rad` 右髋俯仰有界残差；四回合也均站稳、关节投影零次，但 **0/4** 纯脚触球。所有球均被推动约 `1.33–2.21 m`，故仅用球位移作为奖励会把小腿碰撞误当进步。

原始 `report.json` 和 `trajectory.npz`：`/data/rosclaw_overflow/rsi-contact-lat-course-{0..3}-20260928-v1/`、`/data/rosclaw_overflow/rsi-contact-hip-course-{0..3}-20260928-v1/`。每份报告保存源码、模型、资产与轨迹哈希；源码中的新髋残差入口仅为 `SIM_ONLY` 试验工具，**没有**晋升为运动策略。

这些结果否决了继续仅扫描单一侧移幅度或静态髋俯仰值作为当前突破路线。接下来要采集接触前数帧的足—球相对位置/速度、左右支撑状态和实际接触时序，让受限时变策略拥有摆腿相位控制权；训练目标须同时惩罚非足部碰撞和全身失稳。新候选与父代必须在另行预声明、未见的球位/来球速度上配对考核，不可复用这里的点。

在后续 **0.45 m/s 弱出球前沿** `(2.58,-0.09)` 与 `(2.68,-0.13)` 上，右髋俯仰 `±0.08 rad` 四个补充开发回合也未使任一点达到 `0.5 m` 出球门槛：位移 `0.390–0.395 m` 与 `0.264 m` 左右；一例脚后又碰小腿。证据在 `/data/rosclaw_overflow/rsi-far-hip-power-course-{0..3}-20260928-v1/`。因此右髋常数偏置无法同时弥补低速步态的冲量缺口；不应将它加入已封存速度 actor。

受限右踝俯仰 `±0.10 rad` 也做了八个已消费开发回合：近球 `(2.42,-0.10)` 两例仍有小腿碰撞，其中一例触及关节投影三次；`(2.52,-0.14)` 虽保持纯脚、球位移 1.589–1.809 m，但负残差触及关节投影一次，且无显著优于 1.744 m 父代的稳定收益。远球 0.45 m/s 的四例均纯脚却只推动 0.198–0.408 m，依然全部低于 0.5 m 门槛。原始证据 `/data/rosclaw_overflow/rsi-ankle-power-course-{0..3}-20260928-v1/` 和 `/data/rosclaw_overflow/rsi-far-ankle-power-course-{0..3}-20260928-v1/`。踝残差入口只是 SIM_ONLY 受限实验维度；不加入速度 actor，不做晋升。静态髋/踝偏置与速度二档都不足以形成高质量射门，下一步需要可变相位、可控末端速度的运动学习。

又做了足端任务空间开发：以 Isaac Link Jacobian 求受限 `x/z` 脚端位移，并在第二轮约束膝部后退，保持 SONIC 基底、关节限位投影与脚球微步监测。`(2.42,-0.10)` 的第一次 IK 将“膝先碰”变成“脚先、1 个物理微步后膝再碰”，但仍不纯净；增大脚目标及添加 0.03/0.05 m 膝部后退约束的四例反而均使膝先碰。`(2.35,-0.08)`、`(2.45,-0.12)` 也没有纯脚通过。全程站稳、零关节投影不抵消接触失败。证据 `/data/rosclaw_overflow/rsi-foot-ik-dev-{0..4}-20260928-v1/`、`/data/rosclaw_overflow/rsi-knee-clearance-dev-{0..3}-20260928-v1/`。该 IK 是尚未晋升的教师研究接口，不是新小脑。

复盘显示更关键的先验是速度域：原 Isaac 脚球课被 CLI 限制在 0.5 m/s 慢走，而冻结 SONIC 在同一身体资产上可稳定 1.2–1.4 m/s 跑动。后续高速课程独立记录于 `isaac-highspeed-foot-goal-holdout-2026-09-28.zh-CN.md`；不能把高速课程通过倒算为上述髋/踝/IK 补丁成功。
