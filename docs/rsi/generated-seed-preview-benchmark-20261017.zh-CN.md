# 私有 seed 直接预览：保持完整模型身份的局部性能改进

既有真实全模型剖析中，采样view约9.39秒、preview约26.06秒、
bind约62.81秒；初始化约632秒。前三项带cProfile开销，不能直接
拿来与新接口无剖析时间相除，也不能据代码宣称整条流水线提速。

新增 `preview_from_seed(seed=...)`：只接受整数seed，从已完成
原始整模型验证的私有冻结字节生成完整普通JSON预览，包含actor、
critic和历史父代。避免把刚从私有冻结字节恢复的mean再做一次
外部文档复制/重序列化验证。返回对象独立拥有自己的完整字典，
原有preview外部文档入口和bind整预览验证均未放宽。

这不是新增可被外部修改的模型缓存，也不接受调用方自带mean、
sampling law或权限。私有完整字节和依赖源仍前后检查，生成的
原始模型/策略封印必须与原路径一致。不自动替换正在运行的
采集器，不改变动作空间、探索分布、奖励或机器人权限。
