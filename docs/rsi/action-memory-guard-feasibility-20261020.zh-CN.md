# 动作记忆约束：有界方向可行性探针

## 发现与排除

四组同策略探索所得32×4轨迹已完成768000 native子步（含逐步独立重放）。
组内留一优势的4次actor-only Adam更新确实发生，critic没有参与优势；
平均Gaussian KL不超过.005。整40开发物理考试另完成240000 native，
结果却从研究锚点4/40退到1/40，丢失0、10、16，无救回，身体40/40、
非足18、validation0。候选被拒绝，不自动替换任何Champion。

因此不能把退化继续全部归咎于弱critic，也不能把损失下降当球技增长。
同一旧观测的离线对照（无新物理、无新更新）发现：40课程共1948个
离散维度、1762个控制帧的FSQ符号改变。旧actor的批量计算与原生录制
符号在所有课程完全一致，排除了本次对照自身的批量量化伪差异。

| 旧成功课程 | 最大raw均值变化 | 符号变化帧 | 首次Token变化 | 首次真实身体分叉 |
|---|---:|---:|---:|---:|
|0|.00076415|65|20|20|
|10|.00071573|47|25|25|
|15|.00083941|43|32|32|
|16|.00106609|46|27|27|

Token步长为1/16；连续分布的小幅变化不保证其确定性离散动作保持。
表中时间对应是机制线索，不证明所有结果退化仅由量化单一因素造成。

## 下一项实验（开始前固定）

只检验一个问题：同一组内优势的Adam方向，能否在**旧成功训练记忆的
离散动作完全不变**的约束内取得目标改善？不是无限调超参数。

- 仍从未晋升的4/40研究锚点开始，复用已消费的32×4数据，明确不是新采集。
- 保护0、10、15、16四条成功的完整train轨迹。只使用其实际当前108观测；
  Actor不接收课程ID、成败、未来状态。validation不参与保护/梯度。
- 旧parent、critic、normalizer、原始物理与动作限幅全部冻结。
- 原有同一loss、lr、4次最大提案、Gaussian KL≤.005保持不变。
- 在固定的13个回溯alpha（1..1/4096）中，增加硬条件：四条记忆的
  20..299帧确定性FSQ Token变化计数必须为0。不增设人为动作脚本。
- 起点必须先验证CPU/native与CUDA缓存的符号逐个一致，否则整个探针失败。
- 所有提案不可行则恢复权重和Adam矩，停止本探针并保存“方向不可行”，
  不声称学习成功，不启动相同模型重复物理。禁止偷偷扩大回溯次数。
- 有接受更新才安排新的整40原生物理与独立NN/肌肉/native重放。
  旧观测上的动作保持不能替代闭环考试；相同初态下是否真正保持仍由物理验证。
- 仍须超过4个成功，保留旧0/10，身体40/40、非足不超过18，才满足必要的
  研究增长门。该门比canonical晋升弱，不是远球/旧52/private Fresh通过。

如果方向不可行，说明仅缩小同一个Adam方向不能兼顾当前记忆，需要改变
更新方向或表示，而不是继续降低学习率。若记忆保持但无新成功，则证明
“不忘”仍不等于“会学”，要重新检查探索覆盖、奖励排序和接触动作先验。

## 持续实施机制的实际边界

产品层ACTIVE Goal负责后续Agent轮次；研究任务由独立systemd进程执行，
每阶段保存不可变输入、检查点、原始轨迹与终态。只读60秒观察器核对真实
PID、退出码、证据增长和依赖，不启动训练、不唤醒LLM，不算科研进展。
普通任务失败是经验；基础设施或证据合同失败必须修复，不能改门槛绕过。

若所有子任务已结束而Goal未达成，Agent下一动作必须是审计并选择新的
可证伪实验，不得继续等待已结束的任务。主机关机、会话/产品终止或授权
丢失不能被代码承诺为永远不中断，恢复时从持久化事实续做。SIM_ONLY，
硬件、自动Champion晋升及宣传视频达标均没有因此获得授权或证明。
