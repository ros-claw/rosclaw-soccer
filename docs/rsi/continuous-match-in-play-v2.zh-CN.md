# 连续比赛：场内暴露门 v2

连续比赛考试现在使用 `continuous_competitive_match_growth.v2`：原始轨迹必须带有逐帧球位与固定场地/球尺寸，并据全足球越线规则重算首次离场事件。只要球在任一采样帧离场，无论之后是否重新进入，当前未实现裁判式重开的连续比赛考试即拒绝；第一个和最后一个采样帧同样如此，包括进球。这一保守门不定义比赛的实际规则，不会自动把球放回场内，也不禁止单独的进球或训练课程。

主轨迹及其重放必须分别给出一致的 `primary_in_play` / `replay_in_play` 结果；校验器会读回哈希绑定轨迹重新计算，不能只修改报告并重算报告哈希。缺少、非有限、形状不匹配或途中变化的场地元数据直接拒绝。旧 v1 考试报告仍是历史证据，但没有这项门，v2 校验器不会将其视为当前资格；不要覆盖旧文件。

这是 50Hz 记录上的保守采样检查，不能保证两帧之间球未出界，也不是物理安全或公平竞赛的充分证明。将来如实现带真实规则及可信重开证据的比赛，需要新的版本化契约，不能仅因为球回到界内就恢复信用。所有结果仍为 SIM_ONLY。
