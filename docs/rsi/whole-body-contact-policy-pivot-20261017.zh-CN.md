# 从速度补丁转向全身接触策略：实际移植试验与下一步

## 结论与限制

快速追球两场只有一场通过，且发生一次原安全案例退化，已停止固定
速度方案。随后完成 PAiD 全身循环策略在**原 M0 编译世界**中的
四场移植：脚触 2/4、完整原门通过 0/4。不能称作技能突破或教师。

这不是新的训练，没有 optimizer update；不是重新执行九月的 PAiD
原生目标线 smoke，而是不同、明确声明的冷启动同世界试验。
未经独立实现审核或更大初态验证，不使用这些结果进行晋升。

## 先证明参考与动作接口一致

外部参考固定于 `e72e470230047dedaf66df0983f1d0ab746faeb5`。
实际核验模型输入为 160 维观测、2×1×128 LSTM 的 h/c、time_step；
输出为 29 关节动作。按元数据关节名称做双射，不按位置猜测，
不截断、补零或在元数据异常时回退默认值。

执行 301 次 CPU ONNX：300 帧独立零观测探针与一条第100帧变观测探针。
这不是循环闭环或身体执行。导出的 260 帧参考在 H300 的末尾保持
最后一帧；关节位置/速度与本地 `soccer-standard-001_right.npz`
按相同 clamp 逐帧完全一致，其余九条不一致。该检查避免任意选取
一个外部动作却宣称与 checkpoint 内嵌参考相符。

预检封印 `sha256:0781e090739504b799726b86459f89a770e453aec51324b952efa1a1e375022d`。

## 物理试验声明

- 四个已消费开发初态：group0/4/8/12；无后验替换或删掉失败。
- 原 M0 冷启动根部、SONIC 默认关节、滚动球初态。
- 同一二进制世界 `246da475bbad8d3ced351f6ceb18e18fc3d4c2de7236cdd8c427239cecb4ff83`：
  球半径0.11m、质量0.43kg、dt0.002、29执行器。
- H300、50Hz网络、每帧10物理子步、原力矩硬限制及评分不变。
- 全部29关节目标由外部 checkpoint 产生；使用其具名元数据 PD 参数。
  因而是**策略+PD的整体移植**，不能把差异单独归因于网络或 PD。
- 球和目标由实际状态形成身体坐标系观测；目标固定世界[10,0,0.13]。
- 当前帧内嵌参考作为输入；每场 LSTM 从零重置。不使用旧 helper
  的前一帧参考，也不为挑选成功而切换最近动作片段。
- 每场固定执行300帧。实际非足接触、未触球均保留；额外记录原六槽
  之外的机器人碰球，不能把这些接触忽略成新的成功。

外置 runner `rsi_paid_same_world_pilot_20261017.py` 在首次物理分配前
固定源码、模型和原预检资产哈希，执行结束再次核验；展开源码
F821/F822 检查通过。原有 sampler 和冻结执行源未修改。

## 科研决策

发现：现有原世界和冷启动下，外部29关节循环策略可以直接产生
实际球路；无需把数据驱动策略限成12维腿部残差。但本移植没有
通过 M0，不能作为无条件替换方案。

排除：没有模型张量形状、29关节顺序或参考文件选错的已知接口
障碍；也不是只能用动作补丁才能让球运动。没有排除冷启动分布、
单条参考覆盖、PD差异、接触时机与运动目标的影响。

下一轮值得投入的机制：把**接近策略与全身接触策略作为两个显式
技能后端**，以当前身体/脚/球相对状态决定交接，保留各自循环状态
与 PD 合同；不是再次扫描速度或把全身输出暗塞进12维残差。
先审计两段交接状态分布和原控制合同，再预注册有界配对物理试验。
应同时报告进入接触域、脚触、球路和旧能力保持，不只报告球速。

推翻条件：若在明确可触球的交接状态仍不能获得可重复 foot-only
球路，就不启动 DAgger/PPO 蒸馏，也不扩展球队；转而研究接触参考
本身或训练全身专项专家。不能用这四场推断 PAiD 普遍不可用。

PAiD 代码和模型均保持外置。其 CC-BY-NC-4.0 与 README 明确限制
商业宣传；本轮仅做研究比较，不把 checkpoint、动作数据复制进
MIT 仓库，也不制作商业宣传视频。未来宣传用能力需另有合法资产
和合格物理证据。
