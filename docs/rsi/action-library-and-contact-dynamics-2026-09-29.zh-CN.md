## 为什么“脚很快”仍然传不远

仅凭控制帧开始时脚踝中心速度会误判碰撞强度。例如 h06 控制帧脚踝向前约 `2.02 m/s`，球的触后 x 速度只有 `0.17 m/s`。为此新增三个**只读**、身份绑定的物理证据：球—脚接触点、球指向对方几何体的接触法线、同一世界接触点处“对方身体速度 − 足球速度”。最后一个量使用 MuJoCo `mj_jac` 与当时 `qvel` 计算，并非从视频或末端位置差分估算。MuJoCo 文档说明接触法线位于 `mjContact.frame[0:3]`、从 geom1 指向 geom2，`mj_jac` 可求世界点的平移雅可比：([contact 类型](https://mujoco.readthedocs.io/en/3.9.0/APIreference/APItypes.html)，[mj_jac](https://mujoco.readthedocs.io/en/3.10.0/APIreference/APIfunctions.html))。

在 h01–h06 的同一固定动作下，接触时沿法线的相对闭合速度分别约为 `0.53 / 0.46 / 0.80 / 0.67 / 无接触 / 0.71 m/s`。这比“触球前脚踝速度”更接近实际动力学，但 h03 与 h06 的闭合速度相近，出球却差别很大，表明还需量化接触持续时间、法向冲量、腿部有效质量/顺从性以及接触高度和多次碰撞，而非仅提高脚速。证据：`/data/rosclaw_overflow/rsi-team-contact-point-relative-velocity-v20c/report.json`，hash `sha256:d5457a06e1904db8a3dc415e1713a7e80a00e17124e7820d3d5c74fa73bf4e5e`。八场在增加上述只读测量后，**完整世界轨迹 digest 与 v19 全部相同**，确认观测没有改变动作或仿真动力学。

## 下一训练阶段

1. 在已消费场景上补充每次真实脚球碰撞的子步法向冲量、球的动量变化与接触点相对速度，建立足端击球的物理奖励；冻结 locomotion foundation，保持每次候选动作有界，非足部碰撞立即拒绝。
2. 扩展多位置、多速度、多步态相位的训练场景，离线训练有拒绝能力的状态→动作选择器；但若扩大数据后的动作库上界仍无法覆盖高质量回球，不应继续训练选择器，应先训练新的足端时序/速度动作。
3. 在全新、预声明的场景与冻结 Parent 成对评价；通过后才能逐步接上真实传球、射门、门将和连续比赛。当前所有候选均为 `SIM_ONLY`，没有 ROS/硬件动作授权。
