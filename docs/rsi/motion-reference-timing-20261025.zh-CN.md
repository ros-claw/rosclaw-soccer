# 原始动作参考的时序准备：SIM 研究协议

## 动机与边界

即时 PD 目标干预三次试验仅重复救回同一个公开初始情境，未达到
“至少两个不同救回且零退化”的扩展门。该干预族停止。新方向不是
继续扩大关节偏移，而是让原始神经动作先验提前准备支撑、摆腿与恢复。

`motion_reference_timing` 对已经合格的原始50Hz动作参考做局部、严格
单调的时间重参数化。默认 OFF 不替换任何数组；显式零计划也不插值。
非零计划只改完整窗口的内部参考行，起止行及窗口外逐位保留。
关节位置使用原始位置/速度对的 Hermite 插值；参考速度包含时间变化率的
链式法则；身体位置线性插值，wxyz姿态采用 scipy 最短弧 SLERP。
这不是修改实际身体根位置，不改变控制步、物理时钟、PD增益或扭矩硬上限。
也不是训练得到的新神经权重；网络更新数为零。

显式计划上限：峰值位移±3参考帧，窗口24..64控制间隔，且必须覆盖未来完整
原始参考。禁止以裁剪、循环播放或移动实际身体来掩盖越界。

## 预测所有权

`SharedNNForecaster` 新增明确的 pre-proposal 路径。此时实际玩家没有
pending目标；复制完整物理数据、纯SIM策略与历史，不调用 enter、不重置
历史、不倒退已生成的观测。候选参考只装到独立预测策略中；每一预测控制步
重新调用原NN。实际策略最多采用选定参考数组，绝不采用预测身体或未来历史。
首个NN调用也计数。旧的 pending 接口与64控制步上限保留。

## 首次物理资格试验（预注册，不代表已经通过）

使用同一个公开 course9 的原始 ONNX 控制器及固定原始轨迹。
实际1世界、360控制步、3600原生步；在80/100/150/220控制边界，分别从
提案前状态预测96控制步，共3840原生预测步。所有未来目标和每个原生
qpos/qvel/torque/ball_forces必须精确等于后续实际，实际全轨迹还必须
精确等于原始轨迹。使用 OFF 原数组，不测试球技增益。
最后一个预测至316控制步；300之后只作身体诊断，足球评分仍为0..299、
首次触球至迟239、60步球位移，绝不扩大考试时限。

后续有限时序候选的16课程B/C实验必须另外冻结并执行；本资格通过不等于
教师合格、学生学习、Fresh泛化或连续4v4宣传能力。

资格实际通过：源码 `1ee3a2332d0a9fd6785ed4eda541ea04c15366ae`；
`rsi-preproposal-nn96-20261025/complete.json` 的SHA256为
`bb3548b056714ec4d87ea393afb87a87e245f4d1327a4167cf75096239f05b16`。
实际3600原生步，预测3840步、384次NN调用，四窗口全部目标和原生数组精确，
实际全轨迹原样；进程exit0。这只证明复制预测接口，没有球技增益。

## 时序教师16课程预注册

固定公开课程0..3、10..13、20..23、30..33，B原策略、C时序教师，32实际
世界/115200原生步上限。每世界只在真实测量技能入场、首个提案前搜索一次；
入场前无实际球接触由episode runner保证。候选仅原数组OFF和峰值±3参考帧、
24间隔sin²局部时钟。每候选至多96控制步、每世界2880预测原生步，总46080。
若原窗口通过就保留原策略；否则只选已完整观测、身体健康、无非脚触球、
60步位移满足原门槛的候选，按原reward确定次序；无合格候选回退OFF。
不叠加以前即时膝目标修正，旧的course0成功及来源永久保留。
实际完整H300足球评分和H360身体诊断决定扩展，预测短窗口不能替代验收。
每个选定候选的所有原生预测样本及NN目标必须精确等于实际C后续；所有B与
历史原轨迹精确；C未选计划也必须与B精确。完整保存拒绝、早期失败及截尾。
仍须至少两个不同救回且零任务/安全/身体退化才允许扩展40及独立扰动。

## 持续机制

持久Goal保存最终目标与未完成状态；外部续跑指针保存源码、输入、产物、
终态与下一动作。观察器只监测任务，不会自行唤醒推理，也不负责宣告突破。
每次恢复先核对真实进程与证据，再执行下一科学阶段；绝不把已结束任务
描述为仍在训练。只有最终目标证据满足才标记完成。
