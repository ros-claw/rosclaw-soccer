# 接触参考权限：固定接近规律的两课程配对实验

## 动机、假设与对照

完整恒定块、持续反馈两轮都只保住原 2/4，没有新增合格球位；该导航命令搜索族停止。持续阻尼能在远球位 1 的第 75 帧进入技能，却触球弱且发生后续身体碰球。现在检验一个不同机制：**冻结接近与交接，让击球脚的参考轨迹稍低且向内，能否经 SONIC 传递为更好的实际接触**。

固定两条已消耗情境：球位 1 `(0.50,-0.10)` + 原 `damped_feedback`（失败对照）；球位 2 `(0.35,-0.22)` + 原 `nominal_feedback`（成功保护对照）。每个执行原参考 OFF 与 root-local 请求 `(0,-0.025,-0.025)m` 两组。固定该单一请求，不是观察结果后扫参。四个实际自身神经 H300 共 **12,000 新原生步、0 前瞻搜索步、0 优化器步**。不是整个原四球位、M0、Fresh 或球队考试。

如果失败情境被救回而保护情境没有丢失，才值得扩展其他情境和扰动；若参考变了而实际脚球结果无改善，必须定位 Foundation 的传递/支撑/接触几何，而不能把小 FK 残差当成学习成功。

## 实现权限

`rsi/contact_reference_offset.py` 在已经显式准备、重采样和腕隔离的动作参考上，只改变右腿六关节。原根部 metadata、其他 23 关节、时间、源窗口、入口插值、交接门、球/世界/PD 全不变。

以原脚上两个前 5mm 支撑球的中点为几何标记，在参考局部第 90–210 帧施加 `sin²` 平滑包络，首尾为零。它不是网格接触点，也不是给真正的脚直接施加位移。每个参考姿态最多四次阻尼最小二乘，阻尼 0.03m/rad、每次增量不超过 0.04rad、相对原参考总增量不超过 0.12rad，并严格保留原模型关节限位。实际姿态和物理状态从不被这个几何求解器修改。

使用 [MuJoCo 官方 Jacobian 接口](https://mujoco.readthedocs.io/en/stable/APIreference/APIfunctions.html#mj-jac)的 `mj_kinematics → mj_comPos → mj_jac` 流程计算附着在脚刚体上的标记点。运动学残差不能证明身体平衡、冲量或球路；这正是随后真实 SONIC+PD+原生积分对照的目的。

零请求是位级恒等返回，不分配 MuJoCo 数据、不改变原参考。非零请求建立独立 scratch kinematics，不调用 `mj_step`，不动原机器人/时钟/力矩。生成的参考仍须通过原连续性、精确测量入口及 padding 检查。非法源或超限请求拒绝，不偷偷修好原始数据。明确标注“修改过的研究参考”，不冒称原始人类数据。

## 开跑前与闭环条件

- 固定源码/数据/模型和上轮独立复核完整哈希，在项目导入及真实物理分配前验证，结束再校验。
- 开始四个实际实例前，先在历史测量入口校验**两种情境、两种参考**的全部几何及连续性；任何一个失败则整批预检拒绝，不能丢掉失败情境。
- OFF 从第 0 帧实际重跑各自自身神经闭环，全部数组须与上轮对应候选及实际前缀精确一致，不能重放旧关节目标冒称策略执行。
- 改参考组的交接时刻和实际测量入口必须保持；现场几何结果须与预检相同。记录参考变化→神经动作→实际关节→身体→脚球接触与球路全链路，以及失败和实际收费步数。
- 检查整个 H300 的非脚部触球、身体姿态和完整 60 帧观察资格。原研究选择标准不放宽，不因 OFF 本来不安全而把 ON 失败视作通过。

该适配器是确定性研究工具，不是训练的小脑或商业可发布的派生运动模型。只有物理可达性和多扰动教师可靠性成立后，才进入数据驱动学生训练。MotionDecode/PAiD 的研究许可限制依旧适用，不据此制作商业宣传片。
