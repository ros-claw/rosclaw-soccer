# 入场结果预测：冻结训练协议

这是监督式动作结果预测，不是在线强化学习、Actor-Critic 或关节策略训练。网络没有运动执行接口，不能授予动作权限。

数据银行共有1224条原始候选，168条未进入踢球策略，1056条入场记录首个关节目标精确重现；去除4条完全重复特征后有1052行、56个原始初态。未入场失败保留在银行中，不伪造观测。重执行不算独立样本。

四类各14个初态，以固定种子2026102527划分每类10个训练、4个验证。相同初态所有提案、慢快域重复不能跨集合。该验证集来自已经用于开发的公开课程，不是未消费的密封考试。归一化及类别频率基准只使用训练组，指标按初态等权而非提案数加权。

549维因果输入，128/64 ELU隐藏层，三个输出：安全、脚触球、在前两者条件下的高质量结果。最终质量概率为三个sigmoid之积。种子926071、926072、926073各固定512次Adam更新，批量64，学习率0.0003，衰减0.0001，梯度范数上限1。每批先均匀抽训练初态，再均匀抽该初态提案。不选最优种子或验证检查点。

仅当三个种子全部满足：质量Brier优于训练类别频率基准、安全Brier不劣于基准、安全置信度≥0.9覆盖≥10%且其中危险误判≤5%，才进入后续物理排序评审。这不是控制器晋升，也不是物理改善证明。任一失败保留全部检查点、预测、损失和拒绝结论，不追加相同族训练预算去追验证集。

保存安全可加载的网络/优化器/RNG、实际更新次数、身体/先验/数据哈希。后续若要排序参考相位，必须另外冻结物理对照预算与退化门槛。完整4v4连续比赛目标仍未达到。

## 接续：可求梯度的原始踢球先验

下一步先打通直接运动策略学习的技术前提，不再通过预测器间接宣称改善。仅复制已冻结的547→512→256→128→29 ELU先验，不改变观测语义、不新增归一化、不修改输出顺序。29维输出是原ISAAC顺序的动作坐标，不是关节力矩；原PD映射、夹紧及执行门控不变。

训练前须用全部1052条真实入场观测逐条比较Torch与原ONNX输出。预设最大绝对误差≤1e-4、RMS≤1e-5；八组参数的梯度须有限且非零，求梯度不得改变权重。保存原样初始化检查点和配对输出。这是数值接口检验，不是训练，也不证明两种后端的长时物理轨迹等价。通过后仍需独立物理对照，才能设计有先验保持约束的真实运动RL实验。
