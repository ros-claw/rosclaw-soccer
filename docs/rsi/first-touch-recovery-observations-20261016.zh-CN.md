# 首次触球后的身体运动诊断，不是自然度验收

## 测量对象

新增 `first_touch_recovery_observations.observe_first_touch_recovery`，读取
完整 H300 的实测根部姿态、世界速度与 29 关节速度，并保持原接触/
球路/安全标签不变。不执行控制或物理、不推断足地接触或步数、不
自动给出“自然”“稳定”“可继续比赛”的合格判定。

从首次足触球所在帧的 pre-step 身体快照开始，分别观察到 +60 帧和
H300 结束。短窗口完整时为 61 个 pre-step 快照、1.20s 身体快照跨度；
首次帧在它所记录的接触区间之前，不能与 after-step 球位置混为同一
采样时刻。速度沿用来源刷新协议，不重采样或外推。

报告包括世界 x 最大回撤、净位移、最小记录速度、根 y/z 范围、根 z
轴对竖直的最大倾角、记录角速度峰值、关节速度峰值及相邻关节速度
向量变化。相邻速度变化不是瞬时加速度或 jerk；世界 x 回撤不等于
身体坐标倒步。仅球路合格不能替代这些运动质量证据。

没有触球或第 299 帧才触球时，缺失身体尾段为 null；晚触球短窗口
明确标注不完整。不得补零、外推，或与完整窗口混算。单位四元数
严格检查；非有限、截短及可能使派生量溢出的极端输入拒绝。

## 原 A 与反馈候选 2 的全量归档复盘

全部 16 个初态、32 条已认证归档轨迹；重新核验来源见证文件身份、
CPU/Foundation 封印及报告/轨迹绑定、两臂初态逐位相同，原始评分
从轨迹重算一致。本复盘不重复独立动力学或 Foundation 执行。

两臂均有完整短窗口的只有 11 个初态，完整配对统计必须明确这个
分母，其余案例仍保留原标签和缺失/不完整窗口。配对中，原 A 的
世界 x 最大回撤为 0，候选 2 最大约 0.003149m；这些 M0 数据并未
复现此前完整射门视频中的明显连续后退，不能用它们宣称修复了旧
视频或证明不会倒步。
