# 双足连续接触预测数据：预声明

以前述六组已独立物理重放的 72 个基线条件为开发数据；保持每个原始传球情境和其侧位作为同一分组。对 B 处于速度接球阶段的每个 20 ms 控制周期，输入为该控制开始时左右脚固定参考点相对球心的位置与速度；使用上一控制周期末的实际物理状态，第一周期使用实际初态。观测不包含课程编号、未来接触、回传结果或事后选出的触球时间。

标签是随后的五个控制周期内首次 B 球接触：`0` 无超过 1 N 的 B 接触、`1` 首次只有足部接触、`2` 首次包含非足部接触（同时脚和非脚也为 2）。任何距交接、原 300 周期接球期限或真实轨迹结束不足五周期的尾部均右删失，不伪标无接触。相邻 100 ms 窗口高度相关，不能把它们计作独立场景。事件之后仍可能产生正常窗口；目标是检验在线连续输入可预测真实短时接触，而非回合是否成功。

以实际接触力和原生存档状态作为标签与输入来源，保留全部无接触条件，不修改物理或旧轨迹。对六组源与既有独立重放逐哈希核对，另对导出的样本做独立检查后方可进行模型训练。模型必须按原始情境整组留出、完整报告类别不平衡、误报及非脚漏报，不得将未来标签输入策略。训练及评估均为 `SIM_ONLY`；未在真实自身状态下控制并改善原任务之前，不是接球策略、安全保障或比赛成绩。
