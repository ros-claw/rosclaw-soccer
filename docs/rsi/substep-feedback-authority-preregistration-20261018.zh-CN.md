# 同幅度不同反馈时序：局部小脑接口体检声明

## 依据和可证伪预测

已完成的地面读回表明，踝部速度突变同时涉及执行器和约束响应，
保持上一拍目标并非总能改善。高层初态神经选项选择不能在触球后
适应2毫秒尺度的本体变化；此前的12维残差则每20毫秒更新一次。

本轮只问：在完全相同幅度和规则下，更快的反馈是否能改变局部
动作响应？不预设它一定更好，也不将局部阻尼效果等同于足球技能。

若2毫秒反馈相对20毫秒保持没有一致且可重复的局部收益，或明显
引发其他方向的不良变化，不扩大同一固定阻尼族的无界扫参。
有局部收益也只能为后续接触条件化学习提供接口依据，必须另做
完整闭环轨迹、原球路与安全、历史保持和独立考试。

## 固定设计

数据仍是旧八个扰动初态选中复试，四个父上下文簇。时刻固定为
原先事后诊断得到的触球后60帧内最早最大关节速度变化区间。
不使用正在运行的44场神经考试，不声称Fresh、盲测或新独立初态。

每个状态执行三条20毫秒分支，均从相同完整MjData复制：

1. 原实际目标与PD，无附加反馈。必须与原轨迹及已完成地面实验
   的原目标分支一致，完整原轨迹仍回放3000子步。
2. `CONTROL_TICK_HOLD`：在分支首个子步计算一次附加反馈，保持
   十个物理子步。这是50Hz等效采样保持，不是更换原Foundation。
3. `PHYSICS_SUBSTEP_FEEDBACK`：用同一参考、规则和幅度，每个
   2毫秒子步用当时关节速度重新计算反馈。

固定反馈：
`delta_tau = clip(-0.5*(qvel_current-qvel_previous_control_tick), -cap, cap)`。
gain单位Nm/(rad/s)，不搜索gain或epoch；`cap_j=min(2 Nm, 0.04*hard_limit_j)`。
29个canonical关节均使用同一规则，腕部等小关节不会获得2Nm越级
增量。参考来自峰值前一个控制帧的关节速度，严格早于分支。
两种时序首个动作必须逐位相同。输入不含地面真值力或约束力矩。

附加反馈加在原PD请求后、原硬力矩限幅前；原目标、kp/kd、世界、
物理步长和硬上限不变。附加反馈相当于有界诊断控制变化，不能
因“kp/kd参数没有改”就声称总控制律完全不变。

预算：八条完整原轨迹回放24,000子步，24个局部分支240子步。
其中八个无反馈对照、十六个反馈干预。实际消耗逐项保存，失败
保留且不自动重试，不清零原失败或运行中考试预算。

## 观测与决策边界

保留每子步请求／实际附加力矩、实际PD力矩和执行器力、完整
canonical终态、原六个球接触力、骨盆高度和地面／约束观测。
逐状态比较关节速度净变化及每子步变化、根部状态、球体状态。
不只摘取更好的一只踝关节，不用轨迹帧或24分支充当独立样本数。

若只有关节速度减少而根部、球或接触明显恶化，不能称作整体
改善；20毫秒无异常同样不证明整个300帧安全或后续恢复成功。
参考上一拍速度不是已学会的人类运动目标；它可能压制必要摆腿。

新`VelocityDampingProbe`明确`learned=false`、optimizer_updates=0，
仅由离线回放器显式参数启用；默认None路径保持无附加反馈。
SIM_ONLY，不进入真实设备、原生考试控制器、Champion或运行时。

## 避免伪突破

固定PD中，恒定`kp*delta_q_target`力矩与恒定位置增量具有相同
作用（浮点误差除外），已有随机数值测试覆盖相同硬限幅。
本轮比较的是反馈更新时序，不将“改名为力矩”作为创新。
该固定探针不是神经小脑、强化学习、actor-critic或端到端策略。
训练过的三个高层模型的3000步更新另行计数，不能重复归给本轮。
