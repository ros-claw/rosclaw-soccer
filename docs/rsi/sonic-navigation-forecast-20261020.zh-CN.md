# 预测入脚前的完整导航分支资格

上一轮原始八场显示：简单球位入口教师在两个近球位产生了干净触球，但
两个远球位越过入口、胫部先碰球。身体高度仍稳定，不能默认归因为跌倒。
本轮不增加训练算法、不放宽接触要求，先建立可检验的短时预测工具。

## 完整复制，而不是冷启动近似

`physics.sonic_navigation_forecast` 复制完整导航对象图、运动参考、规划
计数/命令/事件、十帧本体历史、上次动作和目标等。只共享三个已校验的
CPU ONNX推理会话；所有数值缓冲独立，类级默认关节数组也变成私有副本。
状态字段不认识就拒绝，不允许为了能deepcopy而跳过未知对象。

原生身体通过 `mj_copyData` 保留完整积分、接触warm-start、时钟和状态，
不调用冷身体构造再写时钟。编译模型只读共享，控制和历史都在分支内
闭环重算。原身体/策略状态在分支前后严格保持一致；计数只计新增步，
不能把借用的历史前缀再次算成新样本。

这些设计要求仍需真实G1数值资格，不因合成单元测试通过就视为成立。
共享ONNX是否确实不污染后续调用，也要用重复分支检验，不能靠推测。

## 固定资格试验：1800个新积分

使用已经消耗、独立复核的course0入脚场景作为比较对象，不是Fresh。
从头实际重算20帧神经/物理前缀，共200步，再从同一当前状态执行：

1. 40帧原球条件教师：分支自己的实测状态驱动神经和规划器，应逐位匹配
   已有闭环的未来；旧未来只用于事后比较，不作为控制器输入。
2. 40帧零导航命令负对照：应改变参考、神经动作和身体响应，否则当前
   预测窗口还不能证明命令权限。
3. 再次执行原教师40帧：应与第一分支逐位相同，检查共享会话的干扰。
4. 所有预测结束后，确认原身体/策略仍停在第20帧，再由这个原身体真实
   执行40帧零命令；逐位核对之前的负对照预测。

总预算：200原前缀+1200预测分支+400原身体后缀=1800新原生2ms积分，
180个神经控制周期。没有延长正式任务时限或改变世界/控制参数。
脚本：`scripts/rsi_qualify_sonic_navigation_fork.py`。

未满足原未来对照、重复对照、负对照、实际后缀或原对象不变任一条件，
就拒绝预测器当前用途，保留失败，不能直接上MPC搜索。

## 结论上限与后续

即使成功，也只支持当前CPU检查点、一个已消耗G1状态和40帧范围的复制
语义，不等于M0、全任务安全、GPU数值等价或新的神经学习成果。
它仍是仿真特权教师工具，不能把预测未来偷偷塞进部署Actor的观察。

通过后再比较有界的入口命令，目标是减少实际入口误差和非脚部接触，
同时保留已经出现的近球位成功。如果预测成立但候选不能改善远球位，
需要换控制机制，不继续无边界调整同一比例增益。

本轮没有真实机器人、Actor优化、技能晋升或宣传视频授权变化。
