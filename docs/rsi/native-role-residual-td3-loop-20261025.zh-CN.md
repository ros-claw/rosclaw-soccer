## 从失败中改变了什么

先前绝对118→128→128→3角色策略在三个种子、BC及DAgger后均没有保住父代
五课程触球能力，已拒绝。此次只复用其128维隐藏表示和训练集归一化，**不调用
旧绝对输出头**。原98→29关节步态网络及PD控制器不变。

新actor的观测121维，包括当前真实父速度命令；特征131维包括隐藏128维和
归一化父命令3维。独立3输出tanh头初始严格为零，生成父命令上限5%的修正。
零残差不重复投影，保留父代逐位一致；非零残差经过机体命令域、角色速度和
球员间距的共同约束，最终输出不能因避碰投影而突破父代偏离预算。

在真正训练前，三个种子×五课程全部执行父代、零头及其独立物理重跑，共
60世界执行、360000个native步。全部非残差物理数组精确相同。它是学习起点
的恒等证明，不是训练收益。

## Agent loop 的真实保证和边界

1. 宿主长期Goal维持active，目标仍是完整球队，而不是某一模块测试通过。
2. 固定源、固定计划、独占输出的任务链负责已声明的采样→学习→全课程物理复测。
3. systemd任务有独立进程和日志；只读分钟监控核实活任务、依赖、停滞及后继义务。
4. 外部版本化恢复记录及 `next.json` 指针保存源提交、计划哈希、checkpoint和下一步。
5. 任务失败保留现场；不靠无限同参数重试、刷心跳、重录视频冒充学习。

**分钟监控不提供Agent唤醒，也不会自主修改算法。** 已实现的执行链会完成当前
有限实验，新的科学假设仍由持续运行的Agent/宿主Goal接续。不能承诺断电、宿主
停止或服务失效后无限运行，更不能保证训练一定成功。此次修正了监控仍指向旧
终态DAgger任务的问题，换成当前采样和学习六任务及准确的完成依赖。
