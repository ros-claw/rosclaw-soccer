# 纯 Foundation 接近对照：先分辨步态跟踪与叠加控制

## 假设与范围

走／跑实验中的 group0/mode3 在触球后很晚出现低骨盆，而
group4/mode3 在触球前、甚至脚端 IK 启用前就出现低骨盆。
因此“全部是踢后收腿问题”不符合记录；但时序也不能单独证明
基础步态、腿部残差、导航命令或 IK 中谁是原因。

另行声明四次小型机制实验：group0 与 group4，各 mode2/mode3。
保留原初态、完整 300 帧、世界、基础网络、导航反馈规则、速度界限
及力矩限制，只移除腿部残差和脚端 IK，比较其闭环响应。
其既有对照为先前已独立审核的相同初态/模式执行，不算四次新基线。
这些已消费初态是失败定位，不是新分布、Fresh 或教师资格。

`foundation_approach_probe=True` 仅接受明确的纯 Foundation、实际
神经输入/输出捕获、开发分区、bounded 接近和 legacy swing；
禁止混入 postcontact 干预、模型、工厂或指导器。默认接口不变。
原生默认物理分支 AST 冻结哈希测试必须继续通过。

## 必须验证的控制与物理链

每次实际执行后，独立 CPU 重放 3,000 子步，另行重算 300 次
Foundation 调用和测量历史。新的零残差链审核要求：

- 请求残差、应用残差、任务空间增量全为零。
- 最终目标与 pre-motor、导航目标逐位一致。
- 导航目标与实际捕获的 Foundation 目标一致。
- 原初态精确绑定，双方初态逐位一致。
- 独立重建 15 次 ONNX 参考及完整 300 帧 encoder 的实际消费。
- 从原始轨迹保留原 M0 标签，身体不安全仍判失败。

审核只补上控制链身份，不替代网络重算、物理重放或来源认证。
仍不以回归测试数量冒充物理执行或学习更新。

## 如何解释结果

移除叠加控制后若身体稳定性明显恢复，可将叠加控制的干扰列为
进一步因果研究方向；但该消融同时移除 residual 与 IK，不能单独
归因于其中之一。反馈身体状态发生分歧后，导航命令和参考也可能
变化，不能声称全程相同开环命令。

若纯 Foundation 同样失稳，则继续查跟踪、参考模式、观测约定与
支撑条件，不以增加 PPO 更新次数替代诊断。若身体稳定但无法触球，
只能说明有稳定接近基线，不代表足球任务已解决。

本声明不修改旧 32 场对照，不接触正在运行的冻结源码，不自动晋级。
四次结果和最终源身份在独立外部证据目录记录。

## 参考消费诊断：高度低不等于已证明摔倒

另对 group4/mode3 的原始及纯 Foundation 轨迹，独立重建全部
参考并核对 encoder 实际输入：新增 30 次 CPU ONNX 调用、600 帧
比较，误差均为 0；没有新身体执行或网络训练。诊断 v2 封印：
`sha256:93b45222d6b1a4210cb44c6fbafc71d45218d850713a4f0eb98475fe42b42d2e`，
外部报告 `rsi-run-mode-height-consumed-reference-diagnostic-v2-20261017.json`。
第一版在读取非 shared-envelope 的纯 Foundation 压缩报告时拒绝，
未发布完成报告，源文件保留；v2 显式区分两种原始传输格式。

| 指标 | 原 residual + IK | 纯 Foundation |
| --- | ---: | ---: |
| 重建参考当前姿态的最低根部高度 m | 0.556935 | 0.550289 |
| 实际最低骨盆子步 m | 0.617779 | 0.620600 |
| 实际最低帧处的参考根部高度 m | 0.564360 | 0.563364 |
| 同帧参考 / 实际站立倾角 rad | 0.489197 / 0.508422 | 0.274685 / 0.331541 |
| 全时段 29 关节参考跟踪 RMS rad | 0.107965 | 0.096241 |

参考自身就包含明显压低姿态，实际最低帧与参考姿态并非毫无
关联。但 legacy 640 维输入没有直接编码根部 xyz，高度只能通过
相关关节姿态等间接影响动作；本诊断不证明高度跟踪因果，也未
认证地面支撑、动力学稳定性或恢复能力，不能称为正常跑姿认证。

下一步应研究满足原任务约束的参考生成与接触条件化控制，不能
仅凭低骨盆归因于踢后抖动，也不能临时降低 0.65m 门以取得通过。
官方 `height` 参数用于支持变高度的行为，例如 squat/kneel，
并未保证能约束 run；使用前须单独验证，不能当作现成修复。
参见 [官方 planner 接口](https://nvlabs.github.io/GR00T-WholeBodyControl/references/planner_onnx.html)。

原 16 初态 × 两模式的完整实验仍在独立冻结源上接续；本次四场
机制对照不替代该完整研究，更不替代教师、多训练种子与 Fresh。
