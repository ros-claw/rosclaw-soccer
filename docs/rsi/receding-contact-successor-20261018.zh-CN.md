# 十身体滚离球研究的自动后继

本轮没有新的神经训练成果，也没有连续球队比赛突破。目标保持
active；实验进程心跳仅证明工作仍在执行，不能当作学习或成功。

## 分层接续，而非无限重跑

1. Goal 层负责让 Agent 持续接续科研：读取实际产物、复盘、开发、
   测试，再决定下一批有区别的实验。systemd 观察器不唤醒 Agent，
   也不能代替思考。调度服务或机器不可用时不能承诺无限在线。
2. 执行层将当前十身体研究的全体原生/独立CPU完成、完整终端审计、
   一次性接触诊断串联。全阶段必须真实正常终态，不能仅看文件存在。
3. 外部启动标记在预检前写入；内部开始标记在子进程前写入。
   工程错误、物理失败都保留，不因 timer 再触发就重复消耗同一批。
   下一次恢复必须由 Agent 解释原因并使用明确的新声明和冻结源。

## 新后继程序

`scripts/rsi_stage_receding_contact_replay.py` 绑定原生/审计单位、
冻结源码、原声明、全部十条 receipt、全部结果、完整配对表和
旧C7逐数组复现结论。它在一次性开始之后：

- 输出六课程/十二端点的原始任务汇总，失败与右删失不删除。
- 在相同世界中按原2ms力矩回放新增十条，共30000积分子步。
  不分配NN、不运行新策略、不做优化器更新。
- 复用原已完成的十二条None/option4密集回放，绝不再次积分其中的
  None-C6/C7。整合22端点是10个消耗过的课程，当前作用域仍仅
  六个课程、十二个配对端点，不是22场独立实验。
- 对照原receipt哈希和原结局，明确选出本轮十二条作用域内的接触
  诊断。重复端点、缺失行、替换结果、预算增大都会拒绝。
- 最终结果仍 `teacher_qualified=false`；成功也不自动晋升、
  不授权训练、不接触Fresh、不构成踢球精度或4v4能力证明。

固定回放新增有限 `receding-catalog2-ten` profile，顺序严格等于
`receding_jobs()`。积分主体自 `root.mkdir()` 起仍通过933505fe历史
AST哈希守卫；没有修改物理、评分、时窗或原模型。

本次针对性软件回归91项通过；包含六组完整审计、后继合同、密集
端点去重与原回放AST守卫。这是软件证据，不是91场物理成功。
