# 真实脚面材料点控制：接入实现，不是新物理成绩

## 为什么进入这个方向

方向顺应四例已完成：原3/4仍3/4，C0向前.214627m但非足接触，
没有救回，不直接蒸馏。已有原型的静态FK结果只支持重新审查控制点，
并不证明新的目标经过Foundation/父motor/PD会形成有效触球。

本开发在独立worktree实施，没有修改当前6f86cae1物理/审计源，
也没有修改正执行全目录回归的main源码。本文件描述软件接入，
尚未启动新完整模型和物理pilot。

## 实际改动

`use_mesh_surface_swing=False`默认关闭。仅允许捕获完整Foundation
和planner的、已审核mesh世界的、固定父代有界接近/接触开发仿真。
禁止与取消释放、力矩MPC、方向顺应、神经力矩小脑、mode/height、
generated binding、其它解码器/运动探针混用。没有硬件路径。

保留原frame30激活门、旧观察时钟下的选脚、首个六槽任一身体碰球
锁存与20帧释放。只替换首碰前原踝原点IK：scratch读取当前canonical
qpos，查询实际凸脚面最近材料点及同一点Jacobian，目标为当前球心
减去实际球半径乘世界+X方向。竖直值仍取候选已有参数，但解释为
位移误差的上限，不是无条件给脚加固定正高度。新定义必须显式记录，
不能称为与旧固定高度具有相同物理意义。

输出仍为原6关节≤.35rad增量、阻尼.05和原边界方向守卫；基准是
真实Foundation的PD虚拟目标，**不是把实测q冒充PD目标**。父motor
在新pre-motor目标后重新计算本帧动作，后续每帧也使用实际新状态；
不能把旧future target回放或未执行的shadow历史当真实闭环。

逐帧新增39维记录，含时钟/side/active、材料点、球心、Jacobian、
原始Foundation腿目标及新增量。未激活的side明确−1，几何全0；
碰球后的释放仍由原接触增量得到，不伪装成新的材料点求解。

CPU物理重放从自身状态/历史重新选择脚、重建点/Jacobian/IK与原释放，
核对完整记录与navigation→pre-motor→父motor→最终target之和，
再保留原3000子步PD/执行器/身体/球和完整神经链审核。几何与IK使用
同一冻结实现，明确不冒称第二套独立控制算法。
