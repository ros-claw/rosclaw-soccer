# 提前介入诊断：80ms 全反馈分支的零动作校准

本阶段不是球队突破，也不是新教师合格证明。全局 Goal 继续 active。

## 为什么做

正在执行的十二体完整原生实验中，两个原失败案例在20ms触球周期修正后
仍未通过原 M0。局部横向速度改善不能替代完整任务通过。是否存在旧成功
回退，须等十二体全部终结、读回后判断，不能用部分结果提前结案。

当前机制假设是：只在足—球距离很近的最后20ms修正力矩，改变接触几何的
时间不足。这不是已证实因果结论；下一步先排除预测模型自身的多周期偏差。

这条路线不重复先前被拒绝的全局 option4 mesh 教师，也不重新训练第四个
同类参考 BC。旧 option4 扩展教师实测5/12，对照6/12，有三次新增不安全，
仍保持拒绝。新的局部分支如最终不能救回原失败，也必须拒绝。

## 冻结的诊断协议

| 项目 | 固定声明 |
| --- | --- |
| 开发案例 | 原 C3 全六个，保留失败及两种 heading 状态 |
| 分支起点 | 原触球帧减2，仅回顾性校准，不可作为 actor 输入 |
| 分支长度 | 40个2ms子步，共80ms |
| 未来控制 | 在20、40、60ms分别根据分支实际状态重算 |
| 控制组成 | SONIC历史/encoder/decoder、原IK接触退出、原残差及随机序列 |
| 动作 | 本次全部为零；接口允许的有界非零动作尚未获验证 |
| 动作接口时长 | 前60ms可加修正，后20ms必须无修正反馈 |
| 重复 | 每案例从同一原状态独立分叉两次 |
| 原轨迹重积分 | 6×3000=18000步 |
| 分支积分 | 6×2×40=480步 |
| 合计 | 18480步，36次分支encoder/decoder，优化器更新0 |

禁止跨越 planner 更新边界。若任一原案例不满足这个预先约束，整个声明
拒绝，不挑其他时间或丢弃案例。世界、球半径0.11m、质量0.43kg、原课程、
原 H300/post60、正式 M0 阈值均不变；这些静态参数仍须运行时检查。

## 实现和失败闭环

`physics/g1_early_feedback_forecast.py` 是独立的新预测器，旧40ms预测器不变。
它复制完整 MuJoCo 状态，不刷新 donor 缓存，不写回 donor。每个新目标从
上一个分支的实际 NN、IK、残差、身体历史和接触力更新，不从原 donor 重置。
三个中间目标与五类实际神经捕获全部保留；不能只比较最终目标。

`scripts/rsi_calibrate_feedback_branches.py --early-zero` 复用原六案例的认证链。
原未来轨迹仅由外部比较器持有；预测器 API 不接收它。比较全部40子步的
状态、实际力矩、PD、pelvis、真实球接触力，以及四个控制周期的六类接触峰值。
三个未来目标分解与 NN 捕获都分别对比原轨迹，NN要求float32字节一致。
两次零分支的完整数组、末态、三个目标与神经捕获要求字节相同。

首次失败保留原始分支/最后状态、实际预算和失败点，终止该预测器；不自动
重试、不扩大预算、不放宽容差、不改旧冻结源码。运行结果还需独立读回。

单元测试使用 toy 拓扑和合成权重，仅证明组合/时钟/预算/数据记录机制；
它不是正式G1或SONIC技能验证，也不计为学习样本、任务增益或宣传素材。

## 后续决策门

1. 完成正在执行的十二体原生实验，读回并保留负结果。
2. 完成六案例独立完整因果执行器校准；该执行器尚未证明实际G1全300帧一致。
3. 运行本次80ms零动作校准并独立读回。不能因toy测试通过直接筛非零动作。
4. 只有零校准合格才另行声明非零局部筛选，检查更早发力是否改变接触几何。
5. 只有完整原考试净增益且无旧能力/安全回退，才考虑鲁棒教师和神经学习。

阶段进程通过不是 Goal 完成；systemd负责冻结实验，观察器只记录状态，
下一实验选择、负结果复盘和开发由持续的 Goal agent 负责。主机关机或客户端
退出不属于后台观察器能解决的范围。
