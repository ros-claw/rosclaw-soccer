# 有界预测入口控制：实验前协议（2026-10-20）

## 问题与范围

此前同一组四个已消耗的开发球位，名义入口控制只有两个干净脚部触球；另两个出现小腿先碰球，不能接纳整个任务域。这里改入口决策，不改球、PD、接触几何、动作阶段、期限或成功标准。仍是单台 G1 的研究试验，不是球队比赛、官方 M0、Fresh、自主训练完成或新神经运动策略。

基础是已通过实际 CPU SONIC/原生 MuJoCo 对照的 40 控制帧预测器：拥有自己的历史、规划缓冲及物理积分状态，预测分支不改原机器人。该资格仅覆盖一个历史状态；本轮还要逐次检查选中分支与真正执行的前缀。共享只读模型和 CPU ONNX 会话是可信固定调用方的约定，不是抵御恶意代码的安全沙箱。

## 固定实验

- 四个旧球位 `(0.35,-0.10) / (0.50,-0.10) / (0.35,-0.22) / (0.50,-0.22)`，各执行名义控制和预测控制。八个独立新物理实例，同课程配对，不算八个新任务。
- 每实例仍为 H300、50Hz 控制/500Hz 物理；真实执行共 24,000 新原生步。
- 同一个 MotionDecode 射门参考窗口 `[286,767)`、120Hz 声明、50 帧入口插值，六腕参考隔离依旧显式记录；不是完整 29 关节模仿的合格证。
- 原有历史脚部入口几何不变。最早交接第 30 帧，最晚第 90 帧；水平误差不超过 0.04m，姿态限制不变。交接连续保留本体历史，没有重置姿态或物理时钟。
- 在第 20/40/60/80 帧（未就绪、未超时才搜索）比较六个命令：名义、半速、零速、两档速度阻尼、反向制动。水平命令范数仍不超过 0.6m/s。
- 每候选从当前自己的神经与物理状态预测 40 帧。先保持命令 20 帧，再以分支自己的观测执行原名义入口控制；第 91 帧起无条件零命令，和真实超时行为相同。
- 每实例最多 4×6×400 = 9,600 个预测原生步；四个预测实例最多 38,400。总新增物理预算最多 62,400 步。没有优化器或训练样本增量冒称。

## 固定评分与拒绝

评分仅截止首次预测到可以交接的状态；交接后导航预测不是踢球预测，不作为后续踢球安全证明。若没有预测就绪，使用完整 40 帧。

导航前缀存在任意机器人非脚部球接触超过 1N、骨盆低于 0.65m、竖直度低于 0.9，即排除候选。覆盖机器人整棵刚体树，不只膝部；不把地面接触计入机器人违规。

安全候选中：有交接时用 `0.01*交接偏移/40 + 0.02*交接水平速度²`；无交接时用 `1 + 10*最小入口误差² + 5*终端入口误差² + 0.02*终端水平速度²`。固定顺序解平局。六个都不安全则零命令回退，并明确记录“所有候选预测不安全”；零速不是安全认证。

真实机器人每帧重新推理 SONIC 并积分原物理。任何分支的姿态、关节目标、参考缓存都不移植回来。入口后的踢球参考仍不根据球重定向，这是能力边界。

## 可复核性及结论边界

执行器 `scripts/rsi_probe_predictive_ball_entry.py` 在导入项目和分配物理实例前校验固定源码、历史独立回放、预测资格、模型、权重及原始数据身份，结束后再次检查。名义组全部轨迹数组必须与历史记录逐元素完全一致。

保留六个候选的全部物理、神经输出、参考、命令和评分（包括失败候选）；每次选中候选须与真实执行直到下次换命令或真实交接之前的全部预测数组精确一致。最终判断使用真正 H300 的全身触球与身体指标，不用预测评分冒充触球成功率。失败、超时或新增违规不能从分母移除。生产者的一致性断言不等于独立复核；独立复核结论须另行记录。

原始资料和轨迹在 Git 外；MotionDecode 研究授权不自动允许商业宣传视频。SIM_ONLY，不晋升、不授权硬件。

### 失败机制及下一步

1. 40 帧只覆盖 0.8 秒，早期候选都看不到原名义控制第 89 帧的有效入口。例：球位 0 第 20 帧六候选都预测不到交接，评分偏好 `brake`，结果错过固定交接期限。后期最小位置误差仅 0.0106m，也已经太晚。不能用放宽期限把失败改成成功。
2. 球位 1 的第 67 帧入口满足几何门，但后来脚碰球在原生步 2189、非脚碰在 2413，球最终倒退 0.273m。几何入口合格并不等于运动历史、支撑腿相位和接触质量合格。导航前缀评分没有覆盖真正决定足球结果的接触参考。
3. 下一轮应直接预测**当前同一身体的完整剩余任务**：保持神经历史，真实交接参考，预测到原任务第 300 帧，检查触球方向、非脚碰球、身体与恢复，而不是只把导航误差调得更小。保留逐帧名义反馈候选，避免把它误替换成“20 帧恒定名义命令”。先用有界前瞻老师产生可靠成功/失败数据，再谈三种子学生训练；禁止把本轮叫作 RL 学会了踢球。

独立读者 `scripts/rsi_verify_predictive_ball_entry.py` 从重新积分的真实前缀，重新执行全部候选的记录 PD 目标与原生物理，并独立重算候选命令、评分和选择。它共享合格的 warm-clone 助手，但不重跑 SONIC 推理或导航参考生成；不能称独立神经策略复现。独立回放最终状态须按外部闭合文件另行确认。
