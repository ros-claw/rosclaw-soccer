# R1 传接射父代局部成功盆测绘协议

状态：`SIM_ONLY / CONSUMED_DEV / NO_PROMOTION`。

固定当前 `main` 上的六台 G1 3v3、单球、8.7 s、原 `nearest` 足选择、传球脚速 `0.80 m/s`、零 stroke、种子 `207200` 和原窄训练门；本轮不训练新策略、不改变球/机器人物理状态。已见中心 `(1.92,-0.80)` 成功，±2 cm 轴向和对角球位均失败。

仅补测预声明的 3×3 局部网格，排除已见中心，共 8 个不同球位：`x∈{1.91,1.92,1.93} m`，`y∈{-0.81,-0.80,-0.79} m`。逐球位完整运行 6-G1 MuJoCo，保存哈希绑定的协议、轨迹、结果和 500 Hz 脚到脚接触链。成功同时要求全部机器人安全、承诺后的发球脚接触、无中断接应脚接触、接应之后真实球在训练门几何内越线，且球速达到射门阈值。重复运行、种子变化不计为新球位。

此网格全属训练/诊断；绝不称 Fresh。若 8 个球位里没有至少 2 个新增完整成功，不以单点监督模仿训练伪造“可泛化小脑”；下一步转一机一球首触课产生多样且独立的正样本。若达到 2 个，也仍需冻结策略，再预声明未见连续球位和新来球速度做独立评估，且不能以此代替标准球门与 4v4 连续比赛门。

## 实际结果与停线

八个新球位的完整物理链为 **0/8**，没有新增正样本；最大球速范围约 `0.0005–1.4995 m/s`，均没有真实门线穿越。每球位的源码稳定报告/轨迹位于 `/data/rosclaw_overflow/rsi-r1-local-map-20260928-{xminus_yminus,xminus_center,xminus_yplus,center_yminus,center_yplus,xplus_yminus,xplus_center,xplus_yplus}-v1/`。这是已见局部网格，不是独立新鲜成功率估计。

依协议停止从 R1 单成功点直接做行为克隆。将中心、±2 cm、两组接触消融、固定左脚、±1 cm 网格共 **24 条不同开发执行**交给哈希校验的失败挖掘器：完整传接射 `1`，承诺后发球脚无接触 `13`，发球脚已接触但接应脚无接触 `4`，传递中断 `2`，没有产生传球承诺 `4`。正式汇总 `/data/rosclaw_overflow/rsi-r1-first-touch-frontier-20260928-v5.json`，哈希 `sha256:e359aa720e6bbfc6b5431f995e570cf6898f530b798ab7838061aa1ff11aac8b`。`v4` 因无传球承诺回合触发拒绝而未生成报告；挖掘器现明确区分 `NO_PASS_COMMITMENT`，不会把这类回合误计成发球失败。此分布是人为选择的开发课程，不能称为球队真实比赛统计。
