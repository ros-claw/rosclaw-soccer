# 持续实施不是进程存活：续跑边界与下一项资格

## 续跑机制

产品目标保持ACTIVE且未设预算；目标续跑负责触发下一轮Agent工作。
已有60秒systemd observer只读进程、CPU增量与落盘检查点，明确不能
自行唤醒LLM，不能开发科学后继，也不能把运行时间计为学习收益。
断点记录保存在外部evidence，包含固定源码、输入哈希、正在执行的
unit/输出、已消费案例、失败结论及下一项。恢复先核验，不重复收费。

每轮依次：检查真实在跑/已结束/失败状态；核验原始证据；做出下一项
可检验假设；测试实现；冻结源码与输入；运行有界SIM实验；审计结果。
不因小改进结束总体目标，不重复已否决训练族，不把资格测试当球技。
所有worker结束后需要Agent继续实施，不允许对旧unit声称“仍在训练”。
没有模型调用机会、机器断电或服务故障时，不能承诺LLM仍在工作。
systemd也不自动获得科学重试权；失败时保留原始轨迹并转入诊断。
