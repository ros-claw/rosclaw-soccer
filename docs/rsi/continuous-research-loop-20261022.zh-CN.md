# 持续研究循环：真实执行、证据接续与失败处理

这里的“持续”不是启动一个监控进程就算在训练，也不是无限重跑同一失败实验。

## 三层接续

1. 推理层：活动研究目标负责审阅结果、诊断失败、声明有科学差异的下一阶段。目标未达成时不能标记完成。监控脚本本身不能唤醒或替代这一层。
2. 执行层：`scripts/rsi_run_motor_dagger_stage.py`在冻结源码下依次执行真实训练、独立CPU复算、无辅助原生44世界考试、独立原生44世界复验。各步骤通过完整凭证衔接，不需要人工逐次发送“继续”。
3. 观察层：已有研究循环监控读取进程、阶段文件和账本，报告等待、运行、失败或需审阅；不能把CPU活动或文件变化当作科学成功。

当前这条执行链每阶段只允许一次，固定最终检查点，不根据结果放宽阈值，不筛掉失败世界。六项调度测试覆盖完整接续、每个阶段失败后停止后继、错误数据生产者在更新前被拒绝。调度测试不是机器人能力证明。

## 数据闭环

失败候选的实际观测与自身循环状态 → 教师在这些真实状态上纠错 → 所有辅助世界独立物理复验 → 只接纳胜任的纠错轨迹 → 从实际失败模型的权重继续学习 → 无辅助重考 → 独立复验 → 保持性与新技能判断。

教师状态不移植给学习者；学习者从自己的零状态重算完整历史。教师辅助的前缀和结局不用于宣称纯学习者的在线PPO成功。当前实现仍是监督式循环小脑适配，不把它写成已经实现在线强化学习。

## 实际进度与证据上限

2026-10-22，原教师在4个问题情境中均失败；三维接触点纠错教师在其中2个通过，24个生产世界及全部24个独立复演各执行93,360个原生物理步。两条胜任纠错历史连同原22条序列构成新学习集，原文件逐字节保留，不把复制算新增样本。

后继模型真实完成256次新Adam更新，并通过24条完整历史的独立CPU输出复算。无辅助物理考试中，第一技能通过数从上一版12/20恢复到13/20，旧情境5恢复；但受保护情境4仍丢失，两个较远TRAIN情境仍有非脚部接触，不能晋升。本轮全部44世界独立物理复验已完成，逐步一致，候选仍被拒绝。

精细碰撞证据表明`left_knee_link`下实际接触几何是`left_shin`小腿胶囊体。球只离地数毫米就接触了它，不能断言是球飞高撞膝。目标关节姿态与实际姿态也不能混为一谈：前者的静态避碰间距可能很大，真实小腿却因控制滞后碰球。新实验因此改用观测姿态加修正量、结合40ms接近速度预测，而不改小腿形状、球半径或接触过滤。

静态与观测预测两版约束各完成24世界生产及独立复验，均未增加通过情境，仍为2/4。不能把实现了约束就叫能力提高，因此停止继续扫教师参数。下一步转向纯学习者的有相关性随机探索：2个TRAIN情境×4个随机种子共8条真实轨迹，31,120个原生步、3,112次网络决策，无教师、无动作裁剪、无越权提议执行。初步有1条通过现有粗规则；独立物理与采样概率复验在进行中，暂未接纳为训练数据。

新的双记忆AR(1) actor-critic损失已实现数学和梯度测试，能拒绝辅助轨迹、未执行提议、错误采样概率和缺失终态；价值梯度不能偷偷更新运动策略。但尚未用该损失对真实机器人仿真轨迹做PPO优化，不能把这些测试称为在线强化学习成果。

## 故障边界

失败会留下实际工作计数、已完成步骤、错误和无自动重试标记，后继不得拿不存在的完成凭证继续。重启后先读取恢复指针及原始凭证；部分执行不能简单从头复跑并抹掉物理预算。需要推理层声明新的恢复阶段。

服务退出后显示`active`但PID为零不代表仍在训练。系统断电、进程故障和推理调度中断也不能靠一句“保证永不停”消失；真正可核对的是任务接续、持久证据、故障可见和后续明确决策。

总体目标仍是稳定、自主、可展示的连续球队比赛，不是局部TRAIN情境、单元测试数量或低训练损失。所有工作保持SIM_ONLY，不授权硬件，不自动晋升研究策略。
