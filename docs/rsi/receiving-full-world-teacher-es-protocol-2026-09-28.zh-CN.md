# 完整 8 人接球教师训练协议（开训前冻结）

状态：`SIM_ONLY / CONSUMED_DEV`。本协议只在已消费的 `red.finisher` 来球课程 `(seed=92801, v=1.25 m/s, lateral=0.08 m)` 上寻找**可训练教师**，不声称训练了神经小脑，也不把训练成绩当作 Fresh/宣传资格。

## 为什么换训练世界

单人 live SONIC 代理的球速响应方向保真，但对两个完整 8 人干预的尾窗脚距分别低估 `0.04263/0.07871 m`，超过预定的 `0.02 m` 门；联合任务排序未获授权。完整 8 人审计又看到脚距变近但球速变快的反例。因此下一轮所有选择都用同一个真实 8-G1 CPU MuJoCo 世界、实时 SONIC、物理球、原接球考试与安全壳评判，代理不参与选优。

## 冻结项与可塑边界

- 冻结已封存的 SONIC、神经力矩学生、8 人球队策略、球/场地/接触模型、130 帧课程与接球阈值；不更改球状态、碰撞、关节/力矩安全投影。
- 仅让 SIM_ONLY 笛卡尔左足接触教师的 `(触前增益, 触后增益, 足踝目标 x 偏移, 足踝目标 y 偏移)` 四个有界参数可塑；这不是最终部署策略。
- 预算最多 3 代×12 条，首轮实际先 2 代×8 条；随机种子 `20260928`。每代有父代与因果横向校准点；其余用固定种子采样、精英更新，所有运行保留轨迹与承诺哈希。当前中心 `(0.3,0.3,-0.18,0.03)`，校准点 `(0.3,0.3,-0.18,-0.03)`。
- 只用完整 8 人物理作为发展分数。安全且本足触球、无本体非脚碰才计分；任务排序主项为尾窗球速/0.35 与脚距/0.35 的较大值，次项惩罚首碰后横向速度和触后骨盆后移。无足碰/不安全记硬失败。

## 停线与下一门

若 2 代内没有一个候选同时满足原权威接球任务的 `≤0.35 m/s`、`≤0.35 m`、至少半秒触后观测、无禁碰/身体安全，则**停止这条固定足位教师路线**，不得因连续分数改善而宣称成功；复盘接触动力学，转向全身时序动作空间。即使已见课找到成功教师，仍只标记 DEV 正例：要在开封前独立声明新的来球位置/速度课程、旧技能保持和完整三人/4v4 验收，按逐级门控完成后才能训练/晋升学生与做宣传片。
