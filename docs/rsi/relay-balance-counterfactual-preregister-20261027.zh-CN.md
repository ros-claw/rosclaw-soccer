# 双 G1 回传的有界平衡反事实：预先声明

本实验是开发集特权教师可达性研究，不是强化学习、不晋升策略、不改变旧的纯脚接稳考试。此前 96 场神经回传中，23 场一人身体失稳，既有 A 也有 B；失稳可能发生在 B 交接后的几秒，不应直接假定只要缩小首个动作跳变就会成功。

## 可推翻的假设

在 B 获得既有实际接球交接条件后，来自当前身体姿态与速度的有界反馈，如果能通过原神经电机的关节目标进入物理世界，可能减少 B 失稳，同时保留先前健康回传。对照结果必须分别记录 A 和 B 是否失稳、实际触球、回传精度及健康结果；不以“动作非零”作为成功。

复用三个以前以物理采样优化、并各自通过原生重放的 `paid_balance_recovery` 教师增益，**不认为它们已经适用于本任务**。其中一个旧教师在不同旧开发迁移集的健康恢复曾从 7/16 降至 2/16，这是明确的负迁移警告，不能按其旧成功直接使用。三个教师和全部对应的旧独立审计文件必须按哈希同时准入；不是选择最好的一个后隐去另外两个。

## 配对合同

对三个既有开发情境块分别完整执行四个初态、两个接球侧位和四个方案，即每块 32 个共享物理世界、总计 96 个。每个初态下：

1. 基线保持原 `start=80`、B 自身影子记忆交接、无反馈的神经回传；必须与上一轮同一初态、同一方案的源轨迹和结果核对。
2. 三个候选分别使用上述三个旧教师；只有 B 真实达到原接球交接条件后才开始使用其当前身体反馈。
3. A 和 B 均实时执行自身神经推理；A、球、初态、物理参数、接触、时钟和 B 交接条件不变，不播放保存动作、不修改球、不在回合内重置。
4. 复用 `body_feedback` 与 `feedback_delta`，额外 B 关节目标修正请求限于 ±0.08 rad、逐控制周期请求变化限于 0.02 rad；最后动作仍被限制在冻结参考神经输出 ±0.2 rad 的原总权限内。记录提议、饱和后的实际动作与身体响应，神经历史反馈必须是实际执行动作。修正本身不是网络学习。
5. 原 300 周期内须发生实际接球交接；交接后的最多 600 控制周期仍为独立新协议。实际身体失败立即结束，不延长或改写先前实验。

所有 32 个声明课程在每块第一步物理执行前做完整预检；新来源与独立手动原生时钟重放均固定代码和输入哈希。保留每条失败，不将 source 和 replay 当作独立课程。严格比较基线、三个教师的完整联合结果与所有 24 个初态，列逐例救援、退化及 A/B 失稳，不能只挑最好的场景或最佳随机教师。

若没有可重复的健康回传净增益，或任何旧成功退化而没有得到严格处理，则拒绝此教师族，不用其生成成功模仿标签。即使开发集有信号，也必须检查方向与动作权限、历史保持、不同扰动和独立 Fresh；最终训练新的数据驱动策略并在真实物理闭环检验后，才能声称学习改善。所有实验仅为 `SIM_ONLY`，不授权真实机器人。
