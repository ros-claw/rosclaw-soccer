# S347：上一帧动作换坐标修复，不等于球技自动提升

普通和矢状镜像推理来回切换时，原适配器变换了传感器与输出关节目标，
但未变换 RoboNaldo 输入中的上一帧 action。新增显式、默认关闭的
`locomotion_action_frame_sync`：先按策略归一化及关节映射还原目标，
在物理关节顺序中镜像，再逆映射/归一化。不能直接反转 action 数组。

这是单个球员同一模型的私有推理坐标修复，不执行动作、不改变物理状态，
不导入其他模型的影子历史。首帧不伪造过去坐标；异常恢复 action 与坐标标记；
重复同一坐标不重复变换。实验开启时逐帧记录每人坐标及切换次数。
默认配置及固定哈希保持不变。

## 实际对照结果

红蓝两侧 × 同步关闭/开启，共四次 20 秒八机器人真实 MuJoCo 课程。
所有模型权重、S345 组合策略、球摩擦、速度、避碰和力矩约束保持一致。

- 四次均身体安全、零机器人间接触、无身体模型故障。
- 两个关闭对照与 S346 旧权重确定性考试逐数组精确复现。
- 关闭时蓝队仍有三秒内真实脚接球；开启时丢失该接球。
- 红队开启/关闭都没有合格纯脚传接球链；整场门控均未通过。
- 开启时坐标切换计数与每帧实际坐标变化完全一致。

因此不全局启用、不替换冠军，也不称“修复后更稳更会踢球”。
数学接口一致性已证明，但旧策略在该接口下需要重新适配与物理保留验证。
后续 S350 又确认基础策略有 LSTM 隐藏态/记忆态；本阶段没有变换这两项，
因此 action 修复不是完整循环策略的坐标修复。详见 S350–S351 报告。
蓝队原有接球还只是触到后继续滚走，并未形成可控停球及下一脚传射。
后续要把实际触球和可控接球分开评价，不能只优化触球率。
