# 接触参考的原 NN 与原生物理验证

## 第一项动态结果：相对实际姿态差量

已在固定失败案例 8 运行一个真实原生回合 3600 子步，以及两个私有 NN 未来共 2560 子步。
参考由当前身体的原 NN 未来生成，未把保存的轨迹当作控制输入。
128 周期的新预测与实际 q/v、力矩、接触力及 NN 关节目标逐数组一致，完整回合保持身体健康。
303 个周期的目标相对原始回合发生变化，证明新参考确实通过网络影响了动作。

但正式任务仍未通过：首次足触球 71→89，触后侧移 1.472→0.303 m，非脚部峰值却从
62.49 升到 144.71 N。不能将其中的侧偏改善描述为学会了更好的射门。

独立读回重建了 5 个实测入口样本、128 个真实身体的 547 维输入，重跑原 NN 并复核实际目标。
还从私有原未来重新生成 IK 和参考曲线；该复核无新物理积分，只有 128 次 NN 推理和
5 次按原构造器源码计数的预热。原数学/IK 函数被复用，不冒称独立数学实现。

## 发现：两个不同的目标基准

IK 在预测的实际关节姿态上求解，第一版却把这个差量加在原始参考关节姿态上。
两者在该例相差明显：原参考与实际父代最大偏差约 0.673 rad。
在相同父代根位姿上，条件参考关节的脚部接触点与 IK 目标相距约 0.434 m，
实际峰值时刻脚部相距约 0.212 m；真实首次足触球还换成了左脚。
这是目标语义不一致的具体证据，而不是运动链路未执行。

## 下一项独立实验：绝对参考端点

`AbsoluteContactReferencePlan` 将腿部参考在指定时刻直接定位到 IK 求出的绝对关节配置。
当前参考入口、旧参考历史、锚点和神经网络权重不变；使用同样的 C2 时间曲线和一致速度。
原相对差量合同仍保留 .35 rad /4 rad/s 限制，不被悄悄放宽。

绝对端点在案例 8 需要约 0.825 rad 的参考差及 5.53 rad/s 的附加参考速度，
不能假装它满足旧合同。因此新合同明确使用物理关节范围约束整个变化参考窗，
并声明 **6 rad/s 的附加参考速度上限**。这是新的 SIM 任务参考权限，不是增加真实执行
残差限幅、PD、力矩上限或修改球体尺寸。

只开展一个预注册来源失败场景的资格试验，不做幅度/速度/seed 网格。
实际动作仍全部由原 NN 和原生 PD 产生；预测、实际回合和原 H300 评分仍必须分别验证。
若参考范围不可行则弃权，若动态失败则保存原始证据，不放宽考试来换成功。
