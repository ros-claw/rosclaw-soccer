# S221：八个角色确实一起学习，但尚未通过完整比赛门

## 实际训练

从 S219 第 44 代继续到第 48 代。每代冻结八个私有 actor，分别在双方
门将、后卫、中场、前锋开球课程中采样；收齐后逐人执行 PPO 更新，
其余七人冻结，实际通过 Core PlasticityLease 约束。4 代共 32 对训练回合。

残差训练掩码。冻结的步行底座仍限制了跑速和运动范围。

## 冻结均值策略的 16 个父子配对场景

双方四角色、每角色 ±0.06 m，父子各 16 对严格重放，共 64 条验收轨迹。
这组球位没有用于本轮更新；训练球位与验收球位由独立课程模块生成。
4 轮训练和验收共计 128 条真实 CPU MuJoCo 轨迹。

| 指标 | 父第 44 代 | 子第 48 代 |
| --- | ---: | ---: |
| 世界安全回合 | 16/16 | 16/16 |
| 比赛评估器传球事件 | 2 | 4 |
| 旧 3 秒诊断接球记录 | 1 | 5 |
| 全程无非脚控球的回合 | 11/16 | 8/16 |
| 严格合格传球回合 | 0 | 0 |
| 完整比赛通过 | 0/16 | 0/16 |

因此保留为研究候选，不晋升。不能用事件数量增长掩盖非脚碰球退化。
诊断记录会因多次传球承诺而多于评估器事件，不能把 5 当作五个独立进球
或五场成功比赛。新版审计逐接触时刻绑定两种记录，并检查整场脚控球门。

## 发现奖励与验收口径不一致

比赛评估器允许两次脚接触相隔 6 秒；旧诊断从传球意图开始只看 3 秒。
例如 S219 红方负偏移：首次脚接触约 1.28 秒，接球约 4.14 秒，
评估器有传球事件，但训练诊断/延迟奖励没有成功。这不能靠增大 γ 修复。
后续将准备超时和有效触球后的飞行窗口分开，加入非脚/对手触球中断，
显式版本化奖励合约；不回改旧轨迹或悄悄重定义历史成绩。
