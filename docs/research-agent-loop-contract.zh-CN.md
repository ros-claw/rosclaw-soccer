# 持续实施的 Agent Loop 合同

目标是通过原生物理证据证明连续自主球队能力，而不是让某个 Python 进程一直运行。
宿主的持久 Goal 必须保持 active，直到真实达标或用户要求停止。观察定时器不提供模型唤醒，
不能以它替代宿主接续，也不能承诺跨宿主退出、断电或网络故障的无限运行。

每次接续读取外部 `next.json` 指向的不可变阶段记录，核对提交、输入哈希、运行单元和真实产物。
接续链为：假设与有限预算 → 源码预检和冻结 → 实验 → 原始产物保存 → 独立读回 →
任务评分及失败归因 → 新方法/训练阶段。实验退出不等于目标完成，预检、心跳和接口通过也不是球技进步。

已有 `research_loop_continuity` 在无存活声明任务时保留空闲起点，默认 300 秒后标为
`SCIENTIFIC_SUCCESSOR_OVERDUE`；改指针或写新心跳不能清除空闲期限。
该状态意味着 Agent 应继续分析/开发/验证，不意味着自动重跑失败实验，更不授权真实硬件动作。
源码开发和失败分析也可以是有效工作，不能为了填充运行队列而无依据扩大实验。

正常阶段结束时不要求用户再说“继续”。目标未达则保留 active 和具体后续待办；
需要新增权限或外部输入时如实提出阻塞。用户暂停/重启请求优先，先保存可恢复状态。
视频仅由已验证的物理轨迹导出，不能用剪辑遮盖正式考试失败来宣称突破。
