# S2226：从单边球技回到双方球队能力

## 目标与结论边界

重新对照《rosclaw_soccer想法1.md》的主线：接球、连续控球、下一次决策和团队成长，而不是无限追加孤立射门参数。当前仍未达到连续自主 4v4 宣传片标准。本轮首先检验已有接球与出球模型能否用于对面球队，随后针对失败角色收集自己的物理学习数据。

## 显式坐标契约，不静默修改旧模型

旧接球输入的 135 个字段混合了关节/本体量与世界坐标量。新增可选契约 `recurrent_receiver_canonical_heading_135_float32.v4`，必须明确指定 `canonical_half_turn`：

- 转半圈时，仅反转世界根部线速度 XY（61–62）、球相对根部世界偏移 XY（67–68）、球世界速度 XY（70–71）和朝向 sin/cos（133–134）。
- 保留重力、本地角速度、关节位置/速度、残差历史和基础 PD 目标；不镜像关节，不改物理姿态，不移动球。
- 不是任意角度转换，不是把全部字段改成本体坐标；旧 v1/v2/v3 不接受该选项。
- 开关进入内容哈希，冻结执行器和训练采样器使用同一转换；训练保留转换后的实际输入、原始采样和对应概率。
- `False` 不改变旧 v2 的数值行为，但新契约明确区分来源。

近球策略本来使用本体相对字段。本轮另建候选，把 8 个私有角色权重的两队行对换，保留父哈希和旧检查点。固定随机探索的行也显式对换，让红方对应角色使用蓝方同角色的随机序列。此操作是结构复用，**不是优化器学习**。

## S2226：8 次真实物理执行

四种条件各进行 primary/replay 两次独立 MuJoCo 模拟，8 秒共享 4v4 场地，双方角色与原场地尺寸不变；每个接球执行器保留独立状态。蓝方球位 `(4.92,-0.49,0.115)`，红方半场对称球位 `(1.08,0.49,0.115)`。红蓝近球随机种子均为 207811，冻结接球网络取均值；不能把整个回合称为无探索均值策略。

| 条件 | 全体身体安全 | 中场接球 | 前锋接球 |
| --- | --- | --- | --- |
| 蓝方旧契约 | 通过 | 通过 | 通过 |
| 蓝方新契约、不转换 | 通过 | 通过 | 通过 |
| 红方新契约、不转换 | 通过 | 无脚触球 | 无脚触球 |
| 红方新契约、半圈转换 | 通过 | 无脚触球 | 无脚触球 |

蓝方两条件整段物理数组完全相等。红方转换后中场最小足球距离从约 0.181 m 降到 0.164 m，但没有实际脚接触，不能算接住。红方前锋也没有接球成功。因此坐标兼容性并不等于物理技能泛化，不晋升候选。

## 后续学习边界

S2228 针对红方中场单独收集 on-policy 接球轨迹，冻结基础小脑、近球策略和前锋接球模型；只允许红方中场候选权重在 Core 学习租约内更新。先测试同一初态下能否学会接球，再考虑扰动泛化和连续串联。固定初态上的探索样本不能称为任务分布泛化；训练样本中的一次成功不能替代冻结候选的独立考试。本文件在实验完成后补实际结果。

新增 20 项测试覆盖精确字段映射、半圈转换自反性、输入副本、非法字段/开关拒绝、旧输入与动作精确兼容、模拟身体旋转，以及训练实际输入与采样概率。接球链路相关初次回归 84 passed；新增采样器测试后独立新模块/采样器 25 passed。mypy（3 个改动源码）与全仓 ruff check 通过。

设置真实本地 G1 资产路径后的全量回归：**3931 passed、18 skipped、11 个既有历史证据绑定失败**，与上轮同一失败列表。日志 `/data/rosclaw_overflow/s2228-full-regression-assets.log`。不设置资产变量的一次回归为 3920 passed、29 skipped、相同 11 failed；不把这些资产跳过算作验证通过。

没有修改 Core 用户工作区；没有硬件执行。所有实验保持 SIM_ONLY，受 ROSClaw / SimForge 技能的模拟与证据边界约束。
