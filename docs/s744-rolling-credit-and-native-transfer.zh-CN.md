# S744–S754：旋转、落点与原生物理回测

## 当前结论与边界

本阶段仍未达到 4v4 宣传片验收。所有工作均为 SIM_ONLY；没有改变球或脚的碰撞尺寸，没有瞬移球、注入出球速度、拼接成功轨迹，也没有开放实机动作权限。

发现了一个可以复现的误差来源：只用球的线速度推算地面落点，会忽略滑动转为滚动过程中旋转对运动方向的影响。加入当前角速度后，预测更准确；**这不等于模型已经踢得更准**。因此下一步采用配对训练和原生物理回测，检验这个观测是否能转化为技能进步。

## 滚动估计的含义

实测仿真球质量 0.41 kg、半径 0.115 m，球体惯量比 κ = I/(mR²) = 0.4。

在理想平坦地面上，忽略弹跳、阻尼、滚动阻力和后续碰撞，滑动摩擦同时改变线速度与角速度。达到无滑动滚动时，水平速度估计为：

`v_roll = (v + κ R (ω_world × upward_normal)) / (1 + κ)`

这只是理想模型，不能用于空中高球，也不预测何时触地。S748/S750 回顾性选择首次脚接触后 0.2 秒内的最后一次接触，**不能把这个未来信息当成在线释放检测器**。正在进行的训练使用每个当前物理步前后的测量值，不读取未来接触。

MuJoCo 自由关节的转动速度是局部坐标，不能直接与世界坐标的平移速度混用。新增 `world/rolling_ball.py` 明确做局部到世界的旋转转换。18 项测试覆盖纯滑动、纯滚动、旋转等变性、四元数双覆盖、非法输入，以及与原生 `mj_objectVelocity` 的 20 个随机状态对照。该模块只读、不产生电机指令，也不改变旧策略默认行为。

坐标和接触语义参考：[MuJoCo 编程文档](https://mujoco.readthedocs.io/en/3.3.0/programming/simulation.html)、[MuJoCo 建模文档](https://mujoco.readthedocs.io/en/3.6.0/modeling.html)。上述公式是本实验使用的理想冲量关系，性能数据来自本地录制轨迹。

## 正在进行的受控实验

- S751 / S752：同一个 S715 最终模型、相同随机种子、相同原生 CPU 物理和 CUDA 冻结教师，各做 8 次 PPO 更新。只改变立即脚接触奖励所用的速度：线速度或计入旋转后的理想滚动速度。两者都不修改真实速度、安全、非脚接触、0.1 米落点验收。
- S753 / S754：固定训练前 S715 与训练后 S745 的最终模型，用相同新种子 75302，在**原生 CPU 物理和原 CPU ONNX 教师**上进行 32 例回测。不从测试结果中挑选某个中间 checkpoint。

即使局部回测通过，仍需回到共享世界验证接应、争球、射门和身体恢复，才能考虑宣传视频。不得把独立短程出球成功替代完整比赛质量。

## 失败与未解决项

- S740 加大参考朝向搜索仍只使 4 个开发上下文中的 2 个达到精度要求；困难上下文没有突破。
- S742 局部有限差分模型预测的改善不能稳定转化为真实接触结果，最终仍只有 2/4 精度通过；不能视为可靠物理梯度。
- S746 把前锋战术传球通道阈值从 0.55 降到 0.50 米，改变了早期比赛决策，最终 15.62 秒触边出界，没有进入学习射门；不是一次成功的晚阶段接应修复。
- S747 首次接触记录脚本因局部变量覆盖分布对象而失败；保留失败目录，S749 新脚本修正后重跑，未覆盖失败实验。
- S738–S741 已修复的未发球接应承诺生命周期，使相关队员无效等待从 1.72 降至 0.16 秒，但球轨迹完全不变；这是运行时改进，不是足球技能提升。
