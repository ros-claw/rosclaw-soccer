- 该任务接管期间，残差策略观测使用固定任务方向，不跟随上层瞬时追球目标反转。
- 原始轨迹记录任务目标，供 `motor_task_contact_v1` 奖励使用。
- 传球的虚拟运动参考距离不再代替真实接球队友的任务目标。
