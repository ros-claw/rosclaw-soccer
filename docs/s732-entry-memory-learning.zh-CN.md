## 为什么改变学习结构

S730的统一输出偏置只能小幅改善最差落点，S731的局部落点模型又被优化过程利用了预测误差。四个入球状态需要不同修正，是当前待验证的判断，不是已经查明的唯一原因。继续增加同类参数搜索不能直接证明自然性和泛化提升。

新增 `training/entry_conditioned_actor.py`：保留并冻结完整136输入/30输出父actor-critic，添加六维入球记忆条件化的actor和critic分支，另行训练探索标准差。六维为动作入口时、同一运动坐标系中的球相对身体XYZ与球线速度XYZ；收集器在整段动作内保持不变，不使用未来触球或落点。新网络总输入142维、输出30维。

训练集入口均值/标准差作为检查点缓冲区保存，尺度最低0.001；输入、校准和输出都有有限值检查。标准化输入截断到±5，动作logit修正限制在±0.5，既有关节残差、参考朝向、关节范围、力矩和接触门槛均不放宽。校准副本隔离，检查点加载后的非法尺度在推理前拒绝。

这是冻结基础控制器上的可学习残差，不是端到端关节力矩网络，也不代表运行中的机器人获准在线改权重。通用学习许可、晋升与证据合同仍属于ROSClaw Core，此处只是足球下游训练适配。
