# S225：八路角色课程采样的确定性验证

本阶段改进采样吞吐，不宣称球技提高。角色课程可显式选择 1–8 个 CPU
MuJoCo 进程，旧双边课程仍限制 1–2 个。每场的种子、输出路径、冻结父策略
及严格接力配置由主进程固定；使用 spawn 和有序 map，不依赖任务完成顺序。
不会自动占满机器，也不终止其他人的 GPU/CPU 进程。

## 实际验证

从 S221 第 48 代出发，S224 用 2 路、S225 用 8 路，执行相同的第一代
八角色课程。八场主轨迹及其独立重放的哈希逐一相同，更新后第 49 代的
policy hash 也完全相同：

`sha256:405ffeb312388f1d1ae140bf5e42a19b2666ff111fc407ef87eda11966b0c439`

S225 完成 8 组训练、父子各 16 组验收，总计 40 组 / 80 条物理轨迹。
独立学习审计复算了 8 个 Core 私有更新证明，八名球员均获得有效采样和
actor/critic 更新。审计通过不等于完整比赛通过：父子均没有合格整场比赛，
严格 qualified_passes 均为零，不晋升候选。

证据目录：`$ROSCLAW_SOCCER_EVIDENCE/s225-eight-worker-replay-v1/`。
`learning-audit.json` 保存逐球位验收；S224 的第 49 代及八场对应训练轨迹
保留于相邻的 `s224-launch-credit-private-ppo-v1/`，可独立比较。

新增四个测试覆盖八路固定任务身份、单一冻结父策略、独立种子、严格接力，
以及超预算、旧课程超预算和布尔伪装 workers 的拒绝。物理试验仅支持当前
机器、软件栈和这组种子的确定性，不保证跨硬件浮点结果相同，也不报告未经
受控基准测量的加速倍数。
