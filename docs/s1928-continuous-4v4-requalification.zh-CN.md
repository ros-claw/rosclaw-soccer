# S1928 起：重新验证连续自主 4v4，而非单次扑救

## 目标与边界

本轮回到 `rosclaw_soccer想法1.md` 的球队主线：红蓝对称，各一名门将、
后卫、中场、前锋，八个独立 Cell，同一物理时钟和一颗球。单场高球扑救
视频不能证明这一能力，也不能用不同场景的镜头拼接证明连续比赛。

这次不是新一轮 PPO 训练。行走沿用冻结神经策略，战术与接触教师仍主要
是解析规则；正在定位阻碍学习闭环的接口和状态分布。全部 SIM_ONLY。

## 已完成的工程接入

`training.continuous_competitive_match_growth` 现在允许显式传入完整 fixture
和 scenario，复用原来的双跑、轨迹绑定、物理接触评估和失败保存。
CLI 增加 `--players 8` 和 `--duration-sec`；默认六人、10 秒协议不变。
八人入口使用对称阵型、双球门、基础球权技能和中央静止开球。
报告中的身体数量从实际 fixture 计算，不再写死为六人。
新增报告保存 fixture 和各 Cell 配置快照；`--contact-ready` 显式选择本轮
实验协调配置，不改变默认协议，也不表示模型已训练或晋升。

```bash
python -m rosclaw_soccer.training.continuous_competitive_match_growth \
  --asset-root "$ROSCLAW_G1_ASSET_ROOT" \
  --players 8 --duration-sec 10 \
  --evidence-dir "$ROSCLAW_SOCCER_EVIDENCE/new-4v4-baseline"
```

这里复查的是历史训练场协议：球门 3×2 米，球半径 0.115 米、质量
0.41 kg 的配置。不是成人标准比赛装备，也不是合格宣传片。不能因为
另一份三人场景使用标准装备，就继承它的尺寸声明。

## 原始实验

证据在外部 `ROSCLAW_SOCCER_EVIDENCE`，不进入 Git。所有完整实验均 primary
加 replay，不把复跑计为独立样本。S1928 v1 在物理开始前因 scenario ID
前缀不符合旧契约而失败；v2 修正标识，未放宽契约。

| 实验 | 时长 | 改变 | 结果 |
|---|---:|---|---|
| S1928 v2 | 10 秒 | 八人基线 | 身体接触累计计数 2231，红前锋关节越限，无传球 |
| S1930 v1 | 10 秒 | 近球接管、预测避让、全角色净距约束 | 零身体接触，身体安全，但球完全没移动 |
| S1932 v1 | 10 秒 | 另启用预触球动作意图 | 零身体接触、身体安全、干净脚触球和夺球；无传射链 |
| S1934 v1 | 20 秒 | 偏置开球、严格接球交接、接应承诺优先 | 身体安全，仍未形成有效传射链 |
| S1936 v1 | 25 秒 | S1932 同配置延长 | 零身体接触、安全门通过，发生夺球、推进和 8.65 m/s 射门；无传球完成/扑救，有非脚触球 |
| S1938 v1 | 25 秒 | 受阻分球、严格交接与门将伸手 | 又出现近球停滞；不能采用该组合 |

S1932 球净水平位移约 0.280 米，峰值球速约 0.646 m/s；这是小范围争球，
不是高质量射门。85 次射门意图不等于 85 次射门。旧 sprint 指标阈值
也不代表人类意义的冲刺。

以上全部仍为 `REJECTED_CONTINUOUS_MATCH_CHAIN`。避让修复了稳定性的一个
问题，却也揭示了近球僵持。不能仅以机器人活动率作为训练奖励或视频门槛。

S1936 共出现 44 次传球意图及握手、13 次扑救意图，仍没有合格传接球和
扑救事件。这是目前最直接的动作执行接口反例：增加高层意图不等于动作完成。
它与 S1932 属于同一开球条件的延长实验，不是独立泛化成功率。

可复跑 S1936 的实验配置：在上面的 CLI 命令使用
`--players 8 --contact-ready --duration-sec 25`，输出到新的空证据目录。
该视频资格仍被拒绝，不发布为稳定自主比赛。

## 接下来需要完成的链路

1. 对称中央争球和两侧偏置开球分别保留，禁止只挑容易开球点作稳定性证据。
2. 将真实近球姿态、基础策略历史和来球状态接入已训练的接球/出球模型。
   必须核验入口分布、坐标系、动作所有权、退出后接续，不能只挂模型文件。
3. 身体控制冻结做第一轮对比；用实际脚接触、队友接到、控球推进和守门反应
   判断贡献，不奖励单纯 `PASS`、`SHOOT` 日志或所有人追球。
4. 开发集训练和独立留出分开；每次改动重跑八人全链，保留碰撞、越限、停滞
   与失球样本。没有完整链时不晋升球队冠军。
5. 完成更长连续比赛、不同开球与双方交换测试后，再制作绑定轨迹的比赛视频。
   当前 25 秒世界接口上限也不能冒充文档要求的 60–180 秒比赛。

足球 fixture、角色和比赛课程留在 Soccer；不把这些参数复制到 Core。
Core 的通用成长、记忆和晋升合同必须通过真实证据接入，而非仅凭命名声称闭环。
