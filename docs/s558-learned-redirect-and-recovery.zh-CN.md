# S558 起：从失败样本中发现转传动作，再学习为闭环神经网络

日期：2026-09-11。SIM_ONLY，原生 CPU MuJoCo 3.12。

## 实质结果与限制

本轮终于得到一个**新的、有限范围的闭环学习结果**：同一实测身体入口的
32 个新球位、球速及关节扰动中，未训练模型安全转传到点为 **0/32**，
学习模型为 **8/32（25%）**，两者身体安全均为 32/32。

这不是完整足球比赛成功。隔离世界只有接球者与球，目标为原始实测队友位置，
但没有真实的第二具身体完成接球；“到点”不能写成“队友已接住”。模型仅
控制前 50 个控制帧的关节残差，之后由显式恢复规则接管。现役比赛策略未替换，
候选仍不具备晋升资格。25% 也远未达到用户期待的稳定宣传演示水平。

与此前不同，这些新扰动案例的动作来自网络实时观测推理，而不是播放训练
时记录的动作。下面把教师回放、学习、开发集和新扰动测试严格区分。

## 1. S558：排除简单速度补偿

原来通过 160 帧停球考试的样本，在继续到 180 帧时丢球。实测球速约从
0.325 降到 0.320m/s，而机器人越走越远，最近脚距离从约 0.260 增到
0.483m。试验八组外环速度反馈增益（0、0.2、0.4、0.6、0.8、1、1.5、2），
保留场景投影、0.7m/s/0.8rad/s 限幅及原 PD/力矩限制。

八组各四扰动，持续控球和出球姿态全部零；身体安全合计 25/32。
没有采用该反馈补丁。它不能单独解决动作衔接问题。

## 2. S559–S560：另建转传任务，不篡改停球考试

原 `reception_reward` 是“停住并保持控球”的奖励，不适合鼓励来球改向后
继续传走。新增纯训练函数 `rolling_redirect_contact_reward`：只在测到脚部
接触时，奖励朝既定目标的球速增量，并惩罚向上弹球。不把相同速率的反向
出球误判为“没有变化”，也不给无脚接触的运动加分。

函数拒绝非有限、异常幅值、形状/设备/类型不匹配与需要梯度的物理输入。
这是接触局部训练提示，不证明所有速度变化都由脚造成，不直接决定成功。
模块位于 Soccer 下游，没有改写 Core 的通用 Growth 或硬件安全边界。

独立的转传门要求：真实脚接触步内，球朝目标速度至少 0.6m/s、方向余弦
至少 0.8、该步朝目标速度增量至少 0.05m/s；之后球进入目标 0.3m 圆域，
球心高度不超过 0.3m，并距首次触球至少 0.1 秒。整段还须身体安全、无非脚
触球、球不出界，入球速度与原传球飞行期限合格。原停球/姿态指标仍单独
保存，没有以新门代替旧门宣称旧考试通过。该门不保证“只触球一次”。

任务时长为 210 控制帧（4.2 秒），目标固定在原始队友的实测位置附近
`(1.9566, 1.3375)m`。S559/S560 各八次 PPO 更新，分别 168/160 个优化步。
两组默认模型开发评估都没有安全转传成功；S559 最终身体安全 32/32，
S560 最终 16/32。更大的探索标准差（logstd 从 -2.5 到 -1）产生了 25 个
训练中朝目标出球的世界记录和五个到点记录，但没有完整安全成功。
这些计数跨更新累加，不是独立场景成功率。

两组首次真实 PPO 更新独立重放，参数差均为零。训练不能仅凭更新了权重
或回报更高就宣布有效。

## 3. S561：成功片段与恢复拼接的物理发现

S560 第零代训练的第 11 个世界确实将地滚球送入目标区域，最近平面距离
约 0.067m，球高约 0.115m。但机器人随后约 2.68 秒开始超过身体姿态/高度
限制，最终倒下，故原任务失败。该样本来自训练集，不是保密测试集。

把这个**已消费的训练动作序列**用于恢复发现：第 50/70/90/110 帧附近
切换为经场景投影的零导航，并在原残差步长包络内指数撤去关节残差。
没有改写球/身体状态，也没有向球加外力。

八组方案乘四个小球位扰动，共 32 次原生物理回放：未切换恢复的基线
身体安全 0/4，转传成功 0/4；七组恢复方案均安全 4/4、转传成功 2/4。
未干预世界的完整 qpos/qvel 与原训练样本逐字节对应、最大差为零。

这一步是**成功教师动作发现**，不是自主策略。随后选用最早的第 50 帧
交接、10 帧时间常数的恢复方案构建教师资料。

## 4. S562：从教师轨迹蒸馏为神经网络

模型为目标条件 143 输入、29 维关节残差输出；冻结基础 LSTM、critic 与
logstd，只训练 actor。教师回放的成功世界有 16/32，但本质仅是两个成功
扰动各重复八次。前 50 帧共有 800 条样本，不能当作 800 个独立环境。

用实测观测与教师原始动作做行为克隆，共 3,000 个 Adam 步。每 500 步
执行一次新的闭环物理评估：此时不再回放教师 raw action，网络自行预测；
恢复规则保持不变。

| 克隆步骤 | 开发集转传成功 | 身体安全 |
|---:|---:|---:|
| 0 | 0/32 | 32/32 |
| 500 | 8/32 | 32/32 |
| 1000 | 24/32 | 32/32 |
| 1500 | 16/32 | 32/32 |
| 2000 | 16/32 | 32/32 |
| 2500 | 24/32 | 32/32 |
| 3000 | 8/32 | 32/32 |

开发集仍是四扰动重复八次。选择最早达到最高开发成绩的 **clone1000**，
再进行下面的新扰动测试。1000 步时训练 MSE 约 0.000902；3000 步虽降至
约 0.000181，闭环成绩反而下降。这直接说明模仿误差不能取代物理验收。

独立从保存的教师观测、clone0、随机种子和优化器配置重放 1000 步，所有
参数最大差为零；critic/logstd 与 clone0 一致，actor 确实改变。

## 5. S563：新扰动配对验收

选定模型后才生成固定种子 56301 的 32 个新样本：球 XY ±0.005m、
球 XY 速度 ±0.01m/s、29 关节角 ±0.0005rad，仍围绕同一个已知身体入口。

| 指标 | clone0 | clone1000 |
|---|---:|---:|
| 安全转传到点 | 0/32 | **8/32** |
| 朝目标出球事件 | 0/32 | 21/32 |
| 到点事件（未合并其它门） | 0/32 | 10/32 |
| 身体安全 | 32/32 | 32/32 |
| 非脚触球（失败项） | 0/32 | 13/32 |
| 全程球在场内 | 21/32 | 23/32 |

所以它是有进展但不可靠的转传技能，不是完整成功的球队。非脚触球显著增加，
必须保留这些反例继续训练；不能只展示八个通过样本就声称普遍稳定。

选定权重 `clone-1000.npz` SHA-256：
`60078c20fc475da73e7098893fed4f704ca761636083bf5ffaa3092775274f4d`。

### S564：扰动扩大四倍，模型不再调参

另用种子 56401，球 XY ±0.02m、球 XY 速度 ±0.04m/s、关节角
±0.002rad，配对 32 个新样本。clone0 仍为 0/32，clone1000 为 **3/32**，
两者身体安全均 32/32；候选非脚触球 16/32。扩大扰动后明显退化，不能
把窄范围的 25% 当成广泛泛化能力。S563 与 S564 条件不同，不混成单一成功率。

### S565：基于实测离脚事件提前恢复

保留第 50 帧作为最长技能前缀，允许在定向出球后连续两个控制区间没有
脚部接触时提前释放。仍使用原先 S563 的同一 32 个样本，属于配对消融，
不是又一批独立测试。实际释放为第 47–50 帧；通过的八例均在第 48–49 帧
释放。转传仍为 8/32、身体安全 32/32，没有提高成功率，但证明该场景中
可用实测事件提前交接，而非只有固定时刻可行。片中仍使用 S563 的固定
恢复版本。事件规则是分析式方案，不是学会了自主交接。
