# S370：接球技能完成前，不提前承诺下一次出球

## 结论

接球神经网络已能在八台 G1 的不间断共享物理世界里控制队友传球（S369）。本轮修复战术承诺与运动技能的时序冲突：接球技能仍占用控制时，禁止建立新的传球/射门承诺。它没有解决完整的下一传链路，不是比赛能力通过。

## 实施

新增 `TeamMotorReadiness` / `TeamMotorReadinessProvider`：快照绑定球员、帧和时钟，错误或过期响应关闭新承诺并记录 motor fault。状态为 ready 也不能绕过触球所有权、队友握手、身体安全或物理执行约束。旧 provider 无此接口时保持原行为。

该接口是运动技能与战术协调之间的状态协议，不是新的学习算法。接球仍使用 S364 的冻结 133 维观测、29 维关节目标残差模型；不是直接力矩 actor，也没有在本轮重新训练。接球期间所有其他球员保持原控制器。

## 实验

证据目录：`/code/rosclaw/phase8_evidence/s370-motor-readiness-shared-world-v1`。

- `repeat` 与 S369 learned 的完整 trajectory 数组逐项精确相同。
- `ready` 开启新接口；两组均为 20 秒、八台机器人、同一球、同一 seed 306。
- 两组均身体安全、机器人间接触 0、motor fault 0；接球网络均运行 100 个控制帧。
- 原路径在 9.02 秒承诺中场到前锋传球，此时接球网络仍控制身体直至 10.2 秒。新路径取消了这次过早承诺。
- 两组仍保留最初实际前锋传中场的接球证据。10.2 秒球速均约 0.207 m/s。
- 11.12 秒的新传球仍没有满足诊断器要求的承诺后脚部触球；不是成功传球。

## 后续问题

原所有权仅保留触球后 0.6 秒。球虽已慢下来并留在脚边，仍会在接球网络释放前失去战术所有权。下一步需要有新鲜物理触球锚点、连续控制观测和失控撤销机制的所有权延续；不能凭距离直接认领球，更不能无限延长旧触球。

11 项接口测试通过。所有结果 SIM_ONLY，未修改公共冠军、硬件权限、碰撞体或安全门槛。`passed=True` 仅为已有宽泛世界 smoke，不能当作整场足球比赛达到用户要求。
