# S125：状态驱动的速度匹配射门选项

## 结论先行

S125 完成了一个有价值但**未获晋升**的候选实现：它把传球到射门的切换从长时域相位拉扯，改为单次、锁存、速度匹配的短桥接。已消费开发集上，完整链路从冻结父策略的 `1/6` 提升到 `4/6`，且 `6/6` 安全、`6/6` 精确重放；然而在首次运行的 S125 v1 封存集上，新选项与父策略都为 `0/6`，新选项仅 `1/6` 安全。因此该候选严格标记为 `REJECTED_CAUSAL_STRIKE_OPTION`，不能成为保留策略，也没有用于产品状态或视频宣传。

这次失败给出了比继续调固定时钟更重要的结论：速度连续的技能切换能够改善部分射手稳定性，但完整链路的主要瓶颈已转移到**传球接触鲁棒性、来球时机预测和触球后的状态恢复**。下一阶段不能再围绕单个触发帧做局部搜索。

## 实现了什么

新增 `G1CausalStrikeOptionController`，状态为：

```text
PREPARE -> TRACK -> COMMIT -> RECOVER
                      \
                       -> ABORTED
```

控制器只读取前序技能相位与射手本体状态，输出一次 `begin_bridge` 事件。它不拥有姿态、关节、力矩或足球控制权：

- `COMMIT` 一经发生即锁存，避免两个独立相位钟反复加速/减速同一段动作；
- 入口位置和速度来自当前 MuJoCo 状态；
- 出口位置和速度来自冻结 G1 运动先验的指定相位；
- 使用五次多项式桥接，显式约束边界速度；
- 桥接末段为冻结策略填充历史观测，避免策略刚接管时历史为空；
- 观察到真实脚—球接触后进入 `RECOVER`；
- 权限上限固定为 `SIM_ONLY`，没有硬件权限，也不允许直接关节力矩输出。

`shared_world` 同时增加了互斥权限检查：新选项、S124 静态 transition actor 和旧 phase-sync 不能共同控制射手时钟。结构化结果升级到 v21，轨迹保留选项状态、就绪标志、来球 ETA、桥接进度和峰值目标速度。

新增的考试器对每个上下文运行三条同世界轨迹：新选项主跑、新选项精确重放、冻结父策略。每条轨迹均保存为外部 NPZ，并绑定请求哈希、实现哈希和文件哈希。

## 失败解剖

### 1. 前序传球技能对毫米级球位变化过敏

v1.00、v1.03、v1.04 的传球者在真实传球触球前约 `40 ms` 出现 `waist_pitch_joint` 越界，幅度分别约 `0.0042`、`0.0098`、`0.0088 rad`。新选项与父策略完全相同，证明这不是射手桥接造成的，而是上游传球技能的接触鲁棒性问题。

### 2. 新桥接确实改善了部分稳定性，但没有解决全分布

父策略在 v1.01、v1.02、v1.03、v1.05 中射手倒地，最低骨盆高度约为 `0.068–0.078 m`。新选项把 v1.00、v1.04、v1.05 的射手保持在约 `0.67–0.71 m`，说明速度匹配切换有真实稳定性收益；但 v1.01、v1.02、v1.03 仍出现右膝、左腕/左肘或腰部越界并倒地。

### 3. “状态驱动”仍不够因果

所有场景都在前序策略帧 170、即约 `3.60 s` 开始桥接，而真实传球触球发生在 `5.59–6.76 s`。控制器虽然计算来球 ETA，却没有把 `incoming_ball` 或 ETA 纳入提交条件。这解释了为什么开发集上有效的短桥接不能适应新的传球延迟。

### 4. 接触发生不等于完整链成功

六例都有传球触球，五例有射手触球，但传球落点误差达到 `0.377–1.617 m`，射门峰值速度除一例外普遍不足，且没有门线进球或门将扑救。完整链门正确地拒绝了“碰到了球但没有形成有效比赛结果”的假成功。

## S126 的实施约束

下一阶段从这份失败中固定四项要求：

1. 在传球动作触球前启用预测式关节安全包络，优先解决上游 `waist_pitch_joint` 的毫米级接触扰动越界；
2. 用真实来球状态或可验证的前序接触预测决定 `TRACK -> COMMIT`，不再让 ETA 只是诊断字段；
3. 将射手触球后的稳定性状态作为显式终止/恢复条件，分别约束膝、腰和上肢越界；
4. 先在已消费 v1 上做失败驱动开发，再预注册完全不同的 v2 留出集；v2 只运行一次，只有全部门控通过才允许保留和制作晋升视频。

S125 的可迁移贡献不是一个“G1 固定帧补丁”，而是验证了通用技能切换应具有的形态：前序观测、准备度门、单次权限交接、速度连续桥接、接触事件终止、精确重放与失败封存。S126 将把来球时机与上下游安全包络真正接入这条机制。
