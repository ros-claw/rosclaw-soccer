## 1. 不成立的方向也保留证据

S2344 比较独立噪声与显式历史条件高斯探索。历史作为额外 29 维观测记录，逐步核验上一采样动作；重算条件概率误差不超过 1e-3。固定零均值初始化的平稳原始噪声方差，并不等于滤波后动作幅度相同。

三个种子、每种 64 回合：独立噪声成功合计 3/192，身体安全 192/192；相关系数 0.85 和 0.95 均 0/192，身体安全分别 166/192 和 117/192。动作更连贯但更容易失稳，拒绝采用。不是“连贯探索必然更好”。

S2346 使用中等独立探索与更长奖励追溯（gamma、lambda 均 0.999），16 轮 179200 控制帧、704 个优化步骤，训练成功 3/1024，四次确定性开发考试仍全部 0/64。两项设置共同变化，不能作单因素归因。独立审计重建全部 20 份轨迹/批次，精确重演 704 步 Adam/RNG；没有以训练日志替代物理成功。

## 2. GPU 成功不是 CPU 成功

S2348 选择 4 条 GPU 成功轨迹和 4 条失败轨迹，在 CPU 上执行保存的关节目标并双次精确重放。成功轨迹只有 3 条保留成功；4 条失败仍失败。这只是保存目标的物理转移检查，不是接球神经策略闭环考试。

S2350 进一步收集 S2336、S2338、S2346 全部 **29 条 GPU 训练成功动作序列**。在 CPU 实时状态上重新运行冻结步行网络，叠加保存的原始接球残差，并重新计算本体/球观测。每条双次物理重放，全部数组精确一致；最终只有 **18/29** 满足原完整接球条件。失败 11 条同样保留。

这批数据是监督学习示范，不是新的 on-policy PPO 数据：不伪造动作概率，不把旧 GPU 概率移植到 CPU。只有通过的 18 条进入后续拟合，仍不证明残差策略已经能自主产生这些动作。

## 3. 可复用监督学习能力与物理考试

`success_distillation` 新增显式 135 输入、29 输出的世界朝向接球合同。默认 133 维保持不变；新合同必须主动选择。只更新 actor，critic、探索噪声及其他保护状态不变；参数拟合不能自动晋升策略。

18 条示范对应 **13 个不同初始状态**。按完整初始 qpos/qvel 分组，避免同一场景不同轨迹泄漏到两侧：训练 13 条、9 个初态；验证 5 条、4 个初态。拟合分别从相同初始网络独立执行 64 和 512 步，每个候选从初始状态重复拟合，输出权重精确一致。

两候选在原 8 个较难开发条件（各 8 副本）均 0/64。训练误差下降不代表接球成功；512 步的验证误差及已知场景物理结果反而更差。

S2354 在示范相关初态上做自由运行的 GPU 确定性策略考试，不回放教师动作。64 副本按 18 条示范分配（含重复初态），未训练策略 6/64，64 步候选 14/64，512 步候选 3/64。这些计数不能解释成独立场景成功率。
