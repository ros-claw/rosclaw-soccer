之前 pending receive 信号已让接球队员在传球起飞之前让出导航控制，但 S312 的传球队员没有实际触球。因此不把 PASS 意图计为传球成功。

固定蓝方旧接球课程、私有策略和动作模型，仅筛选到达半径：

| 到达半径 | 身体安全 | 实际接球诊断 | 解释 |
| --- | --- | --- | --- |
| 0.14 m | 是 | 否 | 无承诺后的源队员脚触球 |
| 0.10 m | 是 | 是 | 承诺 0.02 s，源脚触球 1.68 s |
| 0.06 m | 是 | 是 | 与 0.10 m 本课程结果相同 |

两个成功诊断中，接球队员最小脚球距离约 0.144 m，朝接球队员峰值速度约 0.466 m/s。它们是同一开发课程上的诊断结果，不是独立种子成功率，也不是严格全链路晋升。较小到达半径支持“提前停在脚够不到的位置”这一原因，不能证明所有传球失误都来自站位。

## S314：修复局部角速度误当世界角速度

原轨迹直接记录 free joint 的 qvel。MuJoCo 的自由关节线速度使用世界坐标，角速度使用局部坐标；旧测量将两者直接代入世界坐标下无滑移公式，球旋转后可能误判。[MuJoCo 官方说明](https://mujoco.readthedocs.io/en/stable/overview.html#floating-objects)

现在使用轨迹中的单位 wxyz 四元数将角速度转到世界坐标，再比较 `v_xy` 与球面滚动速度。显式支持已经处于世界坐标的输入，指标版本升级 v2。拒绝无效四元数、坐标标识和非有限初始排除时间。此修复不改变轨迹、物理运动和通过阈值。

新增实际 MuJoCo 自由球体测试，用 `mj_objectVelocity` 交叉验证旋转后的角速度；另有坐标选择、输入不变性及无效输入测试。

重新审计 S306 ref29 红蓝实际轨迹：两个完整轨迹仍未通过滚动门。修正后的中位滑移比约为红 0.154、蓝 0.138，但 p95 仍约 2.5。按已记录身体接触之后至少 0.2 s、地面移动和避开球门的区间检查，仍发现明显碰撞后滑移。接触过滤并不保证排除世界内所有未记录接触。

## S315：隔离碰撞后滑移原因

提取 S306 红蓝 3.54 s 的实际球状态，仅初始化时横移 5 m 避开身体和球门，在相同模型中被动模拟 3 s。只改变地面滑动摩擦，保持球脚摩擦、质量、半径、阻尼、求解器和滚动阈值。5 个摩擦值 × 2 个镜像状态，每例完整重复，共 20 次模拟，逐轨迹数值摘要完全一致。

| 地面摩擦系数 | 红 / 蓝滚动比例 | 两例滚动门 |
| --- | --- | --- |
| 0.05 | 0 / 0 | 不通过 |
| 0.10 | 0.745 / 0.745 | 不通过 |
| 0.20 | 0.901 / 0.901 | 不通过，p95 仍过高 |
| 0.40 | 0.979 / 0.986 | 通过 |
| 0.60 | 1.000 / 1.000 | 通过 |

0.40 候选的中位滑移比约 0.0051，p95 约 0.0079；但移动距离由约 1.023 m 变成 0.642 m。因此它会改变传球落点和时序，不能只凭滚动门直接替换训练世界。本阶段未改变默认配置，也没有把参数筛选说成真实草坪标定。原实验球半径 0.115 m、球门 3 × 2 m，属于历史训练环境，不宣称标准成人球场。
