# S357–S367：停球开始学习，但仍不能用局部进步代替整场合格

这一段的实际进步，是把“干净地碰到球”推进到部分来球的低速近脚控制，
并首次让纯神经关节残差在较早的真实传球状态上学到合格接球。
它仍有明显的球位依赖、非脚触球与遗忘问题，没有晋升为完整 4v4 冠军。

## 一、成功课程与困难课程混合：S357

从 S353 第 48 代完整恢复 actor、critic、Adam 与随机状态，继续训练
64 轮。每轮 128 条、每条 2 秒，完成 6656 优化器步、8192 条扰动轨迹、
819200 控制样本。仅两个源身体/LSTM 状态，不是 8192 个独立比赛场景。

96 条来自三个显式生成的来球几何，32 条来自两个真实传球初态。
未改写任何中途球或身体状态。基础行走 LSTM 冻结，学习 29 个关节
目标残差；这仍不是直接输出关节力矩的策略。

开发集中的合格控制由 8/128 增至 72/128，增益全部来自生成课程：
对应 8/96 → 72/96；原始传球 0/32。最终身体安全 128/128，
非脚接触 8/128。这里 20 个初态组合包含重复副本，不能按 128 个
独立情境报告置信度。

S361 在 CPU 上以固定最终候选和父模型，做新的成对位置/速度扰动：

| 课程 | 父模型合格 | 新模型合格 |
|---|---:|---:|
| 生成球位 22 | 5/16 | 5/16 |
| 生成球位 70 | 5/16 | 6/16 |
| 生成球位 71 | 0/16 | 11/16 |
| 八个原始传球状态 | 0/8 | 0/8 |

生成课程总计 10/48 → 22/48，身体均安全；新模型非脚接触 7/48，
父模型 5/48。泛化增益真实存在，但远没有开发集的 75% 那么好，不能
将新球位考试拿去补做训练后还称为独立考试。

S357 首次更新从保存的 rollout、优化器和 RNG 复算，参数误差为零。
`assessment.json` 核验全部 64 轮权重/数据哈希和 Core 更新审计。

## 二、纠正“开始训练太晚”：S358–S364

S358 将生成球位向真实传球球位做初始条件插值，128 种开发设置均
未控住球；S359 单纯提前启动旧模型或令导航为零，36 个 CPU 对照也
全失败。不能只把窗口提前就声称解决了问题。

S360 对真实传球较早四个状态筛查转身、平移教师：128 设置 × 两个
模型仍无合格控制。但新模型的一条轨迹将球降到约 0.38 m/s，只是
距脚仍约 0.69 m。这提示必须同时学卸力与后续身体跟进。

S364 把训练重点转到实际传球的第 415、410 帧，保留晚入场 430 帧和
两个生成课程。身体与完整 LSTM 均来自对应真实帧，没有插值身体。
较早课程使用原始平移导航、零偏航提示，脚接触后导航归零；这是明确
声明的训练指导，不是已经学会的自主导航。

继续 64 轮实际 PPO，仍为 8192 条轨迹、819200 控制样本，源身体状态
增加到四个。开发结果：

| 代数 | 真实传球 415 帧 | 真实传球 410 帧 | 晚入场 430 帧 | 生成保留 | 非脚接触总数 |
|---|---:|---:|---:|---:|---:|
| 0 | 0/64 | 0/16 | 0/16 | 32/32 | 4/128 |
| 32 | 16/64 | 4/16 | 0/16 | 20/32 | 0/128 |
| 48 | 32/64 | 0/16 | 0/16 | 28/32 | 8/128 |
| 64 | 24/64 | 4/16 | 0/16 | 28/32 | 46/128 |

以上所有开发行身体均安全。第 64 代不是所有方面最优：干净接触出现
明显回退。因此“完成更多更新”不是“自动成为冠军”，第 48、64 代等
检查点均保留，不能只留下最后一次权重。

较早的真实传球终于出现神经策略控制的正例；较晚入场仍失败。需要
独立扰动、实际八体迁移和后续传射连续性验证，才能决定能否使用。

## 三、触球后跟进：有正例，但目前很脆弱

S362 立即跟进 128 种导航教师设置，无合格控制，部分失稳；S363
延迟 0.1–0.4 秒跟进，同一真实传球初态的筛查出现 15 个合格设置，
全部 129 个设置身体安全、无非脚接触。比较显示立即跟进会干扰卸力。

但是 S365 固定一个 0.2 秒延迟设置，在 CPU 上加入 12 个新扰动：
新模型 + 跟进仅 2/13 合格，其中名义初态通过，身体安全仅 8/13。
父模型加同一跟进和不跟进的两模型对照都未控球。
这不是可部署的稳定跟进方案，不能因为名义镜头好看就启用。

## 四、从偶然成功中学习：S366–S367 自模仿对照

参考 [Oh 等人的 Self-Imitation Learning](https://proceedings.mlr.press/v80/oh18b.html)，
用历史回报高于当前价值估计的样本做额外离线 actor–critic 更新。
它是经验回放辅助学习，不把旧数据伪装为新采集的 on-policy PPO。

已下载并阅读作者的 MIT 参考实现，提交为
`13eb8a79e9585f92761e0a4670bd76c2e0a7bf05`，目录
`/code/rosclaw/rosclaw_football/repos/self-imitation-learning`。
没有安装或运行其旧 TensorFlow/Gym 训练栈；本轮是独立 Torch 原型。

只从 S364 前 24 代的**训练轨迹**提取物理合格终态：184 条成功轨迹、
18400 帧，其中真实传球仅 10 条/1000 帧，其余 174 条为生成课程。
用原始 500 Hz 合格掩码，并以保存的轨迹作必要检查，未混入考试数据。
真实/生成样本等量抽取，采用裁剪正优势及较小价值项；这与论文的
优先级回放设置不同，不能称为完整原算法复现。

第一版因未绑定冻结基础策略，被 Core 学习租约拒绝，优化器未更新；
保留失败记录。第二版实际加载冻结基础策略到 CPU、排除其优化器所有权、
核验前后权重哈希，通过 Core 审计后完成 64 个离线梯度步。
没有削弱 Core 的租约约束，也没有把 64 梯度步称作 64 次物理训练。

固定离线候选对其父模型的 S367 CPU 新扰动考试：

| 课程 | 父模型 | 自模仿候选 |
|---|---:|---:|
| 生成 70 | 9/16 | 9/16 |
| 生成 71 | 4/16 | 6/16 |
| 真实传球 415 | 4/16 | 3/16 |
| 真实传球 410 | 0/16 | 0/16 |

身体全部安全，但困难真实传球没有改善，故不采用为突破方案。继续
研究成功回放时，必须解决正例太少、相互冲突和鲁棒性问题，不能只
看离线损失下降。

## 五、进入共享系统，而不是另起一套失忆控制器

S368 新增只读、球员/帧/基础模型及配置哈希绑定的基础推理快照，
新接球残差直接使用每名球员正在运行的基础小脑输出。每实例只拥有
100 帧残差滤波历史，没有 LSTM、身体状态或物理步进的所有权。
跳帧、重复帧、时钟错误、基础模型不匹配均锁定失效，不能悄悄重试。

公共适配器与原实验推理的四条 CPU 闭环对照，全部轨迹数组逐位相等，
最大 qpos 误差为零。其中第 410 帧名义真实来球，在新模型下满足严格
控制条件；第 415 帧名义来球虽然低速近脚，但有非脚接触，仍判失败。
不能把前者的接口复核提升为完整比赛认证。S369 随后做八体实测。
