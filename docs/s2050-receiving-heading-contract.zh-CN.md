# S2050：为接球小脑显式补充身体朝向

这是观测契约与迁移接口的改进，不是接球成功或比赛晋升结果。

旧接球模型使用 133 维输入，其中球相对身体的位置、球速度和身体线速度在世界坐标系，姿态输入只有重力方向。在静止、同关节状态与同基础目标的条件下，身体朝向相反时，旧输入可以完全相同，但正确的脚部动作应不同。

新增显式 `recurrent_receiver_world_heading_135_float32.v2` 契约，在原 133 维之后增加身体世界朝向的 sin/cos，不重解释旧字段。默认仍为旧 133 维；135 维模型必须显式选择，不能靠文件形状自动激活。四元数须有效，水平朝向退化时拒绝继续推理。

迁移器复制全部原 actor/critic/noise 参数，只对 actor 与 critic 第一层增加两列零权重。迁移不是学习，旧模型单独保留。单元测试证明：

- 朝向相反的构造状态在旧 133 维逐位相同，新输入可以区分；
- 原权重全部保留，新两列为零；非零输出模型的迁移前后输出通过 1e-6 数值容差；不宣称不同矩阵尺寸的计算逐位相同，也不宣称长期物理轨迹不变；
- 新朝向列能获得实际梯度；错误尺寸、非有限参数拒绝迁移；
- 旧接球、采样、全身 PPO 相关 77 项测试通过；全量 3700 通过、29 跳过、11 个既有历史证据依赖失败。

PPO 只新增显式 `(135,29)` 支持，旧协议保留。实际作用仍必须经过新协议下的配对物理实验、当前来球学习、未训练偏移考试与旧技能保持检查。它不解决所有观测缺项：对手状态、下一次传球目标等仍不在这一小脑输入中，不能因此宣称已拥有完整比赛认知。

全部 SIM_ONLY；输出仍是受限关节角残差，不是未经保护的关节力矩。
