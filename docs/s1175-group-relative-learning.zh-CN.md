# S1167–S1176：等权训练结果与组内成败学习

## 等权训练没有取得突破

两组各完成 16 代、256 world/代，即各 4096 个训练 episode、1,024,000 个控制步。普通时间步 actor 损失执行 5213 次 Adam step；按尝试等权执行 3643 次，差异来自原有 KL 提前结束机制及两种 KL 检查，而不是删掉失败或减少采集代数。

| CPU seed 116901，32 个训练过的身体上下文 | 初始父级（两组） | 普通 PPO 最后 16 代模型 | 等权 PPO 最后 16 代模型 |
|---|---:|---:|---:|
| 身体安全 | 32 | 31 | 31 |
| 受控出球 | 4 | 3 | 2 |
| 原生 0.1 m 精确首传 | 0 | 1 | 1 |
| 非脚接触 | 3 | 2 | 3 |
| 晚期重触球 | 0 | 1 | 1 |

两种最终策略都不晋升。训练中的 44 次、41 次精确首传也不能替代这项闭环考试。初始 actor 文件逐字节相同；两次 CUDA 物理运行并非逐位配对，不能把每一个轨迹差异都归因于损失权重。两组更新都已完整数值复算，CPU 初始/最终配对也各自通过记录与原生标签审计。

作为另一个诊断，S1173 用五个预定朝向偏置实际走动准备出球，没有旋转或瞬移身体状态。偏置 0、−0.5、−0.95 rad 都只有 1/32 精确；正偏置 0.5、0.95 rad 为 0，且非脚接触增加到 17、26。不把这类朝向补丁投入正式控制。

## 下一种估计方法

[DeepSeekMath 的 GRPO](https://arxiv.org/html/2402.03300v3#S4.SS1) 使用同一问题多次输出的组内奖励统计构造优势，避免依赖额外价值模型作为优势基准。本项目借鉴的是“同一情境多次尝试、比较组内结果”的思路，不是复现论文整体算法或 AReaL。

新增可选 `group_relative_actor`，默认关闭，启用时要求 `episode_balanced_actor=True`：

- rollout 必须显式携带一维 int64 `episode_group`；不能凭观测形状猜分组。
- 按既有 gamma 计算完整有效 episode 的折扣回报，在每个情境组内减均值、除总体标准差；同组完全相同的结果严格输出零信号。
- 只将 actor 的优势替换为该组内结果信号，沿真实动作窗口使用。critic 仍用原 GAE，原始奖励、旧 likelihood/value 核验、动作/PD 包络、KL 检查和原生足球标签不变。
- 不宣称这是完整 GRPO：这里仍训练 critic、采用连续 Gaussian 动作及既有 PPO/KL 停止规则，没有论文中的完整参考策略 KL 目标。它也不是端到端关节力矩小脑。

分组语义由调用者负责：计划中的 S1177 将实际 `course_ids` 写入训练归档，再计算数据哈希并申请 Core plasticity lease；审计须核对分组与物理记录中的 course ID 完全相同。组内仍包含失败，没有只留下赢家。

## 数值与回归验证

先减去组内一个原始值，再做中心化与标准差，避免大公共偏置下的均值舍入给恒定组制造非零信号。不使用浮点 atomic scatter 求和；不据此承诺跨后端逐位一致。

- 72 项相关测试通过：显式分组、排列/平移缩放、常量组严格零、无效/单成员组拒绝、精确优化重放、输入不变、组内同样失败时 actor/noise 不更新而 critic 仍可更新。
- S1175 第二次全仓库回归在 CUDA 不可见的 CPU 环境完成：2690 passed、29 skipped、11 failed；失败身份与 S1159 相同。第一次回归 2687 passed 的原始 XML 也保留，没有覆盖。
- 全仓库 ruff 通过，修改的两个源文件 mypy 通过；不宣称历史全仓库 mypy/format 问题全部消除。
- S1176 用新代码、组内比较关闭的路径，分别复算普通与等权两组全部 16 代：模型、Adam、随机抽样和观测窗口与旧归档一致。它证明默认路径兼容，不证明新学习算法提高球技。

当前组内比较算法尚待真实训练。计划固定训练 16 代，之后用新共同种子 118101 同时检查普通、等权和组内比较三种固定最后模型。不挑最佳中间代，不用视频代替成绩。
