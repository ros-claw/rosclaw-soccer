# S82：前锋自产高难度射门与三 G1 同场闭环报告

## 结论先行

本轮把此前“高难度来球由发射器生成、前锋与门将分段展示”的宣传缺口，推进为三具 G1、一只足球、一个 CPU MuJoCo 世界中的前锋自产射门。最终轨迹中，前锋先完成 3.37 m 连续接近，再由右脚真实接触足球；关闭训练教师后，数据驱动接触 actor 仍打出 7.50 m、10.998 m/s 的宽侧中高球，门线实际交点为 `(8.5000, 1.822400, 0.859773) m`，相对声明目标的误差为 `0.0000269 m`。

三名 G1 的姿态都来自同一条物理时间线。队友和门将各自运行独立 RoboNaldo 神经运动策略；门将只能在观测到前锋触球并经过 0.06 s 反应延迟后，根据球的物理位置和速度移动。前锋、队友、门将均未发生机器人间接触；前锋未摔倒，门将最低骨盆高度 0.7553 m、峰值倾角 0.0494 rad。

必须同时说明：该候选仍未晋升。前锋有 0.635% 的物理步触及执行器饱和门，虽然没有力矩越界、关节越界或跌倒，但 `passed=false`。因此视频明确标注 `DEVELOPMENT CANDIDATE · SIM ONLY`，不能把极高精度等同于硬件安全或成熟球星能力。

## 本轮到底“学”了什么

本轮不是在视频脚本里给足球改速度，也不是让发射器代替前锋。训练链如下：

1. 在同一个三 G1 场景中运行 8 次严格双重回放的足端任务空间教师探针。
2. 探针覆盖四组高冲量和四组低冲量，形成 5 个精度成功样本与 3 个精度失败样本。
3. 从真实球速、目标误差、足端速度和教师任务空间力中，蒸馏一个本体感接触 actor。
4. actor 输出有界横向/垂直接触力，经当前 MuJoCo 足端 Jacobian 转为 29 关节力矩，而不是直接写足球状态。
5. 最终考试把教师速度目标和教师接近门同时置零，只允许 actor 驱动前锋触球。
6. 用相同初态重新跑两遍完整物理过程，结果与轨迹摘要逐项一致才写 `strict_replay=true`。

actor 哈希为 `sha256:163a7a52323d9aebfccfb19ebc76dc327cb0bd70d50e00709fa477f4c784a9a1`。它与当前三人布局、球门目标、身体资产、运动先验、运行参数和实现源码哈希绑定，不能拿旧的单人 actor 冒充三人对抗 actor。actor 固定为 `SIM_ONLY`，`promotion_authorized=false`、`hardware_authorized=false`。

## Rosclaw 工程改进

### 1. 三角色共享世界不再污染前锋观测

三人场景有 87 个执行器。前锋运动策略的历史观测现在只读取自己的前 29 个控制量，避免队友和门将的控制向量改变已经资格验证过的前锋 29 维本体感合同。

### 2. 前锋对抗控制器

新增通用 `front_duel` 团队模块：前锋仍由完整定位球技能拥有；模块只管理队友和门将。三者在每一个控制帧和每一个物理子步中共同前进，没有角色瞬移、球体重置或分段拼接。

### 3. actor 场景绑定

接触 actor 上下文哈希新增三人配置；三人考试还要求 actor 的实现哈希等于当前运行实现。旧单人场景 actor 即使数值效果看似不错，也会因上下文或实现不匹配而 fail closed。

### 4. 失败驱动蒸馏

训练允许保留“无跌倒、无关节/力矩越界、饱和物理步不超过 1%”的近边界 SIM_ONLY 样本，以免把最有信息量的失败全部丢弃；但最终晋升门没有放宽，任何执行器饱和仍使最终证据失败。这把“可以用于学习”和“可以安全晋升”明确分开。

### 5. 三 G1 证据下游渲染

定位球视频渲染器能重建前锋、队友、门将和足球四个物理体。它验证三人声明、共享场景哈希、Body 哈希、轨迹文件哈希和轨迹内容摘要；正式镜头从开放侧拍摄脚球接触，并避开队友和门柱遮挡。

### 6. 包导入环加固

射门包改为延迟暴露自由球控制器，避免团队控制器导入独立 loft teacher 时重新进入尚未初始化完成的团队包。直接导入、包级导入和原有 API 都有回归测试。

## 失败与反思

本轮保留了三个重要反例：

- 第一版直接复用旧单人 actor。它能射门，但 actor 没有绑定三人布局，这是证据漏洞；现在已禁止。
- 第二版给门将叠加看似很小的上肢拦截残差，门将最低骨盆降到约 0.07 m，说明“手臂更帅”不能越过支撑链稳定性考试；最终版撤回手臂残差。
- 第三版试图通过全面降低腿部增益消除饱和。执行器需求变小了，但前锋失去支撑、未触球并摔倒；该候选被否决。它说明饱和不能靠整体软化身体解决，应针对 3 个峰值时刻、具体关节和接触相位优化。

当前效果相较 S81 的突破是：宣传片中的高难度射门已经确实由前锋 G1 产生，而且前锋、门将、队友共处同一物理 rollout；没有把独立发射器高球剪成“前锋踢出”的错觉。尚未突破的是球门真正上角、门将手部扑救以及完全无饱和的安全晋升。

## 下一阶段

1. 对饱和的 3 个控制时刻做关节级相位调度，而不是全身降增益；目标是保持当前接触速度和稳定性，同时把饱和步降为 0。
2. 将固定目标 actor 升级为目标条件 actor，课程覆盖左右侧、0.85–1.40 m 高度和不同球速，采用冻结冠军 + 新专家 MoE 解决稳定性—可塑性矛盾。
3. 加入前锋—门将交替自博弈：前锋从门将漏球分布学习，门将从前锋新角度学习；开发集和封存集分开统计。
4. 在共享世界加入 `RECEIVE/TRAP → SET → STRIKE` 两触状态机，让队友真实传球后由前锋完成高难度射门。
5. 门将上肢动作必须先通过支撑链稳定性课程，再进入手套接触考试；宣传姿态不能替代物理接触事实。
