# S25–S28：G1 门将手臂专精与高难发球闭环报告

日期：2026-08-14
范围：仅仿真（SIM_ONLY），未连接 ROS/DDS/真实机器人，未发送任何硬件命令。

## 1. 本轮目标与结论

本轮不是让门将“看起来挥了手”就算完成，而是同时要求：

1. 手掌相对躯干的扑救位移真实增大；
2. 手扑、首扑、二扑和撞球后的恢复不能退化；
3. 躯干角速度、横移、回中误差、关节和力矩必须在安全范围；
4. 训练球之外，还要通过未见 GPU 留出集和独立 CPU MuJoCo 考试；
5. 最后与当前冠军 S15 在相同种子上直接比较，不能只与“站着不动”的零残差基线比较。

最终得到 S28 手臂专精安全分支：它通过标准、高难两套 GPU 留出集和各 96 回合 CPU MuJoCo 考试。高难 CPU 考试中，首扑率提高 2.08 个百分点、二扑率提高 1.04 个百分点、回报提高 2.76，手掌最大位移平均增加 7.81 cm，最大躯干角速度反而下降 0.163 rad/s。

但是，S28 与正式冠军 S15 的同种子配对结果不是全指标占优：标准档首扑率低 3.12 个百分点。因此 growth 门控结论为 `RETAIN_PARENT_ARCHIVE_CANDIDATE`：S15 继续作为全局冠军，S28 作为“高难球更稳定、恢复更干净”的可复用安全分支保留，未虚假晋升。

## 2. 为什么此前手臂挥动弱

原策略虽然有 14 个手臂输出，但存在三类问题：

- 奖励主要告诉网络“手离拦截点近不近”，没有把球的任务空间拦截位置明确转换成 G1 肩、肘、腕的协同目标；
- 共享神经网络同时学习横移、腰部和手臂，强化手臂时会改坏小脑横移/回中表征，出现“手会动了，人也扭起来了”；
- 旧的稳定性—可塑性回放只用于教师预训练，在线 PPO 更新仍可能遗忘父策略。

## 3. 主要工程实现

### 3.1 G1 任务空间手臂教师

新增 `goalkeeper_reach.py`：从实际 G1 MuJoCo Body 的左右手 Jacobian 构造阻尼最小二乘逆映射，将因果球路拦截点转换成双臂肩/肘/腕目标。模型绑定：

- G1 Body 哈希；
- Jacobian/教师配置哈希；
- 左右手准备姿态；
- 每个手臂关节的有效残差权限。

该模块仅用于训练目标，不执行仿真控制，不拥有力矩或硬件权限。

### 3.2 高难发球课程

新增声明式 `advanced` 世界配置，避免临时改参数后无法复现：

| 项目 | 标准档 | 高难档 |
|---|---:|---:|
| 首球释放 | 0.25 s | 0.18 s |
| 二球释放 | 2.65 s | 2.18 s |
| 飞行时间范围 | 0.48–0.72 s | 0.38–0.60 s |
| 横向目标 | ±1.00 m | ±1.06 m |
| 高度目标 | 0.25–1.48 m | 0.16–1.48 m |
| 96 回合实测球速 | 4.36–6.69 m/s | 5.83–10.73 m/s |
| 96 回合实测平均球速 | 5.56 m/s | 7.65 m/s |
| 96 回合实测 P95 球速 | 6.26 m/s | 9.25 m/s |

高难档同时提高速度、角落宽度、低球/高球跨度，并缩短首次扑救后的恢复时间。

### 3.3 手臂动作不再凭观感判断

GPU MJWarp 与 CPU MuJoCo 现在共同记录：

- 手掌相对根节点准备姿态的最大位移；
- 手掌最大速度及 P95；
- 双手覆盖比例；
- 首次/二次手扑率；
- 躯干角速度、横移速度、二次发球前回中误差。

验收同时要求手臂位移提高和手速不超过自然性上限，防止通过抽搐刷“动作幅度”。

### 3.4 稳定性—可塑性的参数权限隔离

本轮先后实现并验证了：

- 在线父策略蒸馏，而不只在教师预训练时回放父策略；
- 整体动作强度巩固；
- 共享表征、核心动作、手臂动作分层巩固；
- 最终的严格“仅双臂在线更新”：冻结 trunk 以及横移/腰部 actor 的梯度，仅允许 14 个手臂 actor 通道和 critic 更新。

最后一项是本轮的关键突破。它把稳定的小脑核心和需要继续学习的手臂肌肉记忆在参数权限上分开。S28 训练时，平均横移约 5 cm、二次球前回中误差约 9 mm，而手臂仍能继续从物理接触和二扑奖励学习。

### 3.5 CPU 考试与父子配对加固

- CPU 考试可直接载入父模型，与候选在完全相同种子上逐回合比较；
- CPU 关节安全投影迁入 dependency-minimal 的训练模块，避免因 team/ROSClaw 顶层导入导致考试无法启动；
- 视频严格读取 CPU 考试中的世界配置，不能用标准球替代高难考试轨迹；
- 视频记录手掌位移/速度并绑定检查点、CPU 报告和 growth 决策哈希。

## 4. 实验迭代与失败分支

| 分支 | 结果 | 主要发现 |
|---|---|---|
| S25 | GPU 双留出拒绝 | 手掌位移显著增大，但标准档手扑略退、高难档二扑/恢复退化；在线阶段没有父策略约束 |
| S26 | 标准 GPU 通过，高难未见集拒绝 | 在线父蒸馏有效，但共享表征仍把手臂学习传导到横移/腰部 |
| S26 强度/分层搜索 | 开发集曾通过，未见集拒绝 | 暴露开发种子选择偏差；简单把整个策略缩小不能解决问题 |
| S27 | 双留出拒绝 | 名义“只学手臂”，但教师预训练仍改共享 trunk，且 critic 被错误冻结 |
| S28 | GPU 双留出、CPU 双考试通过 | 跳过重复教师预训练；严格冻结 trunk/核心 actor，保留手臂 actor + critic 可塑性 |

失败分支全部保留在外部 evidence 目录，没有覆盖冠军，也没有被描述为成功。

## 8. 与正式冠军 S15 的真实对照

S28 的主要优势集中在高难稳定性：

- 高难平均回报：+4.73；
- 高难恢复率：+2.08 个百分点；
- 高难二次手扑：+1.04 个百分点；
- 高难最大躯干角速度：3.68 → 1.24 rad/s；
- 高难 P95 躯干角速度：3.39 → 1.13 rad/s；
- 高难二次发球前偏移：25.65 → 0.86 cm。

但标准首扑率 27.08% → 23.96%，标准二扑率也低 1.04 个百分点；高难首扑低 1.04 个百分点。因此 Pareto growth 门拒绝覆盖冠军。该判断说明闭环生效：局部进步被保留为专家分支，全局退化不会冒充“自进化”。

## 9. 通俗解释

可以把原来的门将理解成一个人只有一套大脑回路：练手臂时，走路、转腰、平衡也一起被改，所以手伸得更远了，身体却开始乱扭。

S28 做的是把能力拆开：

- “小脑”继续负责站稳、回中和核心动作，训练时锁住；
- “肌肉记忆”只允许肩、肘、腕继续学；
- critic 像教练一样继续判断哪次扑救和恢复更好；
- 标准球、高难球、GPU 和 CPU 是四个不同考场；
- 最后一关还要与现任冠军同题考试。

结果是机器人挥臂更主动，但不再为了伸手把躯干和脚步一起甩出去。它在高难快速球上明显更稳，但普通球的总覆盖尚未完全超过冠军，所以作为“手臂/高难稳定专家”保存，等待下一轮由策略路由器按场景选择，或继续扩大训练后再挑战冠军。

## 12. 下一轮建议

1. 将 S15 与 S28 作为两个不可变专家，训练一个仅做场景选择的保守路由器，而不是强行把全部能力压进单网络；
2. 对 S28 增加高球/远角手扑稀有事件重采样，目标是提升总扑救而不改变 trunk 与核心 actor；
3. 将球速、飞行时间、目标角落分桶，做 bootstrap 置信区间，减少 1/256 事件导致的误判；
4. 扩大 CPU 冠军赛到至少 512 回合后再允许替代 S15；
5. 保持 MotionDecode 仅作为非商业、训练期的小比例风格先验，不扩大其控制权限或许可声明。
