# 接球命令观测的已知歧义

本条是纯函数合成反例，不涉及新的物理执行，也不是修复完成报告。
在相同身体、球位/球速、接球准备锚点、已执行动作和步态相位下，可以选择两个
合法通信的传球方向，并按原声明计算各自的实际目标。
当 pursuit 提议被原速度边界饱和为 [-0.5,0.5,1] 时，当前 112 维角色输入逐位相同，
但投影教师分别要求“保持接球平面”和“追球”，输出命令不同。
因此不存在一个仅依赖这些 112 维输入的确定性函数，能在所有这些任务条件下
完全复现该教师；单纯增加数据或训练轮数不能消除这个跨任务歧义。

反例保存在 `tests/rsi/test_receiving_command_observation_alias.py`。
原 96 例的传球方向固定，因此该反例**不能单独证明**当前精准接球失败就是由此造成。
应结合三个候选自身物理轨迹，另行诊断稀有精准样本覆盖、教师/学生分布偏移和闭环误差。

后续必须将合法任务意图充分传入角色观测，例如身体坐标系中的实际目标相对位置与
声明的传球方向；这些是已通信的任务条件，不是未来落点或成功标签。
应尽量复用原轨迹重建新增特征，保留旧策略与实验的原定义，定义新的版本化观测接口。
不要热改正在执行的 112 维候选，不能把更改后的接口结果归到旧模型。

还须区分训练效应和架构效应：当前命令网络为随机初始化的直接输出头，初始策略
不等于旧 pursuit 控制器。旧策略与训练后网络的对比不能单独隔离优化器的作用。
若要主张神经学习导致能力提升，需要固定训练归一化，按原种子重建同架构的训练前
权重，进行相同世界/来球随机性下的物理对照；或在新版本使用严格父代恒等初始化，
并独立证明该恒等性。所有实验仍为已消耗 TRAIN，不能替代隔离 Fresh。
