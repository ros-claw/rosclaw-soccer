# 持续触球反馈 actor–critic：S1060 起

日期：2026-09-13。下游 Soccer 仿真研究，不是最新 ROSClaw Core
发布能力、整场 4v4 成功证据或真实机器人授权。

**阶段结论：神经触球反馈 PPO 链路已实际训练并完成重放/CPU
审计，但三组候选均未通过晋升。** 长回传让固定基础场景的
精确传球从 0/9 种入场改善到 2/9，带扰动 CPU 回归未改善。
本报告记录成功与失败，不是宣传资格证明。

## 本轮改变了什么

此前 S1045/S1052 是冻结神经策略后的参数搜索。本轮新增的
`training/contact_feedback_actor.py` 则是每个控制周期运行、通过
on-policy PPO 更新的神经 actor–critic。不是开始时选择一次动作，
不是按实验编号重放成功序列，也不是更新标题后重复旧视频。

输入契约显式为 169 维：原有 139 维，加当前和上一控制周期各
15 维接触状态：双脚相对球的位置 6、相对速度 6、左右脚地面
接触力 2、过去采样区间有效位 1。位置与速度转换到传球方向
坐标系；速度按 5 m/s、力按 300 N 归一化并限幅。

脚位置取仿真踝部刚体观测，脚速度是过去 20 ms 的有限差分，
不是读取未来轨迹。地面接触力取刚完成区间的 10 个 2 ms 采样
最大值。初始区间尚未测量，速度/力通道显式归零且有效位为 0。
这些不是精确足底接触点位姿，也不是真机传感器校准证据。

原有 139/32 策略被复制并冻结，步态循环网络也保持冻结。
新 actor 输出限幅为 0.3 的潜变量修正，仍经过旧有 29 关节与
3 导航残差平滑、限幅及物理约束；**不是直接力矩策略**。
新 critic 和探索噪声参数参与训练。actor/critic 最后一层初始
为零，因此初始均值与价值精确保持父级输出。

PPO 明确增加 169/32 与 170/32 契约，不隐式转换旧 checkpoint。
第 170 维仅是训练样本选择位，不进入策略网络。保留整条 episode
的 GAE 与全部有效样本的初始似然校验；接触闭合后的动作已交给
原有释放规则，不对这些被覆盖的动作采样优化。

## S1060：混合入场训练及独立验证

8 轮训练，共 512 个训练 episode、128,000 个环境控制步。
另有固定开发评估，不能充当新场景考试。

Adam 学习率 1e-4，每次最多 4 个 epoch，KL 目标 0.01，探索
logstd 初值 -3.5、采样与优化下界均为 -4。实际完成 724 次
优化器更新；每次 actor 和 critic 都变化，冻结父级不变化。
S1062 从原始记录重建每帧观测、历史、接触窗口、随机动作和
全部模型/Adam 更新，8 轮均精确通过。

## S1068：触球课程

首轮混合训练中，大量未形成有效出球的长片段占据优化样本。
第二轮集中 9 个已有触球基础的 prototype 入场，每个 8
副本；23 个 geometric 状态只从此阶段训练中排除，保留为回归
考试，绝不算成已解决。原始 64 次准备及 32 个未获准进入动作
的失败也继续保留。

课程仍为真正更新 actor/critic 的 PPO，不恢复固定偏置搜索。
目标平面塑形从宽的 `10 exp(-4 error²)` 改为
`20 exp(-(error/0.1)²)`；原生速度、精度、身体、非足部和迟触
判定不变。课程、随机种子和塑形同时改变，不能当成单变量因果
比较。新考试再次包含全部 32 个入场，检测能力遗忘。

已完成 8 轮、576 个训练 episode、144,000 个控制步，193 次
优化器更新。S1069 的 8 轮观测、随机动作和全部模型/Adam

## S1072：为什么探索成功没有稳定转化为策略

离线检查实际轨迹，而不是仅看平均回报：在 S1068 的 37 个精确
训练样本里，目标平面到达时刻比最后一个可学习动作晚的中位数为
3.78 秒。GAE 的 gamma=0.995、lambda=0.98 对应这笔远端奖励
直接传回最后动作的系数中位数仅 0.008517（约 0.85%）。
S1060 的 7 个精确样本也有类似现象：3.76 秒、0.008735。

这不是总梯度，也没有计入价值函数间接传播和优势归一化，不能
据此声称找到了唯一原因。但它为“奖励没有充分教到触球动作”
提供了可检验线索。S1073 保持 S1068 的课程、种子、初始化、
奖励与优化器配置，仅将 trace_decay 从 0.98 改为 0.999，做
有界对照。不会更改 0.1 米阈值，也不会把飞行期动作重新计作
有效触球。若仍失败，下一步应比较同一批轨迹上的信用分配与
示范约束，不把继续堆步数当作默认解法。

S1078 在**同一份 S1068 第一轮 rollout** 上、保留相同奖励与
价值记录，独立用 NumPy 计算 GAE：4 个最终精确世界的所有
可学习样本，平均归一化优势由 lambda=0.98 的 −0.1024 变为
lambda=0.999 的 +2.7096。其余样本由 +0.00569 变为 −0.15059。
这是信用分配方向改变的数学诊断；不等于每个成功动作都获得
正梯度，不是新物理试验，也不能保证最终策略稳定。

物理对照限制也保留：两组初始模型参数及初始 q/v、目标、速度
完全一致，第一轮训练最终标签也一致，但在首次优化**之前**，
GPU 轨迹已出现数值差异（第一轮最大 q 差 0.00440、v 差 0.512，
混合维度，不能统一称为米或米/秒）。因此不是逐位确定性的
物理单变量证明；尚未单独定位后台数值差异的来源。

## S1073：长回传训练结果

8 轮、576 个训练 episode、144,000 个控制步，150 次 Adam
更新。最终固定开发评估精确传球由初始 0/72 变为 16/72，
受控传球 24→32 /72，身体通过 72/72，非足部和迟触均为 0。
8 轮固定开发评估的精确计数均为 16/72，不是挑中间最好的模型。
**固定评估的 8 个副本没有新的球扰动，16/72 只对应 9 种基础
入场中的 2 种，不是 72 个独立场景上的 22% 泛化成功率。**

checkpoint：`s1073-contact-long-credit-v1/actor-008.npz`，SHA256：
`b071bc0ad3932f8005af398d2c8faff17073bda98db50646645ee40c7c8ba235`。
本组源代码树：
`c5c002f9553e290ce8bd9ea0e38dd7afcf0fa310c761baf9c427f103fb11b54e`。

S1075 的全部 8 轮观测、随机动作和模型/Adam 回放精确通过。
但是 S1076 在与 S1070 相同 seed=107001 的 32 入场 CPU 回归中，
初始→最终精确传球仍为 1→0、受控传球 3→1、身体通过 32→32，
非足部 7→4，迟触 0→2。**仍拒绝晋升。** 本组复用已有考试
种子作诊断，不伪称又获得了一批全新独立测试。
S1077 匹配输入、因果观测和目标平面/接触计分审计通过，目标
平面重建误差为 0；这证明记录一致，不代表候选任务通过。

结论：长回传改善了固定基础入场上的学习信号与开发表现，但
没有解决带扰动 CPU 回归；本轮没有获得可推广的足球效果突破。
不能将它解释成“已经学会传球，只缺漂亮视频”，也没有用它
替换球队策略。源代码更新与模型晋升严格分开。

本轮三组总计 1,664 个训练 episode、416,000 个环境控制步，
全部是真正更新 actor/critic 的 PPO；各组任务分布不同，不能把
其成功次数混为同一种成功率。固定评估、CPU 考试和重放另计。

## 下一阶段：针对剩余缺口，而非直接放大训练

1. **分开 actor 与 critic 的学习窗口。** 当前 PPO 用同一个
   `keep` 同时选择策略损失与价值损失，触球窗口结束后的 critic
   也没有直接接受优化。这是代码事实，但尚未实验证明是唯一
   瓶颈。下一组应保留 actor 的有效触球边界，让 critic 学完整
   有效轨迹的价值，并与长回传设置进行固定输入对照；不因此给
   球飞行后的动作新增触球功劳。
2. **把均值成功变成扰动成功。** 固定入场改善只能算开发信号；
   球初速度、位置、入场身体状态均需分组报告。先稳定可触球
   子课程，再恢复未解决的 23 个 geometric 入场，并用未参与
   调参的新种子验收。0.1 米与身体/非足部/迟触条件不放宽。
3. **动作自然性单独闭环。** 在以上可学习反馈上增加经过本体
   适配的运动示范与恢复约束，检查步态、关节速度、支撑和踢后
   稳定，而非只优化目标点。最后才接回多角色共享世界。当前
   尚未完成这项，也不能把 SONIC 冻结步态称为新训出的小脑。

## 工程验证与边界

初次新增 18 项模型/观测测试；连同 PPO、训练窗口回归共
70 passed。检查包括初始父级输出精确一致、无参数存储别名、
actor/critic 实际更新、父级梯度保持空、刚体变换不变性、
错误维度拒绝、无效测量与初始区间语义、修正量边界。

训练 S1068 及其 CPU 审计完成后，额外加固父级 checkpoint 的
加载契约：拒绝空映射、非 Tensor 和非 float32 权重，避免
`load_state_dict` 静默转换 dtype。新增 7 项测试后，定向测试为
77 passed。S1073 使用这次加固后的源代码；既有实验继续绑定原
源代码哈希，没有回填或修改历史报告。

全仓 S1061：2602 passed、29 skipped、11 failed。11 个失败身份
与 S1059 完全一致，未修改其跳过或失败条件。全仓 ruff check、
修改文件格式检查和两个修改模块的定向 mypy 通过；不是全仓
mypy 通过声明。最终加固后的 S1074 全仓复查为 2609 passed、
29 skipped、11 failed；XML 对比确认失败身份与 S1061 完全一致。
全仓格式检查另有 69 个本轮未修改的文件需格式化；未做无关
批量改写，也不将“修改文件格式通过”写成全仓格式通过。

实际训练使用物理 GPU 3，保留用户其他 GPU 服务；所有实验仍为
CPU MuJoCo / CUDA MJWarp 离线仿真。学习租约沿用旧版固定 Core
训练依赖，不代表最新 rosclawd 的动作准入。尚未引入本轮新的
MotionDecode 模仿损失、完整恢复技能、直接力矩或多角色联训。
实验环境为 Python 3.12、Torch 2.13+cu130、NumPy 2.5.1、CPU
MuJoCo 3.12 和已修正阻尼的 MJWarp 3.13 / Warp 1.17。
其中 NumPy 超出当前包声明的 `<2.4` 范围，因此这些结果是现有
研究环境验证，不是标准依赖安装或发布兼容性验证；未据此放宽
项目依赖约束。

证据均在 `/code/rosclaw/phase8_evidence`，模型、轨迹和视频不入 Git。
目前没有宣传资格，不能以新增测试或优化器步数代替足球效果。
