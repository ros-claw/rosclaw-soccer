# S436：不改变控制的接触身份补全

新增 `TeamBallContact`，将球的每个非地面接触对应到几何体、球员、脚/手/身体/环境，以及实测法向力。`TeamMotorPhysicsObservation` 可携带完整的不可变接触记录和观察者身份；旧构造方式仍可使用，但不暗示接触归因已经完整。

这解决的是证据表达不足，不是放松故障规则：原有“自己脚的最大力”和“其他非地面最大力”保持原定义，后者仍包含其他球员的脚。完整明细必须与两个最大值完全一致；部分归因、身份不合法、非有限输入、可变容器及不一致最大值都拒绝。记录不授予持球权、不批准交接、不清除故障，也不晋升模型。

真实八人仿真以相同模型和 0.8 m/s 目标重复运行 510 帧。改动前后 185 个运动数组完全一致；原有出球与接球物理观测数值也完全一致，新增的全部接触身份记录重新验证通过。准备记录中的来源哈希不作为运动数组比较；丰富后的 JSON 不宣称逐字节相同。

全量测试：1764 passed、29 skipped；仍有原先 11 项历史外部证据绑定失败。Ruff 全库检查通过，mypy 444 个源文件通过，compileall 通过。未删除或弱化失败测试。

证据目录：`/code/rosclaw/phase8_evidence/s436-contact-identity-hardening-v1/`。下一步可据此严格区分“队友实际用脚接触了已传出的球”与“身体、环境或未知接触”，再验证出球技能的有界恢复退出；本提交没有提前实现任何故障豁免。
