# S520–S530：成功记忆、低噪声探索与转传衔接复盘

本轮仍为 SIM_ONLY，未产生可宣传的完整比赛视频。

S520 从 256 个相同初态的闭环物理样本中筛出 62 条合法持续接球轨迹，
共 6200 个真实观测/动作对，使用公共 actor-only 成功蒸馏更新。500 步和
2000 步的加权 MSE 分别降到 `1.13e-4`、`6.36e-5`，critic/noise 保持不变。
但独立 CPU 考试只有父模型 15/32、500 步 12/32、2000 步 12/32，说明
拟合更多成功样本并没有自动带来泛化；父模型保留。

S515 用 80 个上下文、三组 1000 步 AdamW 结果训练成功/风险预测器，并把
非脚触球和身体失稳都作为风险标签。S516 新种子 CPU 32 次选择器为 13/32，
固定父模型为 9/32，所有身体安全；但选择器仍有 1 次非脚触球，不能晋升。
这是一次真正使用本体状态的上下文选择实验，不是 oracle 覆盖率。

S519/S521/S522/S523 定位到接球时的离散镜像坐标切换：静止附近的微小探索
会让局部横向速度跨过负号阈值，造成 recurrent locomotion frame 抖动。
S523 只在**已有实际脚触球后的接球阶段**使用显式 idle frame，保持命令和
LSTM 不变。在 128 个匹配初态上，导航噪声 `0.005` 的持续接球从 6/128
恢复到 58/128，身体安全 128/128、非脚触球 0；无噪声基线保持 56/128。
更大的探索噪声仍失败，不能用该修正掩盖不稳定探索。

S525 把这个纯函数加入公共 `training.locomotion_frame`，增加严格标量/批量
输入校验。公共函数逐帧复现 S523 的 76800 个离线选择，差异 0。S526 在实际
八机器人案例集成该 helper，185 组轨迹数组、4 组电机状态、12 组 locomotion
状态全部 bit-identical；持续接球通过，八体安全且 0 机器人碰撞。它因此是
回归安全修正，不是新动作提升。

S527 在 136/3 导航 PPO 中尝试显式低噪声 floor `log_std=-5.5`，32 轮共
1352 个真实优化步，训练期间单次接球最高 60/128，但最终姿态误差约 1.56 rad，
`pose_ready=0`；S529 新 CPU 中零导航残差基线为 14/32，学习候选 g24 为
11/32，不能替换父模型。

S528 用 CEM 同时搜索接球后的关节偏置和有限转身参数，延长到 160 帧。开发
逐代汇总均为 pose-ready=0，S530 同一身体初态的四扰动 CPU 为 0/4；转身仍
没有达到下一传球的姿态要求，候选全部淘汰。

结论很明确：当前已把“稳定接住”做成可复现的数据驱动小脑片段，并能通过
上下文选择提高局部考试；真正瓶颈仍是接球后的身体朝向与球相对脚位。下一轮
不再单独优化末层偏置，而是采集带有**下一传目标、身体 yaw、球相对脚位、残差
历史**的完整衔接轨迹，训练独立的有限时长 handoff policy，再经过四上下文
CPU、全体安全、连续控球和实际 8 体转传的顺序验收。没有通过前不录制宣传视频。

## S531：S528 候选全量 CPU 复核（2026-09-11）

本轮对 S528 第 15 代 32 个候选逐一进行独立 native-CPU 回放（每个候选 4 个
原始扰动、160 帧，保持 recurrent 历史和电机残差，不注入球力）。这四个初态
来自同一个身体状态，不是四个独立身体上下文。证据保存在
`/home/dell/rosclaw_soccer_evidence/s530-controlled-turn-cpu-exam-v1/c150*`，
每个目录的 `result.json` 都绑定了搜索与物理轨迹哈希。

| 门槛 | 结果 |
|---|---:|
| 候选数 | 32 |
| 全部身体安全 | 30/32（125/128 次回放安全） |
| 至少一次持续控球 | 1/32 |
| 达到出球姿态 `pose_ready` | 0/32 |
| 非脚触球（安全候选） | 0 |

唯一出现持续控球的候选仍无法同时收敛身体 yaw、球相对脚位和出球方向，明确
拒绝晋升。这次复核没有修改运行时策略，也没有产生宣传视频；它把“局部接触
成功”与“可连续比赛”的差距量化固定下来。下一步应采集并训练带目标条件的
完整 handoff policy，而不是继续扩大末端偏置搜索。
