# 比赛冲刺事件速度字段

新的 `competitive_skill_event.v2` 将 `ball_speed_mps` 保留为事件帧的球心三维速度模，并用 `agent_speed_mps` 单独记录相邻采样间骨盆水平位移除以时间得到的球员速度估计。非冲刺事件的 `agent_speed_mps` 为 `null`。这一估计不是足部或关节速度，也不是实体机器人实测。

此前 v1 的冲刺事件错误地把球员速度写入 `ball_speed_mps`；不得直接将 v1 的该字段解释为球速。旧回执按原始源码和哈希保留，不能原地改写或将新事件哈希冒充旧回执；如需比较，应在新证据中以保存的球速度和身体轨迹重新计算并注明版本。此修复不改变冲刺门槛、不创建技能成功，也不证明比赛能力。
