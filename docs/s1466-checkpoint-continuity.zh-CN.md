# S1466：把单次更新复算接成完整学习链

新增通用训练工具 `training/checkpoint_continuity.py`，不依赖G1、足球、
MuJoCo或某个动作维度。它只比较已安全读取的相邻检查点，不加载文件、
不更新模型，不授予执行或晋升权限。

仅从保存的“更新前”状态重算出“更新后”状态，还不能证明这个更新前
状态确实来自上一轮。新工具逐项核对模型、优化器及Torch随机状态，
检查代数、类型、张量形状/设备/数值以及有界嵌套结构。
显式重置优化器应建立新协议，不能伪装成未中断的学习链。

实际Torch模型的state_dict是OrderedDict并携带版本元数据。首次检查器
只接受dict而拒绝真实检查点；已增加对OrderedDict及其元数据的严格
核验，并补真实Linear.state_dict测试。原S1466 v1失败记录保留，v2是
独立复核，不覆盖原证据，也没有改动任何模型或优化器文件。
