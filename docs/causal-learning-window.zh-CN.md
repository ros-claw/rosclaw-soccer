# 因果恢复窗口的 PPO 对照实验

状态：SIM_ONLY 实验基础设施，不是已验证的球赛突破。

## 为什么继续改训练

S916 从 S908 的解析初始化恢复策略出发，完成 4 次原生 CPU MuJoCo / CPU ONNX PPO 更新。全部 5 次开发评估保持 29/32 速度成功、22/32 精度成功、32/32 身体安全、0 次自身非脚触球。四次优化器更新独立重放的参数误差均为零；冻结的 S843 前段参数和探索标准差保持不变。完整物理前缀、私有历史及恢复成本重算也通过。

这证明训练可复现、前段没有遗忘，不证明恢复有足够大的提升，更不是公平自主 4v4 比赛成功。S908 的明显恢复改善来自解析初始化和既有 SONIC 基础控制器复用，不能算作本轮 RL 学会的技能。

S917 只读重算四次训练的优势值：全回合标准差分别是恢复窗口内的 17.06、11.09、19.94、19.22 倍。每次 6400 个有效样本中，5728 个属于因果恢复窗口。冻结前段仍贡献了大量射门奖励，而默认 PPO 同时用它们归一化优势、拟合 critic。这提示学习信号可能受压缩，但统计本身不能证明原因。

## 通用实现及边界

`FullBodyPPOUpdateConfig.learning_observation_index` 是可选的二值观测列。默认 `None` 保持历史更新路径和返回字段；不改变任何物理、动作、奖励或准入门限。

启用后，所有存活样本仍必须通过当前策略的动作概率与价值一致性检查。GAE 仍沿完整连续回合计算，不伪造 episode reset 或 alive。随后仅对二值列为 1 的存活样本计算优势归一化、actor/critic 损失及 KL。至少需要两个选中样本；非二值、越界索引等在更新前拒绝。

这是优化样本选择，不是事件真实性或部署授权的证明。事件列的因果来源由采集器负责；冻结前段的均值由 event-protected actor 负责。通用优化器不理解 G1、足球、角色或电机，也不会自动晋升模型。

测试覆盖：默认重放、全选与默认逐参数相等、选中窗口精确重放、仅改变已排除前缀奖励不影响后续窗口更新、排除前段的错误概率/价值仍拒绝、空窗口及非法索引拒绝。相关 PPO 与 protected actor 测试 56 项通过；定向 ruff、format 和 mypy 通过。测试依赖固定旧 Core 源码路径；当前 Core 集成不是本次证据。
