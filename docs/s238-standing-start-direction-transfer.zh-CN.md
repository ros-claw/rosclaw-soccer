# S238：从球队默认站姿开始，而不是借用记录中的初始动量

日期：2026-09-09，SIM_ONLY，仍不宣称完成 4v4 比赛或高死角射门。

S237 的记录初态有非零前向和侧向速度。改变为球队默认关节角、原生初始骨盆高度、水平朝向与零身体速度后，原有参考的触球表现下降。不能把记录初态的成功当作任意时刻可调用的运动技能。

## 公共接口修正

`G1SonicRunupConfig` 新增独立的 `movement_heading_rad`、`facing_heading_rad`，直接进入冻结动作规划器的移动/朝向向量。新方向必须有界、有限并进入配置哈希；两者为零时，历史直行配置哈希保持不变。

这是任务可以调用的方向接口，并不是已经学会自主选择方向的球队大脑。没有新增外力、改碰撞体或回合中写入姿态。

## 实验

1. 从球队默认站姿重新生成 +X 参考：64 个组合保持身体安全，但只有静止球候选，滚远球未通过。
2. 将方向纳入筛选：5 个接近长度 × 3 个参考起点 × 静止/滚远 × 4 个移动方向，共 120 个物理案例。120/120 身体门通过，56 个局部触球候选，其中 26 个是滚远球。首轮脚本在物理完成后的结果打包处解包失败，未生成可用报告；修复后重跑，保留两次日志。
3. 选取 40 帧接近、踢球参考偏移 40、移动方向 -0.5 rad、朝向 0 的候选，独立 CPU MuJoCo 3.12 验证 16 个不同情境。冻结教师：身体 16/16、有效触球 8/16；加上此前训练的 actor：身体 16/16、有效触球 10/16。滚远球案例约 1.35 s 触球，仍有静止球缺口。

这些数字是开发筛选及固定情境结果，不是独立随机比赛的成功率。方向 -0.5 是从筛选中选出的参数，尚未验证一个根据实时球状态自主选方向的策略。
